HyperBrowseComp: 웹 브라우징 에이전트를 위한 다국어 및 멀티모달 스트레스 테스트

> **원본 논문 정보**
> - **제목:** HyperBrowseComp: A Multilingual and Multimodal Stress Test for Web-Browsing Agents
> - **저자:** Alham Fikri Aji, Faiz Rizki Ramadhan, Zayd M. K. Zuhri, Seung Hun Eddie Han, Ryandito Diandaru, Qinrong Cui, Jan Christian Blaise Cruz, Badrinath Chandana, Peerawat Chomphooyod, Ahmed Attia, Jonibek Mansurov, Emilio Villa-Cueva, Canh Duong Nguyen, Imran Turganov, Minghao Wu, Peerat Limkonchotiwat, Irina Nikishina
> - **발행일:** 2026-10-02
> - **PDF 링크:** [HyperBrowseComp: A Multilingual and Multimodal Stress Test for Web-Browsing Agents](https://arxiv.org/pdf/2610.03574v1)


✨ 3줄 핵심 요약
* **고난도 벤치마크:** 13개 언어로 작성된 423개의 인간 검증 질문을 통해 웹 브라우징 에이전트의 성능을 극한으로 시험합니다.
* **멀티모달 및 복합 정보:** 비디오, 이미지, 지도, 스캔 문서 등 이질적인 소스를 탐색하고 다단계 단서를 추적해야 정답에 도달할 수 있습니다.
* **평가 차별화:** 인터넷에 접속하지 않은 모델에서도 쉽게 풀리는 질문을 배제하여, 단순 암기 지식이 아닌 실시간 정보 탐색 및 추론 능력을 평가합니다.

📖 쉽게 풀어쓴 1분 핵심
최신 AI 모델들은 웹 검색을 통해 정보를 찾고 요약하는 능력이 뛰어나지만, 기존 평가 방식은 영어 위주이거나 단순한 사실 확인에 그치는 경우가 많았습니다. 'HyperBrowseComp'는 이러한 한계를 극복하기 위해 만들어진 새로운 테스트 도구입니다. 이 테스트는 단순히 검색창에 질문을 넣는 수준을 넘어, 다양한 언어 환경에서 동영상이나 복잡한 이미지 속 숨겨진 정보를 찾아내고 여러 단계의 복잡한 논리적 단계를 거쳐야만 답을 얻을 수 있도록 설계되었습니다. 결과적으로 AI 에이전트가 실제 사람이 웹을 사용하는 것과 유사한 복합적 환경에서 얼마나 정확하게 정보를 취합하는지 측정합니다.

🎯 배경 및 문제점
* **기존 평가의 한계:** 기존의 웹 브라우징 벤치마크(BrowseComp 등)는 영어 중심이거나 텍스트 데이터에 치우쳐 있습니다.
* **지식 암기형 평가:** 모델이 이미 학습한 파라메트릭 지식(parametric knowledge)만으로 정답을 맞히는 질문이 많아, 실제 실시간 웹 검색 능력을 변별하기 어렵습니다.
* **복합 정보의 부재:** 실제 웹 환경에는 비디오, 지도, 다국어 문서가 혼재되어 있으나, 이를 통합적으로 다루는 평가는 부족했습니다.

💡 핵심 기술 및 아키텍처
* **인간 주도 설계:** 원어민 또는 해당 언어 전문가들이 직접 작성하고 검증한 423개의 문제를 활용합니다.
* **난이도 필터링:** 인터넷 미접속 상태의 모델이 풀 수 있는 질문은 삭제하여, 반드시 외부 검색을 거쳐야만 해결 가능한 문제로 구성했습니다.
* **공통 프로토콜 평가:** 다양한 모델을 동일한 외부 검색 하니스(retrieval harness)와 프로토콜 하에서 테스트하여 성능을 객관적으로 비교합니다.

📊 실험 결과 분석
* **전체 실패율:** 전체 423개 질문 중 성공하지 못한 비율은 57.68%(244개)로 나타났습니다.
* **실패 요인:** '비디오', '표지판(sign)', '인터뷰(interview)'와 같은 특정 단어가 포함된 질문에서 모델들의 실패율이 높게 나타나는 경향이 있었습니다. 
    * (참고: 단어별 실패율 수치는 원문 표에 기재된 대로 특정 단어가 포함된 질문군에서의 실패 빈도를 나타냅니다.)

🌍 세상에 미치는 영향 & 실무 적용 사례
* **에이전트 고도화:** 복잡한 멀티모달 웹 정보를 다뤄야 하는 기업용 리서치 AI나 정보 요약 에이전트 개발의 표준 지표로 활용될 수 있습니다.
* **글로벌 환경 적응:** 다국어 환경에서의 웹 검색 성능을 측정함으로써, 특정 언어권에 편향되지 않은 범용 AI 에이전트 개발을 촉진합니다.
* **차세대 평가 모델:** GPQA나 Humanity’s Last Exam과 같이 고난도 추론을 요구하는 평가 체계의 흐름을 이어받아, AI 모델의 실질적인 ‘웹 활용 지능’을 향상시키는 데 기여할 것입니다.
