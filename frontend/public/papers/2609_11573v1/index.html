> **원본 논문 정보**
> - **제목:** Learn the Solid, Not the File: Canonical Inputs for Neural Networks on CAD Boundary Representations
> - **저자:** Heinrich Jiang, Hager Yasser Mohamed, Alexander Hitt, Valeriia Lomakina, Henning Jiang, Jennifer Jang
> - **발행일:** 2026-09-10
> - **PDF 링크:** [Learn the Solid, Not the File: Canonical Inputs for Neural Networks on CAD Boundary Representations](https://arxiv.org/pdf/2609.11573v1)


✨ 3줄 핵심 요약
* 기존 CAD 경계 표현(B-rep) 인코더는 동일한 3D 고체라도 파일 형식이 바뀌면 성능이 급격히 저하되는 취약점이 있습니다.
* 연구진은 고체 자체의 기하학적 특성에서 파생된 '정준 영역 그래프(Canonical Region Graph)'를 제안하여 파일 형식 변화에 따른 불변성을 확보했습니다.
* 제안 모델은 표준 벤치마크에서 기존 최고 모델과 대등한 성능을 내면서도, 데이터 변형 및 작업자 간 설계 차이에도 매우 안정적인 결과를 보입니다.

📖 쉽게 풀어쓴 1분 핵심
3D CAD 모델은 '경계 표현(B-rep)' 방식으로 저장되는데, 같은 물체라도 설계자나 소프트웨어에 따라 면과 모서리를 나누는 방식이 다를 수 있습니다. 기존 AI 모델은 이 '껍데기(데이터 구조)'에 의존해 학습하기 때문에, 물체는 그대로여도 파일 형식이 조금만 바뀌면 성능이 크게 떨어지는 문제가 있었습니다. 이 논문은 물체 자체가 가진 고유한 기하학적 정보를 바탕으로 입력 데이터를 재구성하는 '정준 영역 그래프'를 도입했습니다. 이를 통해 모델이 파일 저장 방식이나 설계 습관에 휘둘리지 않고, 오직 '본질적인 3D 형태'에 집중하여 일관된 판단을 내리도록 만들었습니다.

🎯 배경 및 문제점
* **B-rep의 모호성:** 동일한 고체를 나타내는 B-rep은 무수히 많습니다. 설계 작업 순서, 내보내기 설정, 소프트웨어 커널 차이로 인해 물리적으로 동일한 부품도 서로 다른 데이터 구조로 저장됩니다.
* **기존 인코더의 취약성:** 기존 신경망들은 이러한 '데이터의 껍데기'에 의존하여 학습하므로, 동일한 고체에 대한 다른 표현형들이 입력될 때 성능이 치명적으로 무너지는 현상을 보입니다.

💡 핵심 기술 및 아키텍처
* **정준 영역 그래프(Canonical Region Graph):** 파일이 아닌 고체 자체의 기하학적 정보에서 노드와 좌표계를 도출합니다.
* **이론적 불변성:** 파티셔닝(면 분할)이나 강체 변환(회전, 이동)이 발생해도 그래프 구조와 기하학적 정보가 유지되도록 보장합니다.
* **그래프 트랜스포머 활용:** 정규화된 특징을 8라운드의 에지 조건부 멀티헤드 어텐션(Edge-conditioned Multi-head Attention) 층을 통과시켜 고체의 특성을 학습합니다. 1,750만 개의 파라미터로 구성되었습니다.

📊 실험 결과 분석
* **데이터 변형 내성:** 원문 발췌의 표(Table 1)에 따르면, 진단적 분할(diag-split), NURBS 재표현, 임의 강체 변환 등 다양한 변형 상황에서 99.9% 이상의 높은 동일성 유지율을 보였습니다.
* **예측 일관성(Churn):** Rhino 임포트/익스포트 테스트(Table 7)에서 기존 모델들이 수십 퍼센트의 예측값 변화를 보인 반면, 제안 모델은 변형 전후의 예측 불일치가 거의 0%에 수렴했습니다.
* **실제 설계 변이:** 서로 다른 작업자가 동일한 부품을 설계한 경우에도 제안 모델은 0.5% 미만의 예측 변화율을 보여 압도적인 안정성을 기록했습니다(Table 8).
* **한계:** 모델의 불변성 때문에 '모델링 생성 이력' 정보가 필요한 작업(예: Fusion 360의 특정 라벨링 작업)에서는 일반 B-rep 기반 모델보다 성능이 낮을 수 있습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **데이터 표준화:** CAD 데이터 생성 시 파일 형식에 따른 '동일 물체 인식' 오류를 해결하여, 데이터셋 품질 향상과 정밀한 설계 자동화에 기여합니다.
* **산업 활용:** 부품 분류, 제조 비용 추정, 조립 시뮬레이션 등 B-rep을 사용하는 모든 엔지니어링 분야에서 파일 형식 변화에 강건한 AI 시스템을 구축할 수 있습니다.
* **향후 과제:** 현재는 단일 부품에 집중하고 있으나, 향후 여러 부품으로 구성된 어셈블리(Assemblies), 2D 스케치, 그리고 설계 이력 정보를 불변성 제약 조건 하에서 결합하는 방향으로 연구가 확장될 예정입니다.
