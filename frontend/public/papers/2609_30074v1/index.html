평가 결론은 얼마나 재현 가능한가? LLM이 추론한 프롬프트 구조에 대한 자기 감사

> **원본 논문 정보**
> - **제목:** How Reproducible Are Evaluation Conclusions? A Self-Audit of LLM-Inferred Prompt Structure
> - **저자:** Dipankar Sarkar
> - **발행일:** 2026-09-24
> - **PDF 링크:** [How Reproducible Are Evaluation Conclusions? A Self-Audit of LLM-Inferred Prompt Structure](https://arxiv.org/pdf/2609.30074v1)


✨ 3줄 핵심 요약
*   LLM을 활용한 프롬프트 구조 추론은 동일한 입력에도 결과가 불안정하며, 구조적 재현성이 매우 낮음.
*   모델들의 재현성 순위는 데이터 재표집(Resampling)과 분석 방식에 따라 쉽게 뒤바뀌어, 상위권 모델을 확정적으로 식별하기 어려움.
*   소규모 샘플 기반의 LLM 평가는 실제보다 훨씬 더 확실한 결론을 내리고 있는 것처럼 보일 위험이 큼.

📖 쉽게 풀어쓴 1분 핵심
많은 연구가 LLM 시스템을 평가할 때 작은 프롬프트 집합을 사용하여 성능을 점수화하고 순위를 매깁니다. 그러나 이 논문은 이러한 '평가 자체'를 다시 분석(자기 감사)해 보았습니다. 결과적으로, LLM이 만든 구조는 매번 결과가 달라질 만큼 불안정했고, 평가 방법론에서 아주 작은 기준만 바꿔도 모델 간 순위가 완전히 변했습니다. 이는 현재의 LLM 평가 방식이 우리가 생각하는 것보다 훨씬 취약하며, 특정 모델이 '최고'라고 단정 짓는 결론은 통계적 근거가 부족할 수 있음을 시사합니다.

🎯 배경 및 문제점
프롬프트를 프로그램처럼 다루는 시스템들이 늘어나면서, 프롬프트의 구조를 파악하기 위해 LLM을 사용하는 사례가 많아졌습니다. 하지만 LLM의 결과는 동일한 조건(temperature-zero)에서도 항상 같지 않다는 고질적인 문제가 있습니다. 본 연구는 이러한 불안정성이 프롬프트 구조 추론 성능을 평가할 때 어떤 왜곡을 만드는지 확인하고자 했습니다.

💡 핵심 기술 및 아키텍처
연구진은 8개 모델 제품군(8B~675B 파라미터)을 대상으로 프롬프트 구조 추론 실험을 수행했습니다.
*   **측정 방식**: 노드 세트 간 자카드 유사도(Jaccard similarity) 등을 사용하여 출력의 일관성을 측정.
*   **분석 기법**: 부트스트랩 기법(Joint cluster bootstrap)을 사용하여 데이터가 변경될 때 순위가 유지되는지 확인하고, 여러 분석 규칙(병합 규칙, 허용 오차 기준 등)을 적용해 결과의 견고함을 검증.

📊 실험 결과 분석
*   **불안정성**: 동일한 호출임에도 노드 세트 일치율(Jaccard)이 0.39~0.96으로 넓게 나타났으며, 72%의 셀은 완벽한 일치에 도달하지 못함.
*   **순위 변동**: 부트스트랩 결과, 최하위 모델은 비교적 명확했으나(99% 확률로 최하위), 상위권 모델은 순위가 매우 불안정(각 68%)하여 누가 최고인지 확정할 수 없음.
*   **분석의 취약성**: 분석 기준(예: 반복 실행 병합 규칙)을 합리적인 범위 내에서 수정하자, 8개 모델 중 4개의 순위가 바뀌고 전체 지표가 7% 포인트 변동함.

🌍 세상에 미치는 영향 & 실무 적용 사례
*   **평가 관행 개선**: 소규모 샘플을 이용한 성급한 성능 순위 매기기를 지양해야 함.
*   **권장 사항**: 연구자들은 향후 LLM 평가 결과를 발표할 때 ▲순위 안정성(Rank stability) ▲셀별 데이터 출처 ▲분석 민감도 분석 ▲실행별 원본 결과물 ▲측정 날짜를 반드시 포함할 것을 권고함.
*   **연구 한계**: 본 연구는 특정 시점의 환경에서 측정되었으나, 대상 모델 8개 중 4개가 측정 10주 이내에 서비스가 종료되어 해당 실험의 재실행이 불가능해짐.
