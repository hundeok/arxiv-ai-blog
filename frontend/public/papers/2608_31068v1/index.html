> **원본 논문 정보**
> - **제목:** Wrong Prediction, Right Answer: Recovering Evidence from Collapsed LLM Sequence Scores
> - **저자:** Qiyao Yan, Chenpeng Wang, Liangming Pan
> - **발행일:** 2026-08-31
> - **PDF 링크:** [Wrong Prediction, Right Answer: Recovering Evidence from Collapsed LLM Sequence Scores](https://arxiv.org/pdf/2608.31068v1)


✨ 3줄 핵심 요약
* 거대언어모델(LLM)이 추론 문제에서 틀리는 이유는 실제 추론 능력이 없어서가 아니라, 내부 논리가 최종 출력 단계에서 편향에 의해 붕괴되기 때문입니다.
* 연구진은 아주 적은 수(최소 25개)의 레이블 없는 데이터로 모델의 내부 편향을 보정하여 숨겨진 정답을 복구하는 진단 프로토콜을 제안했습니다.
* 실험 결과, Qwen3.5 등 여러 모델에서 9~34%p의 정확도 향상을 확인했으며, 이는 모델의 논리가 실제로는 온전하게 작동하고 있음을 입증합니다.

📖 쉽게 풀어쓴 1분 핵심
우리는 흔히 LLM이 오답을 내놓으면 "이 모델은 이 문제를 풀 능력이 없다"라고 생각합니다. 하지만 이 논문은 사실 LLM이 문제 풀이 과정은 정확히 수행하고 있음에도, 최종적으로 단어를 출력하는 단계에서 특정 단어를 선호하거나 질문 형태에 휘둘리는 '구조적 편향' 때문에 정답을 가리고 있다고 지적합니다. 연구진은 모델의 내부 상태를 관찰하고, 아주 적은 데이터를 활용한 보정 기술을 통해 겉으로는 틀린 것처럼 보였던 문제들 속에서 실제로는 모델이 계산해낸 정답을 성공적으로 찾아냈습니다.

🎯 배경 및 문제점
기존의 LLM 평가 방식은 '최종 출력값'만을 기준으로 모델의 성능을 판단합니다. 연구진은 이러한 방식이 두 가지 근본적인 한계를 가진다고 지적합니다.
* **내부 논리와 출력의 분리:** 모델은 추론 과정 중에 정답을 도출하지만, 최종 토큰을 생성할 때 구조적 편향(특정 레이블 선호 등)으로 인해 정답이 왜곡됩니다.
* **기존 방법의 한계:** 내부 상태를 조사하는 '프로빙(Probing)'은 모델이 정보를 보유했음을 보여줄 뿐 실제 생성 과정에 활용하는지 증명하지 못하며, 기존 출력 보정 방법들은 결과의 신뢰성을 완전히 보장하기 어렵습니다.

💡 핵심 기술 및 아키텍처
연구진은 모델의 고유한 추론 능력을 검증하기 위해 '대상 레이블이 필요 없는 가산 보정(additive correction)' 진단 프로토콜을 도입했습니다.
* **최소 파라미터 보정:** 단 2개의 파라미터만을 조정하는 방식으로, 단 25개의 레이블 없는 예시만으로도 모델의 편향을 교정할 수 있습니다.
* **데이터 효율성:** 매우 적은 양의 샘플만으로도 모델 내부의 논리를 복구할 수 있으며, 복잡한 언어적 중첩 문제를 해결한 뒤에도 정답이 유지됨을 확인했습니다.

📊 실험 결과 분석
다양한 모델과 벤치마크를 통해 얻은 주요 성과는 다음과 같습니다.
* **정확도 복구:** Qwen3.5 모델군에서 9~34%p의 정확도 향상을 보였습니다.
* **모델 확장성:** 이러한 보정 효과는 OLMo-2-1B 및 Llama-3.1-8B 모델로 성공적으로 전이되었습니다.
* **통계적 유의성:** 단순히 레이블 비율을 맞추는 기준선(Baseline)보다 훨씬 높은 성능을 보였으며, 이는 모델 내부의 온전한 논리가 성공적으로 복구되었음을 시사합니다. (참고: 표 40 등에서 Permutation baseline 대비 유의미한 차이를 보임)

🌍 세상에 미치는 영향 & 실무 적용 사례
* **벤치마크 재해석:** 현재의 LLM 벤치마크 평가가 모델의 실제 능력을 과소평가하고 있을 가능성을 제시하며, 평가 방식의 변화가 필요함을 촉구합니다.
* **실무적 활용:** 모델을 재학습시키지 않고도 적은 데이터로 특정 도메인이나 작업에서의 성능 저하(편향으로 인한 오답)를 즉각적으로 보정할 수 있는 강력한 도구를 제공합니다. 이는 고비용 학습 없이도 특정 작업에서 모델의 내재된 잠재력을 최대로 끌어낼 수 있음을 의미합니다.
