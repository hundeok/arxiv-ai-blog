FuseReg: 레이어 융합 정규화를 통한 표현 자동 인코더의 재구성-생성 격차 완화

> **원본 논문 정보**
> - **제목:** FuseReg: Regularizing Layer Fusion Mitigates the Reconstruction-Generation Gap in Representation Autoencoders
> - **저자:** Hongyang Du, Yunfei Xie, Junjie Ye, Jiawei Yang, Xiaoyan Cong, Haodong Zhang, Yongchao Huang, Haiyu Wu, Zongxia Li, Shihang Gui, Dawei Liu, Runhao Li, Jingcheng Ni, Chen Wei, Randall Balestriero, Yue Wang
> - **발행일:** 2026-09-25
> - **PDF 링크:** [FuseReg: Regularizing Layer Fusion Mitigates the Reconstruction-Generation Gap in Representation Autoencoders](https://arxiv.org/pdf/2609.31620v1)


✨ 3줄 핵심 요약
* **문제점:** 기존 표현 자동 인코더(RAE)는 인코더의 특정 레이어들만 선택해 융합하므로, 픽셀 복원 품질과 이미지 생성 품질 사이의 상충 관계(trade-off)가 발생합니다.
* **해결책:** 'FuseReg'를 도입하여 특정 레이어 조합 대신 무작위 레이어 하위 집합으로 모델을 학습시킴으로써 레이어 융합에 대한 강건성을 확보했습니다.
* **성과:** 추가적인 인코더 수정 없이 재구성 품질(PSNR)을 높이고, 생성 모델(DiT) 적용 시 비유도(unguided) gFID를 최대 29%까지 개선하는 효과를 거두었습니다.

📖 쉽게 풀어쓴 1분 핵심
표현 자동 인코더(RAE)는 미리 학습된 시각 인코더의 특징을 가져와 이미지를 복원하거나 생성하는 데 사용합니다. 이때 인코더의 어느 층을 가져와 사용할지 결정해야 하는데, 얕은 층은 픽셀의 세밀한 정보를 잘 살리지만 생성 품질이 떨어지고, 깊은 층은 그 반대인 경우가 많습니다. 'FuseReg'는 고정된 층을 사용하는 대신, 학습 중에 여러 레이어 조합을 무작위로 섞어서 학습합니다. 결과적으로 모델이 특정 레이어 조합에만 의존하지 않게 되어, 재구성과 생성 작업 모두에서 더 우수한 성능을 발휘하게 됩니다.

🎯 배경 및 문제점
* **고정된 휴리스틱의 한계:** RAEv2와 같은 기존 모델은 인코더의 마지막 $k$개 레이어를 합치는 방식에 의존합니다. 이로 인해 최적의 픽셀 복원 품질을 내는 융합 방식과 생성 품질이 좋은 방식이 서로 충돌합니다.
* **상충 관계:** ImageNet-256 데이터셋과 DINOv3-L 모델을 사용한 실험에서, 레이어 융합 범위를 $k=7$에서 $k=23$으로 늘리면 복원 품질(PSNR)은 22.58dB에서 27.04dB로 향상되지만, 비유도 gFID가 1.65에서 3.01로 상승하여 생성 품질이 저하되는 현상이 확인되었습니다.

💡 핵심 기술 및 아키텍처
* **FuseReg 기법:** 고정된 레이어 선택 방식을 폐기하고, 학습 과정에서 무작위 레이어 하위 집합을 샘플링하여 학습합니다.
* **이론적 메커니즘:** 하위 집합 샘플링은 서로 다른 레이어 간의 불일치에 대한 민감도를 명시적으로 페널티로 부여합니다. 이를 통해 모델은 특정 계층 정보에만 편향되지 않는 강건한 표현을 학습합니다.
* **확장성:** 복원(재구성) 모델뿐만 아니라 확산(diffusion) 모델 학습에도 동일한 정규화 원리를 적용하여, 두 단계 모두에서 최적의 성능을 낼 수 있도록 설계되었습니다.

📊 실험 결과 분석
* **재구성 성능:** 단일 FuseReg 디코더는 추가 재학습 없이도 전체(full), 희소(sparse), 단일(single) 레이어 융합 모두에서 고정된 융합 방식의 전문 디코더보다 더 높은 PSNR을 기록했습니다.
* **생성 성능:** RAEv2 DiT-XL 생성기를 그대로 유지한 채 디코더만 FuseReg로 교체했을 때, 비유도 gFID가 27% 감소했습니다. 
* **확산 학습 적용:** 확산 단계까지 정규화를 함께 적용한 DiT-Base 모델에서는 비유도 gFID가 29% 감소하는 성과를 보였습니다. (수치 정보는 논문 발췌 내용을 근거로 함)

🌍 세상에 미치는 영향 & 실무 적용 사례
* **효율성:** 인코더 자체를 수정하거나 재학습할 필요 없이 디코더의 학습 방식 변화만으로 복원-생성 간의 격차를 좁힐 수 있습니다.
* **유연성:** 특정 레이어 조합에 고정되지 않는 강건한 디코더를 구축함으로써, 다양한 시각 기반 작업에서 고품질 이미지 생성과 복원을 동시에 달성할 수 있는 기반을 마련했습니다.
* **학계 기여:** 고정된 레이어 융합이 모델의 유연성을 제한한다는 점을 이론적으로 분석하고, 무작위 샘플링을 통한 정규화가 실질적인 생성 품질 개선으로 이어짐을 입증했습니다.
