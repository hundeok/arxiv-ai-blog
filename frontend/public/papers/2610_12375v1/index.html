OnTrack: 스트리밍 구조 인식 최적 운송을 통한 LLM 에이전트 경로의 실시간 모니터링 및 개입

> **원본 논문 정보**
> - **제목:** OnTrack: Real-Time Monitoring and Intervention in LLM Agent Trajectories via Streaming Structure-Aware Optimal Transport
> - **저자:** Babak Barazandeh, Connor Swanson, Chinmay Kulkarni, Nikhil Mungel
> - **발행일:** 2026-10-08
> - **PDF 링크:** [OnTrack: Real-Time Monitoring and Intervention in LLM Agent Trajectories via Streaming Structure-Aware Optimal Transport](https://arxiv.org/pdf/2610.12375v1)


✨ 3줄 핵심 요약
* **실시간 모니터링:** OnTrack은 LLM 에이전트의 작업 실행 과정을 스트리밍 방식으로 분석하여, 오류나 비효율적인 경로를 실시간으로 감지하고 차단합니다.
* **구조적 분석:** 단순 내용 유사도가 아닌, 작업 단계 간의 종속성과 구조를 최적 운송(Optimal Transport) 이론으로 분석하여 루프나 정체 등 문제를 정확히 식별합니다.
* **비용 절감 및 안전:** 실패가 예상되는 에이전트 경로를 미리 차단함으로써 컴퓨팅 자원의 약 18%를 절약하고, 차단된 시도의 83%가 실제로 실패로 향하고 있었음을 확인했습니다.

📖 쉽게 풀어쓴 1분 핵심
AI 에이전트가 스스로 판단하여 업무를 수행하다 보면, 무한 루프에 빠지거나 잘못된 도구를 사용하여 시간과 비용을 낭비하는 경우가 많습니다. 기존의 모니터링 방식은 작업이 다 끝난 뒤에야 오류를 파악하거나, 또 다른 AI를 감시자로 써서 비용과 지연 문제가 발생했습니다. **OnTrack**은 에이전트의 작업 단계를 실시간으로 관찰하며, 과거 성공 사례의 '구조'와 현재 진행 상황을 비교합니다. 마치 지도 앱이 경로를 벗어나면 바로 알려주듯, 에이전트가 위험하거나 비효율적인 방향으로 가면 즉시 개입하여 자원을 아끼고 사고를 방지합니다.

🎯 배경 및 문제점
* **자율성으로 인한 리스크:** 에이전트의 자율적 행동은 할루시네이션(환각), 도구 호출 오류, 무한 루프 등을 유발하여 비용을 낭비하거나 시스템 보안 문제를 야기합니다.
* **기존 방식의 한계:** 
    * 사후 평가(Post-hoc): 문제가 발생한 후에는 이미 비용이 소모되고 피해가 확정됨.
    * 온라인 감시자(Safeguard Agent): 추가적인 LLM 호출로 인해 비용이 증가하고 지연 시간이 발생함.
    * 블랙박스 모델: 개별 단계를 점수화하는 모델은 내부 작동 원리를 알기 어려움.

💡 핵심 기술 및 아키텍처
* **스트리밍 구조 인식 최적 운송:** 에이전트의 작업 단계와 의존 관계를 실시간으로 모델링하여 과거 성공 기록과 비교합니다.
* **3단계 참조 체계:** 
    * 성공적인 과거 기록이 있는 경우(Full reference)부터, 도구 정의(Schema)만 있는 경우, 사전 정보가 전혀 없는 경우 등 데이터 가용성에 따라 모니터링 수준을 조정합니다.
* **신속한 판단:** 알고리즘의 복잡도가 낮아 단계당 약 1밀리초의 시간만 소요되어 실시간 처리가 가능합니다.
* **차단 정책:** 비가역적인 위험한 행동은 즉시 차단하고, 그 외에는 단계적으로 개입하는 유연한 대응 체계를 갖췄습니다.

📊 실험 결과 분석
* **성능 지표:** SWE-bench 데이터를 바탕으로 초기 8단계 수행 결과를 분석한 결과, 기존 내용 기반 유사도 접근 방식보다 AUROC 기준 +0.057 향상된 성능을 보였습니다.
* **비용 효율성:** 에이전트 중단 정책을 통해 전체 컴퓨팅 자원의 약 18%(17~18%)를 절감했습니다.
* **정확도:** 차단된 에이전트 경로의 83%가 실제로 실패로 이어질 경로였음을 입증했습니다.
* **한계점:** 균일한 작업 템플릿(SWE-agent)에서는 구조적 분석의 효과가 일부 제한될 수 있으며, 모든 종류의 할루시네이션이나 인과 관계 역전을 완벽하게 감지한다고 주장하지는 않습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **실시간 가드레일:** IT 시스템 관리, 여행 예약, 주식 거래 등 에이전트의 실수가 치명적인 산업 분야에서 즉각적인 방어벽 역할을 합니다.
* **비용 최적화:** 대규모 모델을 사용하는 에이전트 서비스에서 불필요한 연산 낭비를 획기적으로 줄여 상용 서비스의 수익성을 개선할 수 있습니다.
* **투명한 제어:** 단순히 작업을 중단하는 것이 아니라, 오류의 이유를 제공하고 점진적으로 대응하므로 개발자가 에이전트의 행동을 더 잘 이해하고 관리할 수 있게 돕습니다.
