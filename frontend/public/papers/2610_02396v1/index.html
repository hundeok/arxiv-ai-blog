> **원본 논문 정보**
> - **제목:** Inherit-MAS: Test-Time Evolution of Multi-Agent Systems through Workflow and Execution Inheritance
> - **저자:** Songtao Wei, Yi Li, Zhichun Guo, Bingzhe Li
> - **발행일:** 2026-10-01
> - **PDF 링크:** [Inherit-MAS: Test-Time Evolution of Multi-Agent Systems through Workflow and Execution Inheritance](https://arxiv.org/pdf/2610.02396v1)


✨ 3줄 핵심 요약
* **Inherit-MAS**는 다중 에이전트 시스템(MAS)의 워크플로우를 테스트 타임에 진화시키며, 변경되지 않은 부분의 실행 결과를 재사용(상속)하여 중복 계산을 방지합니다.
* 메타 모델이 워크플로우를 설계하고 판단자(Judge)가 피드백을 제공하며, 수정이 필요한 부분만 선택적으로 개선하여 전체 시스템 효율을 최적화합니다.
* WorkBench 및 HotpotQA 벤치마크에서 기존 진화형 MAS 모델들보다 높은 성능을 보였으며, 에이전트 토큰 사용량을 최대 34.6%까지 절감했습니다.

📖 쉽게 풀어쓴 1분 핵심
복잡한 작업을 수행하는 AI 다중 에이전트 시스템은 초기 설계를 완벽하게 하기 어렵습니다. 이를 해결하기 위해 실행 결과를 바탕으로 시스템을 수정하는 '테스트 타임 진화' 방식이 쓰이지만, 사소한 수정에도 전체를 다시 실행하면 비용이 너무 많이 듭니다. **Inherit-MAS**는 생물학적 진화의 '상속' 개념을 도입했습니다. 즉, 시스템이 개선될 때 수정이 필요한 부분만 바꾸고, 나머지 문제없는 작업 결과는 그대로 재사용합니다. 이를 통해 작업의 정확도는 높이면서도 불필요한 모델 호출과 계산 비용을 획기적으로 줄였습니다.

🎯 배경 및 문제점
* **워크플로우 설계의 난제**: 복잡한 작업 수행을 위한 에이전트 간 역할 분담, 도구 사용, 정보 교환 등의 최적 설계를 사전 예측하기 어렵습니다.
* **비효율적인 진화**: 기존 진화형 시스템은 워크플로우를 수정할 때 전체를 다시 실행하는 경우가 많아 중복 계산이 발생하며, 무분별한 수정은 기존의 유용한 구성 요소까지 훼손할 위험이 있습니다.
* **성능 한계**: 고정된 워크플로우는 실행 과정에서 노출된 약점을 스스로 수정할 수 없어 실제 작업 수행력이 떨어지는 문제가 있습니다.

💡 핵심 기술 및 아키텍처
* **워크플로우 상속 (Workflow Inheritance)**: 메타 모델이 에이전트 역할과 도구 권한을 정의하고, 판단자(Judge)가 실행 결과를 평가합니다. 진화 과정에서 유효한 부분은 유지하고 결함이 있는 노드만 선별적으로 수정합니다.
* **실행 상속 (Execution Inheritance)**: 해결된 요청과 실행 환경이 이전과 동일할 경우, 과거의 계산 결과를 그대로 상속받습니다. 이를 통해 모델 호출과 도구 사용을 줄입니다.
* **선택적 진화**: 무작위 변경이 아닌, 판단자의 피드백에 근거하여 문제의 원인이 되는 지점만을 집중적으로 타격하는 수정을 수행합니다.

📊 실험 결과 분석
* **성능 우위**: GPT-4o-mini 모델 기반 실험에서 WorkBench 55.4% 완료율, HotpotQA 49.7% F1 점수를 기록하여 EvoAgent, EvoMAS, TacoMAS 등 기존 모델 대비 높은 성능을 입증했습니다.
* **비용 절감**: 실행 상속을 비활성화한 경우와 비교했을 때, 에이전트 토큰 사용량이 WorkBench에서 29.1%, HotpotQA에서 34.6% 감소했습니다. 전체 토큰 사용량 또한 각각 5.3%와 18.1% 줄어들었습니다.
* **일관성**: 결정론적 런타임(Qwen3-14B) 환경의 감사 결과, 상속 기술이 적용된 시스템은 전체를 재실행했을 때와 동일한 작업 결과물을 생성함이 확인되었습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **대규모 작업 효율화**: 복잡한 AI 에이전트 협업 시스템에서 운영 비용을 크게 낮출 수 있어, 긴 호흡의 계획과 실행이 필요한 복잡한 기업용 자동화 도구에 즉시 적용 가능합니다.
* **지속 가능한 AI**: 시스템이 스스로 학습하고 진화하면서도 컴퓨팅 자원 낭비를 최소화하는 모델을 제시함으로써, 에너지 효율적인 AI 시스템 구축의 발판을 마련했습니다.
* **실무 활용**: 연구진은 코드를 공개(https://github.com/CrazyMint/Inherit-MAS)하여, 사용자가 직접 자신의 도구와 환경에 맞춰 에이전트 워크플로우를 자동으로 최적화할 수 있는 기반을 제공합니다.
