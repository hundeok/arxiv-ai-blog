NemotronLabs VoiceChat: 도구 호출 기능을 갖춘 오픈소스 전이중 음성 대화 모델

NemotronLabs VoiceChat: 도구 호출 기능을 갖춘 오픈소스 전이중 음성 대화 모델

> **원본 논문 정보**
> - **제목:** NemotronLabs VoiceChat: An Open Full-duplex Speech-to-Speech Model with Tool Calling Capabilities
> - **저자:** Jagadeesh Balam, Travis Bartley, Edresson Casanova, Sanjay Chauhan, Chen Chen, Zhehuai Chen, Zijia Chen, Francesco Ciannella, Slyne Deng, Mikyas Desta, Harishchandra Dubey, Slim Essid, Nourchene Ferchichi, Boris Ginsburg, Mariana Graterol Fuenmayor, Negar Habibi, Kevin Hu, Anand Joseph, Viraj Karandikar, Myungjong Kim, Viacheslav Klimkov, Seelan Lakshmi Narasimhan, Lily Lee, Jason Li, Eileen Long, Ameya Mahabaleshwarkar, Aditya Malte, Adi Margolin, Sasha Meister, Valentin Mendelev, Oluwatobi Olabiyi, Ankita Pasad, Yifan Peng, Elena Rastorgueva, Jayda Ritchie, Jason Roche, Nikhil Srihari, Yuanhang Su, Yoshi Suhara, Viet Anh Trinh, Jinhan Wang, Piotr Zelasko, Hui Wang, Puhui Meng, Chaosen Zhang, Yunsheng Liu, Shawn Wang, Wenjing Li, Zhonglei He
> - **발행일:** 2026-09-18
> - **PDF 링크:** [NemotronLabs VoiceChat: An Open Full-duplex Speech-to-Speech Model with Tool Calling Capabilities](https://arxiv.org/pdf/2609.21967v1)


✨ 3줄 핵심 요약
* **전이중 대화 구현:** 사용자의 발화를 들으면서 동시에 추론, 도구 호출, 응답 생성을 수행하는 통합 스트리밍 아키텍처를 도입했습니다.
* **통합된 도구 호출:** 대화 흐름을 방해하지 않고 외부 도구를 호출할 수 있는 능력을 갖췄으며, 중단 시 즉각적인 대응이 가능합니다.
* **오픈소스 연구 기여:** 실시간 대화의 유연함과 외부 정보 활용 능력을 결합한 모델을 공개하여 오픈소스 음성 에이전트 분야의 연구를 촉진합니다.

📖 쉽게 풀어쓴 1분 핵심
기존의 음성 에이전트는 사용자가 말을 마칠 때까지 기다려야 하는 '반이중(half-duplex)' 방식이 많아 자연스러운 대화가 어려웠습니다. 이번에 발표된 **NemotronLabs VoiceChat**은 사람이 대화하듯, 상대가 말하는 도중에도 듣고, 반응하고, 필요한 경우 외부 도구(외부 프로그램이나 정보 조회 등)를 사용하여 답변할 수 있는 '전이중(full-duplex)' 모델입니다. 이 모델은 음성 인식, 언어 이해, 도구 사용, 음성 생성을 하나의 시스템으로 통합하여, 실시간 대화의 흐름을 끊지 않으면서도 스마트한 기능을 제공합니다.

🎯 배경 및 문제점
* **대화 역동성 결여:** 기존 모델은 VAD(음성 활동 감지)에 의존하여 대화의 흐름이 딱딱하게 끊기는 문제가 있습니다.
* **도구 사용의 한계:** 오픈소스 진영에서는 전이중 통신 환경에서 자연스럽게 외부 도구를 호출하는 범용적인 모델 연구가 상대적으로 부족했습니다.
* **복합 기능 통합의 난제:** 실시간 반응성(중단 대응, 백채널링)을 유지하면서 외부 도구 호출이라는 복잡한 작업을 동시에 수행하는 통합 모델 구축이 기술적 도전 과제였습니다.

💡 핵심 기술 및 아키텍처
* **통합 스트리밍 아키텍처:** 스트리밍 음성 인코더, 언어 모델(LLM) 백본, 도구 호출 출력 스트림, RNN-T 음성 전사 분기, TTS 디코더를 하나로 결합했습니다.
* **병렬 출력 채널:** 에이전트의 대화 텍스트와 구조화된 함수 호출(Tool Calling)을 위한 별도의 병렬 채널을 구성하여 대화와 도구 호출이 섞이지 않게 설계했습니다.
* **학습 방식:** 두 단계(CPT: 지속적 사전 학습, SFT: 지도 미세 조정)로 나누어 학습하며, 대화 데이터와 도구 호출 데이터를 병합하여 최적화했습니다.

📊 실험 결과 분석
* **대화 성능:** Full-Duplex-Bench 1.0에서 오픈 가중치 시스템 중 가장 낮은 '멈춤 처리 인수율'을 기록했고, 사용자 중단 후 100% 대응 성공률 및 4.33/5점의 응답 품질을 보였습니다.
* **대화 흐름 유지:** Full-Duplex-Bench 1.5에서 사용자의 맞장구(Backchannel) 이후 93%의 확률로 응답을 재개했습니다.
* **도구 사용 능력:** Full-Duplex-Bench 3.0에서 82.5%의 도구 선택 F1 점수를 기록했습니다. (단, 인자 정확도와 도구 실행의 완성도는 향후 개선이 필요한 영역으로 언급됨)

🌍 세상에 미치는 영향 & 실무 적용 사례
* **차세대 음성 에이전트:** 상담원, 가상 비서 등 실시간으로 정보 검색 및 도구 수행이 필요한 음성 AI 서비스의 성능을 비약적으로 높일 수 있습니다.
* **오픈소스 생태계:** 폐쇄형 API 중심의 시장에서 고성능 오픈소스 음성 대화 모델을 제공함으로써, 기업과 연구자가 독자적인 지능형 음성 시스템을 구축하는 기반이 됩니다.
* **실무 적용 고려사항:** 한 세션당 최대 5개 이하의 도구 사용 권장, 도구 실행 중에는 사용자의 중단(Barge-in)이 불가능하다는 점 등 실제 배포 시 고려해야 할 설계 제약이 존재합니다.
