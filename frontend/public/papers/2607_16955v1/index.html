CADENCE: 커버리지 적응형 온폴리시 증류를 통한 추론 격차 해소

CADENCE: 커버리지 적응형 온폴리시 증류를 통한 추론 격차 해소

> **원본 논문 정보**
> - **제목:** CADENCE: Closing the Reasoning Gap via Coverage-Adaptive On-Policy Distillation
> - **저자:** Satyam Kumar, Saurabh Jha
> - **발행일:** 2026-07-18
> - **PDF 링크:** [CADENCE: Closing the Reasoning Gap via Coverage-Adaptive On-Policy Distillation](https://arxiv.org/pdf/2607.16955v1)


✨ 3줄 핵심 요약
*   **문제 해결:** 소형 언어 모델의 온폴리시 지식 증류 과정에서 발생하는 '콜드 스타트 붕괴', '다이버전스 스케줄링 불균형', '이진 보상 희소성' 문제를 해결하는 CADENCE 프레임워크를 제안했습니다.
*   **핵심 기술:** 6가지 혁신적 구성 요소(COV A, FTB, CCD, LAP, EMR, BSD)와 안정화 메커니즘을 결합하여, 학생 모델이 교사 모델의 추론 능력을 더 효율적으로 학습하도록 설계했습니다.
*   **성과:** 0.5B 규모의 학생 모델이 3B 교사 모델의 추론 성능 격차를 76.2%까지 좁혔으며, 일반 소비자용 하드웨어(Apple Mac Studio)만으로 데이터센터 수준의 효율을 달성했습니다.

📖 쉽게 풀어쓴 1분 핵심
큰 인공지능(교사 모델)의 지능을 작은 모델(학생 모델)로 옮기는 '지식 증류'는 모델 경량화를 위해 필수적입니다. 하지만 기존 방식은 학생이 추론을 시작조차 못 하거나(콜드 스타트), 학습 방향을 제대로 잡지 못하는 문제가 있었습니다. CADENCE는 모델이 추론하는 동안 스스로 경로를 수정하고, 틀린 답이라도 정답에 가까우면 부분 점수를 주며, 추론 과정의 불필요한 길이를 줄이는 등 6가지 정교한 장치를 도입했습니다. 결과적으로 훨씬 적은 자원으로도 똑똑한 소형 모델을 만들 수 있게 되었습니다.

🎯 배경 및 문제점
온폴리시 증류 과정에서 발생하는 세 가지 주요 실패 모드를 지목합니다.
1.  **콜드 스타트 붕괴(Cold-start collapse):** 학습 초기 학생 모델이 교사의 추론 패턴을 전혀 생성하지 못해 학습 신호가 소실되는 현상.
2.  **상태 비인지적 스케줄링(State-agnostic divergence scheduling):** 프롬프트마다 난이도가 다름에도 일률적인 시간 기반 학습 스케줄을 사용하여 최적화가 저하되는 문제.
3.  **이진 보상 희소성(Binary reward sparsity):** 성공/실패로만 평가하면 부분적으로 정답에 근접한 추론 과정의 정보를 활용하지 못하고 버리게 됨.

💡 핵심 기술 및 아키텍처
CADENCE는 DRIFT 메커니즘을 기초로 다음 6가지 핵심 컴포넌트를 적용합니다.
*   **(A) COV A:** 커버리지에 따라 모델의 학습 속도를 조절하는 적응형 스케줄러.
*   **(B) FTB:** 추론의 핵심인 '분기 토큰' 위치에 그래디언트를 집중시키는 부스팅 기술.
*   **(C) CCD:** 수치적 근접도를 기반으로 오답에도 부분 점수를 부여해 보상 신호를 풍부하게 개선.
*   **(D) LAP:** 추론이 정답일 경우, 불필요하게 긴 답변을 지양하고 간결한 답변을 선호하도록 유도.
*   **(E) EMR:** 추론 토큰들의 엔트로피를 정규화하여 모델의 자신감을 보정.
*   **(F) BSD:** 학습 후반부에 정답 여부를 확인하여 한 번 더 스스로 학습하는 부트스트래핑 단계.

📊 실험 결과 분석
GSM8K 및 MATH-500 벤치마크에서 5번의 시드(seed)를 통해 검증했습니다.
*   **성능:** 0.5B 학생 모델이 3B 교사 모델 대비 GSM8K에서 72.1±0.4%의 성능을 달성하여 기존 대비 성능 격차의 76.2%를 극복했습니다.
*   **비교:** 가장 강력한 기존 베이스라인(DRIFT+이진 보상)보다 GSM8K에서 +4.4±0.7점 높은 점수를 기록했습니다.
*   **효율성:** 모든 실험은 64GB 통합 메모리를 갖춘 Apple Mac Studio에서 수행되어, 고가의 데이터센터 장비 없이도 고성능 추론 모델 학습이 가능함을 입증했습니다.
*   **참고:** CCD 기술을 통해 비제로 보상(nonzero-reward) 비율을 기존 49%에서 약 55%로 향상시켰습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
*   **엣지 AI:** 고성능 추론 모델을 일반 소비자용 PC나 모바일 기기에서도 구동할 수 있는 길을 열었습니다.
*   **비용 절감:** 데이터센터급 하드웨어 없이도 고도화된 추론 성능을 확보할 수 있어, 기업들의 모델 개발 비용을 획기적으로 낮출 수 있습니다.
*   **신뢰성:** EMR(엔트로피 매칭 정규화) 도입을 통해 모델이 자신의 예측 불확실성을 더 잘 인지하고 소통하게 함으로써 실제 서비스에서의 안정성을 높였습니다.
