AGI 미로 예측 데이터셋: 트랜스포머를 통한 세계 모델 학습을 위한 소형 벤치마크

> **원본 논문 정보**
> - **제목:** AGI Maze Prediction Datasets: A Compact Benchmark for Learning World Dynamics with Transformers
> - **저자:** Alexey Potapov
> - **발행일:** 2026-09-02
> - **PDF 링크:** [AGI Maze Prediction Datasets: A Compact Benchmark for Learning World Dynamics with Transformers](https://arxiv.org/pdf/2609.02339v1)


✨ 3줄 핵심 요약
* 미로 탐색 환경에서 에이전트의 내부 상태 표현 능력을 평가하는 새로운 벤치마크(AGI Maze Prediction)를 제안합니다.
* 구조화된 작업 기억(Working Memory)을 가진 트랜스포머 모델이 단순 바이트 예측 모델보다 훨씬 뛰어난 상태 추론 성능을 보였습니다.
* 언어 모델이 환경의 구조적 상태를 내부적으로 유지할 수 있는지 테스트하는 가벼운 평가 환경을 제공합니다.

📖 쉽게 풀어쓴 1분 핵심
AI가 세상이 어떻게 돌아가는지 이해하는 '세계 모델(World Model)'을 가지려면 단순히 다음 단어를 예측하는 것만으로는 부족합니다. 미로를 예로 들면, 에이전트는 벽의 위치나 자신의 현재 좌표 같은 복잡한 정보를 기억하고, 행동할 때마다 이 정보를 업데이트해야 합니다. 이 논문은 AI가 이런 '구조화된 상태'를 스스로 학습하는지 확인하기 위해 미로 게임 환경을 만들었습니다. 실험 결과, 정보를 단순히 텍스트로만 처리하는 일반적인 방식보다, 2차원 공간 정보를 관리하는 '가상 메모리'를 갖춘 모델이 환경을 더 정확하게 이해하고 예측함을 확인했습니다.

🎯 배경 및 문제점
* **기존 문제:** 대규모 언어 모델(LLM)은 텍스트를 통해 환경과 상호작용할 때, 상태 정보를 모델 외부의 텍스트 히스토리나 별도의 외부 도구(코드 등)에 의존하는 경향이 있습니다. 이는 모델 자체가 환경의 구조적 상태를 내부적으로 이해하고 조작하는지 보장하지 못합니다.
* **필요성:** 모델이 행동에 따른 환경의 변화를 정확히 예측하려면, 단순히 텍스트를 출력하는 것을 넘어 내부에 환경의 '구조화된 상태 표현'을 구축하고 업데이트하는 능력이 필요합니다.

💡 핵심 기술 및 아키텍처
* **AGI Maze 벤치마크:** 미로 찾기 게임을 기반으로 한 데이터셋으로, 상태 기반 그리드 월드에서 생성되었습니다.
* **비교 모델:**
    * **바이트 레벨 트랜스포머(Baseline):** 텍스트 관찰 기록만 보고 다음 상태를 예측.
    * **보조 잠재 메모리 트랜스포머:** 비구조적 잠재 메모리를 추가.
    * **의사-비디오 공간 메모리 트랜스포머(제안 모델):** 입력 맵에서 2차원 잠재 공간을 생성하고, 이후 관찰 정보 없이도 행동 이력만으로 해당 공간을 지속적으로 업데이트함.

📊 실험 결과 분석
* **성능 평가:** '그리디 정확 일치(greedy exact-match)' 방식을 사용하여 모델의 예측이 지면 진실(ground truth)과 바이트 단위로 일치하는지 엄격하게 평가함.
* **주요 발견:** 
    * 일반적인 바이트 기반 모델이나 비구조적 메모리 모델은 미로 규모가 커질수록 성능이 하락함.
    * 반면, 2차원 공간 메모리를 갖춘 모델은 미로의 중간 지도나 상태 라벨을 받지 않고도 고정 수평선(fixed-horizon) 태스크에서 완벽한 검증 정확도를 기록함.
    * 수치적 데이터: 논문은 학습된 모델이 선택된 태스크에서 완벽한 정확도에 도달했다고 명시하며, 구체적인 수치(정확도 비율 등)는 공개하지 않음.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **구조화된 메모리:** 모델이 언어적 인터페이스만 갖는 것이 아니라, 작업에 적합한 구조화된 내부 메모리를 설계하는 것이 더 효율적인 세계 모델 구축의 열쇠임을 입증함.
* **확장성:** 복잡한 시각적 환경이나 거대 언어 모델로 넘어가기 전, AI가 환경의 물리적·공간적 법칙을 얼마나 잘 학습하는지 측정할 수 있는 가벼운 실험 환경을 제공함.
* **학습 방향:** 언어 모델이 환경을 단순히 외부적인 텍스트로 처리하지 않고, 지속 가능한 데이터 구조를 통해 환경을 모델링하도록 아키텍처를 개선하는 가이드라인을 제시함.
