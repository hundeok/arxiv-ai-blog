휴머노이드 툴벤치: 도구 선택부터 이동 실행까지의 휴머노이드 도구 사용 벤치마킹

> **원본 논문 정보**
> - **제목:** HumanoidToolBench: Benchmarking Humanoid Tool Use from Selection to Mobile Execution
> - **저자:** Kyochul Jang, Seohyeon Park, Ohchul Kwon, Sangjun Park, Junhyeok Choi, Seungyeop Yi, Chaeyun Kim, Sangkyu Lee, Idan Szpektor, Avi Caciularu, Jongmin Park, Youngjae Yu
> - **발행일:** 2026-10-01
> - **PDF 링크:** [HumanoidToolBench: Benchmarking Humanoid Tool Use from Selection to Mobile Execution](https://arxiv.org/pdf/2610.02089v1)


✨ 3줄 핵심 요약
* 휴머노이드의 도구 선택, 조작, 이동을 통합 평가하기 위한 18개 과제 중심의 'HumanoidToolBench'를 제안합니다.
* 3.1k 규모의 인간 시연 데이터셋 'ToolBook'을 구축하여 시뮬레이션과 실제 로봇(Unitree G1) 환경에서 검증했습니다.
* 실험 결과, 현재의 로봇 정책들은 도구 선택의 정확도와 지시어에 따른 작업 수행 능력에서 명확한 한계를 보였습니다.

📖 쉽게 풀어쓴 1분 핵심
휴머노이드 로봇이 인간처럼 도구를 사용하려면 단순히 도구를 집는 것을 넘어, 특정 과제에 적합한 도구를 골라내고 이를 활용해 목표를 달성하는 복합적인 과정이 필요합니다. 이 논문은 기존 벤치마크들이 이 과정을 포괄적으로 평가하지 못한다는 점에 착안했습니다. 연구진은 55개의 도구 자산과 로봇 제어 기술을 활용하여 로봇이 적절한 도구를 선택하고 이동하며 과제를 완수하는지 테스트하는 새로운 기준을 마련했습니다. 검증 결과, 로봇은 학습하지 않은 도구를 만났을 때 선택 오류를 범하거나, 작업 지시와 관계없이 이미 학습된 동작을 반복하는 경향이 있음이 밝혀졌습니다.

🎯 배경 및 문제점
* **기존의 한계:** 기존 벤치마크들은 고정된 기지(Fixed-base) 팔 로봇에 집중하거나, 도구 선택 능력보다는 시각적 질의응답(VQA)에 치중하여 실제 휴머노이드의 도구 사용 전체 과정을 평가하지 못했습니다.
* **복합적 요구:** 휴머노이드가 물리적 한계를 극복하려면 적절한 도구를 식별하는 능력(선택)과, 도구를 잡고 조작하며 필요시 이동까지 결합하는(실행) 능력이 필수적입니다. 이를 통합적으로 평가할 표준화된 데이터와 환경이 부족했습니다.

💡 핵심 기술 및 아키텍처
* **HumanoidToolBench:** 18개의 과제로 구성되며 세 가지 시나리오(BallMove, BallRetrieve, IceBreak)와 도구 세트(표준 및 Decoy 모드)를 포함합니다.
* **ToolBook 데이터셋:** 메타 퀘스트(Meta Quest) 원격 조종을 통해 시뮬레이션(3,003개)과 실제 로봇(91개)에서 수집된 총 3,094개의 인간 시연 데이터를 제공합니다.
* **로봇 제어:** Unitree G1 로봇을 사용하며, MuJoCo 환경 내에서 GR00T 기반의 전신 제어(Whole-Body Control)와 강화학습 컨트롤러를 통해 동작을 수행합니다.

📊 실험 결과 분석
* **정책 성능:** 시뮬레이션 환경에서 7개 정책, 실제 로봇에서 3개 정책을 평가했습니다.
* **성능 격차:** 도구 선택(Selection) 단계와 과제 완료(Task Completion) 단계 사이에서 상당한 수행 능력의 격차가 발견되었습니다.
* **지시어 무관성:** GR00T N1.7 모델을 정밀 조사한 결과, 과제와 전혀 상관없는 문장(예: "오늘 날씨가 좋다")을 입력해도 기존에 학습된 과제 동작을 거의 동일하게 수행하는 모습을 보였습니다. 이는 로봇이 언어 지시어를 완벽히 이해하기보다는 학습된 패턴에 의존하고 있음을 시사합니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **차세대 휴머노이드 개발:** 본 연구는 휴머노이드가 미지의 도구를 마주했을 때 더욱 유연하게 대처하고, 지시어에 따라 목표를 전환할 수 있는 '지능형 로봇 정책' 개발의 밑거름이 됩니다.
* **실무 활용:** 물류 센터나 가사 도우미 로봇처럼 다양한 환경에서 도구를 사용해야 하는 로봇 시스템의 신뢰성을 검증하는 표준 툴로 활용될 수 있습니다. 
* **연구 방향 제시:** 단순히 동작을 흉내 내는 것을 넘어, 도구의 물리적 특성을 이해하고 선택하는 학습 방향으로 연구의 전환을 촉구합니다.
