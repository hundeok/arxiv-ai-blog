> **원본 논문 정보**
> - **제목:** Successive Capacity Growth: Task-Complexity-Driven Width and Depth Expansion for Vision Transformer Encoders in JEPA World Models
> - **저자:** Frederik Berenz
> - **발행일:** 2026-08-27
> - **PDF 링크:** [Successive Capacity Growth: Task-Complexity-Driven Width and Depth Expansion for Vision Transformer Encoders in JEPA World Models](https://arxiv.org/pdf/2608.27367v1)


✨ 3줄 핵심 요약
* **지능적 확장:** 모델의 성능 정체를 감지하여 필요할 때만 너비(헤드 추가)나 깊이(레이어 추가)를 늘리는 '성공적인 용량 확장(SCG)' 기법을 제안했습니다.
* **효율성 극대화:** 고정된 대형 모델보다 최대 56배 높은 파라미터 효율성을 기록하며, 작업에 따라 최적의 아키텍처를 스스로 구축합니다.
* **안정성 보장:** 함수 보존형 확장과 최적화 상태 복구 메커니즘을 통해 모델 학습의 중단이나 성능 저하 없이 안전하게 용량을 키웁니다.

📖 쉽게 풀어쓴 1분 핵심
기존의 AI 모델은 복잡한 작업에 대비해 처음부터 거대한 용량의 모델을 설계합니다. 하지만 이는 단순한 작업에서는 자원 낭비를, 복잡한 작업에서는 과도한 파라미터로 인한 성능 저하를 일으킵니다. 이 논문은 아주 작은 모델에서 시작하여, 모델이 학습 중 더 이상 발전이 없는 '정체 구간'에 도달하면 그때마다 스스로 구조를 확장하는 방식을 제안합니다. 마치 나무가 필요한 만큼 가지를 뻗듯, 모델도 작업의 난이도에 맞춰 스스로 진화하여 컴퓨팅 자원을 획기적으로 절약합니다.

🎯 배경 및 문제점
* **자원 낭비:** 기존 JEPA 월드 모델의 인코더는 작업 난이도와 관계없이 고정된 크기의 비전 트랜스포머(ViT)를 사용합니다.
* **과잉 공급(Over-provisioning):** 분석 결과, 기존 모델은 헤드 간 거의 완벽한 중복성(유사도 0.0001)을 보이고, 하위 레이어의 정보 기여도가 매우 낮아 불필요한 계산을 수행하고 있음이 확인되었습니다.
* **고정된 설계의 한계:** 작업의 성격(단순 2D 내비게이션 vs 복잡한 다중 객체 역학)에 관계없이 동일한 크기의 모델을 사용하는 것은 학습 효율과 표현 능력을 저하시키는 원인이 됩니다.

💡 핵심 기술 및 아키텍처
* **성공적인 용량 확장 (SCG):** 최소 사양(283K 파라미터)에서 시작해 성능 정체 시 너비(헤드)나 깊이(블록)를 증설합니다.
* **함수 보존형 확장:** 확장 시 모델의 출력값을 즉각적으로 변화시키지 않는 구조를 채택하여, 확장이 실패할 경우 즉시 이전 상태로 안전하게 복구(Rollback)합니다.
* **SIGReg 정규화:** 확장된 모든 의미적 차원이 통계적으로 독립성을 유지하고 예측 목적에 부합하도록 하여, 모델이 커져도 정보가 붕괴하지 않게 합니다.
* **작업 독립적 검증:** 손실 함수가 2에포크 동안 정체될 경우 확장을 시도하고, 2% 이상의 성능 향상이 없으면 복구하는 자동화 메커니즘을 사용합니다.

📊 실험 결과 분석
* **다중 객체 역학 과제 (60차원):** 깊이 확장이 발생하여 고정된 소형 모델 대비 예측 손실을 20.3% 개선했습니다.
* **2D 내비게이션 과제:** 너비 확장 단 한 번으로 고정된 대형 모델 대비 23%의 성능 향상을 기록했습니다.
* **효율성:** 고정된 대형 모델 대비 최대 56배 높은 파라미터 효율성을 달성했습니다.
* **안정성:** 모든 테스트 환경에서 '위양성(불필요한 확장)' 사례는 0건이었으며, 함수 보존율은 1.0(차이 0.0)으로 완벽했습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **학습 패러다임 변화:** '최대 용량을 미리 할당하고 스스로 정리되길 바라는' 방식에서 '작업 요구에 따라 점진적으로 구조화된 지식을 쌓는' 방식으로의 전환을 제시합니다.
* **실무 적용:** 제한된 컴퓨팅 자원을 가진 환경에서 모델을 처음부터 가볍게 시작하여 성능을 단계적으로 최적화할 수 있습니다. 
* **향후 과제:** 실제 데이터셋에서의 검증, 전체 계획 파이프라인 통합, 사용하지 않는 구조를 제거하는 가지치기(Pruning) 기법 연구 등이 향후 발전 방향으로 제시되었습니다.
