정형 데이터 심층 회귀 재검토: 목적 함수와 전역 조기 종료의 한계

정형 데이터 심층 회귀 재검토: 목적 함수와 전역 조기 종료의 한계

정형 데이터 심층 회귀 재검토: 목적 함수와 전역 조기 종료의 한계

> **원본 논문 정보**
> - **제목:** Revisiting Tabular Deep Regression: Objectives and the Limits of Global Early Stopping
> - **저자:** Danil Rudenko, Georgii Bulgakov, Nikolay Kartashev, Ivan Rubachev, Daniil Krasylnikov, Artem Babenko
> - **발행일:** 2026-10-09
> - **PDF 링크:** [Revisiting Tabular Deep Regression: Objectives and the Limits of Global Early Stopping](https://arxiv.org/pdf/2610.13909v1)


✨ 3줄 핵심 요약
* 정형 데이터 회귀 작업에서 기존의 평균 제곱 오차(MSE)를 대체할 만한 더 나은 목적 함수들을 41개 데이터셋으로 체계적으로 재평가했습니다.
* 많은 제안 기법들이 MSE보다 일관된 성능 향상을 보이지 못했으나, '분위수 손실(Quantile Loss)'이 전반적으로 우수한 성과를 나타냈습니다.
* 데이터 내 불확실성 영역마다 최적 학습 시점이 다르다는 점을 밝혀냈으며, 이를 보완하는 '적응형 분위수 회귀(AdaQR)'를 제안했습니다.

📖 쉽게 풀어쓴 1분 핵심
정형 데이터(표 형태의 데이터)를 다루는 딥러닝 모델에서 회귀 분석을 할 때, 전통적으로 가장 많이 쓰이는 방식은 '평균 제곱 오차(MSE)'입니다. 연구진은 최근 제안된 수많은 복잡한 목적 함수들이 실제 실무에서도 정말 더 뛰어난지 검증했습니다. 그 결과, 대부분은 MSE보다 크게 낫지 않았지만 '분위수 손실'은 효과적이었습니다. 나아가, 데이터마다 노이즈(불확실성) 수준이 달라 학습 속도가 다른데, 이를 하나의 기준(전역 조기 종료)으로 멈추는 것은 비효율적임을 확인했습니다. 연구진은 이 문제를 해결하기 위해 입력값에 따라 유연하게 대응하는 '적응형 분위수 회귀(AdaQR)' 기술을 도입했습니다.

🎯 배경 및 문제점
딥러닝 기반의 정형 데이터 분석이 활발해지고 있지만, 정작 어떤 '목적 함수(Objective function)'를 사용해야 성능을 최적화할 수 있는지에 대한 체계적인 비교 연구는 부족했습니다. 기존 연구들은 서로 다른 데이터셋과 모델 환경에서 진행되어 결과 비교가 어려웠습니다. 또한, 정형 데이터에는 데이터마다 노이즈 수준이 다른 '이분산성(Heteroskedasticity)'이 흔한데, 학습 시점에 모델 전체를 동시에 멈추는 '전역 조기 종료(Global Early Stopping)'는 이러한 불확실성 영역 간의 균형을 제대로 맞추지 못한다는 한계가 있었습니다.

💡 핵심 기술 및 아키텍처
* **재평가 체계**: 41개의 정형 데이터셋과 다양한 신경망 아키텍처를 활용하여 기존 및 현대적인 회귀 목적 함수들의 성능을 비교했습니다.
* **분위수 손실(Quantile Loss) 활용**: 타겟의 조건부 분위수를 예측하는 기법이 다양한 환경에서 안정적인 성능을 보임을 확인했습니다.
* **AdaQR (Adaptive Quantile Regression)**: 데이터의 이분산성을 해결하기 위해 분위수 손실에 '입력값 기반 레이블 스무딩(Input-dependent label smoothing)'을 결합했습니다. 이는 데이터마다 다른 노이즈 특성을 학습 단계에서 반영하여, 모델이 특정 데이터 영역에 치우치지 않게 돕습니다.

📊 실험 결과 분석
* 비교 결과, 대다수 제안 목적 함수들은 세밀하게 튜닝된 MSE 대비 제한적이거나 일관되지 않은 성능 향상을 보였습니다.
* 분위수 손실은 여러 신경망 구조에서 MSE보다 일관되게 높은 예측력을 보였습니다.
* 합성 데이터 및 실제 데이터 실험 결과, 서로 다른 데이터 영역은 학습 과정에서 최적 성능에 도달하는 시점이 서로 다르다는 점을 입증했습니다.
* AdaQR은 노이즈가 변화하는 환경에서 기존 분위수 손실보다 향상된 예측 성능을 보였습니다. (상세한 수치는 논문 내 표 34, 35에 기재된 대로 모델별, 데이터셋별 성능 차이를 통해 확인 가능합니다.)

🌍 세상에 미치는 영향 & 실무 적용 사례
이번 연구는 정형 데이터를 활용한 금융, 제조, 물류 등의 실무 현장에서 딥러닝 모델을 회귀 분석에 적용할 때 중요한 길잡이가 될 것입니다. 단순히 유행하는 목적 함수를 쓰는 대신, 검증된 '분위수 손실'과 '적응형 방식(AdaQR)'을 도입함으로써 모델의 예측 안정성을 높일 수 있습니다. 특히 데이터 노이즈 수준이 불균일한 비즈니스 상황에서 고정된 학습 종료 시점이 아닌, 데이터 특성을 반영한 유연한 학습 설계를 가능하게 하여 실무 모델의 예측 오차를 줄이는 데 기여할 것으로 기대됩니다.
