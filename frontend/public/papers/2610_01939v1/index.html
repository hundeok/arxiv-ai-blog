✨ 3줄 핵심 요약
* **PyRUA-Lean**은 로봇 제어 시 불필요한 모델 호출과 데이터 전송을 줄이는 인터랙티브 코드 실행 프레임워크입니다.
* 기존 도구 호출 방식 대비 로봇 작업 성공률을 63.1%에서 71.7%로 개선했습니다.
* 동일한 작업 환경에서 LLM 호출 횟수는 49%, 입력 토큰은 65% 절감하여 효율성을 크게 높였습니다.

📖 쉽게 풀어쓴 1분 핵심
로봇을 제어하는 AI 모델(VLM)은 동작을 수행할 때마다 매번 상황을 다시 확인하고 명령을 내리느라 수많은 데이터를 주고받습니다. 마치 로봇이 한 걸음 내디딜 때마다 본부(LLM)에 무전으로 "다음은 어떻게 할까요?"라고 묻는 것과 같습니다. **PyRUA-Lean**은 로봇이 자체적으로 파이썬 코드를 작성해 스스로 판단하고 수행하게 함으로써 본부와의 통신을 최소화합니다. 이를 통해 로봇은 더 복잡한 동작을 더 적은 비용으로 빠르고 정확하게 처리할 수 있게 되었습니다.

🎯 배경 및 문제점
기존의 비전-언어 모델(VLM) 기반 로봇 제어는 '도구 호출(tool-calling)' 방식을 주로 사용합니다. 이 방식은 다음과 같은 한계가 있습니다.
* **통신 과부하:** 작업 중간의 확인이나 재시도가 필요할 때마다 반복적인 모델 호출이 발생합니다.
* **중복 정보:** 동작 완료 후 불필요한 시각적 피드백이나 상태 정보가 계속 LLM 컨텍스트에 쌓여 비용과 처리 효율을 떨어뜨립니다.
* **복잡도 한계:** 매번 호출을 거쳐야 하므로 연속적이고 복잡한 동작(Long-horizon)을 수행하는 데 제약이 따릅니다.

💡 핵심 기술 및 아키텍처
PyRUA-Lean은 로봇이 파이썬 코드를 직접 실행하는 방식을 도입했습니다.
* **피드백 기반 프리미티브 조합:** 로봇의 기초 동작(Primitive)과 학습된 비전-언어-동작(VLA) 정책을 파이썬 코드로 묶어 실행합니다.
* **선택적 관측:** 에이전트는 코드 내부에서 상황을 판단하고, 오직 필요한 경우에만 명시적으로 이미지나 상태 정보를 본부(LLM)에 요청하여 재계획(replanning)을 수행합니다.
* **자동 재시도 및 조건부 제어:** 코드 안에서 에러 처리나 조건문을 사용하여 모델 호출 없이도 로봇이 스스로 동작을 수정하거나 재시도할 수 있습니다.

📊 실험 결과 분석
700개의 시뮬레이션 작업(LIBERO-PRO, RoboTwin 2.0, RoboCasa365)을 통해 성능을 검증했습니다.
* **성공률:** 도구 호출 방식 대비 전체 성공률이 63.1%에서 71.7%로 상승했습니다. 특히 복잡도가 높은 작업(Multi-step, Long-horizon)에서 36%~40%의 큰 성공률 개선을 보였습니다.
* **효율성:** 동일하게 성공한 사례를 기준으로, LLM 호출 횟수는 49%, 입력 토큰 사용량은 평균 65% 감소했습니다.
* **비용:** 평균적인 추론 비용이 기존 대비 2.2배 저렴해졌습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **실용성 증대:** 높은 비용과 통신 부담 때문에 제약받던 로봇 에이전트의 현장 적용 가능성을 높였습니다.
* **지능적 자율성:** 로봇이 단순한 명령 수행자를 넘어, 파이썬 코드를 통해 스스로 논리적 판단을 내리고 오류를 해결하는 '스마트 에이전트'로 진화하는 기반을 마련했습니다.
* **향후 과제:** 현재는 시뮬레이션 환경에 국한되어 있으며, 향후 실제 물리 로봇에서의 제어 성능, 복잡한 로봇 하드웨어 구성에서의 일반화 성능을 검증할 계획입니다.
