> **원본 논문 정보**
> - **제목:** Compress What You See, Not What You Say: Anchored Context Distillation for Latent-Observation Software Engineering Agents
> - **저자:** Zhensheng Zou, Guoqing Wang, Dan Hao
> - **발행일:** 2026-09-25
> - **PDF 링크:** [Compress What You See, Not What You Say: Anchored Context Distillation for Latent-Observation Software Engineering Agents](https://arxiv.org/pdf/2609.31430v1)


✨ 3줄 핵심 요약
- 소프트웨어 엔지니어링 에이전트의 긴 문맥 문제를 해결하기 위해, 오래된 관찰은 '잠재적 토큰(soft tokens)'으로 압축하고 최근 데이터는 원문 그대로 유지하는 LOHA 기법을 제안합니다.
- 압축 과정에서 발생하는 정보 손실과 에이전트의 행동 변화를 방지하기 위해, 원문 기반의 행동을 기준으로 삼아 잠재적 표현을 학습시키는 ACD(앵커 기반 문맥 증류)를 도입했습니다.
- SWE-bench Verified 평가 결과, 문맥 사용량을 대폭 줄이면서도 에이전트의 문제 해결 능력을 유지하고 처리량(throughput)을 향상시켰습니다.

📖 쉽게 풀어쓴 1분 핵심
소프트웨어 개발 AI 에이전트는 코딩 과정에서 수많은 도구 출력 결과(파일 내용, 테스트 로그 등)를 기억해야 합니다. 이 기록이 쌓이면 메모리 한계를 초과하여 성능이 떨어집니다. 기존에는 중요하지 않은 내용을 삭제하거나 요약했지만, 코딩은 정확한 텍스트 복구가 필수적이어서 정보 유실이 치명적이었습니다. 

이 논문은 **LOHA(Latent Observations, Hard Actions)**를 통해 최근 $K$개의 정보는 원문 그대로 두어 정확성을 챙기고, 그보다 과거의 정보는 '잠재적 토큰'이라는 압축된 형태로 변환합니다. 또한, 압축된 정보로 인해 AI의 행동 방식이 바뀌지 않도록 **ACD(Anchored Context Distillation)**라는 기술로 원본 AI의 행동 패턴을 그대로 복제하도록 학습시킵니다.

🎯 배경 및 문제점
- **문맥의 과부하:** 소프트웨어 에이전트의 전체 토큰 중 도구 관찰 결과가 평균 69%를 차지할 정도로 큰 비중을 차지합니다.
- **정확성 요구:** 단순 요약은 코딩 시 필요한 정확한 파일 내용이나 식별자를 누락시킬 위험이 있습니다.
- **행동 변화:** 기존의 압축 방식은 압축된 정보를 처리하는 과정에서 원래 언어 모델의 행동 방식이 변질되는 문제가 있었습니다.

💡 핵심 기술 및 아키텍처
- **LOHA (Latent Observations, Hard Actions):** 문맥을 두 영역으로 나눕니다. 최근 $K$개의 관찰은 텍스트로 보존(Hard Actions)하고, 그 이전의 관찰은 인코더를 통해 압축된 잠재적 표현(Latent Observations)으로 변환합니다.
- **ACD (Anchored Context Distillation):** 압축된 잠재적 표현을 읽는 에이전트가 원본 텍스트를 읽는 에이전트와 동일한 행동을 하도록 강제합니다. 원본 텍스트를 '앵커(고정점)'로 삼아, 잠재적 데이터에서의 예측값이 원본 모델의 예측값과 일치하도록 증류합니다.

📊 실험 결과 분석
- **압축 효율:** SWE-bench Verified에서 $K=3$ 적용 시 Qwen3-4B 모델은 호출당 문맥을 43%, SWE-Master-4B-RL 모델은 57% 절감했습니다.
- **성능 유지:** $K=3$ 적용 시 문제 해결률은 각 모델에서 미압축 대비 일부 감소했으나(14.5% → 12.1%, 27.5% → 21.8%), 32K 토큰 제한 환경에서는 압축 모델이 원본 모델(11.1%)보다 우수한 21.1%의 해결률을 보였습니다.
- **처리량:** 단일 GPU 서버 환경에서 원본 모델 대비 1.9배의 인스턴스 처리량을 달성했습니다.
- **참고:** $K=8$일 때의 해결률은 14.4%와 23.0%로 나타났으며, 일반적으로 더 긴 윈도우($K$값이 클 때)가 성능에 유리했습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
이 기술은 대규모 코드 저장소를 분석하거나 복잡한 디버깅 작업을 수행하는 AI 에이전트의 효율성을 크게 높일 수 있습니다. 특히 긴 문맥 처리가 어려운 중소형 모델(4B급 등)을 사용하면서도 고성능 에이전트를 구축하려는 환경에서 유용합니다. 동일한 하드웨어 자원으로 더 많은 작업을 동시에 처리할 수 있게 함으로써, AI 기반 소프트웨어 개발 플랫폼의 운영 비용 절감과 응답 속도 개선에 기여할 것으로 기대됩니다.
