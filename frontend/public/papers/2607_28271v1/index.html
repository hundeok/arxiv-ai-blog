레거시 코드 마이그레이션을 위한 결정론적 검증의 에이전트 기반 방법론

레거시 코드 마이그레이션을 위한 결정론적 검증의 에이전트 기반 방법론

레거시 코드 마이그레이션을 위한 결정론적 검증의 에이전트 기반 방법론

> **원본 논문 정보**
> - **제목:** Agentic Method for Deterministic Validation of Legacy Code Migration
> - **저자:** Andras Ferenczi, Jordan Docherty, Mariya Bessonov, Matthew Findlay, Krishna Lingamneni
> - **발행일:** 2026-07-30
> - **PDF 링크:** [Agentic Method for Deterministic Validation of Legacy Code Migration](https://arxiv.org/pdf/2607.28271v1)


✨ 3줄 핵심 요약
*   COBOL에서 Java로의 코드 전환 시 발생하는 테스트 데이터 부족과 코드 커버리지 한계를 해결하기 위한 '락스미스 루프(Locksmith Loop)' 방법론을 제안합니다.
*   기존 입력값 검색으로 도달 불가능한 영역을 '패리티 보존 돌연변이(Parity-preserving mutation)' 기술로 강제 돌파하여 실행 경로를 확장합니다.
*   실제 사례 연구 결과, 오픈 소스 프로그램에서는 거의 100%의 커버리지를, 내부 운영 프로그램에서는 91.90%의 브랜치 커버리지를 달성했습니다.

📖 쉽게 풀어쓴 1분 핵심
오래된 시스템인 COBOL을 최신 Java 언어로 바꿀 때는 두 시스템이 완전히 동일하게 작동하는지 검증하는 것이 가장 어렵습니다. 기존의 자동 테스트 도구들은 입력값만 요리조리 바꿔가며 테스트하다가 특정 지점에서 더 이상 새로운 코드를 실행하지 못하는 '한계점'에 부딪힙니다. 본 논문은 이 한계점을 '잠긴 문'으로 정의하고, 이를 열기 위한 '락스미스(자물쇠 수리공)' 개념을 도입했습니다. AI 에이전트가 코드를 똑똑하게 변형하여 잠긴 경로를 강제로 열고, 이 과정에서 COBOL과 Java가 동일한 결과를 내는지 확인하는 방식으로 더 완벽한 검증을 수행합니다.

🎯 배경 및 문제점
*   **테스트 데이터 부족:** 레거시 시스템은 실제 운영 환경의 복잡한 사례(corner cases)를 모두 포함하는 테스트 데이터를 확보하기 어렵습니다.
*   **검증의 한계:** 기존의 검색 기반 테스트 생성(Search-based test generation) 도구들은 검색 범위를 넓히는 데는 효율적이나, 구조적으로 도달하기 어려운 영역에서는 성능이 정체(Plateau)되는 문제를 겪습니다.
*   **패리티 확인의 어려움:** 마이그레이션 과정에서 발생할 수 있는 행동 불일치(Behavioral drift)를 수정 단계 이전에 포착하는 것이 필수적입니다.

💡 핵심 기술 및 아키텍처
*   **락스미스 루프(Locksmith Loop):** 6가지 검색 알고리즘을 활용한 '증인 검색(Witness Search)'과 AI 에이전트가 수행하는 '돌연변이(Mutation)' 과정을 반복 수행합니다.
*   **패리티 보존 돌연변이:** 기존 코드의 기능을 손상하지 않으면서, 도달 불가능한 경로를 열기 위해 코드나 테스트 환경(Harness)을 변경합니다.
*   **스킬 기반 돌연변이:**
    *   **디스패처-암 스킬(Dispatcher-arm skill):** 외부 입력을 제어하여 실행 경로를 확장합니다.
    *   **호출 삽입 스킬(Call-injection skill):** 접근하기 어려운 특정 코드 블록을 강제로 실행하도록 합니다.
*   **결정론적 분석기:** 코드 변경 후 COBOL과 Java의 호출 추적(Call traces), 외부 작업, 최종 상태를 비교하여 행동 일치 여부를 확정적으로 검증합니다.

📊 실험 결과 분석
*   **연구 대상:** 오픈 소스 COBOL 프로그램 2개 및 내부 운영 수준의 COBOL 프로그램 1개 (소스 코드 라인 수 430~4,114줄).
*   **커버리지 성과:** 
    *   오픈 소스 프로그램: 거의 완전한 커버리지 도달.
    *   내부 운영 프로그램: 91.90%의 브랜치 커버리지 달성.
*   **정합성:** 모든 검증된 테스트 케이스에서 변환된 Java 코드는 COBOL 원본과 결정론적 패리티 검사를 통과했습니다.
*   **비교:** 이 결과는 동일한 마이그레이션 환경에서 기존의 그 어떤 방법보다 높은 커버리지를 기록한 것입니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
*   **실무 적용:** 마이그레이션된 코드에서 행동 불일치 버그를 통합 테스트 이전에 조기에 식별할 수 있어, 레거시 시스템 현대화의 리스크를 줄입니다.
*   **확장 가능성:** 본 방법론은 C#에서 Java로의 전환이나 SQL 등 다른 도메인의 pairwise 변환 검증에도 적용될 잠재력을 가지고 있습니다.
*   **미래 방향:** 향후 연구를 통해 에이전트의 개입을 최적화하고, 토큰 비용을 절감하며, 인간의 개입을 최소화하여 더 넓은 범위의 마이그레이션 검증을 수행할 계획입니다.
