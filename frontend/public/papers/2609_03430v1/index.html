무작위 어텐션: 효율적인 추론을 위한 KV 캐시 제거 전략의 재고

무작위 어텐션: 효율적인 추론을 위한 KV 캐시 제거 전략의 재고

무작위 어텐션: 효율적인 추론을 위한 KV 캐시 제거 전략의 재고

> **원본 논문 정보**
> - **제목:** Random Attention: Rethinking KV Cache Eviction for Efficient Reasoning
> - **저자:** Heng Wang, Jielin Qiu, Wenting Zhao, Cheng Qian, Liangwei Yang, Jiawei Han, Heng Ji, Silvio Savarese, Shelby Heinecke, Huan Wang
> - **발행일:** 2026-09-03
> - **PDF 링크:** [Random Attention: Rethinking KV Cache Eviction for Efficient Reasoning](https://arxiv.org/pdf/2609.03430v1)


✨ 3줄 핵심 요약
* 기존 LLM의 KV 캐시 압축 방식은 중요도 점수를 계산하여 토큰을 제거했으나, 본 논문은 이 점수 선택 신호가 사실상 무의미함을 증명했습니다.
* 프롬프트는 보존하고 나머지 캐시는 각 어텐션 헤드 내에서 무작위로 제거하는 '무작위 어텐션(Random Attention)' 방식을 제안합니다.
* 무작위 어텐션은 기존 최상위 방식들과 대등한 추론 정확도를 유지하면서도, 점수 계산 과정을 생략해 처리량(throughput)을 32~43% 향상했습니다.

📖 쉽게 풀어쓴 1분 핵심
대규모 언어 모델(LLM)이 긴 추론 과정을 거칠 때, 매번 계산한 값을 저장하는 'KV 캐시'는 메모리 부족을 일으키는 주범입니다. 이를 해결하기 위해 기존 기술들은 "어떤 토큰이 나중에 중요할까?"를 점수로 매겨 덜 중요한 것을 지웠습니다. 하지만 연구진은 이런 복잡한 계산이 실제 정확도에 별다른 도움이 되지 않는다는 것을 밝혀냈습니다. 대신 단순히 무작위로 제거해도 모델이 스스로 정보를 보존하며 똑같이 잘 작동한다는 것을 확인했습니다. 덕분에 무거운 점수 계산 과정을 뺄 수 있게 되어, 훨씬 더 빠르고 효율적인 AI 추론이 가능해졌습니다.

🎯 배경 및 문제점
LLM의 추론 성능을 높이기 위해서는 긴 '사고의 연쇄(Chain of Thought)'가 필수적이지만, 이는 KV 캐시의 선형적 증가를 초래하여 심각한 메모리 병목 현상을 일으킵니다. 기존 연구들은 캐시의 제한된 예산 내에서 토큰을 제거하기 위해 점수화 방식을 사용하여 중요도를 추정해 왔으나, 논문은 이러한 '점수 기반 선택'이라는 기본 전제 자체에 의문을 제기합니다.

💡 핵심 기술 및 아키텍처
* **무작위 제거 전략:** 점수 계산 없이 프롬프트는 안전하게 보존하고, 나머지 캐시 토큰은 각 어텐션 헤드 내에서 무작위로 추출하여 제거합니다.
* **추론의 중복성 활용:** 모델이 스스로 필요한 정보를 반복적으로 서술(텍스트 레벨)하고, 여러 어텐션 헤드에 분산 저장(헤드 레벨)하기 때문에, 무작위로 제거해도 충분한 정보가 남게 되어 고도의 점수 계산이 불필요함을 논리적으로 설명합니다.
* **경량화된 아키텍처:** 점수 계산 과정을 완전히 제거함으로써 vLLM 등 기존 시스템에 통합 시 추가 오버헤드를 최소화하고 즉각적인 속도 향상을 구현합니다.

📊 실험 결과 분석
* **정확도:** Qwen3(4B, 14B, 32B), Phi-4 등 4개 모델과 6개의 추론 과제(수학, 과학, 코드 등)에서 기존 방식들과 대등한 정확도를 기록했습니다.
* **처리량:** vLLM 환경에서 기존 최상위 방식 대비 32~43% 높은 토큰 처리 속도를 달성했습니다.
* **예외 사항:** Qwen3-32B의 코드 추론 과제에서 일부 차이가 발생했으나, 이는 프롬프트 길이가 압축 예산을 초과했기 때문임을 확인했습니다. (그 외 수치적 근거는 발췌문에 포함된 Figure 1 및 표 내용을 기반으로 함)

🌍 세상에 미치는 영향 & 실무 적용 사례
* **효율적인 모델 서빙:** 메모리 제약이 심한 환경에서도 LLM의 추론 성능을 유지하면서 더 많은 요청을 처리할 수 있게 합니다.
* **실무적 이점:** 복잡한 중요도 추정 알고리즘을 구현할 필요가 없어 시스템 복잡도를 낮추고, 기존 인프라(vLLM 등)에 매우 쉽게 통합(기존 플러그인에 단일 함수 추가 수준)할 수 있습니다.
* **학계의 관점 전환:** 캐시 압축을 위한 복잡한 휴리스틱 개발에서 벗어나, 모델 고유의 견고함과 중복성을 활용하는 새로운 연구 방향을 제시합니다.
