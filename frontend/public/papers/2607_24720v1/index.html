> - **발행일:** 2026-07-27

✨ 3줄 핵심 요약
* 다중 턴 장기 계획 능력을 체계적으로 연구하기 위해 통제된 환경을 구축하고, 사전 학습·사후 학습·모델 통합의 3단계로 나누어 분석했습니다.
* 명시적 세계 모델링과 양질의 데이터가 장기 계획의 핵심이며, 사후 학습 시 '계획 패턴'과 '계획 지식'을 구분하여 접근해야 합니다.
* 다중 교사 증류(MOPD) 시 교사 간 패턴이 호환될 때는 일반화와 학습이 촉진되지만, 충돌할 경우 치명적인 망각이 발생함을 확인했습니다.

📖 쉽게 풀어쓴 1분 핵심
인공지능 모델이 복잡한 장기적 과업을 수행하려면 단순히 단기적인 기술을 익히는 것만으로는 부족합니다. 본 논문은 AI가 긴 과정을 단계별로 계획하는 능력을 어떻게 습득하는지 파고들었습니다. 사전 학습 단계에서는 '세계 모델(세상의 작동 원리)'을 명확히 배우는 것이 중요하며, 학습 후반부에는 모델이 스스로 전략(패턴)을 다듬게 할 것인지, 아니면 외부 지식(지식)을 주입할 것인지에 따라 최적의 알고리즘(GRPO vs OPD)이 달라짐을 밝혔습니다. 특히 여러 교사로부터 배우는 모델 통합 과정에서, 지식의 충돌이 오히려 학습을 방해할 수 있다는 점을 강조합니다.

🎯 배경 및 문제점
기존 모델들은 인터넷상의 정제되지 않은 데이터로 학습되어 계획 능력이 어떻게 형성되고 결합되는지 파악하기 어려웠습니다. 특히 장기 계획 문제는 과업이 길어질수록 결정 오류가 누적·증폭되는 특성이 있는데, 이에 대한 체계적인 분석이 부족했습니다. 본 연구는 통제된 환경을 통해 데이터 품질, 작업 길이, 계획 지식 등이 모델 성능에 미치는 영향을 엄밀히 규명하고자 했습니다.

💡 핵심 기술 및 아키텍처
* **통제된 다중 턴 환경:** 작업 길이와 데이터 품질을 정밀하게 제어하여 계획 능력의 형성 과정을 실험했습니다.
* **사후 학습 전략 구분:**
    * **GRPO(그룹 상대 정책 최적화):** 환경 기반의 계획 패턴 생성에 유리합니다.
    * **OPD(온-정책 증류):** 저품질 사전 학습 데이터 환경에서 더 넓은 적용 범위를 가지며 일관된 업데이트 방향을 제공합니다.
* **MOPD(다중 교사 온-정책 증류):** 여러 교사의 계획 패턴 분포를 통합하여 교차 환경 일반화 및 지속 학습을 지원합니다.

📊 실험 결과 분석
* **사전 학습:** 단순히 원자적 기술만 배우는 것은 불충분하며, 연쇄 사고(Chain-of-Thought)를 통한 명시적 세계 모델 구축이 필수적입니다.
* **사후 학습:** 계획 지식은 SFT(지도 미세 조정)에, 일반적인 계획 패턴은 RL(강화 학습)에 더 적합합니다.
* **통합 단계:** 호환되는 패턴은 학습을 돕지만, 완전히 충돌하는 패턴은 심각한 간섭과 치명적 망각을 초래합니다.
* **기타:** pass@k 지표가 장기 계획 환경에서는 모델의 상한선을 정확히 반영하지 못할 수 있음을 발견했습니다(발췌문에 구체적인 수치는 언급되지 않음).

🌍 세상에 미치는 영향 & 실무 적용 사례
본 연구는 파운데이션 모델 에이전트의 개발 방향에 중요한 지침을 제공합니다. 개발자들은 이제 단순히 데이터를 많이 학습시키는 것을 넘어, 계획 패턴과 지식을 구분하여 효율적으로 모델을 훈련할 수 있게 됩니다. 또한, 여러 전문 모델을 통합하여 더 강력한 에이전트를 만들고자 할 때, 교사 모델 간의 전략적 충돌을 어떻게 회피할지에 대한 실무적 근거를 제공합니다. 이는 실제 복잡한 현실 문제를 해결하는 고성능 자율 에이전트 설계의 토대가 될 것입니다.
