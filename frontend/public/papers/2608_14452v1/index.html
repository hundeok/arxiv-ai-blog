SheetCompass: 스프레드시트 추론을 위한 계층적 관계 그래프 에이전트

> **원본 논문 정보**
> - **제목:** SheetCompass: Hierarchical Relation Graphs for Agentic Spreadsheet Reasoning
> - **저자:** Panjing He, Mingyue Cheng, Yucong Luo, Li Li, Xiaohan Zhang
> - **발행일:** 2026-08-14
> - **PDF 링크:** [SheetCompass: Hierarchical Relation Graphs for Agentic Spreadsheet Reasoning](https://arxiv.org/pdf/2608.14452v1)


✨ 3줄 핵심 요약
* **구조 인식의 한계 극복:** 기존 모델의 평탄화(Flattening) 방식에서 벗어나, 계층적 그래프를 통해 스프레드시트의 표와 열 단위 구조를 명확히 모델링합니다.
* **전문성 강화:** 도구 사용법 및 도메인 지식을 갖춘 '전문가 기억'과 이전 실행 경험을 반영하는 '추론 기억'의 이중 메모리 구조를 도입했습니다.
* **멀티 에이전트 협업:** 탐색, 프로그래밍, 반성(Reflector)이라는 세 가지 특화 에이전트가 유기적으로 상호작용하여 고도의 자동화 추론 성능을 달성했습니다.

📖 쉽게 풀어쓴 1분 핵심
스프레드시트는 표와 열, 셀 간의 복잡한 연결 고리로 이루어져 있습니다. 그러나 기존의 AI 모델은 이를 단순한 텍스트 줄처럼 읽어 들여 데이터의 구조적 맥락을 자주 놓치곤 했습니다. **SheetCompass**는 스프레드시트를 '구조화된 그래프'로 인식하여, 마치 사람이 시각적으로 레이아웃을 파악하듯 데이터 간의 관계를 이해합니다. 여기에 전문가의 지식과 과거의 실수 경험을 기록하는 메모리 장치를 더해, 복잡한 스프레드시트 작업을 정확하고 반복 가능한 형태로 수행하도록 설계되었습니다.

🎯 배경 및 문제점
대규모 언어 모델(LLM)은 스프레드시트 자동화에 활용되고 있으나, 다음과 같은 한계에 직면해 있습니다.
* **정보 손실:** 복잡한 스프레드시트 데이터를 1차원적인 시퀀스로 변환하면서 데이터 간의 경계와 의미적 연결성이 소실됩니다.
* **구조 파악의 부재:** 사람이 시각적으로 파악하는 전역적인 레이아웃 정보를 모델이 이해하지 못해 복잡한 추론 성능이 급격히 저하됩니다.

💡 핵심 기술 및 아키텍처
* **계층적 관계 그래프(Hierarchical Relation Graph):** 표와 열 수준에서 암시된 레이아웃을 안정적인 앵커(Anchor)로 formalize하여 데이터의 공간적 토폴로지를 인코딩합니다.
* **이중 수준 메모리(Dual-level Memory):** 
    * **전문가 지식 메모리:** 도구 사용법과 도메인 지식을 제공합니다.
    * **추론 경험 메모리:** 실행 경로를 학습하여 오류를 방지하고 워크플로우를 진화시킵니다.
* **멀티 에이전트 협업:** 
    * **내비게이셔널 익스플로러(Navigational Explorer):** 탐색 담당.
    * **로지컬 프로그래머(Logical Programmer):** 실행 담당.
    * **크리티컬 리플렉터(Critical Reflector):** 반복적인 검증 및 피드백 수행.

📊 실험 결과 분석
* **성능 우위:** SCB, SB, SheetRM 벤치마크 테스트에서 SOTA(State-of-the-Art) 성능을 기록했습니다. (구체적인 성능 수치는 논문 내 표 1 및 표 2 참조)
* **구성요소 기여도:** 계층적 그래프를 제거했을 때 가장 큰 성능 하락(SCB pass@1 기준 14.9% 하락 등)이 나타나, 구조적 이해가 추론의 근간임을 입증했습니다.
* **상호보완성:** 멀티 에이전트 워크플로우와 이중 메모리 모두 전체 모델 성능을 유의미하게 향상시키는 핵심 요소로 확인되었습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **생산성 향상:** 반복적이고 복잡한 데이터 조작 업무를 자동화하여 산업 생산성의 병목 현상을 해결할 수 있습니다.
* **실무적 견고성:** 단순 코드 생성을 넘어, 실제 스프레드시트 엔진의 특성(예: 동적 수식 평가, 피벗 테이블 생성 등)을 고려한 호스트 애플리케이션 백엔드 연동을 지원하여 실무 적용 가능성을 높였습니다. 
* **오류 방지:** 실패 패턴 분석을 통해 실행 중 발생할 수 있는 데이터 손상이나 타입 불일치 등의 문제를 체계적으로 차단합니다.
