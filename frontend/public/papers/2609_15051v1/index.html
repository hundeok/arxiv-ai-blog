모든 프롬프트는 평등하지 않다: 멀티모달 강화학습 사후 학습을 위한 탐색 유도형 프롬프트 스캐폴딩

> **원본 논문 정보**
> - **제목:** Not All Prompts Are Equal: Exploration-Guided Prompt Scaffolding for Multimodal Reinforcement Post-Training
> - **저자:** Yuanhao Yue, Qianli Ma, Chengyu Wang, Haoting Wang, Lei Shen, Jun Huang
> - **발행일:** 2026-09-14
> - **PDF 링크:** [Not All Prompts Are Equal: Exploration-Guided Prompt Scaffolding for Multimodal Reinforcement Post-Training](https://arxiv.org/pdf/2609.15051v1)


✨ 3줄 핵심 요약
*   강화학습(RL) 사후 학습 시 모든 프롬프트가 모델 학습에 동일한 기여를 하지 않는다는 점에 착안하여, 효율적인 학습을 위한 '프롬프트 스캐폴딩' 프레임워크를 제안함.
*   프롬프트의 학습 유용성을 측정하는 '탐색 잠재 점수(EPS)'를 도입하여, 학습 효율이 낮은 프롬프트를 교사 모델을 통해 더 유익한 형태로 재작성함.
*   Geo3K 및 MMK12 데이터셋에서 기존 베이스라인 대비 도메인 내 성능 최대 9.7%, MathVision 및 MMMU-Pro에서 각각 11.5%, 11.1%의 성능 향상을 기록함.

📖 쉽게 풀어쓴 1분 핵심
강화학습으로 멀티모달 모델을 훈련할 때, 어떤 질문(프롬프트)은 이미 모델이 충분히 잘해서 학습 효과가 적고, 어떤 질문은 너무 어려워 오히려 학습을 방해합니다. 연구진은 각 질문이 모델을 얼마나 더 똑똑하게 만들 수 있는지를 측정하는 '탐색 잠재 점수(EPS)'를 고안했습니다. 학습에 도움이 안 되는 질문은 버리는 대신, 교사 모델을 활용해 모델이 풀기 좋은 형태로 살짝 수정(스캐폴딩)합니다. 이렇게 하면 정해진 학습 자원을 훨씬 효율적으로 사용하여 모델의 추론 능력을 극대화할 수 있습니다.

🎯 배경 및 문제점
기존의 온라인 강화학습(예: GRPO) 방식은 모든 훈련 프롬프트를 똑같이 중요하게 취급하는 비효율성을 가지고 있습니다. 학습 중인 모델 입장에서 이미 포화 상태인 프롬프트는 새로운 정보를 주지 못하고, 지나치게 어려운 프롬프트는 노이즈 섞인 학습 신호만 제공합니다. 따라서 모델이 발전함에 따라 프롬프트의 가치도 실시간으로 변하는데, 이를 고려하지 않는 고정된 프롬프트 분포는 학습 자원을 낭비하고 성능 향상을 저해하는 결과를 낳습니다.

💡 핵심 기술 및 아키텍처
*   **탐색 잠재 점수(EPS, Exploration Potential Score):** KL 규제 정책 개선 이론에 기반하여, 추가적인 연산 비용 없이 온-폴리시(on-policy) 롤아웃 통계치만으로 프롬프트의 유용성을 즉각 계산합니다.
*   **비동기적 프롬프트 스캐폴딩:** 점수가 낮은 프롬프트는 별도의 작업자(Worker)가 교사 모델을 통해 더 정보량이 많은 형태로 재작성합니다. 이때 전체 학습 흐름에 영향을 주지 않도록 비동기적으로 처리합니다.
*   **동적 프롬프트 풀 관리:** 학습이 진행되면서 예전엔 어려웠던 프롬프트가 다시 유용해질 수 있습니다. 이를 위해 기존 프롬프트를 정기적으로 재평가하고 필요에 따라 다시 훈련 과정에 복귀시키는 순환 구조를 갖추고 있습니다.

📊 실험 결과 분석
*   **성능 향상:** Qwen3-VL-2B/4B 모델 기반 실험 결과, 도메인 내(In-domain) 성능에서 최대 9.7% 상대적 개선을 달성했습니다.
*   **일반화 능력:** 도메인 밖(Out-of-distribution) 벤치마크인 MathVision에서 11.5%, MMMU-Pro에서 11.1%의 성능 향상을 보이며, 학습 데이터 외의 문제 해결 능력도 크게 향상됨을 입증했습니다.
*   **데이터 효율성:** 모든 프롬프트를 동일하게 사용하는 대신, 유용성 기반의 선택적 스캐폴딩을 통해 모델의 학습 효율을 실질적으로 높였습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
이 연구는 강화학습의 학습 데이터 배포 방식이 모델 성능에 매우 중요한 최적화 대상임을 시사합니다. 실무적으로는 고비용의 멀티모달 모델 학습에서 데이터 낭비를 줄이고, 특정 도메인(수학, 기하학, 기호 추론 등)에서의 모델 역량을 효과적으로 끌어올리는 데 활용될 수 있습니다. 다만, 교사 모델이 생성한 재작성 프롬프트가 교사의 편향을 학습할 가능성이 있으므로, 실무 적용 시에는 엄격한 평가와 모니터링이 필수적입니다.
