VisCo: 시각 토큰 압축을 위한 내재적 인코더로서의 거대 언어 모델 활용

VisCo: 시각 토큰 압축을 위한 내재적 인코더로서의 거대 언어 모델 활용

VisCo: 시각 토큰 압축을 위한 내재적 인코더로서의 거대 언어 모델 활용

> **원본 논문 정보**
> - **제목:** VisCo: Leveraging Large Language Models as Intrinsic Encoders for Visual Token Compression
> - **저자:** Yupeng Zheng, Kai Zou, Bin Liu, Nenghai Yu
> - **발행일:** 2026-07-14
> - **PDF 링크:** [VisCo: Leveraging Large Language Models as Intrinsic Encoders for Visual Token Compression](https://arxiv.org/pdf/2607.12756v1)


✨ 3줄 핵심 요약
* **내재적 압축:** VisCo는 별도의 외부 모듈 없이 사전 학습된 시각-언어 모델(VLM) 자체를 압축기로 활용하여 시각 토큰을 효율적으로 압축합니다.
* **성능 안정성:** 압축률이 높은 상황이나 극단적인 단일 토큰 설정에서도 기존 방식들보다 뛰어난 성능 유지력을 보입니다.
* **효율적 재사용:** 이미지를 한 번만 압축하여 생성된 메모리를 다회차 대화에서 재사용함으로써, 대화가 길어질수록 속도와 메모리 효율이 크게 향상됩니다.

📖 쉽게 풀어쓴 1분 핵심
거대 시각-언어 모델(VLM)은 이미지를 처리할 때 너무 많은 '시각 토큰'을 생성하여 메모리를 많이 차지하고 응답 속도를 늦춥니다. 기존의 압축 방식들은 성능이 크게 떨어지거나, 별도 모듈을 학습시키느라 비용이 많이 드는 문제가 있었습니다. VisCo는 VLM이 원래 가진 능력을 그대로 활용합니다. VLM 내부에 '메모리 토큰'을 두어 중요한 시각 정보를 요약하게 함으로써, 성능 손실을 최소화하면서도 메모리 사용량은 줄이고 추론 속도는 높이는 효율적인 압축 프레임워크를 구현했습니다.

🎯 배경 및 문제점
* **자원 소모:** 고해상도 이미지는 방대한 양의 시각 토큰으로 변환되어, 계산량 증가 및 KV 캐시 저장 공간 부족이라는 병목 현상을 유발합니다.
* **기존 방식의 한계:** 
    * **학습 불필요 방식:** 휴리스틱한 기준에 의존하여 높은 압축률에서 성능이 급격히 저하됩니다.
    * **학습 기반 방식:** 외부 압축 모듈을 추가하여 VLM 본연의 사전 지식을 훼손하거나, 학습 비용이 과도하게 발생합니다.

💡 핵심 기술 및 아키텍처
* **파라미터 공유 오토인코더:** 사전 학습된 VLM 백본을 그대로 재사용하여 별도의 외부 모듈 추가를 방지했습니다.
* **계층적 메모리 뱅크:** 인코딩 단계에서 생성된 층별 KV(Key-Value) 캐시를 메모리 토큰으로 활용하여, 저수준의 질감부터 고수준의 의미론적 정보까지 계층적으로 디코딩 단계에 전달합니다.
* **경량화된 학습:** 모델 전체를 재학습하지 않고, 메모리 토큰과 LoRA 어댑터만을 학습시키는 방식을 통해 훈련 효율성을 높였습니다.

📊 실험 결과 분석
* **성능 우위:** Qwen2-VL-2B 및 7B 모델을 기반으로 실험한 결과, 모든 압축률(144개 토큰 대비 36개 및 18개 토큰 유지)에서 FastV, PruMerge+, VisionZip 등 기존 방법론보다 우수한 성능을 기록했습니다.
* **극단적 압축:** 극단적인 단일 토큰 환경에서도 시스템이 안정적으로 작동함을 확인했습니다.
* **추론 효율:** 
    * **긴 응답:** 압축 오버헤드가 디코딩 가속 효과로 상쇄되어 FastV보다 0.2초 더 빠른 응답 속도를 보였습니다.
    * **다회차 대화:** 대화 3회차부터는 이전 압축 결과를 재사용함으로써, 기존 방식보다 월등히 빠른 평균 응답 시간을 달성했습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **실시간 VLM 서비스:** 메모리 제약이 심한 온디바이스 환경이나 실시간 시각 대화 서비스에서 VLM을 더 가볍고 빠르게 배포할 수 있게 합니다.
* **다중 질의 최적화:** 이미지 한 장에 대해 여러 번 질문하는 사용 사례에서 압축 결과 재사용을 통해 사용자 경험을 혁신적으로 개선합니다.
* **미래 확장성:** 본 연구는 시각 데이터뿐만 아니라 더 복잡한 비디오 데이터 압축으로의 확장 가능성을 제시합니다.
