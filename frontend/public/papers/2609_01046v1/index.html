✨ 3줄 핵심 요약
* **러시아어 특화 대응:** 기존 모델들이 취약했던 러시아어 프롬프트 주입 및 난독화 공격에 강력한 방어 능력을 갖춘 0.6B 크기의 경량 가드레일 모델입니다.
* **효율적인 아키텍처:** Qwen3-0.6B를 기반으로 학습되었으며, 요청과 응답 모두를 하나의 이진 분류 규칙(안전/위험)으로 처리하여 14.3ms라는 매우 낮은 지연 시간을 달성했습니다.
* **데이터 전략:** 유해 예시와 양성 예시를 짝지어 구성하고, 8가지 난독화 변환을 적용하여 다양한 우회 시도를 효과적으로 식별하도록 설계되었습니다.

📖 쉽게 풀어쓴 1분 핵심
AI 모델을 사용할 때 사용자가 명령을 바꾸거나(프롬프트 주입), 시스템 제약을 우회하려고(탈옥) 하는 시도가 빈번합니다. 특히 러시아어처럼 키보드 레이아웃을 바꾸거나 기호를 삽입하는 식의 교묘한 '난독화' 공격은 기존 보안 모델들이 잘 잡아내지 못했습니다. HiveTraceGuard-Pro는 이런 공격을 전문적으로 차단하기 위해 만들어진 'AI 경찰관'입니다. 덩치가 작아 처리 속도가 매우 빠르며, 공격자가 아무리 문장을 꼬아서 질문해도 핵심 의도가 유해한지 안전한지 단번에 판단합니다.

🎯 배경 및 문제점
* **언어적 한계:** 기존 가드레일 모델들은 영어 데이터에 집중되어 있어, 키보드 레이아웃 치환, 음차, 기호 삽입 등을 동반한 러시아어 공격 방어에 한계가 있었습니다.
* **운영 효율성:** 많은 기업이 LLM을 운영할 때 속도와 메모리 제약을 겪고 있습니다. 기존의 무거운 가드레일 모델은 대규모 서비스 환경에 도입하기 부담스럽습니다.
* **오탐지 문제:** 유해한 시도와 비슷한 주제의 일반적인 대화를 구분하지 못해 과도하게 차단(Over-blocking)하는 경우가 많았습니다.

💡 핵심 기술 및 아키텍처
* **경량화:** Qwen3-0.6B 모델에 LoRA 튜닝을 적용하여 배포 및 실행 비용을 최적화했습니다.
* **데이터셋 구축:** 학습 데이터 구성 시, 동일한 주제 내에서 유해한 예시와 안전한 예시를 쌍으로 묶고, 여기에 8가지 난독화 기법을 적용하여 모델이 공격 형태가 아닌 '의도'에 집중하게 했습니다.
* **단일 규칙:** 복잡한 판단 과정 없이 '안전(safe)' 또는 '위험(unsafe)'이라는 이진 결과값만을 출력하도록 하여, 응답 지연 시간을 최소화(중앙값 14.3ms)했습니다.

📊 실험 결과 분석
* **러시아어 성능:** 15개 모델을 비교한 실험에서 러시아어 프롬프트 주입 재현율(Recall) 0.999, 러시아어 견고성 F1 점수 0.88로 최상위권 성능을 기록했습니다.
* **처리 속도:** 테스트한 15개 모델 중 가장 낮은 14.3ms의 중앙값 지연 시간을 보였습니다.
* **전체 성능:** 16개의 공개 벤치마크 그룹 기준 집계 점수는 0.7153을 기록했습니다. (전체 34개 모델 중 더 높은 점수를 기록한 모델이 4개 존재함)
* **오차율:** 전체 벤치마크 기준 위양성률(FPR)은 0.268, 위음성률(FNR)은 0.156으로 나타났습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **실무 적용:** 제한된 인프라 환경에서 운영되는 프로덕션 환경의 LLM 서비스에 보안 계층을 추가하기 용이합니다. 특히 다국어(러시아어 등) 서비스를 운영하는 기업이 공격 방어 수준을 즉각적으로 높일 수 있습니다.
* **개방성:** 가중치를 Apache-2.0 라이선스로 Hugging Face에 공개하여 누구나 경량 보안 모델을 자신의 시스템에 결합할 수 있도록 기여했습니다. 다만, 학습 데이터셋과 평가 코드는 보안상의 이유로 비공개로 유지되었습니다.
