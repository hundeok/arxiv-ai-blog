ReToken: 시각적 검색을 위한 시각-언어 모델 개선용 단일 토큰

ReToken: 시각적 검색을 위한 시각-언어 모델 개선용 단일 토큰

> **원본 논문 정보**
> - **제목:** ReToken: One Token to Improve Vision-Language Models for Visual Retrieval
> - **저자:** Yao Xiao, Reuben Tan, Zhen Zhu, Yuqun Wu, Jianfeng Gao, Derek Hoiem
> - **발행일:** 2026-07-30
> - **PDF 링크:** [ReToken: One Token to Improve Vision-Language Models for Visual Retrieval](https://arxiv.org/pdf/2607.28627v1)


✨ 3줄 핵심 요약
- **문제 해결:** 시각-언어 모델(VLM)의 기존 어텐션 기반 검색은 관련성 파악 능력이 떨어져 긴 문맥 처리에 한계가 있음.
- **핵심 기법:** 학습 가능한 단일 토큰 'ReToken'을 도입하여 모델의 값(value) 공간 내에서 질문과 가장 관련성 높은 시각 정보를 직접 검색하도록 설계함.
- **성과:** Qwen3VL-8B 및 InternVL3.5 모델에서 성능을 크게 향상시켰으며, 단일 H100 GPU 환경에서 효율적인 학습과 긴 영상 추론이 가능함.

📖 쉽게 풀어쓴 1분 핵심
긴 영상이나 많은 이미지를 다룰 때, AI는 질문에 필요한 핵심 장면을 찾아내는 데 어려움을 겪습니다. 기존 모델들은 질문과 장면 사이의 관계를 파악하는 '어텐션' 점수를 사용하지만, 이것만으로는 정확도가 낮습니다. 연구진은 **ReToken**이라는 특별한 학습용 토큰을 고안했습니다. 이 토큰은 마치 나침반처럼, 질문 내용과 가장 유사한 핵심 장면을 시각 데이터의 '값(value)' 공간에서 똑똑하게 찾아냅니다. 덕분에 AI는 전체 영상을 다 뒤지지 않고도 필요한 정보만 골라내어 더 빠르고 정확하게 답변할 수 있게 되었습니다.

🎯 배경 및 문제점
- **긴 문맥의 한계:** 시각 정보가 늘어날수록 관련 없는 장면(distractor)으로 인해 성능이 저하되며, 모든 토큰을 한 번에 처리하는 것은 GPU 메모리상 비효율적임.
- **어텐션의 불완전성:** VLM에서 텍스트와 시각 특징 간의 어텐션 점수는 실제 관련성과 상관관계가 낮음(QAEgo4DTest-MC 데이터셋 기준 평균 Recall@1이 5.1%에 불과함).
- **정보 검색 문제:** 긴 영상을 다루는 핵심은 방대한 입력값 중에서 질문 해결에 필요한 작은 정보 집합을 효과적으로 검색하는 것임.

💡 핵심 기술 및 아키텍처
- **ReToken(Retrieval Token):** 질문 뒤에 붙는 학습 가능한 단일 임베딩으로, 모델의 마지막 층에서 프레임별 '값 벡터'와의 코사인 유사도를 계산해 관련성을 판단함.
- **2단계 추론 프로세스:**
    1. **검색 단계:** 저장된 시각 KV 캐시를 통해 질문과 관련된 상위 K개의 프레임을 먼저 선별함.
    2. **답변 단계:** 선별된 핵심 프레임들의 정보만을 사용하여 효율적으로 답변을 생성함.
- **값 공간 활용:** 모델 내에서 실제로 전파되는 '값(value)' 벡터가 키(key)보다 텍스트 기반 시각 검색에 더 적합하다는 점을 활용함.

📊 실험 결과 분석
- **성능 향상:** 
    - Visual Haystacks 벤치마크: Qwen3VL-8B 점수 13.4점 상승, InternVL3.5 점수 12.4점 상승 (20% 이상의 상대적 성능 개선).
    - LVBench: Qwen3VL-8B 모델이 긴 영상에서 8.0점 향상 기록.
- **효율성:** 모든 학습 및 추론 과정이 단일 H100 GPU에서 수행 가능함.
- **비교 분석:** 기존 어텐션 기반 검색 대비 마지막 레이어에서 3배 이상의 Recall 성능을 보임.

🌍 세상에 미치는 영향 & 실무 적용 사례
- **확장성:** 복잡하고 긴 영상 데이터(강의, 영화, 기록물 등)를 분석해야 하는 멀티모달 서비스의 비용 효율성을 크게 높임.
- **실무 적용:** 영상 콘텐츠의 특정 사건을 찾아내거나(이벤트 이해), 엔티티를 식별하는 작업에 최적화됨. 
- **한계점:** 요약과 같이 영상 전체의 맥락이 중요한 과제에서는 성능이 저하될 수 있으며, 2단계 추론 방식으로 인한 응답 시간의 미세한 증가가 발생함. 향후 시간적 구조를 이해하는 방향으로 추가 연구가 필요함.
