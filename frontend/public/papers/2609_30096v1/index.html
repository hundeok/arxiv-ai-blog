궤적 기반 라우팅을 통한 비디오 확산 모델 가속화

궤적 기반 라우팅을 통한 비디오 확산 모델 가속화

궤적 기반 라우팅을 통한 비디오 확산 모델 가속화

> **원본 논문 정보**
> - **제목:** Accelerating Video Diffusion via Training-Free Trajectory Routing
> - **저자:** Mustafa Munir, Huy Vu, Shreyas Misra, Rohit Jena, Sajad Norouzi, Ali Taghibakhshi, Anis Ahmad, Anjul Patney, Pavlo Molchanov, Nima Tajbakhsh
> - **발행일:** 2026-09-24
> - **PDF 링크:** [Accelerating Video Diffusion via Training-Free Trajectory Routing](https://arxiv.org/pdf/2609.30096v1)


✨ 3줄 핵심 요약
- **TRACK**은 비디오 생성 시 단계별로 대형 모델과 소형 모델을 영리하게 교체하여 추론 속도를 획기적으로 높이는 기술입니다.
- 추가 학습(Retraining)이나 아키텍처 변경 없이, 사전 보정 과정을 통해 품질에 민감한 단계는 대형 모델을, 나머지는 소형 모델을 사용합니다.
- Wan 2.1, Cosmos 3 등 주요 모델에서 품질 저하를 최소화하면서 1.95배에서 최대 2.73배까지 속도 향상을 달성했습니다.

📖 쉽게 풀어쓴 1분 핵심
비디오 생성 AI는 고화질 영상을 만들기 위해 거대한 모델을 수십 번 반복해서 실행해야 하므로 매우 느립니다. 이를 해결하기 위해 기존에는 모델 자체를 압축하거나 단계를 줄이는 방식을 썼지만, 여전히 비용이 많이 듭니다. 'TRACK'은 비디오 생성의 각 단계별로 모델의 선택을 최적화합니다. 특정 단계는 큰 모델이, 또 어떤 단계는 작은 모델이 더 효율적이라는 점에 착안하여, 미리 정해진 규칙에 따라 모델을 바꾸어가며 영상을 만듭니다. 덕분에 영상의 품질과 다양성은 그대로 유지하면서도 훨씬 빠르게 비디오를 생성할 수 있습니다.

🎯 배경 및 문제점
고성능 비디오 확산 모델(Wan 2.1, Cosmos 3 등)은 높은 사실성과 시간적 일관성을 제공하지만, 수십억 개의 파라미터를 가진 모델을 반복적으로 실행해야 하므로 추론 지연 시간이 실무 적용의 걸림돌이 됩니다. 단순히 작은 모델을 쓰면 속도는 빠르지만 품질이 떨어지고, 모델을 일괄적으로 교체하는 방식은 영상의 복잡한 시공간적 역동성을 반영하지 못해 품질 저하나 샘플 다양성 감소를 유발합니다.

💡 핵심 기술 및 아키텍처
- **TRAJECTORY-AWARE 라우팅**: 대형 모델을 기준으로 참조 궤적을 먼저 생성한 뒤, 각 단계에서 대형 모델과 소형 모델의 예측값 차이(불일치 점수)를 측정합니다.
- **오프라인 보정(Calibration)**: 소량의 데이터셋을 활용해 각 단계별로 두 모델의 예측 불일치 정도를 계산하여 '교체 정책'을 미리 수립합니다.
- **Top-K 선택**: 불일치 점수가 낮은(즉, 두 모델의 결과가 유사한) 단계는 소형 모델로 할당하고, 품질에 민감한 단계는 대형 모델을 유지하여 성능을 보존합니다.
- **학습 불필요**: 모델 가중치 수정이나 추가 학습 없이 기존 모델을 그대로 활용하므로 구현이 간편합니다.

📊 실험 결과 분석
다양한 비디오 생성 파이프라인에서 TRACK의 성능은 다음과 같습니다.
- **Wan 2.1**: 1.95배 속도 향상
- **Cosmos 3**: 2.04배 ~ 2.73배 속도 향상
- **TurboDiffusion**: 2.69배 속도 향상
- **FastVideo**: 2.17배 속도 향상
실험 결과, TRACK은 기존의 단순한 휴리스틱 기반 교체 방식보다 품질 및 샘플 다양성 유지 측면에서 우수한 성능을 보였습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
이 기술은 고비용의 비디오 생성 모델을 상용 서비스 수준으로 최적화하는 데 매우 실용적인 패러다임을 제시합니다. 모델의 구조를 바꾸지 않아도 되기 때문에 기존 인프라에 즉시 적용 가능하며, 특히 단계별로 모델을 교체하는 방식은 향후 단계 증류(Step-distillation) 기법과 결합하여 생성형 AI 서비스의 효율성을 극대화하는 표준 방법론으로 자리 잡을 것으로 기대됩니다.
