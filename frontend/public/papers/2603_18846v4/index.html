망막 안저 영상을 위한 해석 가능한 파운데이션 모델을 향하여

망막 안저 영상을 위한 해석 가능한 파운데이션 모델을 향하여

> **원본 논문 정보**
> - **제목:** Towards Interpretable Foundation Models for Retinal Fundus Images
> - **저자:** Samuel Ofosu Mensah, Camila Roa, Kerol Djoumessi, Philipp Berens
> - **발행일:** 2026-03-19
> - **PDF 링크:** [Towards Interpretable Foundation Models for Retinal Fundus Images](https://arxiv.org/pdf/2603.18846v4)


✨ 3줄 핵심 요약
* **설계부터 해석 가능:** 'BagNet' 아키텍처를 도입하여 복잡한 사후 해석 기법 없이도 모델의 판단 근거를 직접 시각화합니다.
* **효율적인 성능:** 3억 개 이상의 파라미터를 가진 기존 모델(RETFound) 대비 약 1/16 수준인 1,830만 개의 파라미터만으로 대등한 성능을 달성했습니다.
* **직관적인 공간 구조:** 2D 투영 레이어를 통해 임상적으로 유의미한 데이터 클러스터와 오류 상관관계를 학습 단계에서 직접 관찰할 수 있습니다.

📖 쉽게 풀어쓴 1분 핵심
의료 영상 분야의 인공지능은 높은 성능만큼이나 "왜 그런 판단을 내렸는가?"를 설명하는 해석 능력이 매우 중요합니다. 하지만 기존의 거대 파운데이션 모델들은 내부가 복잡한 블랙박스 형태라 사후에 별도의 설명 도구를 덧붙여야 했습니다. 본 논문에서 제안하는 'Dual-IFM'은 모델의 구조 자체가 판단 근거(클래스 증거 지도)를 생성하도록 설계되어, 추가적인 해석 도구 없이도 질병과 관련된 병변 부위를 즉각적으로 확인할 수 있습니다. 또한, 거대 모델보다 훨씬 적은 자원으로도 우수한 진단 성능을 보이며 임상 현장에 더 적합한 투명성을 제공합니다.

🎯 배경 및 문제점
* **해석의 불충실성:** 기존의 사후 해석 방법(Post-hoc attribution)은 모델의 실제 의사결정 과정과 일치하지 않는 경우가 많아 신뢰하기 어렵습니다.
* **데이터 구조 이해 부족:** 고차원 데이터 공간에서 학습된 표현이 실제 임상적 의미를 담고 있는지, 아니면 데이터의 우연한 상관관계(spurious correlations)를 쫓는 것인지 확인하기 어렵습니다.
* **비효율적 시각화:** t-SNE 같은 기존 시각화 도구는 새로운 데이터가 추가될 때마다 다시 계산해야 하는 비효율성이 존재합니다.

💡 핵심 기술 및 아키텍처
* **BagNet 백본:** 작은 수용 영역(receptive field)을 가진 아키텍처를 사용하여 모델이 이미지의 특정 국소 영역에 근거하여 판단을 내리도록 강제했습니다.
* **내재적 해석(Inherent Interpretability):** 판단 근거가 되는 '증거 지도(Evidence maps)'를 모델 추론 과정의 일부로 통합하여 외부 해석 도구 없이도 병변 위치를 시각화합니다.
* **2D 투영 레이어:** 학습 과정 중 데이터의 표현 공간을 2D로 투영하여, 데이터셋 수준에서 임상적 군집이나 학습 편향을 직접 확인합니다.

📊 실험 결과 분석
* **성능 대등성:** 약 80만 장의 안저 영상을 학습한 Dual-IFM은 16배 더 큰 모델인 RETFound와 안저 질환 진단 등에서 대등한 성능을 보였습니다.
* **추론 속도:** RETFound 대비 추론 속도가 더 빠릅니다(배치당 81ms vs 140ms).
* **해석 정확도:** 모델이 생성한 증거 지도가 실제 질병 관련 병변을 더 정확하게 강조하는 것으로 나타났습니다.
* **자원 소모:** BagNet의 특성상 파라미터 수는 적지만 메모리 점유율은 상대적으로 높을 수 있다는 점이 지적되었습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **임상 도입:** 진단 결과와 함께 그 근거를 의료진에게 직접 제시할 수 있어, AI 기반 진단 시스템의 신뢰도를 크게 높일 수 있습니다.
* **데이터 신뢰성 검증:** 모델이 학습한 데이터 구조를 시각화함으로써, 데이터 자체의 편향성이나 잘못된 학습 패턴을 발견하여 수정하는 데 기여할 수 있습니다.
* **효율적 활용:** 거대 모델보다 적은 파라미터로 높은 성능을 내므로, 하드웨어 자원이 제한적인 환경에서도 고성능 안저 분석 모델을 운용할 수 있는 길을 열었습니다.
