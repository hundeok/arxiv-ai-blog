HEXIS: 에이전트 스킬을 확장 유한 상태 머신으로 컴파일하기

> **원본 논문 정보**
> - **제목:** HEXIS: Compiling Skills into Extended Finite State Machines
> - **저자:** Minghao LI
> - **발행일:** 2026-09-24
> - **PDF 링크:** [HEXIS: Compiling Skills into Extended Finite State Machines](https://arxiv.org/pdf/2609.30123v1)


✨ 3줄 핵심 요약
* 에이전트가 스킬을 실행할 때 발생하는 추론 오류와 절차 누락을 방지하기 위해, 스킬 지식과 제어 흐름을 분리하는 'HEXIS' 프레임워크를 제안합니다.
* 에이전트 스킬을 확장 유한 상태 머신(FSM)으로 컴파일하여 실행 상태를 기록하고, 명시적 조건에 따라 작업을 수행함으로써 실행 안정성을 높입니다.
* 4개의 벤치마크 실험 결과, 기존 Skill + ReAct 방식 대비 성공률이 평균 16.1%p 향상되었으며, 실행 토큰 사용량을 크게 절감했습니다.

📖 쉽게 풀어쓴 1분 핵심
기존의 AI 에이전트는 복잡한 업무를 수행할 때 '어떤 행동을 언제 해야 하는지'를 매번 스스로 판단해야 했습니다. 이 과정에서 중요한 단계를 건너뛰거나 잘못된 순서로 행동하는 문제가 자주 발생했습니다. HEXIS는 이러한 스킬 지식을 '확장 유한 상태 머신(FSM)'이라는 구조로 미리 컴파일합니다. 마치 복잡한 매뉴얼을 단계별 체크리스트가 포함된 흐름도로 변환하는 것과 같습니다. 덕분에 에이전트는 다음에 무엇을 해야 할지 고민할 필요 없이, 상태 머신이 안내하는 절차에 따라 정확하고 효율적으로 작업을 완수할 수 있게 됩니다.

🎯 배경 및 문제점
* **잦은 추론 오류:** 에이전트가 스킬 문서를 단순히 문맥으로만 제공받을 경우, 상황에 맞는 올바른 행동 시점을 스스로 추론해야 하며, 이 과정에서 절차를 누락하거나 부적절하게 대응하는 문제가 발생합니다.
* **긴 문맥의 한계:** 작업이 길어질수록 상호작용 기록이 방대해져, 관련 지시사항을 적절히 활용하기 어려워지는 문제가 있습니다.
* **절차적 준수 부족:** 특히 복잡한 조건문이나 특정 도구 사양을 따라야 할 때, 모델의 실행 능력(Compliance)이 저하되는 현상이 보고되었습니다.

💡 핵심 기술 및 아키텍처
* **확장 유한 상태 머신(FSM) 구조:** 스킬을 '지식'과 '제어 흐름'으로 분리합니다. 상태 내부에서는 로컬 지침을 통해 추론을 안내하고, 상태 간 전환 조건(Transition conditions)을 명시하여 다음 작업을 결정합니다.
* **증분 컴파일러(Incremental Compiler):** 스킬 조항과 도구 인터페이스를 상태 연산, 로컬 지침, 데이터 바인딩으로 매핑합니다.
* **검증 기반 업데이트:** 기존 개발 흔적과 현재 상태를 정렬하여 누락된 종속성을 식별하고, 정적 분석 및 과거 실행 기록 재실행(Replay)을 통과한 경우에만 상태 머신 업데이트를 승인합니다.

📊 실험 결과 분석
* **성능 향상:** 4개의 벤치마크와 4개의 실행기(Executor) 환경에서 기존 'Skill + ReAct' 방식 대비 평균 16.1%p의 성공률 향상을 기록했습니다.
* **효율성 증대:** Qwen3.8-27B 모델 사용 시, 벤치마크 전반에서 실행 토큰 사용량이 38.4%에서 88.9%까지 감소하는 효율성을 보였습니다.
* **학습 및 재사용:** LiveMath 벤치마크 실험 결과, 초기 상태 머신의 성공률은 40%였으나, 피드백을 통한 증분 컴파일 과정을 거쳐 9그룹 이후 100%에 도달했습니다. 또한, 완성된 상태 머신을 재사용할 경우 79.1%의 성공률을 유지하여 높은 재사용성을 입증했습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **실행 안정성 확보:** 정교한 절차 준수가 필수적인 기업용 자동화 에이전트나 복잡한 워크플로우를 처리하는 AI 시스템에서 오류를 획기적으로 줄일 수 있습니다.
* **지식 자산화:** 한번 구축된 컴파일된 스킬은 상태 머신 형태로 저장되어, 추가적인 학습 없이도 새로운 유사 작업에 즉각적으로 재사용할 수 있어 비용 효율적입니다.
* **모델 경량화 지원:** 복잡한 추론 부담을 상태 머신이 분담함으로써, 규모가 작은 모델로도 더 높은 수준의 작업을 안정적으로 수행할 수 있는 기반을 제공합니다.
