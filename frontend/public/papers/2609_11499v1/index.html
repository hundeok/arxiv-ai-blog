재귀적 코드 세계 모델: 재귀적 장면 프로그램을 통한 복잡한 세계 구축

재귀적 코드 세계 모델: 재귀적 장면 프로그램을 통한 복잡한 세계 구축

> **원본 논문 정보**
> - **제목:** Recursive Code World Models: Building Complex Worlds through Recursive Scene Programs
> - **저자:** Zhiqi Li, Yuxuan Liao, Bo Zhu
> - **발행일:** 2026-09-10
> - **PDF 링크:** [Recursive Code World Models: Building Complex Worlds through Recursive Scene Programs](https://arxiv.org/pdf/2609.11499v1)


✨ 3줄 핵심 요약
* **재귀적 접근:** 단일 이미지에서 3D 장면을 재구성할 때, 전체와 부분을 반복적으로 오가는 '글로벌-로컬-글로벌' 재귀 구조를 도입했습니다.
* **실행 가능한 코드:** 장면을 단순 픽셀이 아닌 실행 가능한 프로그램으로 표현하여 정밀한 편집, 구성 요소 재사용, 물리 시뮬레이션 통합이 가능합니다.
* **성능 및 유연성:** 복잡한 장면에서 기존 코드 기반 재구성 방식보다 뛰어난 성능을 보이며, 재귀 깊이가 깊을수록 더 세밀한 구조 재구성이 가능합니다.

📖 쉽게 풀어쓴 1분 핵심
마을 하나를 통째로 3D로 재구성하려면 거리, 건물, 건물 내 창문과 간판 등 아주 복잡한 계층 구조가 필요합니다. RCWM은 인공지능이 이를 한 번에 해결하려 하지 않고, 마치 설계자가 큰 그림을 그린 뒤 작은 부분을 확대해 다듬고 다시 전체와 조화시키는 과정을 반복하게 만듭니다. '전체 파악 → 부분 분할 및 재구성 → 전체와 조화'라는 재귀적 루프를 통해 복잡한 세계를 정교하게 구현하며, 결과물은 단순한 이미지가 아닌 컴퓨터가 읽고 실행할 수 있는 '코드' 형태로 생성됩니다.

🎯 배경 및 문제점
기존의 비전-언어 코딩 에이전트는 이미지를 기반으로 장면을 재구성할 수 있지만, 복잡한 세상에는 단일 재구성 경로로는 해결하기 어려운 수많은 계층적 구조가 존재합니다. 
* **규모 문제:** 건물 내의 작은 간판이나 창문 같은 세부 요소는 전체 장면을 다룰 때 놓치기 쉽습니다.
* **공간적 충돌:** 국소적인 부분만을 따로 수정할 경우, 인접한 물체와의 배치나 경계면에서 오류가 발생할 수 있습니다. 
따라서 복잡한 세계를 구축하려면 세부 구조를 독립적으로 편집하면서도 전체적인 기하학적 일관성을 유지할 방법이 필요합니다.

💡 핵심 기술 및 아키텍처
* **재귀적 장면 프로그램(RSP):** 장면을 실행 가능한 코드 집합으로 정의하여, 각 부분이 고유의 인식 및 편집 루프를 가질 수 있도록 합니다.
* **글로벌-로컬-글로벌 재귀 솔버:** 
    1. 전체 장면을 설정하고,
    2. 해결되지 않은 부분을 재귀적으로 다시 호출하여 세부 구조를 재구성하며,
    3. 다시 전체 상태로 돌아와 편집된 부분들이 전체와 조화롭게 배치되도록 수정합니다.
* **시각적 가이드:** 비전-언어 코딩 에이전트가 참조 이미지와 장면 렌더링 결과를 직접 비교하여 수정 방향을 결정합니다.
* **공유 카메라 프로젝션:** 부모가 가진 카메라 설정을 자식에게 전달하여, 계층 간의 시점 일관성을 유지합니다.

📊 실험 결과 분석
* **재구성 성능:** 다양한 복잡한 장면을 대상으로 실험한 결과, RCWM은 기존의 코드 기반 이미지-대-장면 재구성 방식들보다 우수한 성능을 나타냈습니다.
* **재귀의 효과:** 절제 실험(Ablation studies) 결과, 재귀적 구성 방식이 유효함이 입증되었습니다. 특히 재귀적 호출 깊이(depth)를 깊게 설정할수록 더 미세한 규모의 구조물까지 정밀하게 재구성할 수 있었습니다.
* **데이터:** 10개의 대표 사례에 대한 호출 트리 데이터가 제공되었으며, 가장 복잡한 사례(Valley Village)는 깊이 4단계에 걸쳐 63개의 노드와 169번의 세션을 수행했습니다(수치는 논문 발췌 데이터 기준).

🌍 세상에 미치는 영향 & 실무 적용 사례
* **지능형 설계 자동화:** 사진 한 장만으로 디지털 트윈이나 3D 가상 환경을 자동으로 구축할 수 있는 기반을 마련했습니다.
* **정밀 편집 및 제어:** 결과물이 코드로 제공되므로, 단순히 보기만 하는 3D 모델을 넘어 물리 엔진과의 결합이나 부품 재사용 등 다양한 엔지니어링 작업에 즉각 활용 가능합니다.
* **확장성:** 마을, 섬, 건물 내부 등 복잡도가 높은 환경에서 계층적인 재귀 구조를 통해 일관된 3D 세계를 생성할 수 있어 게임 개발, 가상현실 콘텐츠 제작 등의 분야에 실무적으로 적용될 잠재력이 큽니다.
