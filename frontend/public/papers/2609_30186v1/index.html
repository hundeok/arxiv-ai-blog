제브-모바일: 모바일 GUI 에이전트를 위한 실행기로서의 Jev

> **원본 논문 정보**
> - **제목:** Jev-Mobile: Jev as an Executor for Mobile GUI Agents
> - **저자:** Linghua Zhang
> - **발행일:** 2026-09-24
> - **PDF 링크:** [Jev-Mobile: Jev as an Executor for Mobile GUI Agents](https://arxiv.org/pdf/2609.30186v1)


✨ 3줄 핵심 요약
* **역할 분담 모델:** 시각-언어 모델(VLM)이 상위 목표를 설정하고, 빠르고 가벼운 'Jev' 모델이 실제 GUI 조작을 수행하도록 분리했습니다.
* **효율성 극대화:** 단계별 VLM 방식 대비 평균 실행 시간은 32.7%, 모델 API 비용은 73.4% 절감했습니다.
* **성능 유지:** AndroidWorld 벤치마크에서 79%의 작업 성공률을 기록하며, 기존 방식과 경쟁력 있는 성능을 유지했습니다.

📖 쉽게 풀어쓴 1분 핵심
기존 모바일 에이전트는 화면의 모든 움직임을 결정할 때마다 무겁고 비싼 VLM을 호출해야 했습니다. 'Jev-Mobile'은 이 과정을 똑똑하게 바꿨습니다. VLM은 "이 앱에서 이 작업을 해줘"라는 큰 목표만 제시하고, 실제 화면 속 버튼을 누르거나 글자를 입력하는 반복적이고 구체적인 행동은 가벼운 'Jev'라는 결정 모델이 도맡습니다. 덕분에 복잡한 연산은 줄어들고, 모바일 환경에서 훨씬 빠르고 저렴하게 작업을 완수할 수 있게 되었습니다.

🎯 배경 및 문제점
대부분의 기존 모바일 GUI 에이전트는 거의 모든 상호작용 단계에서 VLM을 사용해 계획과 행동을 결정합니다. 이는 다음과 같은 치명적인 단점을 유발합니다.
* **높은 지연 시간(Latency):** 매 단계마다 대규모 모델의 추론을 기다려야 함.
* **높은 비용:** 고성능 VLM API 사용으로 인한 운영 비용 상승.
* **과도한 의존:** 복잡한 의사결정 모델을 불필요한 단순 반복 작업에까지 투입함.

💡 핵심 기술 및 아키텍처
Jev-Mobile은 **'VLM 계획 - Jev 실행'**이라는 이원화 구조를 채택했습니다.
* **VLM (상위 계획):** 작업의 목표와 필요한 입력 텍스트를 지정합니다.
* **접근성 트리 (AXTree):** 화면 내 조작 가능한 요소들을 구조화된 형식으로 제공합니다.
* **Jev (빠른 결정 모델):** 접근성 트리를 바탕으로 VLM이 설정한 목표 안에서 반복적으로 최적의 행동을 선택합니다.
* **재관찰 루프:** 각 행동 후 화면과 트리를 새로 갱신하여, 인터페이스가 변하더라도 오작동하지 않도록 설계되었습니다.

📊 실험 결과 분석
AndroidWorld 전체 작업군을 대상으로 한 비교 실험 결과입니다.
* **작업 성공률:** Jev-Mobile 79%, SeeAct-V 78%, 단계별(Step-wise) VLM 84%를 기록했습니다.
* **실행 시간:** 단계별 VLM 대비 평균 전체 실행 시간을 32.7% 단축했습니다.
* **운영 비용:** 단계별 VLM 대비 성공한 경로당 평균 모델 API 비용을 73.4% 절감했습니다.
* **실행기 시간:** 실행 모델이 소요한 시간은 5.16초로, 단계별 VLM(94.30초)이나 UI-TARS(12.37초)보다 월등히 빠릅니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **효율적인 에이전트 구축:** 리소스가 제한된 모바일 환경에서 실시간 GUI 에이전트 도입의 문턱을 낮췄습니다.
* **비용 절감:** 자동화 시스템 운영 시 발생하는 API 비용을 대폭 줄여 상용화 가능성을 높였습니다.
* **향후 과제:** 현재는 Android 환경에 국한되어 있으며, 향후 웹 인터페이스와 같은 다양한 플랫폼으로의 확장 가능성과, Jev 모델이 소형 VLM으로 대체될 수 있는지에 대한 연구가 추가로 필요합니다. 또한 접근성 트리에 나타나지 않는 시각적 요소는 직접 감지하지 못한다는 한계가 있습니다.
