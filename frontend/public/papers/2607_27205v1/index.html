TurboVLA: RTX 4090에서 1GB 미만의 VRAM으로 32Hz 실시간 구동이 가능한 시각-언어-행동 모델

TurboVLA: RTX 4090에서 1GB 미만의 VRAM으로 32Hz 실시간 구동이 가능한 시각-언어-행동 모델

TurboVLA: RTX 4090에서 1GB 미만의 VRAM으로 32Hz 실시간 구동이 가능한 시각-언어-행동 모델

> **원본 논문 정보**
> - **제목:** TurboVLA: Real-Time Vision-Language-Action Model at 32 Hz on an RTX 4090 with <1 GB VRAM
> - **저자:** Hengyi Xie, Chenfei Yao, Xianjin Wu, Xuanyang Xi, Yiping Tang, Di Xu, Yingying Zhu, Dingkang Liang, Xiang Bai, Han Ding
> - **발행일:** 2026-07-29
> - **PDF 링크:** [TurboVLA: Real-Time Vision-Language-Action Model at 32 Hz on an RTX 4090 with <1 GB VRAM](https://arxiv.org/pdf/2607.27205v1)


✨ 3줄 핵심 요약
* **직접 매핑 구조:** 기존의 거대언어모델(LLM) 중심 V→L→A 경로를 직접적인 V+L→A 매핑으로 변경하여 연산 효율을 극대화함.
* **초고속·경량화:** 0.2B 파라미터와 0.9GB VRAM으로 31.2ms의 낮은 지연 시간(32Hz)을 달성하여 소비자용 GPU에서도 구동 가능.
* **압도적 성능:** LIBERO 벤치마크에서 97.7%의 평균 성공률을 기록하며 대형 모델들과 대등하거나 더 뛰어난 성능을 입증함.

📖 쉽게 풀어쓴 1분 핵심
기존 로봇 제어 모델들은 거대한 언어 모델(LLM)을 거쳐야 했기에 메모리 소모가 크고 반응 속도가 느렸습니다. 반면, 'TurboVLA'는 언어 모델 없이 시각 정보와 언어 명령을 직접 결합하는 단순하고 가벼운 구조를 택했습니다. 이 방식은 마치 사람이 복잡한 생각을 거치지 않고 보고 들은 대로 즉각 움직이는 것과 같습니다. 그 결과, 훨씬 적은 자원으로도 로봇이 실시간으로 부드럽고 정확하게 동작하도록 설계되었습니다.

🎯 배경 및 문제점
기존 VLA 모델들은 시각 데이터를 LLM의 표현 공간으로 변환한 뒤 다시 로봇 행동으로 바꾸는 'LLM 중심' 방식을 사용합니다. 이는 다음의 문제를 발생시킵니다.
* **과도한 연산량:** 매 단계마다 대규모 연산이 필요하여 하드웨어 비용이 높음.
* **메모리 병목:** 고성능 서버 환경이 강제되며, 엣지 기기(Edge Device) 적용에 한계가 있음.
* **지연 시간:** LLM 중심의 추론 과정이 로봇의 실시간 반응성을 떨어뜨림.

💡 핵심 기술 및 아키텍처
* **직접적 V+L→A 매핑:** BERT 기반의 경량 텍스트 인코더와 시각 인코더를 결합하여, LLM 없이 시각·언어 정보를 직접 처리.
* **양방향 시각-언어 상호작용(Bidirectional Interaction):** 시각과 언어 특징을 서로 교차 주의(Cross-attention) 방식으로 업데이트하여 정밀한 제어 표현을 생성.
* **행동 청크 디코더(Action Chunk Decoder):** 단일 전방향 통과(Forward pass)를 통해 연속적인 행동 시퀀스를 즉시 생성.

📊 실험 결과 분석
* **성능 지표:** LIBERO 벤치마크에서 97.7%의 평균 성공률 달성.
* **효율성:** 0.9GB VRAM과 31.2ms(32Hz)의 지연 시간으로 구동되며, 0.2B의 파라미터 규모를 가짐.
* **비교 분석:** 8B~2B 수준의 기존 모델(Evo-1, CogVLA 등)들과 비교했을 때, 훨씬 적은 파라미터로 더 낮은 지연 시간과 높은 성공률을 확보함. (※ 구체적인 타 모델 성능 수치는 발췌된 그래프/표를 기반으로 하며, 모든 비교 대상의 정확한 파라미터 수치는 지문 내에서 일부만 확인 가능함)

🌍 세상에 미치는 영향 & 실무 적용 사례
* **엣지 로봇의 혁신:** 고가의 클라우드 서버 없이도 로컬 환경의 소비자용 GPU(RTX 4090 등)에서 고성능 로봇 제어가 가능해짐.
* **비용 절감:** 추론 비용과 인프라 구축 비용을 획기적으로 낮춰 로봇 기술의 산업 현장 보급을 가속화함.
* **한계 및 향후 과제:** 고수준의 복잡한 추론이나 태스크 계획에는 한계가 있어, 향후 LLM의 고수준 기획 능력과 TurboVLA의 효율적 실행 경로를 결합한 계층적 시스템 연구가 기대됨.
