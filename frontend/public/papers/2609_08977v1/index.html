✨ 3줄 핵심 요약
* **엔드투엔드 통합:** 시각, 음성, 텍스트 입력을 실시간으로 처리하여 자연스러운 전이중(full-duplex) 상호작용을 수행하는 'Gander' 모델을 제안합니다.
* **뇌-소뇌 협업 구조:** 실시간 반응을 담당하는 '소뇌(Cerebellum)'와 복잡한 추론 및 에이전트 임무를 수행하는 '뇌(Brain)'로 역할을 분리한 아키텍처를 도입했습니다.
* **스트리밍 청크 방식:** 입출력을 1초 단위의 고정된 '청크(chunk)'로 평탄화하여 지연 시간을 최소화하고, 능동적인 끼어들기 및 반응이 가능하게 설계했습니다.

📖 쉽게 풀어쓴 1분 핵심
기존의 AI는 사용자가 말을 마치면 답변을 시작하는 방식이었지만, 'Gander'는 사람처럼 대화 도중에도 실시간으로 환경을 보고 들으며 능동적으로 반응합니다. 사용자가 중간에 말을 끊거나, 복잡한 업무를 시켜도 즉각적으로 대응할 수 있습니다. 이는 AI의 두뇌 역할을 하는 'Brain'이 장기적인 계획을 세우고, 소뇌 역할을 하는 'Cerebellum'이 사람과 대화하듯 실시간으로 소통하는 이중 구조 덕분에 가능합니다.

🎯 배경 및 문제점
기존의 대형 언어 모델(LLM) 기반 에이전트들은 주로 턴제 방식의 텍스트 기반 인터페이스에 머물러 있어, 실제 환경에서의 동적인 상호작용이나 복잡한 워크플로우 수행에는 한계가 있었습니다. 특히 음성, 영상 등 여러 모달리티가 혼합된 환경에서 사용자의 끼어들기나 동시다발적인 피드백을 처리하는 데 어려움이 있었으며, 이를 해결하기 위한 통합된 프레임워크가 부족했습니다.

💡 핵심 기술 및 아키텍처
1. **뇌-소뇌(Brain-Cerebellum) 협업 프레임워크:** 실시간 소통을 맡은 소뇌와 고차원적 추론을 수행하는 뇌가 도구 호출(tool calling)과 오케스트레이션 런타임을 통해 끊임없이 상호작용합니다.
2. **스트리밍 청크 평탄화(Streaming Chunk Flattening):** 모든 입력과 출력을 1초 단위의 시간 축으로 직렬화합니다. 모델은 매 청크마다 듣기를 계속할지, 말할지, 혹은 끼어들지 여부를 스스로 결정합니다. 
3. **효율적 오디오 처리:** 오디오 스트림을 5배 압축하여 토큰 속도를 최적화함으로써, 백본 모델이 지연 없이 데이터를 처리할 수 있도록 했습니다.

📊 실험 결과 분석
* 내부 인간 평가 결과, Gander는 오픈 소스 SOTA(최고 성능) 모델들과 대등한 수준의 자연스럽고 표현력 있는 대화 능력을 보여주었습니다.
* 배경 소음, 다자간 대화, 백채널(맞장구) 통신과 같은 실세계의 까다로운 환경에서도 강건한 성능을 입증했습니다.
* 특정 벤치마크 실험 결과, 'Daily-Omni'에서 19.13점, 'WorldSense'에서 5.01점의 성능 향상을 기록했습니다.

🌍 세상에 미치는 영향 & 실무 적용 사례
Gander는 사용자가 대화하며 동시에 에이전트에게 복잡한 워크플로우를 시키는 환경에서 강력한 활용도를 가집니다. 예를 들어, 사용자가 슬라이드를 수정하라고 요청하면 에이전트가 "알겠다"고 답변함과 동시에 작업을 수행하고, 중간에 사용자가 내용을 변경하면 즉시 반영하는 식의 실시간 업무 자동화가 가능합니다. 본 논문은 모델, 코드, 데이터를 공개하여 에이전트 연구 발전을 가속화하고자 합니다.
