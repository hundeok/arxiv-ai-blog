다국어 GSM-Symbolic: 언어 간 능력 전이는 무엇으로 결정되는가?

다국어 GSM-Symbolic: 언어 간 능력 전이는 무엇으로 결정되는가?

> **원본 논문 정보**
> - **제목:** Multilingual GSM-Symbolic: What determines capability transfer across languages?
> - **저자:** Kenneth Enevoldsen, Riley Herchert, Sofie Mosegaard, Dan Saattrup Smart, Simon Enni, Isaac Chung, Sofie Bruun, Ayush Sunil Munot, Max Müller-Eberstein, Adnan El-Assadi, Elisa Bassignana, Gianluca Barmina, Hafsteinn Einarsson, Iben Nyholm Debess, Linda Freienthal, Lukas Galke Poech, Mike Zhang, Nicolas Legrand, Vladimir Salnikov, Yevhen Kostiuk, Zafar Hussain, Sagandeep Kaur, Agnes Toftgård, Marie Mattson, Kristoffer Nielbo
> - **발행일:** 2026-10-02
> - **PDF 링크:** [Multilingual GSM-Symbolic: What determines capability transfer across languages?](https://arxiv.org/pdf/2610.03367v1)


✨ 3줄 핵심 요약
- 15개 언어에 걸친 수학적 추론 능력의 전이 과정을 분석하기 위해 3만 개의 문항이 포함된 'Multilingual GSM-Symbolic' 데이터셋을 구축함.
- 언어 간 능력 전이의 주요 결정 요인은 모델 크기, 언어 자원 수준, 추론 능력, 언어학적 거리 순으로 나타남.
- 이 분석 프레임워크는 언어 간 성능 변화의 92%를 설명하며, 타겟 언어의 소량 데이터만으로도 미지의 언어 성능을 효과적으로 추정할 수 있음.

📖 쉽게 풀어쓴 1분 핵심
거대언어모델(LLM)이 영어로 배운 수학적 능력이 다른 언어에서는 어떻게 발휘되는지, 그 원인이 무엇인지를 체계적으로 연구함. 기존에는 언어마다 평가 기준이 달라 비교가 어려웠으나, 본 논문은 '심볼릭 템플릿' 기술을 활용해 15개 언어에 걸쳐 동일한 조건으로 모델의 수학적 추론 능력을 측정함. 연구 결과, 모델이 클수록, 해당 언어의 데이터가 많을수록, 그리고 모델 자체의 추론 성능이 좋을수록 언어 장벽을 더 잘 극복하는 것으로 밝혀짐. 이는 언어별로 일일이 복잡한 평가를 수행하지 않고도 특정 언어에서의 성능을 예측할 수 있게 함.

🎯 배경 및 문제점
- 언어 간 능력 전이를 지배하는 결정 요인에 대한 이해가 부족함.
- 기존 평가는 서로 비교 불가능하고 데이터 포화 상태에 빠지기 쉬운 방식에 의존함.
- 모든 언어 쌍을 일일이 평가하는 것은 비용이 많이 들고, 저자원 언어에서의 성능 한계를 파악하기 어려움.

💡 핵심 기술 및 아키텍처
- **Multilingual GSM-Symbolic**: 15개 언어에 걸친 1,500개의 검증된 템플릿을 기반으로 3만 개의 문항을 생성한 확장 가능한 다국어 수학 데이터셋.
- **심볼릭 템플릿**: 단일 샘플에서 수백만 개의 고품질 변형 문제를 생성하여 과적합을 방지하고 일반화 성능을 보장함.
- **통계적 분석**: 모델 크기, 언어 자원 수준, 추론 능력, 언어학적 거리 등을 독립 변수로 설정하여 능력 전이를 정량화함.

📊 실험 결과 분석
- 모델 성능에 가장 큰 영향을 미치는 순서는 모델 크기(β=1.77), 언어 자원 수준(β=0.77), 추론 능력(β=0.67), 언어학적 거리(β=-0.25) 순임.
- 모델 크기와 추론 능력은 저자원 언어와 고자원 언어 간의 성능 격차를 줄이는 핵심 요소임.
- 개발한 분석 프레임워크는 언어 간 성능 변화의 92%를 설명함.
- 미지의 언어에 대한 성능 예측 오차 범위는 6.0pp 이내이며, 타겟 언어의 템플릿 10개만 추가해도 예측 오차는 4.19pp까지 감소함.

🌍 세상에 미치는 영향 & 실무 적용 사례
- **비용 효율적 평가**: 모든 언어 쌍을 평가할 필요 없이 적은 데이터로 성능 추정이 가능하여 언어별 평가 비용을 획기적으로 절감함.
- **개발 최적화**: 모델 개발자가 저자원 언어의 성능을 개선하기 위해 어떤 요소를(모델 크기 확대 등) 중점적으로 강화해야 할지 전략적 방향을 제시함.
- **연구 기반 마련**: 다국어 모델의 추론 능력 연구를 위한 데이터셋과 분석 프레임워크를 공개하여 후속 연구 및 모델 평가를 지원함.
