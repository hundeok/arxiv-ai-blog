기술을 프롬프트가 아닌 가중치로 증류하기: 온-폴리시 자기 증류를 위한 특권 신호로서의 추상적 기술

> **원본 논문 정보**
> - **제목:** Distill Skills into Weights, Not Prompts: Abstract Skills as Privileged Signals for On-Policy Self-Distillation
> - **저자:** Yubo Jiang, Fengying Xie, Zhiguo Jiang, Haopeng Zhang
> - **발행일:** 2026-08-10
> - **PDF 링크:** [Distill Skills into Weights, Not Prompts: Abstract Skills as Privileged Signals for On-Policy Self-Distillation](https://arxiv.org/pdf/2608.09826v1)


✨ 3줄 핵심 요약
* **한계 극복**: 기존 강화학습(RLVR)은 모델이 정답을 모두 맞히거나 모두 틀린 경우 학습 신호를 얻지 못하는 ‘대수적 사각지대(63.0~68.0%)’가 발생함.
* **SKALD 제안**: 추상화된 기술 카드(Skill Card)를 교사 모델의 문맥으로 활용해 학생 모델에 가중치 형태로 기술을 증류하고, 추론 시에는 외부 정보 없이 모델 자체 성능을 향상함.
* **성능 향상**: 0.6B, 1.7B, 4B 모델 규모에서 기존 GRPO 대비 평균 성능(avg@8)이 각각 +2.46, +4.85, +12.01 향상됨.

📖 쉽게 풀어쓴 1분 핵심
강화학습으로 수학적 추론 능력을 키울 때, 모델이 낸 답이 모두 정답이거나 모두 오답이면 모델은 무엇을 개선해야 할지 알 수 없습니다. 연구진은 이를 해결하기 위해 'SKALD'라는 방법을 도입했습니다. 먼저 교사 모델에게는 문제 풀이의 핵심 원리와 주의사항(기술 카드)을 알려주고, 학생 모델은 아무 정보 없이 문제를 풀게 합니다. 이후 교사 모델이 학생 모델의 풀이 과정을 보며 "여기서는 이렇게 생각했어야지"라고 가르치듯 정보를 가중치에 담아 증류합니다. 덕분에 학습이 끝난 모델은 별도의 도움 없이도 더 똑똑하게 문제를 풉니다.

🎯 배경 및 문제점
* **보상의 희소성**: 검증 가능한 보상 기반 강화학습(RLVR)에서 그룹 내 모든 결과가 동일할 경우, 상대적 보상 기반 정책 최적화(GRPO)는 학습 기울기(gradient)를 생성하지 못함.
* **사각지대**: 연구 실험 결과, 문제 풀이 그룹의 63.0~68.0%가 이러한 '0 분산(zero-variance)' 상태에 해당하여 학습 효율이 떨어짐.
* **기존 방식의 단점**: 모델 프롬프트에 기술을 포함하는 것은 임시방편이며, 별도의 큰 교사 모델을 운용하는 것은 비용과 배포 측면에서 부담이 큼.

💡 핵심 기술 및 아키텍처
* **SKALD (Skill-Anchored Latent Distillation)**:
    * **이중 문맥 보기**: 동일한 모델(Qwen3-Base)을 학생과 교사로 나누어 운영. 교사는 '추상적 기술 카드'를 입력받고, 학생은 문제만 입력받음.
    * **안정화된 학습**: 학생이 이해하기 어려운 정보로 교사 모델이 학습을 유도하는 분포 불일치를 해결하기 위해 '어닐링 지수 기울기 목표(Annealed exponentially tilted objective)'를 사용.
    * **학습 게이트**: 보상 차이가 확실할 때만 증류를 활성화하는 경험적 필터를 사용하여 불필요한 노이즈를 방지.
    * **추론 시 독립성**: 학습이 완료되면 기술 카드나 교사 모델의 도움 없이 모델 자체만으로 추론 가능.

📊 실험 결과 분석
* **성능 격차**: 1.7B 모델 기준, SKALD는 동일 연산량(FLOPs)을 가진 GRPO 대비 +4.06의 성능 향상을 보였으며, 4B 모델에서는 +12.01로 격차가 더 벌어짐.
* **증류 효율**: 1.7B 모델에서 정답이 모두 같은 그룹에 대해서만 증류를 수행해도 전체 이득의 84.7%를 회수할 수 있음이 확인됨.
* **안정성**: 기존 방식은 학습 과정에서 발산하는 경우가 있으나, 제안 기법은 기울기 노름(gradient norm)을 0.61 수준으로 제어하여 모든 실험에서 안정적으로 수렴함.

🌍 세상에 미치는 영향 & 실무 적용 사례
* **학습 효율 극대화**: 추가적인 모델 연산 없이 모델 내부에 기술을 내재화함으로써, 추론 단계의 복잡도를 낮추면서도 고성능의 수학적 추론 능력을 확보 가능함.
* **범용적 확장**: 정답 판별이 불가능한 영역에서 추상적인 가이드를 통해 학습을 유도할 수 있어, 복잡한 논리적 추론이 필요한 다양한 도메인의 언어 모델 훈련에 적용 가능.
* **실무적 이점**: 모델 배포 시 프롬프트 엔지니어링 없이 모델 가중치만으로 기술이 적용되므로, 실제 서비스 환경에서 메모리 및 레이턴시 효율성이 증대됨.
