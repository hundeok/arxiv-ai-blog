# Qwen-UI-Agent 기술 보고서: 차세대 실생활 중심 기초 GUI 에이전트를 향하여

> **원본 논문 정보**
> - **제목:** Qwen-UI-Agent Technical Report: Toward Next-Generation Real-World Centric Foundation GUI Agents
> - **저자:** Hanzhang Zhou, Panrong Tong, Xu Zhang, Quyu Kong, Chenglin Cai, Tianyu Xia, Gongjie Zhang, Jianan Zhang, Long Li, Long Chen, Lei Wang, Gaole Dai, Pengxiang Li, Liangyu Chen, Yue Wang, Steven Hoi
> - **발행일:** 2026-07-30
> - **PDF 링크:** [Qwen-UI-Agent Technical Report: Toward Next-Generation Real-World Centric Foundation GUI Agents](https://arxiv.org/pdf/2607.28227v1)


## ✨ 3줄 핵심 요약
*   모바일, PC, 웹 환경을 통합하여 실사용 기기에서 복잡한 업무를 수행하는 차세대 GUI 에이전트입니다.
*   GUI 조작과 CLI 명령어를 결합한 통합 행동 공간과 온라인 강화학습을 통해 장기적이고 복잡한 과제를 해결합니다.
*   모바일 환경(AndroidDaily 등)과 PC 환경(OSWorld 등) 등 다양한 벤치마크에서 최첨단(SOTA) 수준의 성능을 달성했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
'Qwen-UI-Agent'는 스마트폰이나 컴퓨터의 화면을 사람처럼 보고 조작하여 업무를 처리하는 AI 에이전트입니다. 단순히 버튼을 클릭하는 것을 넘어, 여러 앱을 오가며 복잡한 명령을 수행하고, 필요할 경우 직접 코드를 입력(CLI)하여 작업을 처리합니다. 특히 '실제 기기'에서 작동하도록 설계되어 사용자의 일상적인 모바일 앱 사용 환경에서도 높은 성공률을 보이며, 스스로 학습하고 발전하는 능력을 갖추고 있습니다.

## 🎯 배경 및 문제점
기존의 GUI 에이전트는 주로 가상 환경(샌드박스)에서 테스트되어, 실제 사용자의 기기에서 발생하는 다양한 변수나 복잡한 앱 환경을 충분히 반영하지 못했습니다. 또한 긴 시간 동안 이어지는 과제를 해결하는 데 필요한 연속적인 의사결정과 멀티 플랫폼 간의 작업 연동 능력이 부족했습니다.

## 💡 핵심 기술 및 아키텍처
*   **통합 행동 공간(Hybrid GUI+CLI):** GUI 인터페이스 조작과 CLI 명령을 하나의 모델 턴 안에서 혼합하여 배치(batch) 형태로 실행합니다.
*   **에이전트 기반 데이터 플라이휠:** 에이전트가 직접 과제를 생성하고, 실패를 진단하며, 계획을 수정하여 성능을 스스로 개선합니다.
*   **강화학습 지원:** 10,000개 이상의 환경에서 동시 학습이 가능하며, 100단계가 넘는 긴 호흡의 과제 수행 과정을 온라인 강화학습으로 최적화합니다.
*   **하네스 레이어(Harness Layer):** 모바일 알림을 기반으로 능동적인 서비스를 제안하고, 플랫폼 간 상태를 유지하며 작업을 이어갈 수 있게 돕는 보조 계층입니다.

## 📊 실험 결과 분석
다양한 벤치마크에서 최상위권 성능을 기록했습니다.
*   **모바일:** MobileWorld 82.1%, MobileWorld-Real 92.2%, AndroidDaily 97.5% 성공률 달성.
*   **컴퓨터:** OSWorld-Verified에서 79.5% 성공률, OSWorld-v2에서 40.0%의 부분 완료 점수 기록.
*   **웹/그라운딩:** WebArena 73.6%, ScreenSpot-Pro 81.5% 성공률 기록.
*   *(참고: 위 수치는 보고서에 명시된 실험 결과이며, 비교 대상인 기존 최첨단 모델들 대비 경쟁력 있는 성과를 보였습니다.)*

## 🌍 세상에 미치는 영향 & 실무 적용 사례
*   **일상 업무 자동화:** 스마트폰의 화면 잠금 설정, 회의 예약, 쇼핑 최저가 검색, 배달 음식 주문 등 일상적이고 복잡한 디지털 업무를 대행할 수 있습니다.
*   **멀티 디바이스 연동:** 모바일과 컴퓨터를 넘나들며 상태를 기억하고 작업을 수행함으로써 진정한 의미의 개인 비서 역할을 수행할 수 있습니다.
*   **안전 및 사용자 제어:** 사용자의 인증이 필요한 순간에는 스스로 조작을 멈추고 제어권을 사용자에게 넘기는 안전 설계가 포함되어 있어 실생활 도입의 가능성을 높였습니다.
