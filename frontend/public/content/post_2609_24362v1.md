# VLM-in-Sandbox: 에이전트 기반 시각적 추론을 위한 시각적 작업 공간

> **원본 논문 정보**
> - **제목:** VLM-in-Sandbox: Visual Workspaces for Agentic Visual Reasoning
> - **저자:** Hexiong Yang, Mingrui Chen, Jie Cao, Ran He
> - **발행일:** 2026-09-21
> - **PDF 링크:** [VLM-in-Sandbox: Visual Workspaces for Agentic Visual Reasoning](https://arxiv.org/pdf/2609.24362v1)


## ✨ 3줄 핵심 요약
* 시각 언어 모델(VLM)이 샌드박스 환경에서 추론할 때 발생하는 시각적 정보 과부하 문제를 해결하는 새로운 프레임워크입니다.
* 생성된 시각적 증거(이미지 등)를 별도의 저장소에 관리하고, 모델이 필요한 정보만 선택적으로 작업 공간으로 불러와 효율적으로 추론합니다.
* 4개의 VLM과 7개의 벤치마크 실험 결과, 기존 방식보다 높은 정확도를 기록하면서도 토큰 사용량과 처리 지연 시간을 효과적으로 줄였습니다.

## 📖 쉽게 풀어쓴 1분 핵심
기존의 VLM(시각 언어 모델)은 복잡한 문제를 풀 때 샌드박스 도구를 활용해 여러 이미지를 생성합니다. 하지만 이 모든 이미지를 대화 기록에 계속 쌓아두면 문맥이 너무 길어지고 모델이 혼란을 겪는 문제가 있었습니다. 'VLM-in-Sandbox'는 이를 마치 '컴퓨터의 파일 시스템'처럼 관리합니다. 생성된 이미지는 디스크에 따로 저장하고, 모델이 꼭 필요할 때만 선별적으로 시각적 정보(작업 공간)에 올리도록 설계되었습니다. 이를 통해 모델은 중요한 단서에만 집중할 수 있게 되어, 더 적은 비용으로 더 정확한 추론이 가능해졌습니다.

## 🎯 배경 및 문제점
샌드박스 환경을 사용하는 LLM 에이전트는 파일이나 코드 실행 등 symbolic(상징적) 데이터를 다루는 데 최적화되어 있습니다. 반면 VLM은 잘라낸 이미지, 강조 표시(mask), 확대 영역 등 시각적인 중간 증거를 생성하는데, 이를 대화 기록에 모두 포함하면 다음과 같은 문제가 발생합니다.
* **맥락 과부하:** 무분별하게 쌓이는 시각적 데이터로 인해 모델의 인지적 자원이 낭비됩니다.
* **비효율성:** 모든 생성물을 보존하려는 방식은 토큰 사용량을 급증시키고 처리 속도를 늦춥니다.

## 💡 핵심 기술 및 아키텍처
* **시각적 작업 공간(Visual Workspace):** 생성된 이미지를 '이미지 원장(Image Ledger)'에 기록하여 관리합니다.
* **제한된 활성 컨텍스트:** 모델은 생성된 방대한 자료 중 필요한 것만 명시적으로 선택(Promote)하여 제한된 개수의 슬롯에 배치합니다.
* **훈련이 필요 없는 프레임워크:** 별도의 추가 학습 없이 기존의 VLM 모델을 그대로 활용하면서, 샌드박스 도구와 시각적 증거 관리 기능을 분리하여 수행합니다.

## 📊 실험 결과 분석
* **정확도 향상:** 4개의 모델(GPT-4.1-mini, Gemini-2.5-Flash, Qwen3.5-9B, Ministral-3-8B-Instruct)과 7개 벤치마크 테스트에서 가장 높은 가중 평균 정확도를 기록했습니다.
* **효율성 증대:** GPT-4.1-mini를 사용한 실험에서 '모든 데이터를 유지하는 방식(retain-all control)' 대비 토큰 사용량을 18.6% 절감하면서도 66.27%의 정확도를 달성했습니다.
* **시스템 지표 개선:** 로컬 서버 환경에서 요청 작업량이 줄어듦에 따라 캐시되지 않은 토큰 수, 첫 토큰 생성 시간, 엔드투엔드 지연 시간이 모두 개선되었습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **에이전트 설계의 표준화:** 시각적 증거의 상태를 명시적으로 관리하는 것이 샌드박스 VLM 에이전트 설계의 핵심 추상화 모델임을 입증했습니다.
* **복합 추론 업무:** 수학적 추론, 시각적 비교 등 단계별 도구 사용이 필수적인 고난도 작업에서 모델의 실수를 줄이고 정확성을 높이는 데 기여할 수 있습니다.
* **확장성:** 정적 이미지뿐만 아니라 향후 동영상 분석이나 시계열 데이터 처리 시, 중요한 프레임만 선택적으로 관리하는 방식으로 확장 가능한 잠재력을 가집니다.
