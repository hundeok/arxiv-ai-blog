# 이기종 설문 데이터 간 정신 건강 상태 예측을 위한 LLM 기반 스키마 인식 분할 학습

> **원본 논문 정보**
> - **제목:** LLM-Based Schema-Aware Split Learning for Privacy-Preserving Mental Distress Prediction Across Heterogeneous Surveys
> - **저자:** Md Khalid Syfullah, Alvi Ataur Khalil
> - **발행일:** 2026-09-14
> - **PDF 링크:** [LLM-Based Schema-Aware Split Learning for Privacy-Preserving Mental Distress Prediction Across Heterogeneous Surveys](https://arxiv.org/pdf/2609.15871v1)


## ✨ 3줄 핵심 요약
- 서로 다른 질문과 형식을 가진 설문 데이터를 자연어 설명으로 통일하여, 기관 간 데이터 공유 없이도 협력적인 정신 건강 예측 모델을 구축함.
- LLM에 LoRA(저순위 적응) 기술과 분할 학습(Split Learning)을 결합해 클라이언트의 계산 자원 소모를 1,000배(3오더) 이상 줄임.
- 연합 학습(Federated Learning) 대비 9개 환경 중 8개에서 더 우수한 성능을 기록하며, 적은 데이터로도 높은 범용성을 확보함.

## 📖 쉽게 풀어쓴 1분 핵심
정신 건강 설문조사는 기관마다 질문 방식이나 척도가 달라 데이터를 한데 모으기가 매우 어렵습니다. 또한 개인정보 보호법 때문에 환자의 원본 데이터를 외부로 반출하는 것도 불가능합니다. 본 연구는 LLM을 활용해 다양한 형식의 설문을 공통된 자연어 문장으로 변환하고, 모델을 클라이언트와 서버로 나누어 학습시키는 '분할 학습' 방식을 제안합니다. 이를 통해 각 기관은 원본 데이터를 안전하게 유지하면서도, 서버에 있는 똑똑한 AI 모델의 학습에 참여하여 정확한 정신 건강 예측 결과를 얻을 수 있습니다.

## 🎯 배경 및 문제점
- **데이터 파편화:** 기관마다 사용하는 정신 건강 설문 도구(DASS 등)가 달라 데이터 형태가 제각각인 '데이터 이질성' 문제가 존재함.
- **개인정보 보호:** 정신 건강 데이터는 민감하여 HIPAA, GDPR 등 강력한 규제로 인해 데이터 통합 공유가 제한됨.
- **기존 방식의 한계:** 기존 모델들은 데이터 이질성을 해결하거나 개인정보를 보호하는 방식 중 하나에만 치중되어 있으며, 두 문제를 동시에 해결하면서 클라이언트의 자원 부담을 낮추는 통합 솔루션이 부족했음.

## 💡 핵심 기술 및 아키텍처
- **스키마 인식 직렬화:** 서로 다른 형식의 설문 데이터를 '질문: 응답' 형태의 자연어 문장으로 변환하여 LLM이 동일한 의미 공간에서 처리하도록 함.
- **분할 학습(Split Learning):** 무거운 LLM의 백본(Backbone)은 서버가 담당하고, 클라이언트는 가벼운 프론트엔드만 실행하여 기관 내부에서 원본 데이터를 보호함.
- **LoRA 기반 파인튜닝:** LLaMA-3.2-3B 모델에 LoRA를 적용하여 전체 파라미터의 약 0.75%만을 학습함으로써 계산 효율성을 극대화함.

## 📊 실험 결과 분석
- **성능:** 2,000개의 학습 샘플만으로도 평균 0.708의 ANLS(Average Normalized Levenshtein Similarity) 점수를 기록함.
- **효율성:** 기존 연합 학습(FL) 모델 대비 클라이언트 측 계산량을 3오더(1,000배) 가량 절감함 (FL 클라이언트 15~25GB vs 본 연구 1.3GB 수준).
- **우수성:** 연합 학습 모델과 비교하여 9개 실험 환경 중 8개에서 더 높은 성능을 보임. 다만, 모델 반전 공격(model-inversion attacks)에 대한 방어는 본 연구의 범위를 벗어난다고 명시함.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
- **의료 데이터 활용:** 병원, 학교, 기업 등 각기 다른 환경에서 수집된 정신 건강 데이터를 원본 유출 없이 안전하게 공유·분석하여 공중 보건 개선에 기여함.
- **자원 효율성:** 고성능 GPU가 부족한 현장에서도 분할 학습 방식을 통해 대규모 LLM 기반의 AI 예측 모델을 도입할 수 있는 길을 제시함.
- **범용성:** 새로운 설문조사 방식이 도입되더라도 스키마 직렬화 과정을 통해 즉각적으로 기존 시스템에 통합할 수 있는 확장성을 확보함.
