# RRSI: 에이전트 하네스의 정규화된 재귀적 자기 개선

> **원본 논문 정보**
> - **제목:** RRSI: Regularized Recursive Self-Improvement of Agent Harnesses
> - **저자:** Peng Xia, Rujun Han, Zifeng Wang, Yanfei Chen, Yufan Zhang, Yoonho Lee, Chengsong Huang, Han Yu, Zhongying CuiZhu, Yifei Ming, Huaxiu Yao, Burak Gokturk, Tomas Pfister, Chen-Yu Lee
> - **발행일:** 2026-09-21
> - **PDF 링크:** [RRSI: Regularized Recursive Self-Improvement of Agent Harnesses](https://arxiv.org/pdf/2609.24972v1)


## ✨ 3줄 핵심 요약
*   **문제점:** LLM 에이전트의 하네스(프롬프트, 도구, 메모리 등)를 자동 개선하는 기존 방식은 특정 벤치마크에 과적합되어 실제 환경에서의 일반화 성능이 저하되는 문제가 있습니다.
*   **핵심 솔루션:** 'RRSI'는 개선 제안과 선택 과정에 정규화 원리를 도입하여, 불필요하거나 특정 작업에만 치중된 하네스 수정을 방지하고 재사용 가능한 메커니즘을 강화합니다.
*   **성과:** 8개 벤치마크에서 우수한 성능 향상을 보였으며, 일반화 성능은 높이면서도 기존 방식 대비 추론 시 사용하는 정책 토큰을 30% 절감했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
LLM 에이전트는 두뇌에 해당하는 모델뿐만 아니라, 그를 둘러싼 프롬프트나 도구 사용 방식인 '하네스'의 역할이 매우 큽니다. 최근에는 AI가 스스로 자신의 하네스를 고쳐 성능을 높이는 '재귀적 자기 개선'이 시도되고 있는데, 자칫하면 특정 시험 문제만 잘 풀도록 암기(과적합)해버리는 부작용이 생깁니다. RRSI는 마치 운동선수가 특정 기술만 반복 연습하는 대신 전반적인 기초 체력을 기르도록 하는 '정규화(Regularization)' 기법을 도입했습니다. 이를 통해 AI는 더 영리하면서도, 불필요한 비용을 줄이고, 처음 보는 작업에서도 더 잘 작동하는 똑똑한 시스템으로 진화합니다.

## 🎯 배경 및 문제점
현대 LLM 에이전트는 단일 모델이 아닌 '시스템'으로 작동하며, 하네스(도구 인터페이스, 컨텍스트 관리 등)가 성능을 결정합니다. 기존에는 사람이 직접 하네스를 수정했으나, 최근에는 LLM이 스스로 성능 피드백을 받아 하네스를 반복 개선하는 자동화 기법이 등장했습니다. 하지만 이 과정에서 한정된 벤치마크 데이터만 반복 사용함에 따라, 시스템이 벤치마크의 정답이나 특정 로직을 암기하는 '적응적 과적합' 현상이 발생하여 실제 배포 환경에서의 성능이 떨어지는 문제가 지적되었습니다.

## 💡 핵심 기술 및 아키텍처
RRSI는 하네스 개선 과정에 정규화 원리를 적용한 세 가지 핵심 메커니즘을 사용합니다.
1.  **제안 단계(Proposer):** 시간 경과에 따라 수정을 제한하는 '어닐링 예산(annealed budget)'을 적용하고, 이전 진화 이력을 고려하여 탐색되지 않은 새로운 경로를 우선적으로 제안합니다.
2.  **비평 및 가지치기(Critic & Pruner):** 벤치마크별 특화된 데이터가 포함된 제안은 미리 걸러내고, 기여도가 낮거나 비용이 과도한 변경 사항은 제거합니다.
3.  **수용 단계(Selector):** 
    *   **안정성 기반 수용:** 평가 노이즈를 고려한 기준을 설정하여 불필요한 하향 수정을 방지합니다.
    *   **복잡성 기반 수용(Ridge 스타일):** 성능 향상 대비 비용 증가를 통제하여 무분별한 복잡도 증가를 억제합니다.
    *   **구조적 가지치기(Lasso 스타일):** 실질적인 성능 향상 증거가 부족한 구성 요소는 삭제하여 구조를 간결하게 유지합니다.

## 📊 실험 결과 분석
코딩, 에이전트 워크스페이스, 공학 설계 등 8개 벤치마크를 대상으로 실험한 결과입니다.
*   **성능 향상:** 진화가 진행된 벤치마크에서는 최대 14.1포인트, 학습에 사용되지 않은 5개 아웃-오브-분포(OOD) 벤치마크에서도 최대 4.7포인트의 성능 향상을 기록했습니다.
*   **효율성:** 정규화를 적용하지 않은 기존 방식보다 30% 적은 정책 토큰을 사용하면서도 더 나은 성능을 보여, 하네스의 효율성과 재사용성이 개선되었음을 증명했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
RRSI는 인공지능이 스스로 자신의 구조를 개선할 때 발생할 수 있는 '좁은 시야(과적합)' 문제를 해결함으로써, 더욱 범용적이고 효율적인 AI 에이전트를 구축할 수 있는 토대를 마련했습니다. 특히 매번 새로운 모델이 출시될 때마다 인간이 하네스를 수동으로 최적화해야 하는 비효율적인 과정을 자동화하고, 한 번 구축된 하네스가 다양한 실제 업무 환경에서 안정적으로 작동하도록 돕습니다. 다만, 본 연구는 고정된 모델 백본을 전제로 하므로 향후 모델 파라미터가 실시간으로 업데이트되는 환경에서의 추가 검증이 필요합니다.
