# JustFit: 적시 상태 관리를 통한 24 GiB 노트북에서의 200K 토큰 LLM 서비스

> **원본 논문 정보**
> - **제목:** JustFit: 200K-Token LLM Serving on a 24 GiB Laptop with Just-in-Time State Management
> - **저자:** Yuhua Chen
> - **발행일:** 2026-09-15
> - **PDF 링크:** [JustFit: 200K-Token LLM Serving on a 24 GiB Laptop with Just-in-Time State Management](https://arxiv.org/pdf/2609.17475v1)


## ✨ 3줄 핵심 요약
* **메모리 효율 극대화:** 24 GiB 메모리의 노트북에서 27B 규모의 LLM으로 200K 토큰 이상의 긴 문맥을 처리할 수 있는 추론 런타임을 구현했습니다.
* **적시 상태 관리:** KV 캐시 압축, 구성 요소별 상주 관리, 상태 보존 전환 기술을 통해 모델 가중치 양자화와 무관하게 메모리 사용량을 최적화합니다.
* **실제 성능 입증:** 기존 mlx-vlm 베이스라인 대비 문맥 처리 능력을 약 6.93배 확장하였으며, 복잡한 수학 문제 해결에서도 높은 정확도를 보였습니다.

## 📖 쉽게 풀어쓴 1분 핵심
대규모 언어 모델(LLM)을 개인용 노트북에서 돌릴 때 가장 큰 걸림돌은 모델 가중치 자체가 아니라, 질문이 길어질수록 급격히 늘어나는 '문맥(Context) 정보'가 메모리를 가득 채우는 문제입니다. **JustFit**은 모델이 계산하는 순간에만 필요한 데이터를 메모리에 올리고, 불필요한 부분은 즉시 해제하는 '적시(Just-in-time) 관리' 방식을 도입했습니다. 이를 통해 고성능 서버 없이도 개인용 노트북에서 방대한 코드나 긴 문서를 분석할 수 있는 환경을 제공합니다.

## 🎯 배경 및 문제점
개인용 기기에서 고성능 모델(27B급)을 구동하려는 수요가 늘고 있으나, 제한된 메모리(24 GiB) 환경에서 긴 문맥을 유지하며 추론하는 것은 매우 어렵습니다. 기존의 추론 방식은 문맥이 쌓일수록 메모리 한계에 쉽게 도달하여 서비스가 중단되는 문제가 있었습니다. 즉, 단순히 모델 무게를 줄이는 것만으로는 부족하며, 추론 과정 전반에서 메모리를 유연하게 관리하는 기술이 필요해졌습니다.

## 💡 핵심 기술 및 아키텍처
JustFit은 다음 세 가지 핵심 메커니즘을 결합한 MLX 기반 런타임입니다.
* **KVExec:** KV(Key-Value) 캐시 실행을 압축하여 메모리 점유를 줄입니다.
* **PhaseSwap:** 모델의 구성 요소(Head, MTP 등)가 추론 단계별로 필요한 시점에만 메모리에 상주하도록 제어합니다.
* **StateTrans:** 여러 요청이 동시에 들어올 때, 상태를 안전하게 보존하며 서비스 간 전환을 수행합니다.
이 기술들은 모델 가중치 양자화와 독립적으로 작동하여 메모리 효율을 극대화합니다.

## 📊 실험 결과 분석
* **문맥 처리 용량:** 24 GiB M4 Pro MacBook에서 Qwen3.8-27B 모델 구동 시, 212,992 토큰의 문맥을 처리하여 기존 베이스라인(30,720 토큰) 대비 약 6.93배의 성능 향상을 보였습니다.
* **수행 속도:** 32K 입력 및 64 출력 토큰 조건에서 19.11 tokens/s의 성능을 기록했습니다.
* **메모리 점유:** 32K+6K 작업 반복 시 중앙값 기준 약 16,374 MiB의 메모리를 사용했습니다.
* **추론 능력:** AIME 2026 수학 문제 30개 중 29개를 정확히 해결하며 긴 문맥 기반 추론의 유효성을 증명했습니다.
*(참고: 논문에서는 각 메커니즘을 분리하여 테스트한 결과는 보고하지 않았습니다.)*

## 🌍 세상에 미치는 영향 & 실무 적용 사례
개인용 노트북에서 서버급의 긴 문맥 처리가 가능해짐에 따라, 민감한 데이터를 외부 서버로 전송하지 않고도 로컬 환경에서 안전하게 대규모 코드를 분석하거나 복잡한 추론 작업을 수행할 수 있습니다. 이는 개인 정보 보호를 중시하는 개발 환경이나 에너지 효율적인 AI 구동을 실현하는 데 기여하며, 향후 더 나은 메모리 관리 기반의 로컬 AI 서비스 모델을 제시합니다.
