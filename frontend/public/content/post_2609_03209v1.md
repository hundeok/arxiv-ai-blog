# 질문에서 증거로: 통제된 데이터 분석을 위한 소형 분석 대수

> **원본 논문 정보**
> - **제목:** MasterControl Seventeen Every Time
> - **저자:** MasterControl AI Lab
> - **발행일:** 2026-09-02
> - **PDF 링크:** [MasterControl Seventeen Every Time](https://arxiv.org/pdf/2609.03209v1)


## ✨ 3줄 핵심 요약
* 언어 모델은 사용자의 질문 의도를 해석하는 역할만 수행하고, 실제 분석 방법과 절차는 미리 검증된 '결정론적 정책'을 통해 선택합니다.
* 분석 결과값뿐만 아니라 그 결과가 도출된 근거, 데이터 스냅샷, 정책 버전 등을 포함한 '분석 계약(Contract)'을 제공하여 재현성을 보장합니다.
* 440번의 실험 결과, 런타임에 직접 분석 절차를 생성하는 모델보다 정책 기반의 분석기가 훨씬 더 정확하게 분석 계약을 준수했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
데이터 분석에서 숫자 '17'이 나왔을 때, 이 숫자가 의미하는 바(어떤 데이터를, 어떤 기준으로, 어떤 기간 동안 계산했는지)를 보존하는 것은 매우 어렵습니다. 이 논문은 언어 모델이 분석 방법까지 스스로 설계하게 두는 대신, '질문 해석'은 모델에게 맡기고 '분석 방법'은 사전에 승인된 프로그램에서 가져오도록 강제하는 아키텍처를 제안합니다. 이렇게 하면 분석 과정이 항상 동일하게 작동하여 결과에 대한 완벽한 추적과 재현이 가능해집니다.

## 🎯 배경 및 문제점
데이터 분석 시 질문에 따라 매번 새로운 측정 방식을 모델이 스스로 생성하게 하면, 결과값의 의미가 변질되거나 일관성을 잃기 쉽습니다. 특히 '지난주', '온도 일탈'과 같은 표현은 해석 주체에 따라 범주나 계산 방식이 달라질 수 있습니다. 기존의 런타임 계획(Runtime-planning) 방식은 모델이 데이터 결합, 필터링, 연산 순서를 마음대로 설계하므로 분석 결과의 정합성을 보장하기 어렵다는 점이 문제로 지적되었습니다.

## 💡 핵심 기술 및 아키텍처
* **분석 계약 (Analytical Contract):** 결과값(v)과 관리되는 의미(m), 증거(E)를 하나로 묶어 제공합니다.
* **결정론적 정책 (Deterministic Policy):** 모델이 해석한 질문을 입력받아, 미리 정의된 분석 프로그램 템플릿 중 승인된 것만을 매핑합니다. 모델이 직접 SQL을 생성하거나 분석 단계를 구성하지 못하게 차단합니다.
* **재현성 보장:** 데이터 스냅샷, 정책 버전, 커널 상태 등이 고정되어 있으면, 동일한 질문에 대해 항상 동일한 결과와 증거가 출력되도록 설계되었습니다.

## 📊 실험 결과 분석
* **실험 조건:** 11가지 분석 작업(카운트, 그룹화, 랭킹 등)을 대상으로 440번의 실험 수행.
* **비교 방식:** 
    1. 런타임 계획 모델(Qwen3-8B, Ministral-3-8B, Granite-4.1-8B)이 스스로 분석 절차를 생성.
    2. 정책 기반 분석기(Qwen3-8B가 해석 후 사전에 작성된 프로그램 실행).
* **결과:** 330번의 런타임 계획 에피소드 중 완벽한 계약을 준수한 사례는 0건이었으나, 정책 실행 분석기는 110번의 에피소드에서 110번 모두 성공했습니다. (단, 이 결과는 특정 설정에 국한된 것이며 범용적인 증명은 아님을 논문에서 명시함)

## 🌍 세상에 미치는 영향 & 실무 적용 사례
기업 환경에서 데이터 분석의 투명성과 신뢰성을 확보하는 데 중요한 이정표를 제시합니다. 특히 제약, 제조, 금융과 같이 데이터 해석의 정확성과 증거 보존(Audit Trail)이 필수적인 분야에서, AI 모델의 유연한 자연어 처리 능력과 규격화된 분석 시스템을 결합하여 '설명 가능한 데이터 분석'을 실현할 수 있습니다. 무분별한 모델 주도 분석보다는 '승인된 분석 프로그램의 조합'이 실무적 안정성을 높인다는 설계 원칙을 강조합니다.
