# 커널제로: 지속적인 GPU 커널 생성을 위한 제안자와 코더의 상호 진화

> **원본 논문 정보**
> - **제목:** KernelZero: Co-Evolving Proposer and Coder for Continuously Improved GPU Kernel Generation
> - **저자:** Changxin Ke, Rui Zhang, Zixiang Fang, Zhenghong Li, Yuanbo Wen, Jiashuo Shen, Shuo Wang, Jiaming Guo, Ling Li, Qi Guo, Yunji Chen
> - **발행일:** 2026-09-27
> - **PDF 링크:** [KernelZero: Co-Evolving Proposer and Coder for Continuously Improved GPU Kernel Generation](https://arxiv.org/pdf/2609.33074v1)


## ✨ 3줄 핵심 요약
* **KernelZero**는 GPU 커널 생성의 정확성과 효율성을 동시에 최적화하기 위해, PyTorch 모듈을 생성하는 '제안자(Proposer)'와 이를 커널로 변환하는 '코더(Coder)'를 공동 진화시키는 프레임워크입니다.
* '프런티어 기반 모듈 생성'과 '정확성 인지 그룹 상대 정책 최적화(CA-GRPO)'를 통해 모델의 현재 취약점에 맞춤화된 학습 데이터를 자동으로 생성하고 최적화합니다.
* KernelBench 테스트에서 Claude-4.5-Sonnet 및 DeepSeek-V4-Pro를 상회하는 고성능 CUDA 및 Triton 커널 생성 능력을 입증했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
GPU에서 돌아가는 고성능 프로그램인 '커널'을 AI가 직접 짜는 것은 매우 어렵습니다. 기존 방식은 데이터가 부족하거나, 코드가 맞으면 성능이 떨어지고 성능을 쫓으면 오류가 나는 '정확성-성능 간의 딜레마'에 빠져 있었습니다. **KernelZero**는 이 문제를 해결하기 위해 두 명의 전문가를 협업시켰습니다. 하나는 어떤 기능을 구현할지 기획하는 '제안자'이고, 다른 하나는 실제로 코드를 짜는 '코더'입니다. 이 둘은 서로의 약점을 보완하며 함께 발전하며, 정확성이 확보된 뒤에만 성능을 극대화하는 전략을 사용해 매우 빠르고 정확한 GPU 코드를 스스로 만들어냅니다.

## 🎯 배경 및 문제점
* **데이터 부족:** 현재 모델의 능력치와 일치하는 고품질 학습 데이터가 부족하여 학습 효율이 낮습니다.
* **딜레마:** 커널 생성 시 정확성만을 강조하면 성능 향상이 제한적이고, 성능을 최우선으로 하면 코드 오류 가능성이 급격히 커집니다.
* **복잡성:** CUDA나 Triton 같은 도메인 특화 언어와 컴퓨터 아키텍처에 대한 깊은 이해가 필수적이라 자동화가 매우 까다롭습니다.

## 💡 핵심 기술 및 아키텍처
* **공동 진화(Co-evolution) 프레임워크:** 제안자와 코더를 번갈아 최적화하여 점진적으로 실력을 향상시키는 교육 커리큘럼을 자동으로 구축합니다.
* **프런티어 기반 모듈 생성:** 코더의 현재 약점을 분석하여 이에 특화된 PyTorch 학습 모듈을 생성합니다.
* **CA-GRPO (Correctness-Aware Group Relative Policy Optimization):** 코드의 정확성이 충분히 검증된 후에만 성능 최적화 단계로 진입하도록 하여 안정성을 확보합니다.

## 📊 실험 결과 분석
* **성능 우위:** KernelZero-7B 모델은 CUDA 생성 분야에서 Claude-4.5-Sonnet을, Triton 생성 분야에서는 DeepSeek-V4-Pro를 능가했습니다.
* **정확도(pass@1):** 
    * KernelBench Level 1/2 기준 CUDA 코드의 pass@1은 각각 75.8%, 69.6%입니다.
    * Triton 코드의 pass@1은 각각 77.2%, 72.5%를 기록했습니다.
* **최대 정확도(pass@10):** CUDA 코드의 경우 pass@10 기준 Level 1은 100%, Level 2는 97%의 높은 성공률을 보였습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **개발 생산성 향상:** 전문적인 GPU 커널 작성에 필요한 높은 진입 장벽을 낮춰 머신러닝 시스템 최적화 시간을 대폭 단축할 수 있습니다.
* **최적화 자동화:** 모델 학습 및 추론 과정에서 가장 핵심적인 연산 커널을 상황에 맞춰 최적으로 자동 생성함으로써, 하드웨어 활용도와 실행 속도를 극대화할 수 있습니다.
* **실무적 유연성:** 하드웨어 아키텍처(NVIDIA A100 등)의 특성을 고려한 타일링, 융합, 파이프라이닝 등의 최적화 기법을 자동으로 적용하여 대규모 모델 학습의 효율성을 개선합니다.
