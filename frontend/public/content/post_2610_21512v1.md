# QREF: 쿼리 개선 및 증거 필터링을 통한 딥서치 에이전트의 추론과 검색 정렬

> **원본 논문 정보**
> - **제목:** QREF: Improving DeepSearch Agents by Aligning Search with Reasoning via Query Refinement and Evidence Filtering
> - **저자:** Yujia Chen, Yuhui Wang, Junzhe Wang, Shihan Dou, Di Liang, Yujiong Shen, Yuhao Zhou, Zhiheng Xi, Ming Zhang, Senjie Jin, Jiayi Chen, Dingwei Zhu, Yajie Yang, Yuan Hua, Chenyao Lu, Tao Gui, Qi Zhang, Xuanjing Huang
> - **발행일:** 2026-10-15
> - **PDF 링크:** [QREF: Improving DeepSearch Agents by Aligning Search with Reasoning via Query Refinement and Evidence Filtering](https://arxiv.org/pdf/2610.21512v1)


## ✨ 3줄 핵심 요약
* **문제점:** 딥서치 에이전트가 생성하는 중간 검색 쿼리는 의도가 불분명하거나 중복되는 경우가 많아 검색 효율을 떨어뜨리고 노이즈를 축적함.
* **해결책:** 쿼리를 정교하게 다듬는 'Query Refiner'와 관련 없는 정보를 제거하는 'Evidence Filter'로 구성된 플러그앤플레이 모듈 'QREF'를 개발함.
* **성과:** 4개 벤치마크에서 성능 향상을 입증했으며, WebSailor에서 33.55%, TongyiDeepResearch에서 11.04%의 Pass@1 개선을 달성함.

## 📖 쉽게 풀어쓴 1분 핵심
인공지능 에이전트가 복잡한 문제를 풀 때 웹 검색을 활용하는데, 이때 AI가 검색창에 입력하는 문장(쿼리)이 너무 모호하거나 엉뚱하면 좋은 정보를 찾기 어렵습니다. 본 논문은 이 '검색 쿼리'의 품질을 높이는 데 집중했습니다. AI가 던진 질문을 다시 작성하여 구체적으로 바꾸고, 검색 결과 중 불필요한 정보는 골라내는 필터를 적용했습니다. 결과적으로 AI는 더 정확한 근거를 찾고, 효율적으로 문제를 해결하게 됩니다.

## 🎯 배경 및 문제점
* 딥서치 에이전트는 추론과 검색을 반복하며 정보를 수집하지만, 중간 단계의 쿼리 품질 관리에 대한 연구는 부족했음.
* 300개의 에이전트 추론 과정을 분석한 결과, 세 가지 주요 실패 패턴이 발견됨:
    1. **변별력 부족:** 검색 의도를 충분히 담지 못함.
    2. **낮은 구체성:** 질문이 지나치게 포괄적임.
    3. **중복성:** 검색 배치 내의 쿼리들이 서로 보완적이지 못함.
* 분석 대상의 47.04% 배치에서 최소 한 가지 이상의 오류가 발생했으며, 실패하는 에이전트는 성공하는 에이전트보다 약 3배 많은 비효율적 쿼리를 생성함.

## 💡 핵심 기술 및 아키텍처
* **Query Refiner (쿼리 개선기):** LLM 기반 모듈로, 쿼리를 자체 완결적이고 구체적으로 수정함. 불필요한 중복을 제거하고 검색 엔진 친화적인 연산자를 적절히 활용함.
* **Evidence Filter (증거 필터):** 검색 결과로 나온 문서 조각들이 현재 추론 목적과 일치하는지 평가하여 유효한 정보만 남기고 노이즈를 제거함.
* **학습 전략:** 지도 학습(SFT)으로 초기화한 후, 실제 웹 환경에서의 상호작용을 통한 강화 학습(RL)으로 쿼리 개선기의 성능을 최적화함.

## 📊 실험 결과 분석
* **성능 향상:** QREF 적용 시, 기반 모델(Backbone) 수정 없이도 4개 벤치마크에서 전반적인 추론 성능이 향상됨.
* **쿼리 품질:** 
    * '낮은 쿼리 구체성' 오류가 95% 감소함.
    * 비효율적 쿼리 비율이 크게 낮아짐.
    * 쿼리 간 중복도(IoU)가 0.41에서 0.29로 감소하여 검색의 다양성이 확보됨.
* **모듈 효과:** Query Refiner와 Evidence Filter를 동시에 사용했을 때 가장 좋은 성능을 보였으며, 둘은 상호 보완적인 역할을 함.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **에이전트 효율성 제고:** 검색 과정의 비효율성을 줄임으로써 AI 에이전트가 방대한 데이터를 더 빠르게 처리하고 정확한 결론에 도달하도록 도움.
* **실무 적용:** 웹 기반 조사 시스템, 자동화된 연구 보조 도구, 지식 집약적 정보 검색 모델 등 검색 성능이 중요한 모든 AI 에이전트 기반 서비스에 즉시 적용 가능한(Plug-and-play) 구조를 제공함.
