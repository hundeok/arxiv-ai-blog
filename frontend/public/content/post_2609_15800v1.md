# 희소한 증거 탐색: 명시적 문맥 선택 및 통합을 통한 에이전트 기반 시각적 RAG

> **원본 논문 정보**
> - **제목:** Navigating Sparse Evidence: Agentic Visual RAG via Explicit Context Selection and Consolidation
> - **저자:** Yucheng Shen, Lingyong Yan, Jiulong Wu, Shuaiqiang Wang, Jianmin WU, Dawei Yin, Min Cao
> - **발행일:** 2026-09-14
> - **PDF 링크:** [Navigating Sparse Evidence: Agentic Visual RAG via Explicit Context Selection and Consolidation](https://arxiv.org/pdf/2609.15800v1)


## ✨ 3줄 핵심 요약
- 시각적 검색 증강 생성(VRAG)에서 정보의 분산과 불명확한 증거 조직 문제를 해결하기 위해 'SCORE' 프레임워크를 제안했습니다.
- 탐색 과정에서 관련 정보를 선별하여 텍스트 원장에 기록하고, 최종 단계에서 원본 이미지를 재구성하여 증거를 논리적으로 통합합니다.
- 실험 결과, 기존의 벤치마크들에서 모델 규모와 관계없이 최신(SOTA) 정확도를 달성했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
기존의 시각적 RAG 시스템은 복잡한 문서(PDF, 슬라이드 등)에서 정보를 찾을 때, 너무 많은 정보 속에서 정작 중요한 증거를 놓치거나 여러 페이지에 흩어진 정보를 제대로 연결하지 못하는 문제가 있었습니다. 'SCORE'는 탐색 중에는 필요한 정보만 텍스트 원장에 메모해두었다가, 정답을 생성하기 직전에 관련 이미지를 다시 불러와 논리적인 순서로 정렬합니다. 이를 통해 모델은 산만한 탐색 과정에 휘둘리지 않고, 증거에 기반한 정확한 추론을 수행할 수 있게 됩니다.

## 🎯 배경 및 문제점
- **증거 분포의 불균형:** 시각적 문서에서 답변의 근거가 되는 정보는 특정 페이지의 아주 작은 영역에 몰려 있거나, 여러 페이지에 걸쳐 파편화되어 있어 발견이 어렵습니다.
- **암묵적인 증거 조직:** 기존 에이전트 방식은 탐색 과정의 노이즈가 섞인 상태에서 답을 생성하여, 증거와 추론 사이의 연결 고리가 불명확해지는 문제가 있습니다.

## 💡 핵심 기술 및 아키텍처
- **SCORE (Selection and COnsolidation for Robust Evidence):** 탐색과 통합을 분리한 에이전트 루프입니다.
- **텍스트 원장(Textual Ledger):** 탐색 중 발견한 관련 정보와 출처 포인터만을 기록하여 시각적 문맥을 효율적으로 관리합니다.
- **명시적 통합(Consolidation):** 답변 생성 단계에서 참조된 원본 이미지를 다시 불러와 논리적 순서로 재구성함으로써, 시각적 근거(Visual Grounding)를 확보합니다.
- **최적화 전략:** '필터링된 콜드 스타트 궤적 증류'와 '증거 기반 강화 학습'을 결합하여 증거의 커버리지, 통합의 간결성, 답변의 정확도를 동시에 향상시킵니다.
- **Crop-and-Zoom:** 이미지 내 작은 글씨나 표를 읽기 위해 특정 영역을 고해상도로 재촬영하는 기술을 적용했습니다.

## 📊 실험 결과 분석
- 3개의 기존 VRAG 벤치마크에서 평가를 진행했습니다.
- 모든 벤치마크에서 모델의 규모(Backbone scales)에 상관없이 최신(SOTA) 정확도를 기록했습니다.
- 제안한 학습 방식(콜드 스타트 증류 및 강화 학습)의 각 단계가 모두 성능 향상에 기여함을 확인했습니다.
- 정확한 수치는 논문 발췌문에 구체적으로 명시되어 있지 않습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
- **문서 이해의 정밀도 향상:** 보고서, 슬라이드, 스캔된 PDF 등 복잡한 시각 자료에서 정확한 정보를 추출해야 하는 금융, 법률, 학술 분야에 적용 가능합니다.
- **추론 과정의 투명성:** 증거가 명확하게 인덱싱되고 재구성되므로, 왜 모델이 그러한 답변을 내놓았는지 추적(Grounding)할 수 있어 AI의 신뢰성을 높입니다.
- **실무 적용:** 시각적 데이터가 많은 기업 내부 지식 베이스 검색 시스템에서 파편화된 자료를 연결하여 최종적인 인사이트를 도출하는 데 유용하게 활용될 수 있습니다.
