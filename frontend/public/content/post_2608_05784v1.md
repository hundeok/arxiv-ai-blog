# 활동 프레임: 에이전트 메모리와 재실행을 위한 결정론적 화면 활동 컴파일

> **원본 논문 정보**
> - **제목:** Activity Frames: Deterministic Screen-Activity Compilation for Agent Memory and Replay
> - **저자:** Nossa Iyamu
> - **발행일:** 2026-08-06
> - **PDF 링크:** [Activity Frames: Deterministic Screen-Activity Compilation for Agent Memory and Replay](https://arxiv.org/pdf/2608.05784v1)


## ✨ 3줄 핵심 요약
* 사용자 활동 기록(화면 캡처 등)을 AI 모델 없이 '활동 프레임(Activity Frames)'이라는 구조화된 데이터로 변환하는 결정론적 컴파일러를 제안합니다.
* 기존 LLM 요약 방식보다 메모리 효율이 86배 높고, 질문 답변 정확도는 98.4%로 훨씬 우수하며, 결과값이 매번 동일(결정론적)하게 도출됩니다.
* 이 방식은 모델의 추론 비용을 획기적으로 줄여주며, 에이전트가 사용자의 실제 행동을 정확하게 이해하고 재실행할 수 있도록 돕습니다.

## 📖 쉽게 풀어쓴 1분 핵심
현재의 AI 에이전트는 사용자가 '말한 것'은 기억하지만, 실제로 컴퓨터에서 '무엇을 했는지'는 잘 모릅니다. 이를 파악하기 위해 화면 캡처를 LLM에 전부 맡기면 비용이 너무 많이 들고, 매번 답변이 바뀌거나 엉뚱한 내용을 지어내는(환각) 문제가 발생합니다. 본 논문은 AI 모델을 쓰지 않고도 단순한 코드(컴파일러)를 이용해 캡처 데이터를 '활동 프레임'으로 변환합니다. 이는 마치 컴퓨터가 이해하기 쉬운 요약본을 만드는 것과 같아서, AI 에이전트가 훨씬 저렴한 비용으로도 정확하게 과거 활동을 파악하고 재실행할 수 있게 합니다.

## 🎯 배경 및 문제점
* **기억의 부재:** 현재의 에이전트는 대화 내용에만 의존하며, 사용자가 특정 앱에서 보낸 시간이나 작업 흐름 같은 '행동적 에피소드'를 인식하지 못합니다.
* **비효율적 소비:** 원시 캡처 데이터를 직접 처리하면 토큰 소비량이 너무 많고, LLM 요약은 모델의 성능에 따라 결과가 불안정하며 신뢰할 수 없는 정보를 생성합니다.
* **비용 문제:** 에이전트가 행동을 매번 재학습하거나 추론하게 만드는 것은 자원 낭비가 심합니다.

## 💡 핵심 기술 및 아키텍처
* **결정론적 컴파일(Deterministic Compilation):** 모델을 거치지 않는 알고리즘을 사용합니다. 입력 데이터가 같으면 항상 동일한 출력(Byte-identical)을 내놓으므로, 결과를 캐싱할 수 있고 감사가 가능합니다.
* **활동 프레임(Activity Frames):** 원시 캡처 데이터를 애플리케이션, 사이트, 타이밍, 입력량 등 의미 있는 정보 단위로 세분화하여 구조화한 데이터 형태입니다.
* **인프라화:** 68ms의 빠른 처리 속도와 모델 사용량 0(zero-model)을 달성하여, 메모리 기록 과정을 지능형 추론이 아닌 단순 인프라 영역으로 전환했습니다.

## 📊 실험 결과 분석
* **성능 향상:** 128,756개의 프레임을 처리한 결과, 원시 데이터를 프롬프트용 데이터 블록으로 86배 압축했습니다.
* **높은 정확도:** 독립적인 SQL 오라클(검증 도구)과 비교 시, 활동 프레임 기반 에이전트는 98.4%의 질문 답변 정확도를 기록했습니다. 반면, 동일한 데이터를 LLM이 요약했을 때는 66~80% 수준에 그쳤습니다.
* **비용 절감:** 추론 시 모델의 성능 격차를 무효화하여, 낮은 사양의 모델도 고사양 모델과 동일한 품질의 답변을 도출할 수 있게 했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **에이전트 비용 최적화:** '루틴 오버헤드 비율(R)'과 '루틴 재발률(h)'을 실측할 수 있게 되어, 에이전트 운용 비용을 예측하고 줄이는 데 기여합니다.
* **신뢰성 확보:** 인간이 수행한 실제 작업을 객관적으로 기록하고 재실행할 수 있어, AI 에이전트가 사용자의 루틴을 정확하게 대행하는 실무 자동화의 토대가 됩니다.
* **오픈 소스:** 스키마, 컴파일러, 평가 도구 일체를 공개하여 관련 시스템들이 표준화된 방식으로 사용자 활동을 기록하고 교환할 수 있는 길을 열었습니다.
