# 거대 언어 모델 사전 학습에서 도메인 데이터 반복의 스케일링

> **원본 논문 정보**
> - **제목:** Scaling Domain Data Repetition in LLM Pretraining
> - **저자:** Jingwei Li, Xinran Gu, Rui Dai, Xintong Hao, Chengyin Xu, Yan Wu, Shuran Zheng, Jingzhao Zhang
> - **발행일:** 2026-08-14
> - **PDF 링크:** [Scaling Domain Data Repetition in LLM Pretraining](https://arxiv.org/pdf/2608.14071v1)


## ✨ 3줄 핵심 요약
* 모델 크기 증가에 맞춰 학습 토큰 예산을 비례적으로 늘릴 때(고정 TPP), 도메인 데이터의 최적 반복 횟수는 모델 규모가 커짐에 따라 완만하게 증가합니다.
* 특정 도메인의 최적 반복 횟수는 해당 도메인의 검증 손실(Validation Loss)과 강한 음의 상관관계를 가지며, 손실이 낮을수록 더 많은 반복을 수용할 수 있습니다.
* 데이터 내 고유 샘플의 비율보다는 도메인 특성과 모델 규모가 최적 반복 횟수를 결정하는 핵심 요소이며, 소형 모델에서 구한 값을 대형 모델의 보수적 추정치로 활용 가능합니다.

## 📖 쉽게 풀어쓴 1분 핵심
거대 언어 모델(LLM)을 학습시킬 때 고품질의 전문 데이터(수학, 코드 등)는 구하기 어렵습니다. 이 때문에 학습 예산이 늘어날수록 전체 데이터에서 이 고품질 데이터의 비중이 낮아지는 문제가 발생합니다. 연구진은 이 부족한 데이터를 '반복 학습'시켜 보완하는 전략을 분석했습니다. 결론적으로, 단순히 데이터를 많이 반복하는 것보다 모델의 크기와 도메인의 난이도를 고려해야 합니다. 특히, 학습이 잘되는(손실이 낮은) 도메인일수록 더 많이 반복해도 모델이 과적합되지 않고 효과적으로 학습된다는 사실을 밝혀냈습니다.

## 🎯 배경 및 문제점
LLM의 규모가 커짐에 따라 최적의 성능을 내기 위해 필요한 학습 토큰 수도 증가합니다. 그러나 일반적인 웹 데이터와 달리 고품질 도메인 데이터는 확보가 어려워, 학습 전체 과정에서 차지하는 비중이 점점 희석됩니다. 이를 해결하기 위해 데이터를 반복 학습시키면 과적합의 위험이 따르는데, 기존 연구들은 데이터 양을 고정하고 비교하여 반복을 최소화해야 한다는 결론을 내렸습니다. 본 연구는 실제 LLM 학습 환경처럼 모델 크기에 따라 토큰 예산이 늘어나는(고정 TPP) 상황에서의 최적 반복 전략을 재조명합니다.

## 💡 핵심 기술 및 아키텍처
* **고정 TPP(Tokens-per-parameter) 환경:** 모델 규모가 커짐에 따라 학습 데이터 예산도 함께 비례해서 늘어나는 현실적인 스케일링 환경을 설정했습니다.
* **데이터 반복 메커니즘:** 고품질 도메인 데이터의 고유 비율($\alpha$)과 반복 횟수($e$)를 조절하며 검증 손실의 변화를 측정했습니다.
* **최적 반복 횟수 추정:** 검증 손실 함수를 2차 함수로 피팅하여 그 최솟값을 최적의 반복 횟수로 도출하는 방식을 사용했습니다.
* **학습률 스케줄링의 영향:** WSD(Warmup-Stable-Decay) 스케줄 등 다양한 학습률 전략이 반복 횟수 허용 범위에 미치는 영향을 비교 분석했습니다.

## 📊 실험 결과 분석
* **도메인 특성:** 수학(Math) 도메인은 반복 횟수가 약 5회일 때 손실이 최소화되는 등 도메인별로 최적값이 뚜렷하게 차이 납니다.
* **상관관계 지표:** 최적 반복 횟수는 최소 검증 손실과 -0.944의 매우 강한 음의 상관관계를 보였으며, 모델 크기와는 0.400의 약한 양의 상관관계를 보였습니다. 고유 데이터 비율($\alpha$)과의 상관관계는 0.018로 사실상 무관했습니다.
* **학습률 효과:** 학습률 감쇠(Decay)를 늦추거나 일정하게 유지할수록 과적합 없이 더 많은 반복 횟수를 견딜 수 있음을 확인했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **데이터 전략 최적화:** LLM 개발자는 소형 프록시 모델에서 도메인 데이터의 최적 반복 횟수를 미리 계산하여, 대형 모델 학습 시 자원 낭비 없이 성능을 극대화할 수 있습니다.
* **학습 효율 향상:** 부족한 고품질 데이터를 효과적으로 재활용하는 가이드라인을 제공함으로써, 데이터 수집 비용이 높은 전문 분야(의료, 법률, 수학 등)의 모델 성능 개선에 기여할 수 있습니다.
* **실무 적용:** 모델 학습 시 학습률 스케줄과 데이터 반복 횟수를 동적으로 조절하여 과적합을 방지하고 도메인 지식 습득 효율을 높이는 실질적인 레시피로 활용 가능합니다.
