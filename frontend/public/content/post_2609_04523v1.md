# MaxKernel: TPU를 위한 에이전트 기반 커널 생성

> **원본 논문 정보**
> - **제목:** MaxKernel: Agentic Kernel Generation for TPUs
> - **저자:** Shangkun Wang, Nina Cai, Charles Hoong, Julian Walker, Gerson Kroiz, George Vanica, Deepak Patil, Andi Gavrilescu, Hassan Sipra, Sethu Sankaran
> - **발행일:** 2026-09-03
> - **PDF 링크:** [MaxKernel: Agentic Kernel Generation for TPUs](https://arxiv.org/pdf/2609.04523v1)


## ✨ 3줄 핵심 요약
*   **MaxKernel**은 하드웨어 수준의 전문 지식이 필요한 TPU 커널 개발을 자동화하는 다중 에이전트 프레임워크입니다.
*   인간 협업(HITL), 완전 자동화(Auto), 그래프 기반 탐색의 3가지 모드로 커널 설계, 컴파일, 테스트, 최적화를 수행합니다.
*   JaxBench 및 최신 모델(DeepSeek-V4 등) 실험에서 사람이 직접 튜닝한 베이스라인을 뛰어넘는 성능 개선을 입증했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
TPU와 같은 고성능 하드웨어에서 최상의 성능을 뽑아내려면 개발자가 직접 메모리 관리와 연산 파이프라인을 최적화하는 '커널 프로그래밍'이 필수적입니다. 하지만 이는 매우 복잡하고 전문적인 영역입니다. MaxKernel은 AI 에이전트들이 협력하여 이 과정을 대신해 주는 시스템입니다. 마치 숙련된 엔지니어처럼 코드를 작성하고, 하드웨어 성능 데이터를 분석하며, 오류가 발생하면 스스로 수정하는 과정을 반복하여 최적의 커널을 찾아냅니다.

## 🎯 배경 및 문제점
딥러닝 모델이 커지면서 특정 하드웨어에 최적화된 커널 개발 수요가 급증했습니다. 기존의 표준 컴파일러 파이프라인만으로는 성능 한계가 있어 수동 최적화가 필요하지만, 다음과 같은 문제들이 존재합니다.
*   **높은 진입장벽:** HBM(고대역폭 메모리)과 SRAM 간의 데이터 이동 관리, DMA 파이프라이닝 등 하드웨어 구조에 대한 깊은 이해가 필수적입니다.
*   **반복 작업의 어려움:** 컴파일러 오류가 모호하고 메모리 제약이 엄격하여, 함수를 수정하고 성능을 측정하는 반복적인 프로파일링 과정에 막대한 시간이 소요됩니다.

## 💡 핵심 기술 및 아키텍처
MaxKernel은 '공유 하위 에이전트(Sub-agents)'를 활용하여 다음과 같은 3가지 개발 패러다임을 지원합니다.
1.  **HITL(Human-in-the-Loop):** 인간 개발자와 협력하여 단계별로 커널을 설계합니다.
2.  **Autonomous(Auto) Agent:** 지표 및 추적 데이터를 기반으로 스스로 최적화 루프를 실행합니다.
3.  **그래프 기반 자동 탐색:** 최적화 공간을 효율적으로 탐색하기 위해 커널의 상태를 노드(코드, 계획, 지표)로 표현한 그래프를 구축합니다. 이를 통해 병렬 탐색과 빔 서치(Beam Search)를 수행하며, LLM의 문맥 창 제한 문제를 효과적으로 방지합니다.

## 📊 실험 결과 분석
50개의 TPU 워크로드(JaxBench)와 최신 오픈소스 모델을 대상으로 테스트한 결과입니다.
*   **MLA v1:** 기존 수동 Pallas 구현 대비 지연 시간 8.68% 감소, 처리량 9.50% 증가.
*   **Qwen3-Next GDN:** 학습 단계(Fwd+Bwd) 전체 속도가 최대 4.70배 향상.
*   **DeepSeek-V4 Sparse Attention:** 베이스라인 대비 2.36배에서 최대 7.85배까지 성능 개선.
*   **기타:** Mamba v2(1.10배), StreamIndex_topk(1.66배) 등의 성능 향상을 확인했습니다. 또한, Ragged Page Attention v3의 크래시 문제를 보호 로직 추가를 통해 스스로 해결하는 등 강력한 디버깅 능력을 보였습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
MaxKernel은 복잡한 가속기 프로그래밍의 문턱을 낮추어 엔지니어들이 더 짧은 시간 안에 고성능 모델을 배포할 수 있게 돕습니다. 특히, 최신 LLM 아키텍처에서 발생하는 성능 병목을 자동화된 방식으로 해결할 수 있어, 하드웨어 활용도를 극대화하려는 AI 인프라 분야에 큰 기여를 할 것으로 기대됩니다. 현재 해당 기술은 오픈소스로 공개되어 누구나 접근 가능합니다.
