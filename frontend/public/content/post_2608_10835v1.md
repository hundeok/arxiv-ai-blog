# UniProbe: 다중 구조 내부 표현을 활용한 거대 시각-언어 모델용 학습 가능한 토큰 단위 환각 탐지기

> **원본 논문 정보**
> - **제목:** UniProbe: A Learnable Token-Level Hallucination Detector for Large VLMs using Multi-Structural Internal Representations
> - **저자:** Dvir Samuel, Guy Bar-Shalom, Fabrizio Frasca, Ethan Fetaya, Yftah Ziser, Gal Chechik, Haggai Maron
> - **발행일:** 2026-08-11
> - **PDF 링크:** [UniProbe: A Learnable Token-Level Hallucination Detector for Large VLMs using Multi-Structural Internal Representations](https://arxiv.org/pdf/2608.10835v1)


## ✨ 3줄 핵심 요약
* **UniProbe**는 거대 시각-언어 모델(LVLM)의 내부 연산 흔적을 그래프로 구조화하여 토큰 단위로 환각을 탐지하는 경량화된 학습형 탐지기입니다.
* GNN, ViT, GRU를 결합해 시각적 관계, 공간적 배치, 생성 순서 정보를 동시에 학습함으로써 기존 방식보다 정교한 탐지 성능을 제공합니다.
* 실시간 스트리밍 모드를 통해 생성 과정에서 환각을 즉시 탐지하고 재생성함으로써, 모델의 기본 성능은 유지하면서도 객체 환각을 최대 55%까지 감소시킵니다.

## 📖 쉽게 풀어쓴 1분 핵심
AI 모델이 이미지에는 없는 내용을 있는 것처럼 말하는 '환각(Hallucination)' 현상은 신뢰성 측면에서 큰 문제입니다. 기존의 해결책들은 모델 전체를 다시 훈련해야 하거나, 모델이 생성하는 과정을 깊이 이해하지 못한다는 한계가 있었습니다. 

UniProbe는 모델이 내부적으로 처리하는 '연산의 흔적(이미지 조각, 질문, 생성된 단어 간의 관계)'을 그래프 형태로 분석합니다. 이를 통해 단순히 결과값만 보는 것이 아니라, 모델이 어떤 근거로 그 단어를 선택했는지 추적합니다. 마치 AI의 사고 과정을 들여다보는 것과 같아, 환각이 발생할 때 이를 실시간으로 포착해 수정할 수 있습니다. 

## 🎯 배경 및 문제점
거대 시각-언어 모델(LVLM)은 뛰어난 추론 능력을 갖췄음에도 불구하고, 시각적 정보와 무관하거나 상충하는 텍스트를 생성하는 환각 문제가 빈번합니다. 효과적인 대응을 위해서는 응답 전체를 버리는 대신 환각이 발생한 특정 토큰만 정밀하게 찾아내야 합니다. 

기존 연구들은 다음과 같은 문제점이 있었습니다.
* 모델 전체를 다시 훈련(Fine-tuning)하는 방식은 비용이 너무 많이 듭니다.
* 외부 검증 도구는 모델 내부의 생성 과정을 간과합니다.
* 기존 내부 신호 분석 방식은 공간적, 순차적 정보를 단순화하여 모델의 복잡한 추론 구조를 제대로 반영하지 못합니다.

## 💡 핵심 기술 및 아키텍처
UniProbe는 고정된(frozen) LVLM의 내부 상태를 읽어오는 구조로, 세 가지 핵심 모듈이 상호작용합니다.
1. **관계 추적 그래프 (GNN):** 이미지 조각, 질문 토큰, 생성된 토큰 사이의 주의(Attention) 관계를 구조화합니다.
2. **공간 및 순차 모듈:** 이미지의 기하학적 배치를 분석하는 **ViT**와 생성 순서의 맥락을 파악하는 **GRU**를 교차 배치하여 구조적 특징을 극대화합니다.
3. **자기 적응 전략:** 실제 모델의 생성 분포에 맞춰 환각을 자동으로 레이블링하고 추가 학습함으로써, 훈련 데이터와 실제 서비스 환경 사이의 분포 차이(Distribution Shift)를 최소화합니다.

## 📊 실험 결과 분석
* **환각 감소:** 객체 환각을 최대 55%까지 성공적으로 줄였습니다.
* **효율성:** 표준 생성 대비 1.06배의 지연 시간(Latency)만 추가되어 실시간 활용이 가능합니다.
* **구조적 성능:** 단순히 평면적인 프로브(Flat Probe)를 사용했을 때보다 F1 점수가 30.0 이상 높게 나타나, 복합적 구조 학습의 중요성을 입증했습니다.
* **최적 구간:** 모델 내부의 중간 계층(mid-network layers)에서 환각 탐지 성능이 가장 높게 나타났습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **신뢰성 제고:** 사용자의 질문에 대해 실시간으로 환각 여부를 확인하여, 훨씬 더 신뢰할 수 있는 AI 비서나 멀티모달 인터페이스를 구축할 수 있습니다.
* **실무 적용:** 모델 전체를 재학습할 필요 없이 기존에 구축된 오픈소스 LVLM 위에 가벼운 탐지기만 얹는 방식이므로 도입 비용이 낮습니다.
* **한계점:** 논문에 따르면 내부 히든 스테이트와 주의 지도(Attention Map)에 접근할 수 있어야 하므로, 폐쇄형 모델보다는 오픈소스 모델에 직접 적용하기 적합합니다. 또한 모델별로 내부 표현이 다르므로 각 모델에 맞는 별도의 탐지기 훈련이 필요합니다.
