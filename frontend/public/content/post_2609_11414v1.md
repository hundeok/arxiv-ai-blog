# SWRouter: 다중 턴 대규모 언어 모델 대화를 위한 유사성 기반 윈도우 라우팅

> **원본 논문 정보**
> - **제목:** SWRouter: Similarity-Contractive Window Routing for Multi-Turn Large Language Model Conversations
> - **저자:** Yu Wang, Yuchen Li, Rui Kong, Xinran Chen, Jiamin Chen, Hengyi Cai, Shuaiqiang Wang, Jiashu Zhao, Yulun Zhang, Zhonghao Lyu, Haoyi Xiong, Linghe Kong, Jimmy Xiangji Huang, Dawei Yin
> - **발행일:** 2026-09-10
> - **PDF 링크:** [SWRouter: Similarity-Contractive Window Routing for Multi-Turn Large Language Model Conversations](https://arxiv.org/pdf/2609.11414v1)


## ✨ 3줄 핵심 요약
* 다중 턴 대화에서 발생하는 정보 손실과 혼선을 방지하기 위해 '유사성 기반 윈도우 분할'을 도입했습니다.
* 프롬프트 구성 품질과 라우터의 모델 선택 능력을 분리하여 평가하는 체계적인 프레임워크를 제시합니다.
* 기존 최고 성능의 LLM 대비 16.26%, 기존 기준 모델(Conv-ID) 대비 8.22%의 평가 정확도 향상을 달성했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
여러 대규모 언어 모델(LLM) 중 최적의 모델을 선택해 질문을 보내는 '라우팅' 기술은 단일 질문에는 효과적이지만, 대화가 이어지는 '다중 턴' 상황에서는 과거 대화 맥락을 어떻게 처리하느냐에 따라 성능이 크게 좌우됩니다. SWRouter는 대화 맥락을 의미적으로 관련 있는 조각으로 잘 나누어 프롬프트를 구성하고, '모델을 잘 골랐는지'와 '프롬프트가 잘 만들어졌는지'를 따로 평가하는 방식을 통해 라우팅 성능을 극대화했습니다.

## 🎯 배경 및 문제점
기존의 라우팅 기법은 다중 턴 대화에서 다음과 같은 근본적인 한계를 지닙니다.
* **맥락 구성의 어려움:** 대화 히스토리를 요약하거나 유지하는 과정에서 정보 손실이나 혼선이 발생합니다.
* **평가 방식의 오류:** 프롬프트가 잘 작성되어 성능이 좋은 것인지, 라우터가 모델을 잘 선택해서 좋은 것인지 구분하지 못하는 평가 방식이 사용됩니다.

## 💡 핵심 기술 및 아키텍처
* **유사성 기반 윈도우 분할(Similarity-based Window Partitioning):** 대화 히스토리를 의미적으로 응집력 있는 윈도우로 나누어, 모델이 맥락을 정확히 이해할 수 있는 최적의 프롬프트를 구성합니다.
* **분리된 평가 프레임워크(Decoupled Evaluation Framework):** 
    * **평가 정확도(Evaluation Accuracy):** 라우팅된 응답의 실제 최종 품질.
    * **구성 정확도(Construction Accuracy):** 프롬프트 구성 자체가 얼마나 정보를 잘 보존했는지 측정.
    * **라우터 성능(Router Performance):** 프롬프트 품질과 상관없이 라우터가 실제로 더 나은 모델을 선택했는지 측정.

## 📊 실험 결과 분석
* **성능 향상:** ShareGPT 및 MTBench 벤치마크에서 개별 최강 모델 대비 16.26%, Conv-ID Context 기준 모델 대비 8.22% 높은 평가 정확도를 기록했습니다.
* **일반화 성능:** PreAlgebra, MBPP, C-EVAL 등 분포 외(Out-of-distribution) 태스크에서도 Conv-ID Context 대비 평균 2.68% 더 나은 성과를 보였습니다.
* **분석 결과:** 향상된 성능은 주로 프롬프트 구성 정확도의 개선에서 비롯되었으며, 라우터 성능 지표(P_router)가 항상 1보다 커 효율적인 모델 선택이 이루어지고 있음을 확인했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
이 연구는 LLM 라우팅이 단순히 모델을 선택하는 문제를 넘어, **'맥락 최적화(프롬프트 구성)'와 '모델 선택'을 통합적으로 설계**해야 함을 입증했습니다. 대화형 AI 서비스나 복잡한 추론이 필요한 AI 에이전트 시스템에서 과거 대화 기록을 효율적으로 활용하여 답변의 품질을 높이는 데 기여할 수 있습니다. 현재는 7B/8B 규모의 모델을 기준으로 평가되었으며, 향후 다양한 크기 및 상용 LLM으로의 확장 적용 가능성을 제시합니다.
