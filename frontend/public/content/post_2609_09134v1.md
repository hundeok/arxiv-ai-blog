# 하니스와 모델의 공동 진화: 모방 학습의 한계를 극복하는 온-정책 수정

> **원본 논문 정보**
> - **제목:** Co-Evolving Harnesses and Models: On-Policy Correction Helps Weaker Models Catch Up Where Imitation Fails
> - **저자:** Zhou Yu, Bin Bi, Shiva Kumar Pentyala, Shubham Mehrotra, Sougata Chaudhuri, Shilpa Bhagavath, Zeyuan Chen, Ran Xu, Phil Mui, James Zhu, Sitaram Asur
> - **발행일:** 2026-09-08
> - **PDF 링크:** [Co-Evolving Harnesses and Models: On-Policy Correction Helps Weaker Models Catch Up Where Imitation Fails](https://arxiv.org/pdf/2609.09134v1)


## ✨ 3줄 핵심 요약
* 에이전트 성능을 높이기 위해 최적화된 '하니스(시스템 프롬프트, 도구 등)' 환경에서, 단순히 더 강한 모델의 행동을 모방(Imitation)하는 학습은 오히려 성능 저하를 일으킵니다.
* 이는 모방 학습이 약한 모델의 기존 계획 수립 방식을 파괴하여, 정교하게 조정된 하니스와의 적합성을 깨뜨리기 때문입니다.
* 이를 해결하기 위해 모델이 스스로 시도한 경로에서 실패한 부분만 전문가가 수정해 주는 '온-정책(On-policy) 수정' 기법을 도입하여, 기존 환경 적합성을 유지하면서 성능을 개선했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
AI 에이전트의 능력은 모델 자체의 지능과 그 모델이 사용하는 도구·환경 설정인 '하니스'에 의해 결정됩니다. 최근 작은 모델도 하니스를 잘 최적화하면 큰 모델만큼 성능을 낼 수 있다는 점이 밝혀졌습니다. 연구진은 여기서 한 걸음 더 나아가, "최적화된 하니스 위에서 큰 모델의 방식을 작은 모델에게 배우게 하면 더 좋아지지 않을까?"라고 생각했습니다. 하지만 실험 결과, 단순히 큰 모델을 흉내 내게 했더니 오히려 성능이 크게 떨어졌습니다. 큰 모델의 전략을 무작정 따라 하려다 보니 작은 모델이 자기 환경에 딱 맞게 세팅된 기존 시스템에서 겉돌게 되었기 때문입니다. 이를 해결하고자 모델의 기존 스타일을 유지하면서 특정 실패 구간만 교정하는 새로운 학습 방식을 개발했습니다.

## 🎯 배경 및 문제점
* **기존 방식의 한계:** 하니스 진화(최적화)와 모델 파인튜닝은 각각 에이전트 성능을 높이는 두 가지 독립적 수단으로 사용되어 왔습니다.
* **예기치 못한 성능 저하:** 하니스가 최적화된 상태에서 전문가 모델의 성공 경로를 학습(모방 학습)시키자, 7개 벤치마크 모두에서 성능이 하락했습니다. (평균 -14.9 포인트 하락)
* **근본 원인:** 약한 모델이 전문가의 복잡한 계획 전략을 따라 하려다 자신의 하니스와 맞지 않는 실행 방식을 취하게 되어, 오히려 하니스의 지원을 효과적으로 받지 못하는 '적합성 붕괴'가 발생했습니다.

## 💡 핵심 기술 및 아키텍처
* **온-정책 전문가 수정 파이프라인(On-policy Expert-correction Pipeline):** 
    * 모델이 스스로 작업 경로를 생성(Rollout)하도록 합니다.
    * 자동화된 메타 에이전트가 실패한 특정 구간만 찾아냅니다.
    * 전문가 모델이 그 구간만 수정된 대안을 제시하여 학습 데이터를 생성합니다.
* **핵심 가치:** 모델의 원래 계획 수립 스타일을 유지하면서 지식만 보완합니다. 이는 하니스가 제공하는 환경적 이점을 훼손하지 않으면서 성능을 끌어올리는 전략입니다.

## 📊 실험 결과 분석
* **성능 비교:** 온-정책 수정 방식을 도입했을 때, 하니스 진화만 거친 모델(평균 성공률 78.0%) 대비 성능이 79.7%로 상승했습니다.
* **이전 방식과의 대비:** 전문가를 그대로 모방했을 때는 모든 태스크에서 성능이 떨어진 반면, 본 방식은 7개 태스크 중 5개에서 성능 향상을 보였고 나머지 2개는 안정적인 수준을 유지했습니다.
* **분석 결과:** 실패 원인 분석 결과, 모델의 '계획 수립' 오류는 최소화하면서도 '지식' 영역에서 실질적인 개선이 일어났음을 확인했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **경제적 효용성:** 비용이 많이 드는 대형 모델을 직접 사용하지 않고도, 작은 모델을 효율적으로 최적화하여 기업용 에이전트(코드 리팩토링, 데이터 감사 등)를 구축할 수 있습니다.
* **실무 적용:** 모델 훈련 시간이 1시간 이내로 짧아, 하니스 최적화와 모델 파인튜닝을 순차적 혹은 반복적인 '공동 진화(Co-evolution)' 루프 형태로 통합하여 실무에 즉시 적용 가능합니다.
* **향후 과제:** 강화학습과 결합하여 성능 한계를 더 높이고, 하니스 최적화 단계에서부터 이후의 파인튜닝 과정을 고려한 공동 최적화 연구가 추진될 예정입니다.
