# 탐색적 모델링: 제3의 사전 학습 축과 종단간 생성의 잠금 해제

> **원본 논문 정보**
> - **제목:** Explorative Modeling: Unlocking a Third Pretraining Axis and End-to-End Generation
> - **저자:** Alexi Gladstone, Heng Ji, Yilun Du
> - **발행일:** 2026-07-29
> - **PDF 링크:** [Explorative Modeling: Unlocking a Third Pretraining Axis and End-to-End Generation](https://arxiv.org/pdf/2607.27372v1)


## ✨ 3줄 핵심 요약
* 기존 생성 모델의 한계인 '비(非) 종단간 학습' 문제를 해결하기 위해, 학습 루프에서 다수의 후보를 생성하고 최적의 결과를 선택하는 '탐색적 모델링(Explorative Modeling)'을 제안합니다.
* 탐색은 모델 크기와 데이터 양에 이은 '제3의 사전 학습 축'으로 작용하며, 규모가 커질수록 성능 향상폭이 단조 증가하는 특성을 보입니다.
* 탐색적 모델(XM)은 기존 모델 대비 FLOP 효율 4.1배, 샘플 효율 6.2배, 파라미터 효율 47% 향상을 달성하며, 추론 단계를 획기적으로 줄인 종단간 생성을 구현합니다.

## 📖 쉽게 풀어쓴 1분 핵심
현재의 생성 모델(확산 모델 등)은 학습 방식과 추론 방식이 달라, 학습 중에 본 적 없는 데이터에 노출될 때 발생하는 오류가 누적되는 문제가 있습니다. 연구팀은 이를 해결하고자 학습 과정에서 모델이 여러 후보를 만들어보고 그중 가장 좋은 것을 선택하게 하는 '탐색적 모델링'을 도입했습니다. 이는 단순히 모델의 크기를 키우거나 데이터를 늘리는 것 이상의 효과를 내며, 특히 모델 규모가 커질수록 그 효율성이 배가되는 강력한 학습 패러다임입니다.

## 🎯 배경 및 문제점
딥러닝 분야에서 '종단간(End-to-End) 학습'은 수작업 설계를 배제하고 직접 데이터를 통해 학습하여 성능을 극대화해왔습니다. 그러나 생성 모델은 예외적으로, 학습 시와 추론 시의 생성 방식이 서로 다른 비종단간 방식을 취하고 있습니다(예: 확산 모델의 단계적 노이즈 제거). 이로 인해 추론 과정에서 오차가 누적되고 성능 저하가 발생합니다. 본 논문은 이러한 '생성 절차의 분해'가 근본적인 문제라고 지적합니다.

## 💡 핵심 기술 및 아키텍처
* **탐색적 모델링(Explorative Modeling):** 학습 루프를 분해하여 모델이 생성한 K개의 후보 중 데이터와 가장 일치하는 결과를 선택하여 학습합니다. 이를 통해 예측이 모호해지는 대신 특정 모드(mode)에 확고하게 수렴하도록 돕습니다.
* **제3의 사전 학습 축:** 기존의 '파라미터 크기'와 '데이터 양'이라는 두 축 외에 '탐색(Exploration)'이라는 새로운 차원을 추가하여, 모델의 생성적 표현력을 능동적으로 확장합니다.

## 📊 실험 결과 분석
* **효율성 극대화:** 탐색을 통해 기존 대비 FLOP 효율 4.1배, 샘플 효율 6.2배, 파라미터 효율 47% 향상을 기록했습니다.
* **확장성(Scaling):** 탐색을 통해 얻는 이득은 규모가 커질수록 증가합니다. 데이터 규모에 따라 7%에서 36%로, 모델 크기에 따라 13%에서 23%로 향상폭이 커졌으며, 연산량을 3배로 늘렸을 때 효율 이득은 2배 이상 증가했습니다.
* **성능 기록:** ImageNet 데이터셋에서 유도(guidance) 없이 FID 1.43이라는 최신 수준(near-state-of-the-art)의 성능을 달성했습니다.
* **추론 속도:** 제어 작업에서 기존 확산 모델 대비 16~256배 적은 추론 단계로 동일한 성능을 냅니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **생성 모델의 패러다임 전환:** 생성 모델을 더 종단간 모델에 가깝게 구현함으로써, 복잡한 단계적 절차 없이도 고품질의 출력을 생성할 수 있게 합니다.
* **자원 최적화:** 동일한 컴퓨팅 자원을 투입하더라도 탐색적 모델링을 적용하면 더 높은 효율로 모델을 학습시킬 수 있어, 고비용 AI 학습의 경제성을 개선할 수 있습니다.
* **일반화 성능 향상:** 탐색에 더 많은 학습 컴퓨팅을 할애함으로써 모델의 일반화 능력을 직접적으로 개선하는 효과를 거두었습니다.
