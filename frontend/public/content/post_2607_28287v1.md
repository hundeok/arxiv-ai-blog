# Tycho: ARC-AGI-3를 위한 프로그래밍 기반 월드 모델과 능동적 추상화

> **원본 논문 정보**
> - **제목:** Tycho: Active Abstraction with Programmatic World Models for ARC-AGI-3
> - **저자:** Jens Lehmann, Andrei Aioanei, Sahar Vahdati
> - **발행일:** 2026-07-30
> - **PDF 링크:** [Tycho: Active Abstraction with Programmatic World Models for ARC-AGI-3](https://arxiv.org/pdf/2607.28287v1)


## ✨ 3줄 핵심 요약
* **능동적 추상화(Active Abstraction)**: AI가 게임 환경을 직접 모델링하고, 해당 모델을 구축·수정·사용할지 여부를 스스로 결정하는 새로운 문제 해결 프레임워크인 'Tycho'를 제안함.
* **성능 및 효율성**: '배우가 요청하는 위임(Actor-requested delegation)' 전략이 가장 뛰어난 효율성을 보였으며, 최신 모델(GPT-5.6, Opus 5)은 모든 게임 레벨을 완벽하게 해결함.
* **모델링의 한계**: 단순히 환경을 정확히 복제하는 것(모델 정확도)과 게임의 목적을 파악해 효율적으로 행동하는 것(의사결정 품질)은 별개의 문제임을 입증함.

## 📖 쉽게 풀어쓴 1분 핵심
ARC-AGI-3는 AI가 생소한 게임의 규칙을 빠르게 파악해 최소한의 움직임으로 승리해야 하는 어려운 과제입니다. 기존 방식은 AI가 매번 상황을 직접 추론하는 방식이었지만, 'Tycho' 시스템은 AI가 직접 게임의 규칙을 코드로 작성(모델링)하고 이를 테스트하며 게임을 풀어나갑니다. 연구 결과, 무조건 모델을 만드는 것보다 필요할 때만 모델 제작을 위임하는 방식이 가장 효율적이었습니다. 이는 AI가 '언제 내가 모델을 만들어야 할지, 언제는 직관으로 해결할지'를 판단하는 '능동적 추상화' 능력이 매우 중요함을 시사합니다.

## 🎯 배경 및 문제점
* 기존 인공지능은 수많은 환경 시행착오를 통해 학습하거나 방대한 데이터를 암기하는 방식에 의존해왔습니다.
* 반면, ARC-AGI-3 벤치마크는 단 몇 번의 경험만으로 규칙을 추론하고 효율적으로 과제를 수행하는 진정한 '일반화 능력'을 요구합니다.
* 환경의 상태 변화를 단순히 예측하는 시뮬레이터 모델을 만드는 것만으로는 게임의 최종 목표(Objective)를 달성하는 최적의 행동을 보장하지 못하는 문제가 있습니다.

## 💡 핵심 기술 및 아키텍처
* **게임 환경 정형화**: 게임을 파라미터화된 결정론적 무어 머신(Moore machine)으로 정의하여, 관찰 내용과 애니메이션/레벨 종료 프레임을 구분합니다.
* **Tycho 에이전트 시스템**: 게임 중 관찰한 이력을 바탕으로 실행 가능한 가설(코드)을 구축, 테스트, 수정, 계획하는 기능을 수행합니다.
* **오케스트레이션 정책**: 
    * 직접 추론(Direct reasoning)
    * 배우가 직접 모델링(Actor-authored)
    * 배우가 빌더에게 모델링 요청(Actor-requested delegation)
    * 검증 실패 시 자동 모델 복구(Automatic repair) 
    등 4가지 방식을 비교 분석했습니다.

## 📊 실험 결과 분석
* **최고 성능**: '배우가 요청하는 위임' 정책이 가장 높은 RHAE(상대적 인간 행동 효율성)를 기록함.
* **모델 효율성**: GPT-5.6 Sol과 Opus 5는 25개 게임, 183개 레벨을 모두 완료했으며, 특히 Opus 5는 공식 인간 베이스라인 대비 61% 적은 행동으로 모든 과제를 수행함.
* **복구 기능의 역설**: 자동 모델 복구 기능은 환경 시뮬레이션의 정확도는 높였으나, 전체적인 게임 공략 효율(RHAE 83.07)은 위임 방식보다 낮았습니다. 이는 모델 자체의 정확도가 곧 게임 점수로 직결되지 않음을 보여줍니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **효율적인 문제 해결**: 이 연구는 AI가 모든 상황을 계산하는 대신, 필요할 때만 가설을 세우고 모델링하는 '전략적 자원 배분' 능력이 실무 AI 시스템의 비용 절감과 성능 향상에 필수적임을 입증했습니다.
* **일반화 가능성**: 특정 모델에 국한되지 않고 다양한 frontier 모델(GPT, Opus 등)에서 검증되어 시스템의 범용성을 확인했습니다.
* **미래 방향성**: 향후 AI 에이전트가 복잡한 비즈니스 프로세스나 미지의 물리 환경에서 직접 규칙을 학습하고 스스로 도구를 제작하는 '능동적 도구 활용 에이전트' 개발에 중요한 토대가 될 것입니다.
