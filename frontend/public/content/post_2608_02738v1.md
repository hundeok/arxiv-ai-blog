# 지식-기하학 분리: 스트리밍 추천을 위한 갱신 가능한 사전학습 전이

> **원본 논문 정보**
> - **제목:** Knowledge-Geometry Decoupling: Refreshable Pretrained Transfer for Streaming Recommendation
> - **저자:** Zixuan Wang, Yuhong Chen, Yuxuan Zhu, Guidong Lei, Zhiluohan Guo, Yu Zhao, Kun Wang, Bangyang Hong, Kangle Wu, Yabo Ni, Anxiang Zeng, Cong Fu, Hui Li
> - **발행일:** 2026-08-03
> - **PDF 링크:** [Knowledge-Geometry Decoupling: Refreshable Pretrained Transfer for Streaming Recommendation](https://arxiv.org/pdf/2608.02738v1)


## ✨ 3줄 핵심 요약
* 사전학습 모델과 하위 작업(task) 간의 파라미터 간섭을 방지하기 위해 '지식'과 '기하학'을 분리하는 KGD 프레임워크를 제안합니다.
* 불필요한 노이즈를 제거하는 학습 방식과, 사전학습 모델의 변경에도 하위 작업이 영향을 받지 않는 구조로 지속적인 모델 갱신을 가능하게 합니다.
* 쇼피(Shopee) 실제 서비스 환경에서 GMV(총 거래액)를 1.75%, 광고 수익을 1.53% 향상시키는 실무적 성과를 입증했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
추천 시스템은 최신 데이터를 반영하기 위해 모델을 주기적으로 새로 학습(갱신)해야 합니다. 하지만 기존 방식은 사전학습된 지식과 각 작업별 특성(기하학)이 같은 파라미터를 공유하여, 모델을 갱신할 때마다 기존 학습 결과가 엉망이 되는 문제가 있었습니다. KGD(Knowledge-Geometry Decoupling)는 이를 해결하기 위해 **'지식 학습용 인코더'**와 **'작업 수행용 학습기'**를 분리했습니다. 지식은 깨끗하게 유지하고, 작업별 특성은 별도 공간에 저장함으로써, 사전학습 모델이 매일 갱신되어도 하위 작업은 안정적으로 유지되도록 설계되었습니다.

## 🎯 배경 및 문제점
* **기존 방식의 한계:** 기존의 '다음 토큰 예측(next-token prediction)' 방식은 관련 없는 세션 간의 노이즈까지 학습하여 오염된 지식을 생성합니다.
* **최적화 충돌:** 사전학습된 지식과 작업별 특성(데이터의 기하학적 구조)이 동일한 파라미터를 공유하면, 하위 작업 최적화 시 사전학습된 지식이 손상되거나 그 반대의 현상이 발생합니다.
* **스트리밍 문제:** 실제 서비스 환경에서 데이터는 계속 흐르며 분포가 변하지만, 기존 모델 구조는 이러한 지속적인 갱신 과정을 효율적으로 처리하지 못합니다.

## 💡 핵심 기술 및 아키텍처
* **BMTP (Behavioral Multi-Token Prediction):** 협업적·의미론적으로 연관된 미래 항목만 선별적으로 학습하여 노이즈 없는 고품질 지식을 추출합니다.
* **ACR (Anchored Calibration Residual):** 사전학습된 임베딩 방향을 유지하면서도, 하위 작업에 필요한 변별력 있는 기하학적 구조를 직교 보정 방식으로 추가합니다.
* **읽기 전용 교차 주의(Read-only Cross-Attention):** 작업용 학습기가 사전학습 인코더의 상태를 읽기만 할 수 있도록 제한하여, 작업 최적화 과정이 인코더의 지식을 오염시키지 않도록 차단합니다.

## 📊 실험 결과 분석
* **공공 벤치마크:** 8개의 공개 데이터셋에서 기존 최상위 사전학습-전이 모델 대비 4~12% 성능 향상을 보였습니다.
* **지속성 테스트:** 90일간의 실제 스트리밍 데이터 환경에서 기존 모델들은 성과 정체(gain 없음)를 보인 반면, KGD는 지속적인 우위를 유지했습니다.
* **Shopee 실제 서비스:** 쇼피 홈페이지 검색 결과, 10%의 트래픽을 대상으로 한 A/B 테스트에서 GMV 1.75%, 광고 수익 1.53%, CTR 0.95%, CVR 0.72%의 유의미한 상승을 기록했습니다(p < 0.01).

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **실무 적용:** 쇼피 검색 시스템에 KGD가 완전히 배포되어 운영 중입니다.
* **운영 효율성:** 일일 단위의 모델 갱신이 가능하며, 대규모 사용자를 대상으로 하는 서비스에서 시스템 안정성과 추천 정밀도를 동시에 확보했습니다.
* **확장성:** 데이터 변화가 잦은 이커머스 추천 시스템 등에서 사전학습 모델을 효율적으로 재사용하고 갱신하는 새로운 표준을 제시합니다.
