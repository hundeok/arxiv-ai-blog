# 시퀀스에서 구조로: LLM 에이전트를 위한 관계적 불확실성 전파

> **원본 논문 정보**
> - **제목:** From Sequence to Structure: Relational Uncertainty Propagation for LLM Agents
> - **저자:** Zhengzhao Ma. Boxi Cao, Yaojie Lu, Hongyu Lin, Xianpei Han, Le Sun
> - **발행일:** 2026-08-17
> - **PDF 링크:** [From Sequence to Structure: Relational Uncertainty Propagation for LLM Agents](https://arxiv.org/pdf/2608.16002v1)


## ✨ 3줄 핵심 요약
* 기존 불확실성 측정법은 개별 단계의 확률에만 의존하여 에이전트의 누적된 오류를 포착하지 못하는 한계가 있음.
* RUPA는 에이전트 실행 과정을 의존성 그래프로 모델링하고, 관계를 따라 위험도를 전파하여 전체 경로의 신뢰성을 평가함.
* 다양한 벤치마크 실험 결과, RUPA는 기존 방식보다 더 정확한 불확실성 추정을 제공하며 조기 실패 감지 및 실행 최적화에 기여함.

## 📖 쉽게 풀어쓴 1분 핵심
LLM 에이전트는 복잡한 작업을 수행할 때 여러 단계의 사고와 도구 사용, 외부 환경과의 상호작용을 거칩니다. 기존 기술들은 각 단계에서 LLM이 얼마나 확신하는지(토큰 확률 등)만을 확인했는데, 이는 여러 단계를 거치며 쌓이는 '잠재적 오류'를 놓치기 쉽습니다. 이 논문이 제안하는 **RUPA**는 에이전트의 전체 과정을 하나의 '의존성 지도(그래프)'로 그립니다. 즉, 현재의 행동이 이전의 어떤 사고나 도구 결과와 연결되어 있는지 분석하고, 그 연결 고리를 따라 위험 요소가 어떻게 흘러가고 커지는지를 계산합니다. 이를 통해 단순히 지금 답변이 맞을 확률뿐만 아니라, 전체 작업이 실패할 가능성을 더욱 정밀하게 예측할 수 있습니다.

## 🎯 배경 및 문제점
* **기존 방법의 한계:** 토큰 확률이나 예측 엔트로피 같은 국소적 신호에만 의존하여, 긴 호흡의 작업에서 발생하는 오류 누적이나 장기적 의존성을 간과함.
* **실패의 복합성:** 에이전트의 실패는 단일 예측 오류가 아니라, 추론·도구 사용·환경 상호작용이 얽힌 과정에서 단계적으로 발생함.
* **신뢰성 부족:** 현실 환경에서의 에이전트 배포를 위해서는 실행 전 위험을 평가하는 기술이 필수적이나, 기존 방식은 충분한 정보를 제공하지 못함.

## 💡 핵심 기술 및 아키텍처
* **관계적 궤적 그래프(Relational Trajectory Graph):** 실행 이력을 순차적인 나열이 아닌, 7가지 관계(순차, 최신, 반복, 진행, 병렬, 피드백, 목표 정렬)로 연결된 그래프로 구조화함.
* **불확실성 전파(Uncertainty Propagation):** 단순히 정보를 더하는 것이 아니라, 각 관계의 중요도와 시간적 거리를 고려한 가중치를 부여하여 과거 노드의 위험도를 현재 노드로 전파함.
* **통합적 평가:** 전파된 구조적 위험도와 현재 단계의 국소적 불확실성을 결합하여 최종적인 '궤적 단위 신뢰도'를 산출함.

## 📊 실험 결과 분석
* **성능 향상:** τ-2, Terminal-Bench-2, GAIA 벤치마크에서 기존 불확실성 측정 기법들을 능가하는 성능을 보임.
* **보완적 정보 제공:** 국소적 확률 정보(엔트로피)가 비슷한 상황이라도, RUPA는 그래프 구조를 통해 실패 가능성을 훨씬 더 정확하게 구분해냄 (AUROC 약 0.85 기록).
* **구성 요소 입증:** 삭감 연구(Ablation Study) 결과, 그래프 모델링을 제거하거나 전파 과정을 생략할 때 성능이 유의미하게 하락하여, 제안된 구조와 전파 방식의 유효성을 확인함.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **신뢰할 수 있는 자동화:** 자율적인 소프트웨어 엔지니어링, 웹 자동화, 과학적 탐구 등 복잡한 다단계 과업을 수행하는 에이전트의 신뢰성을 크게 향상할 수 있음.
* **위험 관리:** 에이전트가 중대한 오류를 범하기 전에 스스로 멈추거나 재시도하도록 유도하는 등, 불확실성에 기반한 지능형 의사결정 전략의 기초를 제공함.
* **실무적 기반:** 6종의 오픈소스 LLM을 활용한 실험을 통해 모델 패밀리에 상관없이 적용 가능한 범용적인 프레임워크임을 증명함.
