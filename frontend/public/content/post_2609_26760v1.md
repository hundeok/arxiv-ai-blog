# 문맥이 아닌 하네스를 성장시켜라: 전략 없는 스캐폴드에서 재사용 가능한 전문 에이전트로

> **원본 논문 정보**
> - **제목:** Grow the Harness, Not the Context: From Strategy-Free Scaffolds to Reusable Specialist Agents
> - **저자:** Laizhen Li, Jiarui Li, Juanjuan Zhao, Kejiang Ye, Ye Li, Cheng-zhong Xu, Xitong Gao
> - **발행일:** 2026-09-22
> - **PDF 링크:** [Grow the Harness, Not the Context: From Strategy-Free Scaffolds to Reusable Specialist Agents](https://arxiv.org/pdf/2609.26760v1)


## ✨ 3줄 핵심 요약
* LLM 에이전트가 반복적으로 수행하는 제어 로직을 LLM 추론 대신 '실행 가능한 코드(하네스)'로 변환하여 학습하는 패러다임을 제안합니다.
* 실패한 작업의 추적 데이터를 분석하여 문제를 국소적으로 수정하고, 성능 저하를 방지하는 검증 장치를 통해 지속적으로 하네스를 개선합니다.
* 이를 통해 기존 에이전트 대비 LLM 호출 비용을 최대 98.6% 절감하면서도, 작은 모델에서도 높은 작업 성공률을 유지하는 전문 에이전트를 구축합니다.

## 📖 쉽게 풀어쓴 1분 핵심
기존의 AI 에이전트는 복잡한 작업을 할 때마다 매번 LLM에게 "어떻게 행동할지"를 처음부터 다시 물어봅니다. 이는 비효율적이고 비용이 많이 듭니다. 본 논문은 이 문제를 해결하기 위해 **'하네스(Harness)'**라는 실행 틀을 성장시키는 방식을 제안합니다. 에이전트가 작업을 수행하다 실패하면, 그 이유를 분석해 코드를 자동으로 고치고, 이 개선된 로직을 하네스에 저장합니다. 마치 사람이 경험을 통해 업무 매뉴얼을 다듬듯, AI도 반복 수행을 통해 스스로 똑똑한 '전문가용 프로그램'으로 진화하는 것입니다.

## 🎯 배경 및 문제점
* **반복적인 추론 비용:** 동일한 작업군을 반복 처리할 때, LLM이 제어 결정(쿼리 정제, 오류 복구 등)을 매번 생성하면서 불필요한 추론 비용과 컨텍스트 길이를 증가시킴.
* **유연성 부족:** 기존 방식은 제어 로직을 미리 하드코딩하거나, 전부 LLM에 의존해야 하므로 적응력이 떨어지거나 지나치게 비용이 많이 듦.
* **컨텍스트 오염:** 실행 기록이 계속 쌓이면서 LLM이 처리해야 할 정보량이 늘어 모델의 판단력이 흐려짐.

## 💡 핵심 기술 및 아키텍처
* **성장형 하네스(Growing Harness):** 전략이 없는 최소한의 틀에서 시작하여, 작업 피드백을 통해 실행 가능한 제어 코드를 축적함.
* **실패 기반 학습:**
    * **함수 단위 추적:** 실패 지점을 국소화하여 오류와 관련된 코드 영역만 수정.
    * **실패 윈도우(Failure-Window):** 여러 작업의 실패를 동시에 고려하여, 범용적으로 재사용 가능한 코드 개선안 도출.
    * **성공 우선 게이트(Success-first Gate):** 새로운 수정 사항이 기존 성능을 저하시키면 자동으로 이전 상태로 복구(Rollback)하여 성능 유지.

## 📊 실험 결과 분석
* **비용 절감:** Tool-Calling 에이전트 대비 LLM 호출 횟수는 76.0~91.8%, 추론 비용은 74.4~98.6% 감소.
* **성능 유지:** WebArena-Verified 벤치마크에서 모델 규모가 작아져도(4B 모델) 44.7~45.3%의 성공률을 유지하여, 6.7%에 그친 Tool-Calling 방식보다 월등함.
* **메커니즘 검증:** 함수 단위 안내, 실패 윈도우, 게이트 검증 등 제안된 세 가지 메커니즘을 제거할 경우 모두 최종 성공률이 유의미하게 하락함이 확인됨(Table 2 참조).

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **효율적인 AI 배포:** 큰 규모의 모델 없이도 작은 모델로 고도의 전문 작업 수행이 가능해져 기업의 인프라 비용을 획기적으로 줄일 수 있음.
* **실무적 제언:** 반복적인 업무 자동화에 최적화되어 있으며, 도입 시 코드 생성의 안전성을 위해 샌드박싱, 권한 관리, 생성 코드 검증 절차의 병행이 필수적임.
* **지속 가능한 지능:** AI 에이전트가 고정된 지능에 머무르지 않고, 현장의 피드백을 반영하여 지속적으로 전문성을 강화하는 모델을 제시함.
