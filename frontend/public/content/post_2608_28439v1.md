# 충실성만으로는 충분하지 않다: 에이전트 기반 데이터시트 추출을 위한 디스패치 수준의 계측

> **원본 논문 정보**
> - **제목:** Fidelity Is Not Enough: Dispatch-Level Instrumentation for Agentic Datasheet Extraction
> - **저자:** Qing Ye, Meng-Hsuan Lin
> - **발행일:** 2026-08-28
> - **PDF 링크:** [Fidelity Is Not Enough: Dispatch-Level Instrumentation for Agentic Datasheet Extraction](https://arxiv.org/pdf/2608.28439v1)


## ✨ 3줄 핵심 요약
*   단순히 결과값의 정확도(충실성)만 확인하는 기존 방식은 에이전트가 문서를 읽지 않고 답변을 조작하는 오류를 걸러내지 못합니다.
*   모든 도구 호출 기록을 추적하는 '디스패치 수준 계측'을 통해 모델이 문서를 참조하지 않거나 인프라 설정 문제로 도구 사용이 차단된 상황을 감지할 수 있습니다.
*   데이터시트 추출 환경에서 물리적 측정과 결합한 독립적인 검증 체계를 도입하여 실질적인 데이터의 신뢰성을 확보하는 방안을 제시합니다.

## 📖 쉽게 풀어쓴 1분 핵심
AI 에이전트가 기술 문서(데이터시트)에서 정보를 추출할 때, 사람들은 흔히 '결과값이 문서 내용과 일치하는가(충실성)'만 확인합니다. 하지만 연구진은 모델이 문서를 전혀 열어보지 않고도 그럴싸한 거짓 답변을 생성할 수 있음을 발견했습니다. 모델이 구조적 출력 제약 때문에 도구 사용 기능을 스스로 비활성화하거나, 서버 설정 문제로 도구 호출이 무시되는 경우입니다. 이 논문은 단순히 결과값만 보는 대신, 에이전트가 어떤 도구를 호출했는지 기록하는 '디스패치(dispatch) 로그'를 분석해야만 이러한 '침묵의 실패(silent failure)'를 찾아낼 수 있다고 강조합니다.

## 🎯 배경 및 문제점
*   **충실성(Fidelity)의 한계:** 에이전트가 문서를 읽지 않고도 외부 지식이나 추측으로 정답처럼 보이는 결과물을 내놓을 경우, 결과값만 검증하는 기존 평가 방식은 이를 '성공'으로 간주합니다.
*   **침묵의 실패(Silent Failure):** 특정 모델은 JSON 구조 강제와 같은 출력 제약 조건을 수행하는 과정에서 도구 사용 기능이 내부적으로 비활성화되어, 문서를 전혀 참조하지 않고 답변을 생성하는 현상이 발생했습니다.
*   **인프라 종속성:** 모델 자체의 문제뿐만 아니라 서빙 인프라의 설정(토크나이저 오류, 대규모 스키마 처리 실패 등)으로 인해 도구 호출이 정상적으로 이루어지지 않는 사례가 확인되었습니다.

## 💡 핵심 기술 및 아키텍처
*   **디스패치 수준 계측(Dispatch-level Instrumentation):** 에이전트가 수행한 모든 도구 호출, 입력값, 출력값, 타이밍을 기록하여 추적하는 시스템입니다.
*   **계측 도구:**
    *   **규칙 기반 실패 분류기:** 도구 출력 오류, 도구 선택 오류, 조건 누락, 검증 생략 등 실패 원인을 자동으로 분류합니다.
    *   **침묵 실패 탐지기:** 결과값이 아닌 도구 호출 여부만을 확인하여, 에이전트가 문서를 참조했는지 판별합니다.
*   **독립적 오라클(Causal Chamber):** 문서 내의 정보가 실제 물리적 측정 환경에서도 유효한지 검증하는 보조적 확인 체계입니다.

## 📊 실험 결과 분석
*   **탐지 성능:** 실험 결과, 계측 시스템은 207개의 정상 사례에서는 오탐(False Positive)을 발생시키지 않았으며, 의도적으로 삽입된 50개의 실패 사례를 모두 찾아냈습니다.
*   **비용 및 효율성:** 에이전트 방식은 단일 패스(Single-pass) 방식보다 비용이 더 발생하며(모델별로 상이함), Qwen 모델의 경우 베이스라인 대비 3.9배 높은 비용이 소요되었습니다.
*   **설정의 중요성:** 추론 모드(reasoning-on) 사용 시 에이전트의 오류율이 변동되며, 특정 모델은 도구 사용 여부에 따라 성능 차이가 극명하게 갈리는 등 인프라 설정이 성능에 미치는 영향이 매우 큼을 확인했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례

*   **체크리스트 제공:** 개발자는 본 논문에서 제시하는 '저비용 디스패치 수준 신호' 체크리스트를 활용하여, 에이전트가 실제로 문서를 탐색하고 있는지 검증하는 신뢰성 있는 파이프라인을 구축할 수 있습니다.
