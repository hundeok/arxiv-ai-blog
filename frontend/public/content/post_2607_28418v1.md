# WIDE: 토큰 단위 동적 너비 가지치기를 통한 적응형 LLM 추론 가속

> **원본 논문 정보**
> - **제목:** WIDE: Boosting Adaptive LLM Inference via Token-level Dynamic Width Pruning
> - **저자:** Haozhe Hu, Hao Wu, Peiran Yin, Chao Han, Yunpu Ma, Xiaoyu Shen
> - **발행일:** 2026-07-30
> - **PDF 링크:** [WIDE: Boosting Adaptive LLM Inference via Token-level Dynamic Width Pruning](https://arxiv.org/pdf/2607.28418v1)


## ✨ 3줄 핵심 요약
- **세밀한 제어:** WIDE는 토큰마다 필요한 어텐션 헤드와 FFN 채널을 동적으로 선택하여 모델의 연산량을 유연하게 조절하는 최초의 미분 가능한 프레임워크입니다.
- **실용적 가속:** 모델을 가지치기한 후, 이를 실제 하드웨어에서 효율적으로 실행하기 위해 커널 수준의 동적 희소성 가속 기술을 공동 설계했습니다.
- **성능 향상:** 50% 희소성 조건에서 기존 최신 동적 깊이 가지치기 대비 55.1% 성능 향상을 달성했으며, 추론 시 최대 4.95배의 속도 개선을 보여주었습니다.

## 📖 쉽게 풀어쓴 1분 핵심
거대언어모델(LLM)을 효율적으로 쓰기 위해 불필요한 부분을 잘라내는 '가지치기'는 필수입니다. 하지만 기존 방식은 모델의 특정 부분을 통째로 영구히 제거하므로, 어떤 입력이 들어와도 똑같은 성능 저하를 감수해야 했습니다. **WIDE**는 마치 상황에 맞춰 에너지를 절약하는 스마트 시스템처럼, 들어오는 단어(토큰)마다 꼭 필요한 연산 영역만 활성화합니다. 이를 통해 모델의 지능은 유지하면서, 실제 컴퓨터 환경에서 훨씬 빠르게 답변을 생성할 수 있도록 지원합니다.

## 🎯 배경 및 문제점
- **정적 가지치기의 한계:** 기존 방식은 모델의 계층이나 신경망을 미리 잘라내어 고정합니다. 이로 인해 입력 데이터의 특성과 관계없이 일괄적인 연산이 수행되며, 가지치기 강도가 높을수록 모델의 정확도가 급격히 떨어지는 문제가 발생합니다.
- **동적 가지치기의 실효성:** 입력에 따라 연산을 바꾸는 동적 방식이 도입되었으나, 구조적 결정 단위가 너무 크고 실제 하드웨어에서 가속하기가 어려워 실질적인 추론 속도 개선으로 이어지기 힘들었습니다.

## 💡 핵심 기술 및 아키텍처
- **토큰 단위 동적 너비 가지치기:** 계층 단위가 아닌 신경망 블록 수준의 세밀한 단위로 어텐션 헤드와 FFN 채널을 선택합니다.
- **2단계 학습 파이프라인:** 모델이 효과적인 토큰별 희소성 실행 패턴을 학습하도록 돕습니다.
- **커널 공동 설계(Co-design):** 동적 희소성 연산을 세 가지 단계로 분해하여 처리합니다.
    1. **마스크 재정렬:** 연산 순서 최적화.
    2. **하드웨어 독립적 건너뛰기:** 블록 단위로 불필요한 연산 생략.
    3. **하드웨어 의존적 건너뛰기:** 연산 내부(intra-block) 수준에서의 효율적 실행.

## 📊 실험 결과 분석
- **품질 유지:** 기존 방법론보다 우수한 품질 유지 능력을 보여주었습니다.
- **성능 비교:** 50% 희소성 환경에서 최신 동적 깊이 가지치기 기법 대비 55.1% 높은 성능 향상을 기록했습니다.
- **속도 향상:** 이론상 커널 수준에서 프리필(prefill) 단계는 최대 1.98배, 디코딩(decoding) 단계는 최대 4.95배의 가속을 달성했습니다. 엔드투엔드(End-to-end) 기준으로는 각각 1.68배, 1.55배의 속도 개선을 보였습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
WIDE는 모델 경량화 기술이 가진 기존의 '품질 저하'와 '실제 속도 향상 실패'라는 두 가지 숙제를 해결할 수 있는 기반을 마련했습니다. 특히 실시간 처리가 중요한 AI 에이전트 시스템이나 복잡한 추론 모델을 서비스할 때, 하드웨어 자원을 낭비하지 않으면서도 높은 성능을 제공할 수 있게 합니다. 개발자들은 제공된 오픈소스 코드를 통해 실제 LLM 배포 환경에서 이 기술을 즉시 도입해 볼 수 있습니다.
