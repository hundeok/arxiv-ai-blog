# MindForge: 소스 코드 없는 프로그램 합성을 통한 소형 언어 모델의 전 생애주기 소프트웨어 엔지니어링 학습

> **원본 논문 정보**
> - **제목:** MindForge: Teaching Small Language Models Whole-Life-Cycle Software Engineering via Source-Free Program Synthesis
> - **저자:** Yihao Chen, Shi Chang, Khaled Chawa, Feng Lin, Boyuan Chen, Shaowei Wang, Ahmed E. Hassan
> - **발행일:** 2026-07-29
> - **PDF 링크:** [MindForge: Teaching Small Language Models Whole-Life-Cycle Software Engineering via Source-Free Program Synthesis](https://arxiv.org/pdf/2607.27146v1)


## ✨ 3줄 핵심 요약
* **MindForge**는 오픈소스 프로그램을 소스 코드 없이 컴파일된 실행 파일과 문서만으로 구성된 환경으로 자동 변환하여 학습 데이터로 활용합니다.
* 소형 모델인 **Qwen3.6-27B**를 이 환경으로 미세 조정(Fine-tuning)한 결과, 프로그램 합성 테스트(ProgramBench) 통과율을 37.98%에서 49.51%로 대폭 향상했습니다.
* 다양한 소프트웨어 엔지니어링 벤치마크에서 훨씬 규모가 큰 대형 모델들과 대등하거나 더 우수한 성능을 입증했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
기존 코딩 인공지능들은 주로 기존 코드를 수정하는 작업에는 능숙하지만, 처음부터 완전히 새로운 프로그램을 만드는 것은 여전히 매우 어려운 과제입니다. 그 이유는 학습을 위한 적절한 환경과 데이터가 부족하기 때문입니다. 'MindForge'는 오픈소스 프로젝트를 활용해 인공지능이 소스 코드를 직접 보지 않고도 실행 파일과 문서만으로 소프트웨어 개발 전 과정을 학습할 수 있는 '소스 프리(Source-free)' 환경을 구축했습니다. 이를 통해 270억 개의 매개변수만 가진 소형 모델도 대규모 언어 모델 수준의 프로그래밍 실력을 갖추게 되었습니다.

## 🎯 배경 및 문제점
현재 코딩 에이전트들은 버그 수정이나 기능 추가와 같은 기존 코드 수정 업무에서는 큰 발전을 이루었습니다. 그러나 완전히 새로운 프로그램을 처음부터 개발하는 것은 여전히 난제로, 기존의 벤치마크에서 최첨단 모델들조차 1% 미만의 과제만 해결하는 수준입니다. 이러한 문제를 해결할 전 생애주기 소프트웨어 엔지니어링 학습 환경이 부재하다는 점이 가장 큰 장애물로 지적되었습니다.

## 💡 핵심 기술 및 아키텍처
* **자동화된 파이프라인**: 오픈소스 CLI 프로그램을 컴파일된 실행 파일과 문서만 남은 환경으로 자동 변환합니다.
* **학습 전략**: GLM-5.2 모델을 교사 모델로 활용하여 프로그램 합성 과정을 데이터화하고, 이를 바탕으로 소형 모델(Qwen3.6-27B)을 미세 조정합니다.
* **소스 프리(Source-free) 환경**: 원본 소스 코드에 의존하지 않고도 에이전트가 소프트웨어 개발 주기를 이해하고 수행할 수 있도록 설계되었습니다.

## 📊 실험 결과 분석
* **성능 향상**: MindForge로 학습된 27B 모델은 기존 Qwen3.6-27B 모델의 테스트 통과율을 37.98%에서 49.51%로 높였습니다.
* **경쟁력**: 이는 훨씬 큰 규모의 모델들과 비교해도 뒤처지지 않는 수준입니다.
* **범용성**: 7개의 미학습 소프트웨어 엔지니어링 벤치마크(RepoZero-C2Rust, DeepSWE, SWE-bench 등)에서 일관된 성능 향상을 보였습니다. 
    * *예시(절대값 상승폭):* RepoZero-C2Rust에서 31.00점, DeepSWE에서 14.16점, NL2Repo-Bench(테스트 포함)에서 10.70점 등.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
이번 연구는 소형 언어 모델이 거대 모델의 컴퓨팅 자원 없이도 전문적인 소프트웨어 엔지니어링 과제를 수행할 수 있음을 보여줍니다. 기업들은 고비용의 대형 모델을 사용하는 대신, 특정 엔지니어링 작업에 특화된 소형 모델을 구축하여 효율적인 자동화 도구를 개발할 수 있습니다. 이는 개발자의 생산성을 높이고, 복잡한 신규 프로젝트 생성 및 레거시 시스템의 언어 전환, 버그 수정 등을 자동화하는 데 실질적인 기여를 할 것으로 기대됩니다.
