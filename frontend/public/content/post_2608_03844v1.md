# MAFIA: 감사 대상 LLM 에이전트를 대상으로 하는 질의 전용 메모리 공격 및 사실 주입

> **원본 논문 정보**
> - **제목:** MAFIA: Query-Only Memory Attacks via Probing and Factual Injection against Audited LLM Agents
> - **저자:** Jiaming Chen, Yisen Gao, Yanping Li, Zifan Liu, Yumeng Zhang, Jun Zhang
> - **발행일:** 2026-08-04
> - **PDF 링크:** [MAFIA: Query-Only Memory Attacks via Probing and Factual Injection against Audited LLM Agents](https://arxiv.org/pdf/2608.03844v1)


## ✨ 3줄 핵심 요약
- MAFIA는 메모리 기반 LLM 에이전트의 외부 메모리에 악의적인 정보를 주입하여 에이전트의 행동을 조종하는 새로운 '질의 전용' 공격 프레임워크입니다.
- 메모리 프로빙을 통해 효율적으로 공격 위치를 선정하고, 사실 기반의 위장 기술을 활용하여 에이전트의 보안 감사 시스템을 우회합니다.
- 실험 결과, 최대 90.7%의 높은 공격 성공률을 기록했으며, 보안 감사 시스템의 탐지율을 기존의 83.3%에서 7.4% 수준까지 성공적으로 억제했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
최근 LLM 에이전트들은 방대한 외부 메모리에 과거의 경험을 저장하고 이를 활용해 복잡한 작업을 수행합니다. 하지만 공격자가 이 메모리에 거짓 정보를 몰래 집어넣으면 에이전트는 이를 사실로 믿고 잘못된 판단을 내리게 됩니다. 기존의 공격 방식은 보안 필터링(감사)이나 메모리 내의 경쟁 때문에 효과가 낮았습니다. MAFIA는 마치 '침투 훈련'을 하듯 메모리 구조를 추론해 공격 효율을 극대화하고, 악성 정보를 교묘한 사실로 위장하여 보안 감사를 통과시키는 방식으로 이러한 한계를 극복했습니다.

## 🎯 배경 및 문제점
- **장기 기억의 취약점:** 에이전트의 메모리는 영구적으로 저장되어 이후 세션에서도 재사용되므로, 한 번 오염되면 지속적인 악영향을 미칩니다.
- **감사 체계의 존재:** 많은 에이전트가 입력 시점에 보안 분류기를 통해 악의적인 프롬프트를 차단합니다.
- **높은 검색 경쟁:** 에이전트의 메모리 뱅크는 수천 개의 정상 데이터로 가득 차 있어, 소량의 악성 데이터가 상위 검색 결과(top-K)에 노출되기가 매우 어렵습니다.

## 💡 핵심 기술 및 아키텍처
1. **메모리 프로빙(Retrieval Probing):** 공격자가 메모리에 직접 접근할 수 없으므로, 다양한 '씨앗 질의(seed queries)'를 던져 에이전트가 어떤 데이터를 검색하는지 파악합니다. 이를 통해 클러스터링 기반의 전략적인 데이터 배치를 수행합니다.
2. **사실적 위장(Factual Cloak):** 악성 페이로드를 단순히 공격적인 문구로 구성하는 대신, 자연스럽고 사실적인 정보로 포장하여 의미론적 유사성을 높입니다. 이를 통해 에이전트의 입력 감사를 통과합니다.
3. **라운드 로빈 배분:** 한정된 공격 예산 내에서 검색 노출도를 극대화하기 위해, 중요도가 높은 검색 영역을 순차적으로 선정하여 공격 데이터를 배치합니다.

## 📊 실험 결과 분석
- **공격 성공률:** MAFIA는 평가된 환경에서 최대 90.7%라는 높은 공격 성공률을 보였습니다.
- **보안 탐지 우회:** 기존 방식에 비해 에이전트의 감사 탐지율을 83.3%에서 최대 7.4%까지 대폭 낮추어, 공격이 감지되지 않고 메모리에 안착할 가능성을 크게 높였습니다.
- **비교 분석:** 메모리 규모가 커질수록 기존 공격법(MINJA) 대비 공격 성공률 격차가 벌어지며, 대규모 메모리 환경에서의 강력한 성능을 입증했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
- **보안 인식 전환:** 입력 시점의 단순한 프롬프트 감사만으로는 에이전트의 안전을 보장할 수 없다는 점을 시사합니다.
- **방어 대책 제언:** 
    - 메모리 데이터에 대한 쓰기 격리 및 최소 권한 정책 적용.
    - 데이터 출처(provenance) 추적.
    - 메모리에서 검색된 데이터가 실제 작업에 반영되기 전 수행하는 '검색 후 검증(post-retrieval verification)' 절차의 중요성을 강조합니다.
- **학술적 가치:** 실제 서비스가 아닌 표준 벤치마크 환경(MIMIC-III, eICU 등)에서 검증을 수행하여 공격 기술의 위험성을 체계적으로 밝히고 방어 방향성을 제시했습니다.
