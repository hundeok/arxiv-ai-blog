# ActMap: 생성 단계 활성화 맵을 이용한 단일 패스 불확실성 정량화

> **원본 논문 정보**
> - **제목:** ActMap: Single-Pass Uncertainty Quantification from Generation-Time Activation Maps
> - **저자:** Jacopo Dardini, Roberta Calegari
> - **발행일:** 2026-09-10
> - **PDF 링크:** [ActMap: Single-Pass Uncertainty Quantification from Generation-Time Activation Maps](https://arxiv.org/pdf/2609.11498v1)


## ✨ 3줄 핵심 요약
* **단일 패스 분석:** 모델의 전체 생성 과정을 단 1회 수행하는 것만으로 답변의 신뢰도를 평가할 수 있는 'ActMap' 기법을 제안합니다.
* **효율적 압축:** 생성 중 발생하는 방대한 내부 상태(히든 스테이트)를 96KiB 크기의 고정된 12×32×128 텐서로 압축하여 저장 및 처리 효율을 극대화했습니다.
* **성능 우위:** 기존의 샘플링 기반 방식이나 토큰 확률 기반 방식보다 뛰어난 정밀도(AUROC)를 보이며, 훨씬 큰 크기의 데이터를 사용하는 기존 화이트박스 기법과 대등한 성능을 냅니다.

## 📖 쉽게 풀어쓴 1분 핵심
대규모 언어 모델(LLM)은 틀린 답도 매우 자신 있게 말하는 경향이 있습니다. 기존에는 이 답변이 맞는지 확인하려고 같은 질문을 여러 번 반복해서 묻거나(샘플링), 마지막 출력값만 확인하곤 했습니다. 'ActMap'은 모델이 답변을 만드는 그 찰나의 내부 정보를 낚아채어, 아주 작은 지도(맵)로 압축합니다. 이 지도를 가벼운 AI(Vision Transformer)가 읽어 "이 답변은 정답일 확률이 높다/낮다"를 즉시 판단합니다. 추가 연산 부담은 거의 없으면서도, 정답 여부를 예측하는 성능은 기존 최고 수준의 방식들과 어깨를 나란히 합니다.

## 🎯 배경 및 문제점
LLM의 답변 신뢰성을 측정하는 기존 방식들은 세 가지 한계가 있습니다.
1. **샘플링 기반(블랙박스):** 여러 번 생성해 비교하므로 시간이 오래 걸리고 비용이 많이 듭니다.
2. **출력 확률 기반(그레이박스):** 모델 내부의 깊은 계산 과정을 무시하고 마지막 출력값만 보기에 정확도가 떨어집니다.
3. **기존 화이트박스:** 모델 내부를 보지만, 정보를 단일 벡터로 너무 많이 압축해버려 생성 과정의 입체적인 데이터(층별, 토큰별 변화)를 상당 부분 소실합니다.

## 💡 핵심 기술 및 아키텍처
* **ActMap 생성:** 생성 과정의 모든 층(layer)과 모든 토큰의 히든 스테이트를 기록한 후, 이를 12개의 시간적 통계 채널을 포함하는 12×32×128 크기의 고정 텐서로 압축합니다.
* **경량 분류기:** 압축된 맵을 읽기 위해 소형 Vision Transformer(ViT)를 사용합니다. 논문에 따르면, 동일한 용량의 MLP(다층 퍼셉트론)를 사용해도 비슷한 결과가 나오는 것으로 보아, 압축된 맵 자체가 답변 신뢰도에 관한 핵심 정보를 충분히 담고 있음을 알 수 있습니다.
* **실시간 처리:** 생성 중에 후킹(Hooking)을 통해 데이터를 수집하므로 추가적인 LLM 호출이 필요 없으며, 연산 오버헤드는 측정 불가능할 정도로 미미합니다.

## 📊 실험 결과 분석
* **성능 지표:** 7~8B 모델 3종을 대상으로 12개 데이터셋 세트를 실험한 결과, ActMap의 평균 AUROC는 .825로, 기존 방식들(TAD .790, MTE .741)보다 우수했습니다.
* **효율성:** 기존의 대규모 활성화 텐서 분석 기법(ACT-ViT) 대비 67배 작은 데이터를 사용하면서도, 12개 실험 쌍 중 10개에서 더 낮은 보정 오차(ECE)를 기록했습니다.
* **저장 공간:** 38,000개의 답변 생성 데이터를 저장할 때, 기존 방식은 235GiB가 필요했으나 ActMap은 3.5GiB로 압축 가능합니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **확장 가능한 감독:** 모든 답변을 사람이 검토하기 어려운 환경에서, 신뢰도가 낮은 답변을 자동으로 필터링하거나 인간 검토가 필요한 대상으로 라우팅하는 실용적인 도구로 활용될 수 있습니다.
* **투명성 확보:** 생성된 답변에 대한 ActMap을 보관하면, 나중에 답변의 정확성을 사후 감사(audit)할 때 효율적인 근거 데이터로 사용할 수 있습니다.
* **실무적 제약:** 모델의 내부 구조에 직접 접근해야 하므로, API 형태의 폐쇄형 모델에는 적용이 어렵고 자가 호스팅(Self-hosted) 모델 환경에 적합합니다. 또한, 측정된 점수는 확률적 상관관계일 뿐이며 진실을 보증하는 것은 아님을 유의해야 합니다.
