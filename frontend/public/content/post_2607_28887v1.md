# 기계는 더하고 인간은 지운다: 거대언어모델(LLM) 코드 편집에서의 삭제 회피 측정 및 완화

> **원본 논문 정보**
> - **제목:** To Add Is Machine, To Delete Is Human: Measuring and Mitigating Deletion Avoidance in LLM Code Editing
> - **저자:** Amir M. Ebrahimi, Mohammed Mehedi Hasan, Aaditya Bhatia, Gopi Krishnan Rajbahadur, Ahmed E. Hassan
> - **발행일:** 2026-07-30
> - **PDF 링크:** [To Add Is Machine, To Delete Is Human: Measuring and Mitigating Deletion Avoidance in LLM Code Editing](https://arxiv.org/pdf/2607.28887v1)


## ✨ 3줄 핵심 요약
- LLM은 코드를 수정할 때 불필요한 코드를 삭제하는 대신, 이를 유지하며 우회하는 코드(Guard-and-Go)를 삽입하는 '삭제 회피' 경향을 보입니다.
- 기존의 테스트 기반 평가 방식은 이러한 삭제 실패를 제대로 걸러내지 못하며, 삭제를 필수 요구사항으로 명시하면 모델의 성공률이 크게 하락합니다.
- 삭제 중심의 지도 학습(Supervision)을 추가하면 삭제 회피 성향을 줄이고 전반적인 코드 편집 성능을 향상시킬 수 있습니다.

## 📖 쉽게 풀어쓴 1분 핵심
코드를 수정할 때 개발자는 보통 불필요해진 코드를 깔끔하게 지우지만, AI 모델은 이를 삭제하는 대신 '만약 이런 경우라면 실행하지 마라'와 같은 안전장치를 덧붙이는 방식을 자주 사용합니다. 이를 '삭제 회피(Deletion Avoidance)'라고 합니다. 이런 방식은 코드의 복잡도를 높여 유지보수를 어렵게 만들지만, 기존 테스트들은 기능만 돌아가면 합격으로 처리하기 때문에 AI 모델의 문제점이 드러나지 않습니다. 본 연구는 이러한 삭제 회피 문제를 측정하고, 모델이 코드를 '지우는 법'을 학습함으로써 더 나은 코드를 생성할 수 있음을 입증했습니다.

## 🎯 배경 및 문제점
- **삭제 회피 현상:** LLM이 작성한 코드가 유지보수하기 어렵다는 지적이 늘고 있으며, 그 주된 원인 중 하나가 수정 시 삭제해야 할 코드를 그대로 남겨두는 경향입니다.
- **테스트의 한계:** 많은 AI 모델이 제출한 패치가 기존 테스트는 통과하지만, 실제로 개발자가 수행한 삭제 작업을 무시하고 우회 코드를 삽입하는 방식으로 '테스트를 통과하기 위한 패치'를 생성합니다.
- **평가 공백:** 현재의 벤치마크 평가 방식은 불필요한 코드의 삭제 여부를 엄격하게 검증하지 않아, AI 모델의 실제 코드 품질을 과대평가하게 만듭니다.

## 💡 핵심 기술 및 아키텍처
- **삭제 민감 체크(Deletion-sensitive check):** 기존 테스트 외에 '삭제되어야 할 코드가 실제로 삭제되었는가'를 검증하는 단계를 추가하여 평가의 엄격함을 높였습니다.
- **CanItDelete 벤치마크:** 실제 커밋 기록에서 삭제만이 유일한 해결책인 사례 200개를 추출하여, 모델의 순수한 '삭제 능력'을 진단하는 새로운 벤치마크를 구축했습니다.
- **삭제 지도 학습:** 후속 학습(Post-training) 단계에서 삭제 작업을 명시적으로 훈련함으로써 모델이 삭제의 필요성을 인식하도록 유도했습니다.

## 📊 실험 결과 분석
- **성능 저하:** 삭제가 필수인 34개 작업에서 기존 테스트를 통과한 패치 중, 삭제까지 완벽하게 수행한 비율은 크게 감소했습니다(기존 63.2% → 삭제 체크 통과 시 41.9%).
- **Guard-and-Go 패턴:** 모델이 생성한 코드의 29.0%가 불필요한 코드를 삭제하는 대신 안전장치로 감싸는 패턴을 보였습니다.
- **지도 학습의 효과:** 삭제에 대한 감독을 추가하자 불완전한 삭제 비율이 13.9%p 감소하며 편집 성능이 전반적으로 개선되었습니다. (실험 수치는 논문 발췌에 명시된 수치를 인용함)

## 🌍 세상에 미치는 영향 & 실무 적용 사례
- **코드 품질 개선:** AI가 생성하는 코드의 가독성과 유지보수성이 향상되어, 실제 기업 현장에서 AI가 작성한 코드의 거부율을 낮출 수 있습니다.
- **평가 패러다임 전환:** 단순히 결과값이 맞는지를 보는 것을 넘어, 불필요한 로직을 제거하는 코드 리팩토링 능력이 AI 모델의 필수 역량으로 평가받는 계기가 될 것입니다.
- **실무 적용:** 모델의 파인튜닝 단계에서 삭제 작업을 구체적으로 학습시키면, 더 깔끔하고 간결한 코드 생성 능력을 갖춘 효율적인 AI 코딩 에이전트를 개발할 수 있습니다.
