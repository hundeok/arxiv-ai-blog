# 닫힌 모드는 게이지 선택이다: 인증된 코드 세계 모델에서의 도달 가능성 대비 위상수학

> **원본 논문 정보**
> - **제목:** An Enclosed Mode Is a Gauge Choice: Topology Relative to Reach in Certified Code World Models
> - **저자:** Javier Aguilar Martín
> - **발행일:** 2026-08-28
> - **PDF 링크:** [An Enclosed Mode Is a Gauge Choice: Topology Relative to Reach in Certified Code World Models](https://arxiv.org/pdf/2608.28541v1)


## ✨ 3줄 핵심 요약
- 인증된 코드 세계 모델은 샘플링 게이트가 관측할 수 없는 영역(닫힌 모드 등)에 대해 잘못된 위상 구조를 가질 수 있으며, 이는 특정 조건에서 전혀 탐지되지 않습니다.
- 모델의 위험성은 위상 그 자체가 아니라, 계획자가 접근 가능한 경로와 모델의 오류가 얼마나 겹치느냐(도달 가능성)에 달려 있습니다.
- 모델 수정을 위해서는 내부 영역에 대한 증거와 이를 감지할 수 있는 해상도를 갖춘 센서가 필수적이며, 그렇지 않으면 모델은 그저 그럴듯한 '게이지(gauge)' 값을 채워 넣을 뿐입니다.

## 📖 쉽게 풀어쓴 1분 핵심
코드 세계 모델(CWM)은 샘플링 게이트를 통해 검증된 실행 가능한 세계 모델을 생성합니다. 그러나 게이트가 볼 수 없는 내부 영역(예: 도달 불가능한 구역을 감싸는 고리 형태)에서는 모델이 실제와 다른 위상 구조를 가져도 게이트는 이를 알아차리지 못합니다. 연구 결과, 이러한 오류는 계획자가 해당 영역에 접근하는 순간(채널이 열릴 때) 큰 위험으로 돌변합니다. 저자는 모델의 위상 오류가 계획자의 경로와 만나는 '도달 가능성'에 따라 위험도가 결정됨을 증명했으며, 잘못된 모델을 수정하려면 단순히 영역을 표시하는 것이 아니라 오류의 차원과 일치하는 정밀한 방어 기제가 필요함을 강조합니다.

## 🎯 배경 및 문제점
기존 연구들은 인증된 코드 세계 모델이 데이터 기반으로 오류를 복구하려 할 때, 단순한 기하학적 형태(점이나 구)만을 선호하여 실제 복잡한 경계면을 유도하지 못하는 한계가 있음을 지적했습니다. 본 논문은 '닫힌 모드(enclosed mode)'라는 최소한의 환경을 통해, 샘플링 게이트가 모델을 완벽하게 검증했다고 하더라도 게이트의 시야 밖에서는 여전히 위험한 위상 오류가 존재할 수 있음을 규명하고자 했습니다.

## 💡 핵심 기술 및 아키텍처
- **게이지 선택(Gauge Choice):** 게이트가 도달 가능한 범위 내에서는 정확하지만 그 외부는 임의로 설정될 수 있는 모델의 성질을 '게이지'로 규정했습니다.
- **도달 가능성 대비 위상수학:** 모델의 위험은 영역 자체의 복잡성이 아닌, 계획자의 경로가 위상적 특징(구멍, 채널 등)과 얼마나 접촉하는지에 따라 결정됩니다.
- **방어 기제:** 모델 오류의 차원과 일치하는 '울타리(fence)'를 배치하여 계획자의 비정상적인 탐색을 억제하는 방어 기술을 제시했습니다.

## 📊 실험 결과 분석
- **위험의 단계적 변화:** 3개 모델 패밀리를 통해 각도 채널 폭($\gamma$)을 조절한 결과, 채널이 열리자마자 탐색 비용(play cost)이 급격히 변화함을 확인했습니다. 
- **수치의 근거:** 실험 데이터에 따르면, 채널이 0.1일 때 계획 비용은 약 1.09에서 0으로 급감(붕괴)하는 양상을 보였습니다.
- **복구의 한계:** 모델은 내부 영역에 대한 증거가 부족할 경우 위상을 올바르게 추론하지 못하고, 학습 데이터 내의 단편적인 점들을 맞추는 '미신적인 적합(superstitious point fits)'을 수행했습니다.
- **차원 일치:** 점 형태의 방어막은 1차원 경계 오류를 막지 못했으나, 오류의 차원과 일치하는 방어막을 설치하자 탐색 비용이 0.999에서 0.058로 개선되었습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
- **안전한 모델 설계:** 실무자는 모델이 검증 가능한 영역과 보이지 않는 영역을 구분하여, 계획자의 경로가 위험한 위상적 오류와 겹치지 않도록 설계해야 합니다.
- **데이터 증거의 중요성:** 경계 너머의 데이터 증거가 확보되지 않은 상태에서 모델 수정을 강제하는 것은 불가능합니다. 
- **실제 적용:** 복잡한 환경에서의 자율 주행이나 로봇 경로 계획처럼 '숨겨진 위상적 위험'이 존재할 수 있는 시스템에서, 모델의 도달 가능성 분석을 통한 단계적 방어 전략(Distrust-fence) 수립이 필수적입니다.
