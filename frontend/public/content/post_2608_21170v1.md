# 시각적 프롬프팅이 전부인가? 점진적 시각적 스캐폴딩을 통한 VLM 공간 추론 연구

> **원본 논문 정보**
> - **제목:** Is Visual Prompting All You Need? Studying VLM Spatial Reasoning under Progressive Visual Scaffolds
> - **저자:** Lars Benedikt Kaesberg, Tianyu Yang, Florian Valentin Wunderlich, Terry Ruas, Jan Philip Wahle, Daniel Kurzawe, Bela Gipp
> - **발행일:** 2026-08-21
> - **PDF 링크:** [Is Visual Prompting All You Need? Studying VLM Spatial Reasoning under Progressive Visual Scaffolds](https://arxiv.org/pdf/2608.21170v1)


## ✨ 3줄 핵심 요약
- VLM의 공간 추론 실패는 추론 능력 자체보다 시각 정보의 인지(grounding) 과정에서 발생하는 경우가 많음.
- 공간 정보를 명확히 보조하는 '시각적 스캐폴드(visual scaffolds)'를 도입하자 VLM의 작업 정확도가 최대 34.0%p 향상됨.
- 동일한 계획 수립 문제라도 시각적 표현 방식에 따라 모델의 성능과 실패 원인이 근본적으로 달라짐을 증명함.

## 📖 쉽게 풀어쓴 1분 핵심
거대 시각-언어 모델(VLM)이 복잡한 퍼즐이나 공간 계획 문제를 풀지 못할 때, 흔히들 모델의 지능이 부족해서라고 생각합니다. 하지만 이 연구는 "모델이 문제를 못 푸는 것이 아니라, 애초에 그림을 제대로 못 보는 것일 수 있다"는 점에 주목했습니다. 연구진은 SPaRC 벤치마크를 활용하여 모델이 정보를 더 쉽게 파악할 수 있도록 돕는 '시각적 도우미(스캐폴드)'를 입력 데이터에 추가했습니다. 결과적으로 모델의 논리력은 그대로인데 그림만 조금 더 알아보기 쉽게 바꾸었더니, 정답률이 획기적으로 상승했습니다. 이는 VLM의 성능을 높이기 위해 무조건 큰 모델을 쓰는 것보다, 정보를 얼마나 잘 보여주느냐가 중요하다는 것을 보여줍니다.

## 🎯 배경 및 문제점
- **인지와 추론의 혼재:** VLM의 멀티모달 추론 실패가 시각적 인지 단계에서 발생하는지, 아니면 이후의 논리적 추론 단계에서 발생하는지 명확히 구분되지 않았음.
- **표현의 영향력 간과:** 기존 연구들은 주로 모델 자체를 수정하거나 텍스트 기반의 프롬프팅에 집중했으며, 동일한 문제를 시각적 정보 표현 방식만 바꾸었을 때 어떤 변화가 생기는지 깊이 연구하지 않음.

## 💡 핵심 기술 및 아키텍처
- **SPaRC 벤치마크:** 격자 기반의 시각적 퍼즐 문제들로 구성되어, 시각적 정보와 공간 계획 문제를 체계적으로 테스트함.
- **시각적 스캐폴드(Visual Scaffolding):** 시각적 양식(modality)은 유지하되, 격자의 구조를 모델이 더 쉽게 읽을 수 있도록 만드는 진단적 개입(diagnostic interventions) 기법.
- **구조적 접근:** 시각 정보의 가독성을 높여 모델이 '시각적 접지(grounding)'를 더 잘 수행하도록 유도함.

## 📊 실험 결과 분석
- **성능 향상:** Qwen 3.5 397B 모델 기준으로, 시각적 스캐폴드 적용 시 원본 대비 정확도가 14.4%에서 47.8%로 33.4%p 상승함.
- **추론 보완:** GRPO 기반 학습과 결합했을 때, 기존 방식에서는 거의 효과가 없던 반면, 스캐폴드 도입 후 최대 4.6%p의 추가적인 정확도 상승을 확인함.
- **오류 분석:** 시각적 개체 탐지(object detection) 관련 오류는 크게 줄었으나, 규칙에 기반한 추론(rule reasoning)은 여전히 도전적인 과제로 남음. 즉, 시각적 지원이 인지적 오류는 해결해주지만 복잡한 논리 문제를 대신 해결해주지는 않음.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
- **평가 기준 정립:** VLM 벤치마크가 '시각적 인지 능력'을 측정하는지 '추론 능력'을 측정하는지, 아니면 둘 다의 혼합인지를 결정하는 핵심 요인이 시각적 인터페이스임을 입증함.
- **실무적 제언:** 복잡한 시각 정보를 처리해야 하는 산업용 AI 시스템 설계 시, 무리한 모델 크기 확장보다는 정보를 직관적으로 가시화하는 입력단 설계를 우선하는 것이 효율적일 수 있음을 시사함.
