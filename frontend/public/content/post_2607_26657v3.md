# 인폴드: 초효율적 체화 로봇 제어를 위한 세계 모델 상상력의 예측 표현화

> **원본 논문 정보**
> - **제목:** Enfold: Folding World Model Imagination into Predictive Representations for Ultra-Efficient Embodied Control
> - **저자:** Weili Zeng, Yitong Xing, Fulong Liu, Chengqun Yang, Antao Xiang, Feng Tian, Jingnan Gao, Jisong Cai, Xin Wang, Xiaomin Wu, Yao Mu, Xiaokang Yang, Yichao Yan
> - **발행일:** 2026-07-29
> - **PDF 링크:** [Enfold: Folding World Model Imagination into Predictive Representations for Ultra-Efficient Embodied Control](https://arxiv.org/pdf/2607.26657v3)


## ✨ 3줄 핵심 요약
* **상상력의 내재화:** 미래를 생성하는 복잡한 연산 과정을 현재 시점의 비전-언어 표현 학습으로 통합하여, 실시간 추론 시 별도의 영상 생성 과정을 제거했습니다.
* **비대칭적 구조:** 학습 시에는 생성 모델의 다단계 상태를 지도 신호로 사용하지만, 배포 시에는 생성기 없이 인코더만으로 행동을 예측하여 효율성을 극대화했습니다.
* **압도적 속도:** 기존 모델 대비 행동 지연 시간을 최대 10.1배 단축했으며, 인간의 개입 등 환경 변화에 유연하게 대응하는 제어 능력을 확보했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
로봇이 미래를 예측하려면 보통 '앞으로 일어날 일을 영상으로 생성'하는 과정을 거치는데, 이는 연산 비용이 많이 들고 속도가 느립니다. **Enfold(인폴드)**는 이 문제를 다르게 접근합니다. 미래를 매번 직접 그리는 대신, 미래를 그릴 때 필요한 '핵심 연산 원리'를 인공지능의 현재 눈(시각적 문맥) 속에 미리 학습시켜 심어버리는 것입니다. 덕분에 로봇은 실제 작동할 때 미래를 상상하느라 멈칫거릴 필요 없이, 보고 있는 화면만으로 즉각적으로 최적의 행동을 결정할 수 있습니다.

## 🎯 배경 및 문제점
* **기존 방식의 한계:** '먼저 상상하고 행동하기(Imagine-then-act)' 방식은 매번 비디오를 생성해야 하므로 계산 자원이 많이 들고 행동 지연(latency)이 발생합니다.
* **복잡한 의존성:** 기존 세계 모델은 행동을 예측하기 위해 미래의 시각적 데이터를 물리적으로 생성해야 하는 구조적 결함이 있어, 실시간 반응이 중요한 로봇 제어에 부적합한 경우가 많습니다.

## 💡 핵심 기술 및 아키텍처
* **미래 생성 연산의 전이:** 생성 모델이 미래를 구축하는 과정에서 나타나는 중간 상태(다단계 상태)를 현재 시점 전용 인코더의 학습 데이터로 활용합니다.
* **비대칭 인프라:** 학습 단계에서는 생성 모델의 정보를 흡수하지만, 실제 배포 단계에서는 생성기를 완전히 제외합니다. 이를 통해 인코더는 무의미한 세부 변화를 제거하고, 전이 구조(transition structure)와 같은 본질적인 예측 정보만을 습득하게 됩니다.
* **표현 학습의 내재화:** 현재 시각적 문맥과 언어 지시어로부터 미래를 예측할 수 있는 상태 정보를 직접 도출하도록 인코더를 최적화했습니다.

## 📊 실험 결과 분석
* **행동 지연 감소:** Fast–W AM 모델 대비 행동 지연을 3.7배 단축했으며, Enfold-Flash 모드에서는 10.1배까지 향상되었습니다. (기존 모델 대비 성능 수치)
* **강력한 제어:** LIBERO, RoboTwin2.0 및 실제 로봇 환경에서 높은 수준의 제어 성능을 보였습니다.
* **적응성 확인:** 인간의 개입으로 현장이 수정될 경우, 단순한 과거 궤적 재현이 아니라 수정된 환경에 맞춰 생성된 연속성과 행동이 즉각적으로 적응함을 확인했습니다.
* **분석:** 표현 학습 분석 결과, 로봇은 불필요한 시각적 노이즈를 억제하고 시간이 흐름에 따라 변화하는 본질적 정보를 더 잘 포착하는 것으로 나타났습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **실시간 로봇 제어:** 생성형 AI의 복잡한 추론 능력을 유지하면서도 실시간성이 핵심인 제조 및 물류 로봇 분야에 적용 가능합니다.
* **효율적 모델 배포:** 고가의 GPU 자원이 부족한 현장 로봇에서도 거대 모델의 상상력을 활용한 고도화된 작업을 수행할 수 있는 기반을 마련했습니다.
* **유연한 상호작용:** 환경 변화에 실시간으로 적응하는 능력을 통해, 인간과 협업하는 서비스 로봇의 지능 수준을 한 단계 높일 것으로 기대됩니다.
