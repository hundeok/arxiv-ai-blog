# 턴 주입, 토큰 주입이 아닌 방식: LLM의 자가 수정을 위한 추론 경로 재설정 학습

> **원본 논문 정보**
> - **제목:** Inject a Turn, Not a Token: Learning Where to Redirect LLM Reasoning for Self-Correction
> - **저자:** Jiwon Jeon, Myungsik Cho, Jeonghye Kim, Youngchul Sung
> - **발행일:** 2026-10-09
> - **PDF 링크:** [Inject a Turn, Not a Token: Learning Where to Redirect LLM Reasoning for Self-Correction](https://arxiv.org/pdf/2610.13672v1)


## ✨ 3줄 핵심 요약
*   LLM이 추론 과정 중 오류를 범했을 때, 기존 문맥 내에 지시문을 끼워 넣는(inline) 방식은 효과가 낮아 새로운 사용자 턴(turn)으로 지시를 주입하는 기법인 'UPTURN'을 제안함.
*   학습된 MLP 헤드를 사용하여 추론 과정 중 어느 시점에 개입할지(where to intervene)를 결정하며, LLM 자체에 대한 추가 미세 조정(fine-tuning)이 필요 없음.
*   4개의 추론 모델과 6개의 수학 벤치마크 실험 결과, 모든 환경에서 기존 자가 수정(self-correction) 기법 대비 평균 정확도를 향상함.

## 📖 쉽게 풀어쓴 1분 핵심
LLM은 생성 과정에서 한 번 잘못된 길로 들어서면 끝까지 오류를 범하는 경향이 있습니다. 기존 연구들은 이를 고치기 위해 모델 전체를 다시 훈련하거나 수정 문장을 생성하게 했으나, 이는 비용이 큽니다. 본 연구는 모델을 재훈련하는 대신, **"어느 시점에 수정을 가할 것인가?"**를 결정하는 작은 신경망(130K 파라미터 MLP)을 학습시켰습니다. 또한, 단순히 글자 사이에 교정 지시를 넣는 대신, **'사용자가 다시 질문하는 새로운 턴'**을 만들어 지시를 주입함으로써 모델이 올바른 논리 경로를 찾도록 강제했습니다. 이 방법은 LLM의 핵심 구조를 건드리지 않고도 추론 실패를 복구하는 성능을 극대화합니다.

## 🎯 배경 및 문제점
*   **자가 수정의 한계:** LLM은 자기 주도적 수정 능력이 부족하며, 외부 피드백 없는 수정은 오히려 추론 정확도를 떨어뜨리기도 합니다.
*   **비효율적인 훈련 방식:** 기존의 수정 기법은 LLM 자체를 미세 조정하거나, 복잡한 외부 비평가/검증기를 훈련해야 하므로 비용과 데이터 소모가 큽니다.
*   **추론 경로의 이탈:** 생성형 모델은 이전 단계의 출력에 의존하므로, 초기 단계의 작은 실수 하나가 전체 추론 결과를 오답으로 이끕니다.

## 💡 핵심 기술 및 아키텍처
*   **UPTURN 프레임워크:** 모델의 추론 도중 특정 지점에서 개입하여, 이전 문맥(prefix)은 유지한 채 새로운 사용자 턴으로 지시사항을 삽입하고 나머지 부분(suffix)을 재생성합니다.
*   **개입 지점 결정(Where to intervene):** Qwen3-0.6B 모델을 인코더로 고정하고, 그 위에 130K 파라미터 규모의 작은 MLP 헤드를 얹어 최종 정답률을 기준으로 최적의 수정 시점을 예측하도록 학습했습니다.
*   **미세 조정 없음:** LLM 본체를 재학습하지 않으므로 기존 추론 모델들과 결합하여 즉시 사용할 수 있습니다.

## 📊 실험 결과 분석
*   **정확도 향상:** 4개의 추론 모델과 6개의 수학 벤치마크 테스트 결과, 32번의 시도(rollout)를 기준으로 한 베이스라인 모델 대비 모든 환경에서 평균 정확도가 상승했습니다.
*   **비교 우위:** 동일한 수정 예산 내에서 기존의 Reflexion(반성) 기법이나 수정 토큰 삽입 기법보다 뛰어난 성능을 보였습니다.
*   **강건성:** 벤치마크와 사용된 모델에 상관없이 일관된 성능 향상을 보였으며, 특히 기존 모델이 해결하지 못했던 오류 사례들에 대해 높은 '구조율(rescue rate)'을 기록했습니다. (구체적인 수치로 벤치마크별 정확도 상승폭은 논문 발췌 표 17 및 표 18 참조)

## 🌍 세상에 미치는 영향 & 실무 적용 사례
*   **비용 효율적인 성능 개선:** 거대한 LLM을 추가로 훈련할 필요 없이, 아주 작은 모듈만 추가하여 모델의 추론 능력을 보완할 수 있습니다.
*   **범용성:** 특정 모델에 종속되지 않고 GRPO 등 기존의 다양한 추론 최적화 방법과 상호 보완적으로 작동합니다.
*   **실무 적용:** 수학 문제 풀이와 같이 논리적 단계가 중요한 분야에서, 추론 과정의 오류를 실시간으로 탐지하고 바로잡는 도구로 즉시 활용 가능합니다.
