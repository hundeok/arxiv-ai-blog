# OpenART: 개방형 환경 진화를 통한 에이전트 레드 팀 구성 확장

> **원본 논문 정보**
> - **제목:** OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution
> - **저자:** Yunhao Chen, Xin Wang, Yixu Wang, Yi Liu, Jie Li, Yan Teng, Xingjun Ma, Xia Hu, Yu-Gang Jiang
> - **발행일:** 2026-08-01
> - **PDF 링크:** [OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution](https://arxiv.org/pdf/2608.00677v1)


## ✨ 3줄 핵심 요약
* **오픈형 레드 팀 프레임워크:** AI 에이전트의 안전성을 평가하기 위해 50개 도메인에 걸쳐 1만 개의 검증된 상태 기반 시나리오를 제공하는 'OpenART'를 도입했습니다.
* **환경 진화 공격(EMHA):** 에이전트의 학습 파라미터 수정 없이, 환경 상태만을 단계적으로 변화시켜 복합적인 보안 위협을 탐지하는 '진화형 마르코프 하이퍼그래프 공격(EMHA)'을 제안했습니다.
* **안전성 검증 효과:** 75개의 에이전트-모델 조합을 평가한 결과, 작업 복잡도가 높아질수록 환경 변화가 에이전트의 보안 실패를 더 효과적으로 노출함을 입증했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
기존의 AI 안전성 평가는 짧고 단순한 단일 작업 위주였습니다. 하지만 실제 AI 에이전트는 긴 시간 동안 여러 도구와 데이터를 사용하며 '상태'를 계속 변화시킵니다. **OpenART**는 이러한 에이전트의 실제 작동 환경을 모방하여, 환경을 조금씩 진화시키며 에이전트가 시간이 지남에 따라 어떻게 보안 실수를 저지르는지 확인합니다. 이를 통해 단순히 명령어를 던지는 방식보다 훨씬 더 정교하고 장기적인 위험을 찾아낼 수 있습니다.

## 🎯 배경 및 문제점
* **기존 방식의 한계:** 현재의 안전성 벤치마크는 짧고 정적인 환경을 다루기 때문에, 에이전트가 복잡한 워크플로우 속에서 점진적으로 위험에 노출되는 '누적적 위험'을 연구하기 어렵습니다.
* **표준화 부족:** 벤치마크마다 사용하는 인터페이스가 달라 서로 다른 에이전트 런타임 간의 직접적인 성능 비교가 어렵습니다.
* **상태 의존성:** 에이전트의 안전성은 단일 행동이 아닌, 환경 변화에 따른 장기적인 대응 방식에 의해 결정되는데 이를 반영하는 체계적인 틀이 부족했습니다.

## 💡 핵심 기술 및 아키텍처
* **OpenART 아레나:** 500,000개 이상의 도구, MCP(Model Context Protocol), 기술을 사용하여 50개 도메인, 10,000개의 상태 기반 시나리오를 구성했습니다.
* **진화형 마르코프 하이퍼그래프 공격 (EMHA):** 파라미터 업데이트 없이 환경 상태를 변경하는 블랙박스 정책입니다. 하이퍼그래프 경로를 통해 권한이 부여된 상태 전환을 조율하며, 작업 목표는 유지한 채 환경만 변화시켜 에이전트의 취약점을 공략합니다.
* **표준화된 인터페이스:** 대상 어댑터를 통해 15개의 에이전트와 5개의 파운데이션 모델을 동일한 환경에서 평가할 수 있도록 했습니다.

## 📊 실험 결과 분석
* **공격 성공률(ASR):** 75개의 에이전트-모델 설정에서 전체 평균 85.0%의 엄격한 공격 성공률(Strict ASR)을 기록했습니다.
* **복잡도에 따른 효과:** 단순 환경에서는 명령어 기반 공격보다 1.8~2.7% 앞섰으나, 복잡한 환경에서는 17.2~17.6%까지 격차가 벌어졌습니다. 이는 작업 복잡도가 높을수록 환경 진화 방식이 보안 결함을 더 잘 찾아냄을 의미합니다.
* **에이전트 구현의 중요성:** 모델 성능 외에도 에이전트 자체의 ID와 구현 방식이 안전성 변동의 7.6%를 추가로 설명하며, 실제 구동 환경(Runtime)이 안전성에 큰 영향을 미침을 확인했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **실무적 적용:** 복잡한 기업용 워크플로우(금융, 물류, 법률 등)를 수행하는 에이전트의 보안 취약점을 사전에 점검하는 표준 도구로 활용될 수 있습니다.
* **장기적 보안 설계:** 에이전트가 도구를 호출하는 과정에서 발생하는 '상태 드리프트(안전 상태에서 위험 상태로의 점진적 변화)'를 파악하여, 개발자가 에이전트 배포 전 보안 방어 기제를 보강하는 데 기여합니다.
* **연구 표준화:** 50개 도메인의 방대한 시나리오와 통합된 평가 인터페이스를 제공함으로써, 향후 다양한 에이전트 모델 간의 객관적인 안전성 경쟁 및 연구를 촉진할 것입니다.
