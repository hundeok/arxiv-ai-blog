# 컴퓨터 사용 기록으로부터 작업 모델 유도하기

> **원본 논문 정보**
> - **제목:** Inducing Task Models from Computer-Use Traces
> - **저자:** Yucheng Jiang, Zora Zhiruo Wang, Ruishi Chen, Diyi Yang
> - **발행일:** 2026-08-20
> - **PDF 링크:** [Inducing Task Models from Computer-Use Traces](https://arxiv.org/pdf/2608.20319v1)


## ✨ 3줄 핵심 요약
* **TASKMODELINDUCTION(TMI)**는 사용자의 컴퓨터 활동 기록(스크린샷, 마우스, 키보드)에서 섞여 있는 복합적인 작업을 분리하고 구조화된 모델로 변환합니다.
* 각 작업을 계층적 목표 모델과 절차적 제어 흐름 모델로 재구성하여, 사람이 이해할 수 있고 AI 에이전트가 재사용 가능한 지식 형태로 만듭니다.
* 실험 결과, 기존 방식 대비 작업 추론 정확도에서 높은 성능을 보였으며, AI 에이전트의 새로운 작업 수행 정확도를 30.0% 향상했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
우리가 컴퓨터로 일할 때는 이메일 확인, 문서 작성, 웹 검색 등 여러 작업을 동시에 번갈아 가며 수행합니다. 이런 복잡한 활동 기록은 단순히 마우스 클릭이나 키보드 입력 같은 파편화된 데이터로 남습니다. TMI(Task Model Induction) 기술은 이 파편화된 기록을 분석해 "사용자가 어떤 목적으로 이 일을 했는지(목표 모델)"와 "어떤 순서와 방식(제어 흐름)으로 수행했는지"를 체계적인 지도로 그려냅니다. 이를 통해 AI는 사람의 작업 방식을 효과적으로 학습하고, 조직은 업무 과정을 감사하거나 문서화된 지식으로 재활용할 수 있게 됩니다.

## 🎯 배경 및 문제점
* **데이터의 비구조화**: 스크린샷이나 입력 로그는 그 자체로는 의미를 파악하기 어려운 저수준(low-level) 데이터입니다.
* **멀티태스킹의 복잡성**: 사용자의 실제 업무는 여러 작업이 섞여 있고, 하나의 작업 안에서도 세부 목표가 교차하여 나타납니다.
* **기존 방식의 한계**: 기존 기술들은 미리 정의된 단일 워크플로우에 의존하거나, 작업의 구조적 모델이 아닌 단순히 단계별 요약만을 제공하는 데 그쳤습니다.

## 💡 핵심 기술 및 아키텍처
TMI는 두 단계의 핵심 과정을 거칩니다.
1. **잠재적 작업 발견**: 무질서한 입력 기록에서 섞여 있는 작업들을 분리하고 개별 작업을 식별합니다.
2. **모델 구성**: 각 작업에 대해 두 가지 층위를 결합합니다.
    * **목표 모델(Objective Model)**: 재귀적 목표 분해를 통한 계층적 구조를 생성합니다.
    * **절차 모델(Procedure Model)**: 구조적 프로그래밍 정리(Structured Programming Theorem)를 기반으로 `SEQ`(순차), `FOR`(반복), `WHILE`(조건 반복) 연산자를 사용하여 실제 수행 흐름을 재구성합니다.

## 📊 실험 결과 분석
* **내적 타당성**: 통제된 인간 및 에이전트 활동 기록에서, 실제 작업 그룹화와 0.974의 일치도를 보였으며, 전체 실행 단계의 74.9%를 정확히 재구성했습니다. 이는 기존의 작업 유도 베이스라인을 크게 상회하는 수치입니다.
* **외적 타당성**: TMI로 생성된 기술(skill)을 사용했을 때, AI 에이전트가 학습하지 않은 새로운 작업을 수행하는 정확도가 기존 베이스라인 대비 30.0% 향상되었습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **에이전트 학습**: 비싼 비용의 수동 주석(annotation) 작업 없이도, 인간의 실제 작업 기록으로부터 AI 에이전트가 스스로 업무 노하우를 습득할 수 있습니다.
* **업무 표준화 및 감사**: 조직 내에서 수행되는 암묵적 업무 방식을 명시적이고 감사 가능한 모델로 변환하여 업무 매뉴얼화 및 표준화에 기여합니다.
* **개인화 시스템**: 사용자의 활동 기반 모델을 통해 시스템이 다음에 무엇을 할지 예측하여 업무 효율을 높일 수 있습니다.
* **참고 사항**: 개인정보가 포함된 기록을 처리할 경우, 정보 유출 방지를 위해 스크린샷이나 키보드 입력 데이터에 대한 사전 비식별화 처리가 필수적입니다.
