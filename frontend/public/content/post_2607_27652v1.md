# 검색 에이전트를 위한 그래프 구조 하니스: Harness-G

> **원본 논문 정보**
> - **제목:** Harness-G: A Graph-Structured Harness for Search Agents
> - **저자:** Yanning Hou, Haoyuan Chen, Sihang Zhou, Xiaoshu Chen, Xirui Liu, Duanyang Yuan, Lingyuan Meng, Quan Liu, Jian Huang
> - **발행일:** 2026-07-30
> - **PDF 링크:** [Harness-G: A Graph-Structured Harness for Search Agents](https://arxiv.org/pdf/2607.27652v1)


## ✨ 3줄 핵심 요약
* **검색-동등성 붕괴 해결:** 기존 자유 형식 검색 쿼리 방식이 겪는 언어적 모호성과 학습 효율 저하 문제를 '그래프 기반 행동 선택' 인터페이스로 전환하여 해결했습니다.
* **구조화된 행동 메뉴:** 모델이 임의의 문장을 생성하는 대신, 환경이 제공하는 명확한 문장·엔티티 선택지(Action Menu) 중 하나를 고르도록 하여 탐색의 일관성을 높였습니다.
* **성능 우위:** 6개 QA 벤치마크에서 기존 최고 수준 모델인 Graph-R1 대비 1.5B 모델에서 10.74점, 3B 모델에서 3.98점 높은 F1 점수를 기록했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
기존 AI 검색 에이전트는 사람이 검색어를 입력하듯 자유로운 형식으로 쿼리를 생성합니다. 하지만 모델은 의미가 같아도 매번 다른 단어로 쿼리를 생성하곤 하며, 이로 인해 학습 과정에서 무엇이 진짜 좋은 검색 결과인지 판단하기 어려워지는 '검색-동등성 붕괴' 현상이 발생합니다. **Harness-G**는 이를 해결하기 위해 모델에게 '자유 글쓰기'를 시키지 않습니다. 대신 환경이 제공하는 그래프 정보 속에서 "어떤 문장을 선택할지" 혹은 "어떤 개체를 검색할지"와 같은 명확한 메뉴를 선택하게 합니다. 이 방식을 통해 학습의 효율성과 예측 가능성을 크게 높였습니다.

## 🎯 배경 및 문제점
* **자유 형식 쿼리의 한계:** LLM이 생성하는 자연어 쿼리는 표면적으로는 다르지만 실제 의미는 같은 경우가 많습니다(검색-동등성 붕괴). 이는 탐색 과정을 비효율적으로 만들고 강화학습의 보상을 불안정하게 합니다.
* **학습 불균형:** 기존 방식은 모델이 생성한 쿼리가 환경에 의해 어떻게 검색 결과로 매핑되는지 명확하지 않아, 정책(Policy)과 환경 사이의 상호작용이 모호하게 설계되어 있습니다.

## 💡 핵심 기술 및 아키텍처
* **그래프 기반 인터페이스:** 자유 형식 쿼리 대신 문장·엔티티 선택을 위한 '유한 행동 선택' 구조를 도입했습니다. 이를 통해 모델은 `SELECT`, `LOOKUP`, `ANSWER_WITH`, `ANSWER` 중 하나를 선택합니다.
* **구조화된 비근시적 신용 할당 (SNC):** 학습 과정에서 고정된 정답 평가기(Frozen Answer Scorer)를 사용하여, 모델이 선택한 행동이 최종 정답에 기여했는지를 비교 평가합니다. 이를 통해 미래의 성과를 이끌어낸 과거의 행동에 정확하게 점수를 배분합니다.
* **일관된 탐색:** 모델이 생성한 토큰이 아닌, 시스템이 제공하는 행동 ID를 사용하므로 매번 동일한 상태에서 대체 가능한 행동들을 직접 비교할 수 있습니다.

## 📊 실험 결과 분석
* **성능 향상:** 6개 QA 벤치마크 테스트에서 Harness-G는 모든 모델 규모에서 가장 높은 평균 F1 점수를 달성했습니다.
* **비교 우위:** Graph-R1과 비교했을 때, 1.5B 파라미터 모델에서 F1 10.74점, 3B 모델에서 3.98점 향상되었습니다.
* **제로샷 전이:** 의학, 농업, 법률 등 훈련 데이터에 포함되지 않은 전문 도메인에서도 기존 최고 수준의 프롬프트 기반 모델(HyperGraphRAG)보다 F1 점수가 평균 3.69점 높게 나타나, 도메인 특화 지도 학습 없이도 구조적 탐색의 범용성이 입증되었습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **지식 집약적 업무의 효율화:** 복잡한 다단계 추론(Multi-hop reasoning)이 필요한 지식 탐색 작업에서 모델이 더 정확하고 일관된 정보를 찾도록 유도합니다.
* **데이터 효율성:** 특정 도메인에 특화된 추가 학습 없이도 그래프 구조를 생성하는 파이프라인만 있다면 새로운 지식 도메인으로 즉시 확장 가능합니다.
* **실무 적용:** 모델이 검색 과정을 스스로 통제하는 대신, 시스템이 제공하는 선택지 내에서 행동하게 함으로써 기업용 검색 엔진 등에서 모델의 탐색 경로를 감시하거나 최적화하는 데 유리합니다.
