# 환경을 가리지 마라: 관찰 데이터 감독이 강화학습 중 에이전트의 탐색 방식을 바꾸는 법

> **원본 논문 정보**
> - **제목:** Don't Mask the Environment: Observation Supervision Changes How Agents Explore Under RL
> - **저자:** Juzheng Zhang, Disha Makhija, Manoj Ghuhan Arivazhagan, Vinayshekhar Bannihatti Kumar, Rashmi Gangadharaiah
> - **발행일:** 2026-09-17
> - **PDF 링크:** [Don't Mask the Environment: Observation Supervision Changes How Agents Explore Under RL](https://arxiv.org/pdf/2609.20715v1)


## ✨ 3줄 핵심 요약
- 기존의 에이전트 학습(SFT)은 행동(Action)만 예측하지만, 본 논문은 환경 관찰(Observation)까지 예측하게 하는 'ActObs' 기법을 제안합니다.
- ActObs는 모델 파라미터나 데이터를 추가하지 않고도, 강화학습(RL) 단계에서 더 효과적인 탐색을 유도하고 성능을 향상시킵니다.
- 관찰 데이터를 예측함으로써 모델은 행동의 결과를 더 잘 이해하게 되며, 이는 강화학습 과정에서의 무분별한 변화를 방지합니다.

## 📖 쉽게 풀어쓴 1분 핵심
보통 인공지능 에이전트를 학습시킬 때는 "어떤 행동을 했는지"에만 집중합니다. 하지만 실제 환경에서는 에이전트가 행동을 하면 환경이 그에 따른 "결과(관찰)"를 돌려줍니다. 연구진은 에이전트가 이 결과까지 예측하도록 훈련하면, 단순히 행동을 흉내 내는 것을 넘어 "내가 이렇게 행동하면 이런 결과가 나오겠구나"라는 인과관계를 더 잘 배우게 된다는 사실을 발견했습니다. 이를 적용한 'ActObs' 방식은 복잡한 환경에서 에이전트가 더 지능적으로 탐색하게 하여, 최종적인 과제 수행 능력을 크게 높여줍니다.

## 🎯 배경 및 문제점
- **표준적인 지도 미세조정(SFT)의 한계:** 현재의 표준 관행은 환경의 피드백(관찰 데이터)을 단순히 참고용 문맥으로만 사용할 뿐, 학습의 타겟으로는 삼지 않습니다.
- **가정의 오류:** 기존 방식은 관찰 데이터를 읽는 것은 유용하지만, 이를 예측하는 것은 불필요하다고 가정합니다.
- **RL 초기화의 부족:** SFT 단계에서 행동만 학습하게 되면, 이후 강화학습(RL) 과정에서 환경의 변화에 적절히 대응하거나 효과적으로 탐색하는 능력이 부족해질 수 있습니다.

## 💡 핵심 기술 및 아키텍처
- **ActObs(Action + Observation):** 기존 학습 방식에서 관찰 데이터 토큰에 적용되던 마스크(제외)를 제거하고, 행동과 관찰 데이터를 모두 예측하도록 언어 모델링 손실 함수를 확장했습니다.
- **파라미터 효율성:** 새로운 데이터나 파라미터, 복잡한 시퀀스 토큰 추가 없이 기존의 궤적(Trajectory) 데이터를 그대로 활용합니다.
- **인과관계 모델링:** 모델이 `p(o_t | h_t, a_t)`(이전 상태와 행동에 따른 다음 환경 관찰 예측)를 학습하도록 하여, 행동이 환경에 미치는 결과를 내재화하게 합니다.

## 📊 실험 결과 분석
- **성능 향상:** Qwen3-4B 모델에서 ActObs를 적용한 GRPO(강화학습)는 기존 방식보다 모든 샘플링 버젯(Budget)에서 더 높은 성공률(pass@k)을 보였습니다. 
- **Qwen3-8B 결과:** 일부 지표에서는 신뢰도가 미세하게 조정되기도 했으나, pass@16 기준으로 성공률이 3.4%p 상승했으며 더 많은 종류의 과제를 해결했습니다.
- **일반화 능력:** 학습 과정에서 보지 못한 새로운 도메인인 'aider-polyglot' 코드 편집 과제에서도 4B 모델 기준 pass@1 성공률이 4.2%p 향상되었습니다.
- **학습 안정성:** ActObs는 강화학습 중 정책의 엔트로피를 더 잘 유지하면서도, 초기 SFT 상태와 유사한 안정적인 정책을 유지하는 경향을 보였습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
- **에이전트의 자율성 강화:** 터미널 환경과 같은 복잡한 CLI 환경에서 에이전트가 시행착오를 겪을 때, 단순히 행동을 반복하는 것이 아니라 환경의 반응을 보고 전략을 수정하는 능력이 향상됩니다.
- **범용성 확장:** 본 연구는 터미널 에이전트에 한정하여 실험되었으나(제한사항), 향후 코딩, 웹 브라우징, GUI 제어 등 환경 변화가 실시간으로 발생하는 모든 에이전트 시스템에 적용 가능할 것으로 기대됩니다.
- **데이터 활용 효율:** 추가 데이터 수집 없이 기존에 보유한 에이전트 로그만으로도 모델의 인과관계 추론 능력을 극대화할 수 있어, 실무적인 비용 절감 효과가 큽니다.
