# 에이전트 오류 데이터셋: 실패 분석 및 오류 인지 사후 학습을 위한 50,000개 오류-진단 쌍 확장

> **원본 논문 정보**
> - **제목:** Agent Error Dataset: Scaling 50,000 Error--Diagnosis Pairs for Failure Analysis and Error-Aware Post-Training
> - **저자:** Kunlun Zhu, Xuyan Ye, Yibo Li, Cheng Qian, Beibin Li, Heng Ji
> - **발행일:** 2026-09-30
> - **PDF 링크:** [Agent Error Dataset: Scaling 50,000 Error--Diagnosis Pairs for Failure Analysis and Error-Aware Post-Training](https://arxiv.org/pdf/2609.40111v1)


## ✨ 3줄 핵심 요약
* LLM 에이전트의 실패 사례에서 관찰, 행동, 환경 반응을 수집하여 50,228개의 '오류-진단' 쌍으로 구성된 데이터셋(AED)을 구축했습니다.
* 에이전트의 오류를 진단하고 수정안을 생성하는 파이프라인(AET)을 통해, 수정안 적용 시 검증 성공률이 18.4%에서 51.1%로 상승했습니다.
* 해당 데이터셋으로 미세 조정된 모델은 에이전트의 오류 진단 및 행동 복구 성능에서 기존 모델 대비 향상된 정확도를 보였습니다.

## 📖 쉽게 풀어쓴 1분 핵심
인공지능 에이전트가 업무를 수행하다 실패하면, 우리는 그 과정이 왜 실패했는지 알기 어렵습니다. 본 논문은 에이전트가 실패한 기록(상황, 선택한 행동, 결과)을 모아 '왜 틀렸는지(진단)'와 '어떻게 고쳐야 하는지(수정)'를 학습시키는 데이터셋인 **AED(Agent Error Dataset)**를 제안합니다. 이 데이터를 학습한 인공지능은 단순히 정답을 외우는 것이 아니라, 자신이 왜 실패했는지 스스로 깨닫고 올바른 행동을 선택하는 능력을 갖추게 됩니다.

## 🎯 배경 및 문제점
LLM 기반 에이전트는 다양한 도구를 활용해 복잡한 과업을 수행하지만, 실패 시 원인을 파악하는 것은 매우 어렵습니다. 기존에는 성공 사례(Success-only) 위주의 학습이 주를 이루었으나, 이는 실패를 통해 배우는 과정이 부족하여 에이전트의 일반화 성능과 문제 해결력을 저해했습니다. 

## 💡 핵심 기술 및 아키텍처
* **AED(Agent Error Dataset):** 33개 환경, 23개 정책 모델에서 수집한 50,228개의 오류-진단 쌍.
* **AET(Agentic Error-to-Training) 파이프라인:** 실패 사례를 수집하고, 오류를 진단하며, 수정안을 생성한 뒤 검증하는 5단계 자동화 과정입니다.
* **학습 방식:** 모델이 스스로 오류를 진단하도록 학습하고, 다음 행동을 수정(Actor recovery)하도록 유도하는 두 가지 관점의 훈련 데이터를 구성했습니다.

## 📊 실험 결과 분석
* **수정안 성능:** 첫 번째로 제안된 수정안을 적용했을 때, 에이전트의 검증 성공률이 18.4%에서 51.1%로 32.7%p 상승했습니다.
* **진단 정확도:** Qwen3-8B 모델을 AED로 미세 조정했을 때, 정답 레이블과 일치하는 정확도가 47.2%에서 63.6%로 향상되었습니다(943개 테스트 케이스 기준).
* **복구 성능:** WebShop-lite 환경에서 '행동 수정 기반 학습(action-only repair)'이 성공 사례만을 학습한 방식보다 6.67%p 더 높은 점수를 기록했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
이 연구는 LLM 에이전트가 시행착오를 통해 스스로 학습할 수 있는 기반을 마련합니다. 실무적으로는 소프트웨어 에이전트의 신뢰성을 높이고, 에이전트의 오류를 자동으로 진단하여 시스템의 복원력을 높이는 데 기여할 수 있습니다. 연구팀은 데이터셋과 코드를 공개하여(agenterrordata.apodex.com) 관련 연구가 활발히 이어질 수 있도록 지원합니다.
