# 3D 코드 세계: 코드로 탐험하는 3D 세상

> **원본 논문 정보**
> - **제목:** 3DCodeVerse: Exploring 3D Worlds as Code
> - **저자:** Yipeng Gao, Ziyao Zeng, Jinfa Huang, Yijiang Li, Haolin Xiong, Wang Qin, Xinlei Yu, Youheng Yao, Jie Zhang, Kun-Yu Lin, Rong Liu, Yinyuan Zhao, Yajie Zhao, Meiqi Guo, Jiebo Luo, Lei Shu, Yunhao Ge, Xinyu Hu, Laurent Itti
> - **발행일:** 2026-10-15
> - **PDF 링크:** [3DCodeVerse: Exploring 3D Worlds as Code](https://arxiv.org/pdf/2610.22341v1)


## ✨ 3줄 핵심 요약
* **3DCodeVerse**는 코딩 에이전트가 편집 및 검증 가능한 3D 콘텐츠를 대규모로 생성하고 다룰 수 있도록 돕는 연구 생태계입니다.
* 대규모 실행 가능 3D 코드 데이터셋(3DCodeVerse-2M)과 자동 검증을 위한 멀티 에이전트 기반 프레임워크(Harness)를 제공합니다.
* 실험 결과, 오픈소스 모델의 3D 코딩 능력을 크게 향상시켰으며, 인간 평가에서 90%의 승률을 기록하는 성과를 보였습니다.

## 📖 쉽게 풀어쓴 1분 핵심
기존의 3D 생성 모델들은 단순히 이미지나 픽셀을 만드는 수준에 머물러 있어 수정이 어렵고 물리적 정확성이 떨어지는 경우가 많았습니다. 이 연구는 3D 모델을 '실행 가능한 코드'로 정의합니다. 즉, Blender나 Three.js 같은 도구에서 작동하는 코드를 직접 생성하게 함으로써, 사용자가 나중에 얼마든지 형태를 수정하거나 물리 시뮬레이션 환경에 불러와 정교하게 다룰 수 있게 만들었습니다. 이를 위해 대량의 예제 코드 데이터셋을 구축하고, 코드가 제대로 동작하는지 스스로 테스트하고 수정하는 똑똑한 에이전트 시스템을 도입했습니다.

## 🎯 배경 및 문제점
3D 생성 기술은 발전하고 있지만, 생성된 결과물이 정적인 경우가 많아 재사용이나 편집이 어렵습니다. 또한 기존의 방식은 물리적 법칙을 엄격히 준수하거나 정밀한 부품 조립을 구현하는 데 한계가 있었습니다. 이를 해결하기 위해 연구진은 코드를 기반으로 3D 자산을 생성하여, 형태의 정확성과 수정 가능성을 동시에 확보하고자 했습니다.

## 💡 핵심 기술 및 아키텍처
1. **3DCodeVerse-2M**: 실행 가능한 3D 코드로 구성된 대규모 데이터셋입니다. 오픈소스 데이터와 코딩 에이전트가 생성한 프로그램들로 구성되어 있습니다.
2. **3DCodeVerse Harness**: 방향성 비순환 그래프(DAG) 기반의 멀티 에이전트 프레임워크입니다. 인간의 개입 없이 스스로 코드를 실행하고, 공간적 측정과 시각적 피드백을 통해 생성된 프로그램을 자동 평가 및 수정합니다.
3. **평가 체계**: 구조적 타당성, 기하학적 상세 정보, 조립 적합성 등을 다각도로 판단하며, 비전-언어 모델(VLM)이 수치화된 증거를 바탕으로 최종 품질을 점수 매깁니다.

## 📊 실험 결과 분석
* 오픈소스 모델들을 이 데이터셋으로 파인튜닝했을 때 3D 코딩 성능이 크게 향상되었습니다.
* 인간 평가자가 진행한 일대일 대결에서, Claude Opus 5.5를 활용한 3DCodeVerse Harness가 Claude Design (3D Object)을 상대로 90%의 승률을 거두었습니다.
* 물리 시뮬레이터(MuJoCo) 실험에서, 코드 기반 생성 자산은 관절과 같은 움직임을 완벽하게 유지한 반면, 기존의 픽셀 기반 모델(UWM)은 모양이 일그러지는 현상을 보였습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **생산성 향상**: 디자이너나 개발자가 일일이 3D 모델을 다듬을 필요 없이, 코드로 제어 가능한 고품질 자산을 즉시 생성하여 워크플로우를 가속화할 수 있습니다.
* **정밀한 시뮬레이션**: 로봇 공학 등 물리 법칙이 중요한 분야에서, 실제와 동일한 물리적 제약을 가진 3D 자산을 프로그램으로 자동 생성하여 테스트 효율을 높일 수 있습니다.
* **창작의 확장**: 텍스트 프롬프트만으로 수정 가능한 3D 환경을 코드로 생성함으로써 3D 콘텐츠 제작의 진입 장벽을 낮출 것으로 기대됩니다.
