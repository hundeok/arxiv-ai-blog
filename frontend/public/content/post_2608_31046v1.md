# 온-정책 증류는 정말로 작동하는가? 노이즈가 많은 교사 모델에서 자기 개선으로

> **원본 논문 정보**
> - **제목:** Does On-Policy Distillation Really Distill? From Noisy Teacher to Self-Improvement
> - **저자:** Yi Ding, Ruqi Zhang
> - **발행일:** 2026-08-31
> - **PDF 링크:** [Does On-Policy Distillation Really Distill? From Noisy Teacher to Self-Improvement](https://arxiv.org/pdf/2608.31046v1)


## ✨ 3줄 핵심 요약
* 기존 온-정책 증류(OPD) 방식의 성능 향상은 교사 모델의 지도 때문이 아니라, 저확률 토큰을 억제하는 과정에서 기인함을 발견했습니다.
* 외부 감독 없이 모델 스스로 토큰 수준의 엔트로피를 활용해 학습하는 '온-정책 자기 적응(OPSA)' 기법을 제안했습니다.
* OPSA는 교사 모델 없이도 기존 OPD 방식보다 높은 성능을 보이며, 수학적 추론 과제에서 263% 이상의 상대적 성능 향상을 달성했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
AI 모델을 학습시킬 때 흔히 '교사 모델'의 답변을 참고하는 증류(Distillation) 방식을 사용합니다. 하지만 연구 결과, 교사 모델이 제공하는 신호에는 상당한 노이즈가 섞여 있으며, 실제로 모델의 성능을 높이는 것은 교사의 지도가 아니라 단순히 '확률이 낮은 답변(tail tokens)을 억제'하는 효과였습니다. 이를 바탕으로 외부의 도움 없이도 모델 스스로 자신의 내부 데이터와 엔트로피(불확실성)를 분석해 학습하는 OPSA(On-Policy Self-Adaptation)를 개발했습니다. 이 방식은 별도의 교사 모델이나 외부 보상 없이도 기존 방식보다 뛰어난 학습 결과를 냅니다.

## 🎯 배경 및 문제점
기존의 온-정책 증류(OPD)는 교사 모델이 학생 모델의 경로를 점수화하여 지도하는 방식입니다. 하지만 교사 모델은 학생이 생성한 경로를 평가할 때 태생적으로 오프-정책(off-policy) 상태가 되어 신뢰할 수 없는 노이즈가 발생합니다. 특히 모델 규모가 커질수록 이러한 노이즈는 더 심해지며, 실제로 모델이 무엇을 배우고 성능이 왜 향상되는지에 대한 근본적인 의문이 제기되어 왔습니다.

## 💡 핵심 기술 및 아키텍처
OPSA는 외부 감독 없이 다음 세 가지 원리로 작동합니다:
* **토큰 수준의 학습:** 전체 문장이 아닌 확률이 낮은(lowest 20%) 토큰에 집중하여 학습합니다.
* **엔트로피 적응형 부정적 이점(Entropy-Adaptive Negative Advantages):** 토큰의 엔트로피(불확실성)를 계산하여, 엔트로피가 높은 곳에 더 강한 학습 신호를 부여합니다.
* **자기 적응:** 교사 모델의 출력값을 대신하여, 모델 스스로 생성한 답변의 내부 정보를 통해 확률 분포를 다듬습니다. 이로써 불확실한 지점에서는 탐색을 보존하고, 낮은 확률의 토큰은 억제하여 분포를 개선합니다.

## 📊 실험 결과 분석
* **성능 향상:** Qwen3-1.7B 모델에 적용했을 때, AIME24 벤치마크에서 Avg@32 점수가 35.41포인트(263% 상대적 향상) 상승했습니다.
* **기존 방식 대비:** OPSA는 교사 모델이 없는 상태에서도 기존 OPD 방식 대비 AIME24의 Avg@32에서 16.77포인트 더 우수한 성적을 거두었습니다.
* **효율성:** 교사 모델을 거치는 추가적인 연산 과정을 제거하여 학습 시간을 단축했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
이번 연구는 거대 언어 모델이 외부의 비싼 보상 시스템이나 지도 모델 없이도 '자기 내부 정보'만을 활용해 스스로 똑똑해질 수 있음을 증명했습니다. 특히 데이터 구축이나 외부 보상 모델 학습이 어려운 실무 환경에서, 효율적이고 강력한 추론 모델을 구축할 수 있는 새로운 경로를 제시합니다. 추가적인 외부 데이터 없이 모델 스스로 더 정교한 추론 능력을 갖추게 됨에 따라 LLM의 자체 학습 최적화에 중요한 전환점이 될 것으로 기대됩니다.
