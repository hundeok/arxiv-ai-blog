# LiveAnimate: 실시간 안정적 장기 스트리밍 인간 애니메이션

> **원본 논문 정보**
> - **제목:** LiveAnimate: Stable Long-Form Streaming Human Animation in Real-Time
> - **저자:** Yuxuan Zhang, Haozhong Xiong, Yubo Huang, Jiayi Song, Jinpeng Yu, Haofan Wang, Jiaming Liu, Ruihua Huang, Liwei Wang
> - **발행일:** 2026-08-12
> - **PDF 링크:** [LiveAnimate: Stable Long-Form Streaming Human Animation in Real-Time](https://arxiv.org/pdf/2608.11745v2)


## ✨ 3줄 핵심 요약
*   14B 파라미터 규모의 비디오 확산 트랜스포머(DiT)를 기반으로, 실시간 스트리밍이 가능한 최초의 장기 인간 애니메이션 생성 시스템입니다.
*   'Pose-Retrieval Sink Attention(PR-Sink)' 기술을 통해 스트리밍 시간과 관계없이 메모리 사용량과 지연 시간을 일정하게 유지합니다.
*   NVIDIA H100 GPU 2대를 사용하여 약 20 FPS의 속도로 끊김 없는 고품질 애니메이션을 생성합니다.

## 📖 쉽게 풀어쓴 1분 핵심
기존의 고성능 인간 애니메이션 기술은 한 영상을 만드는 데 수 분에서 수 시간이 걸려 실시간 방송이나 화상 회의에 사용하기 어려웠습니다. **LiveAnimate**는 거대한 AI 모델을 효율적으로 압축하여 실시간으로 동작하게 만든 시스템입니다. 특히 과거의 동작과 유사한 자세를 취할 때, 관련 정보를 효율적으로 기억했다가 꺼내 쓰는 '똑똑한 메모리 시스템'을 도입했습니다. 덕분에 영상이 길어져도 캐릭터의 얼굴이나 복장 정보가 흐트러지지 않고 처음처럼 유지됩니다.

## 🎯 배경 및 문제점
기존의 비디오 확산 모델들은 짧은 영상 생성에는 능숙했으나, 실시간 스트리밍에 필요한 긴 호흡의 생성 과정에서 다음과 같은 한계가 있었습니다.
*   **시간 지연:** 한 클립을 만드는 데 많은 시간이 소요되어 실시간 상호작용이 불가능함.
*   **품질 저하:** 시간이 지날수록 모델이 앞선 정보를 잊어버려 캐릭터의 신원(Identity)이나 외형이 왜곡됨.
*   **메모리 폭증:** 스트리밍 시간이 길어질수록 과거 정보를 저장하기 위해 필요한 연산량과 메모리가 선형적으로 증가함.

## 💡 핵심 기술 및 아키텍처
*   **블록 기반 인과적 생성:** 비디오 생성 과정을 블록 단위로 나누어 순차적으로 처리함으로써 실시간성 확보.
*   **PR-Sink Attention:** 메모리 용량을 고정하면서 과거 정보를 효율적으로 관리하는 기술입니다.
    *   **Static Sink:** 첫 생성 블록을 고정하여 변하지 않는 외형 정보 유지.
    *   **Dynamic Sink:** 현재와 유사한 과거 동작 데이터를 찾아내어 관련 특징을 복구.
    *   **Rolling Window:** 최근 생성된 블록들을 관리하여 맥락 유지.
*   **2단계 훈련 파이프라인:** 양방향 DiT를 블록 기반 인과 모델로 조정하고, 3단계 샘플링만으로 고품질 결과를 내도록 증류(Distillation) 수행.

## 📊 실험 결과 분석
*   **성능:** 2개의 NVIDIA H100 GPU 환경에서 19.63 FPS의 실시간 스트리밍 성능을 기록했습니다.
*   **안정성:** 3분 분량의 벤치마크 테스트 결과, 초반 30초와 마지막 1분 구간의 이미지 품질 점수(IQA)가 각각 4.047과 4.026으로 거의 일정한 수준을 유지했습니다.
*   **비교:** 기존 모델들은 시간이 지남에 따라 배경이 깜빡이거나 이미지 품질이 급격히 떨어지는 현상을 보였으나, LiveAnimate는 높은 일관성을 유지했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
*   **실시간 라이브 스트리밍:** 가상 아바타를 활용한 방송에서 시청자와 지연 없이 실시간으로 상호작용 가능.
*   **원격 현장감(Telepresence):** 화상 회의 시스템에서 실제 인물의 동작을 실시간으로 반영하는 고품질 아바타 기술 적용.
*   **디지털 휴먼 생성:** 고비용의 오프라인 렌더링 없이도 14B 파라미터급 모델의 품질을 실시간으로 활용 가능.
*   **한계점:** 현재 480x480 해상도로 생성되며, 다중 인물이나 복잡한 카메라 움직임은 아직 지원하지 않습니다.
