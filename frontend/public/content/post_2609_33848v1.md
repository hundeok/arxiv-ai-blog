# 퀭자이어(QwenGyre): 초장기 호라이즌 에이전트 학습을 위한 탄력적 강화학습 프레임워크

> **원본 논문 정보**
> - **제목:** QwenGyre: An Elastic Reinforcement Learning Framework for Training xLong-Horizon Agents
> - **저자:** Weiqi Wang, Yuxin Zhou, Mouxiang Chen, Siyuan Zhang, Yi Zhang, Yuyan Luo, Zhiyu Yin, Chencan Wu, Jiemin Jiang, Wentao Yao, Chujie Zheng, JianWei Zhang
> - **발행일:** 2026-09-27
> - **PDF 링크:** [QwenGyre: An Elastic Reinforcement Learning Framework for Training xLong-Horizon Agents](https://arxiv.org/pdf/2609.33848v1)


## ✨ 3줄 핵심 요약
*   **시스템 효율성:** '탄력적 스케줄러'를 통해 실행 중인 작업을 중단하지 않고도 GPU 자원을 롤아웃과 학습 간에 유연하게 재배치하여 유휴 시간을 최소화합니다.
*   **데이터 최적화:** '궤적 프로세서'가 복잡한 분기 경로를 정리하고 중복된 학습 데이터를 제거하여 학습 비용을 제어합니다.
*   **성능 향상:** Qwen 3.8 2.4T 모델 대상 실험 결과, 기존 방식 대비 최대 1.85배의 학습 속도 향상과 6.0%의 벤치마크 성능 개선을 달성했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
AI 에이전트가 소프트웨어 개발처럼 수 시간씩 걸리는 복잡한 작업을 수행할 때, 기존의 강화학습 방식은 GPU 자원을 효율적으로 쓰지 못하는 문제가 있었습니다. 작업이 끝날 때까지 학습을 기다려야 하거나, 작업 중간에 발생하는 수많은 분기 처리로 인해 데이터가 중복되는 낭비가 심했기 때문입니다. **QwenGyre**는 작업이 진행 중일 때도 남는 GPU 자원을 즉시 학습에 투입하고, 분기된 작업 경로들을 효율적으로 구조화하여 학습 효율을 극대화한 새로운 프레임워크입니다.

## 🎯 배경 및 문제점
*   **극한의 대기 시간:** 'XLong-horizon(초장기)' 작업은 단일 실행이 수 시간, 수백 번의 상호작용, 약 100만 토큰에 달합니다. 기존의 'Colocate(병렬 배치)' 방식은 일부 작업이 종료될 때까지 나머지 자원을 놀리는(Idle) 문제가 발생했습니다.
*   **비효율적 데이터:** 에이전트가 수행하는 비선형적 분기 작업으로 인해 중복된 경로가 생성되어, 학습 효율이 떨어지고 불필요한 계산 비용이 발생합니다.

## 💡 핵심 기술 및 아키텍처
*   **탄력적 스케줄러(Elastic Scheduler):** 실행 중인 작업을 중단하지 않고, 유휴 롤아웃 자원을 학습 용도로 재할당합니다. 
*   **궤적 프로세서(Trajectory Processor):** TITO(Token-in, Token-out) 기술을 활용해 모델의 호출 기록을 정교하게 보존합니다. 또한, 분기된 실행 기록을 '궤적 트리' 구조로 변환하여 중복된 타겟 정보를 제거하고 효과적으로 학습 데이터를 구성합니다.
*   **스트리밍 학습(Streaming Training):** 데이터를 마이크로 단위로 나누어 병렬 처리함으로써, 학습 속도를 높이고 파이프라인의 유휴 시간을 최소화합니다.

## 📊 실험 결과 분석
*   **성능:** NL2RepoBench에서 48단계 학습 후, 성능이 52.5%에서 58.5%로 6.0% 향상되었습니다.
*   **속도:** 다양한 도메인 데이터셋에서 기존 Colocate 방식 대비 최대 1.85배, Async(비동기) 방식 대비 최대 1.78배의 속도 향상을 기록했습니다.
*   **확장성:** 32개 노드 환경에서 8개 셀(4개 노드 구성)을 4개 셀(8개 노드 구성)로 재조정했을 때, 실행 시간 증가분은 단 2.2%에 불과하여 자원 재배치의 효율성을 입증했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
이 프레임워크는 소프트웨어 엔지니어링, 시스템 재구현, 대규모 코드베이스 리팩토링과 같이 자율성이 극도로 요구되는 프로젝트에 활용될 수 있습니다. 특히 대규모 파운데이션 모델을 기반으로 한 복잡한 에이전트 학습 과정에서 발생하는 막대한 시간적, 자원적 비용을 획기적으로 절감함으로써, 더욱 복잡하고 긴 호흡의 과제를 수행하는 AI 에이전트 개발을 가속화할 것으로 기대됩니다.
