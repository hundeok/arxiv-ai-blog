# PACE: 자동화된 알고리즘 설계를 위한 원시 코드 진화 방식

> **원본 논문 정보**
> - **제목:** PACE: Primitive-Aware Code Evolution for Automated Algorithm Design
> - **저자:** Zhuoliang Xie, Ruihao Zheng, Xiang Xu, Genghui Li, Zhengkun Wang
> - **발행일:** 2026-08-07
> - **PDF 링크:** [PACE: Primitive-Aware Code Evolution for Automated Algorithm Design](https://arxiv.org/pdf/2608.07395v1)


## ✨ 3줄 핵심 요약
* 기존 LLM 기반 알고리즘 설계는 전체 프로그램을 하나의 단위로 다뤄, 유용한 부분 로직이 함께 소실되는 비효율이 존재함.
* PACE는 유용한 로직을 '실행 가능한 알고리즘 원시 코드(EAP)'라는 독립적 단위로 분리하여 보존하고 재사용함.
* 4개 작업에 대한 실험 결과, PACE는 알고리즘 구성 요소를 구조적으로 보존하면서 경쟁력 있는 알고리즘을 효과적으로 발견함.

## 📖 쉽게 풀어쓴 1분 핵심
기존의 AI 기반 알고리즘 설계 방식은 알고리즘 전체를 하나의 덩어리로 보고 수정합니다. 그래서 성적이 낮은 알고리즘을 폐기하면, 그 안에 포함되었던 아주 훌륭한 작은 아이디어(코드 조각)들까지 모두 함께 버려지는 문제가 있었습니다. PACE는 이 '작은 아이디어'를 'EAP(Executable Algorithmic Primitives)'라는 독립적인 부품으로 정의합니다. 마치 레고 블록처럼, 알고리즘이 바뀌어도 유용한 블록은 그대로 유지해 다른 알고리즘에 끼워 맞출 수 있게 함으로써 효율적인 탐색을 가능하게 합니다.

## 🎯 배경 및 문제점
대규모 언어 모델(LLM)을 활용한 자동화된 알고리즘 설계(AAD)는 뛰어난 성능을 보였으나, 구조적 한계가 있었습니다.
* **통합 단위의 한계:** 알고리즘을 더 이상 나눌 수 없는 하나의 프로그램으로 취급합니다.
* **지식 소실:** 전체 알고리즘의 성능이 낮으면, 그 안에 포함된 잠재적으로 가치 있는 로직까지 한꺼번에 폐기됩니다.
* **비효율적 탐색:** 이미 발견했던 유용한 로직을 다시 찾아내는 과정을 반복하게 되어 탐색 자원이 낭비됩니다.

## 💡 핵심 기술 및 아키텍처
PACE는 알고리즘 내의 로직을 '진화 가능한 객체'로 분리하는 체계를 갖추고 있습니다.
* **EAP (Executable Algorithmic Primitives):** 프로그램의 로직을 독립적인 함수 단위로 추출하여 저장하는 기술입니다.
* **구조적 유지 및 전이:** 알고리즘이 변하더라도 검증된 EAP를 호출하여 사용할 수 있도록 보장하는 연산자를 사용합니다.
* **톰슨 샘플링(Thompson Sampling):** 별도의 추가 데이터셋 없이도, 부모 알고리즘 대비 성능 향상 폭을 기반으로 가장 유망한 EAP를 선택하여 효율을 극대화합니다.

## 📊 실험 결과 분석
* **실험 대상:** 4개의 서로 다른 알고리즘 설계 작업에서 검증되었습니다.
* **핵심 성과:** PACE는 기존 방식과 달리 알고리즘 구성 요소를 구조적으로 보존합니다.
* **정량적 수치:** 원문 발췌본에는 구체적인 성공률이나 성능 지표의 수치는 명시되어 있지 않으나, 실험을 통해 경쟁력 있는 알고리즘을 발견함과 동시에 가치 있는 로직을 유지하는 효과가 입증되었습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
PACE는 복잡한 알고리즘 설계 과정을 부품 단위의 조립 과정으로 전환함으로써, 개발자가 밑바닥부터 알고리즘을 설계하지 않아도 되도록 돕습니다.
* **연구 및 개발:** 알고리즘 설계의 재사용성을 높여 연구 효율성을 크게 개선합니다.
* **실무 적용:** 레이싱 카(Racing Car) 제어와 같은 제어 태스크나 보행기(Bipedal Walker) 환경과 같이 다양한 입력을 처리해야 하는 복합적인 로직 설계 분야에 즉시 적용 가능합니다.
* **지식 축적:** 시행착오를 통해 얻은 '성공적인 코드 조각'을 데이터베이스화하여 향후 AI 시스템이 스스로 더 정교한 알고리즘을 구축하는 기반 지식이 됩니다.
