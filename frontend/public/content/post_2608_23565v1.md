# ReWorld: 장기 기억 능력을 갖춘 상호작용형 세계 모델

> **원본 논문 정보**
> - **제목:** ReWorld: An Interactive World Model with Long-Horizon Memory
> - **저자:** Zhifei Chen, Luozhou Wang, Guibao Shen, Dongyu Yan, Shuai Yang, Tianshuo Xu, Yihua Du, Wei Wang, Tianyi Gui, Lianghua Huang, Yingcong Chen
> - **발행일:** 2026-08-24
> - **PDF 링크:** [ReWorld: An Interactive World Model with Long-Horizon Memory](https://arxiv.org/pdf/2608.23565v1)


## ✨ 3줄 핵심 요약
- **기억과 제어의 분리 학습:** 모델 학습 시 '제어(단기)'와 '기억(장기)'을 위한 어텐션 윈도우를 분리하고 헤드 라우팅을 최적화하여 상충 문제를 해결했습니다.
- **고정 예산 메모리:** 추론 단계에서 '랜드마크 뱅크'를 활용해 고정된 KV 캐시 용량 내에서도 과거 장면을 정확히 재현합니다.
- **실시간 스트리밍:** LoRA 증류 기술을 통해 단 4단계의 샘플링만으로 고해상도 영상을 실시간 스트리밍할 수 있습니다.

## 📖 쉽게 풀어쓴 1분 핵심
사용자의 조작에 반응하는 '세계 모델'은 현재의 움직임을 제어하는 능력과, 과거에 방문했던 장소를 기억하는 능력을 동시에 갖춰야 합니다. 하지만 기존 모델들은 이 두 가지를 동시에 학습할 때 서로 간섭을 일으켜 성능이 저하되는 문제가 있었습니다. **ReWorld**는 학습 시 어텐션 기능을 정교하게 나누어 단기 반응성과 장기 기억력을 모두 확보했습니다. 특히, 추론 과정에서는 랜드마크 뱅크라는 기억 저장소를 사용해 제한된 메모리 안에서도 방대한 과거 정보를 효율적으로 불러와, 사용자가 다시 방문한 장소를 일관성 있게 그려냅니다.

## 🎯 배경 및 문제점
- **제어와 기억의 상충:** 모델이 현재 액션에 즉각 반응(제어)하게 만들면 장기 기억 능력이 떨어지고, 반대로 장기 기억에 집중하면 제어 정확도가 낮아지는 구조적 모순이 발생합니다.
- **기억의 한계:** 기존의 '슬라이딩 윈도우' 방식은 오래된 정보를 쉽게 잊어버리고, '전체 KV 캐시' 방식은 롤아웃이 길어질수록 메모리가 부족해지는 문제가 있습니다.
- **실시간성 부족:** 복잡한 연산으로 인해 상호작용 가능한 수준의 속도로 영상을 스트리밍하는 데 어려움이 있었습니다.

## 💡 핵심 기술 및 아키텍처
- **혼합 어텐션 윈도우:** 대부분의 어텐션 헤드는 최근 정보를 처리하게 하고, 일부 헤드는 전체 과거 정보를 다루도록 설계했습니다. 랜덤 헤드 라우팅으로 각 헤드가 특정 기능에 고착되는 것을 방지합니다.
- **랜드마크 뱅크:** 추론 시 과거 정보가 캐시 용량을 초과하면, 가장 가까운 위치의 '랜드마크' 데이터를 우선적으로 검색해 캐시에 다시 로드합니다.
- **메트릭 정렬 데이터 엔진:** 게임 엔진(Unreal Engine), 실사 영상 등 8개의 서로 다른 데이터 소스를 동일한 물리적 거리 단위로 통일하여 모델이 일관된 카메라 이동을 학습하게 했습니다.
- **LoRA 기반 증류:** LoRA 어댑터를 사용해 고성능 다단계 모델을 실시간 구동 가능한 4단계 모델로 효율적으로 압축했습니다.

## 📊 실험 결과 분석
- **제어 성능:** 최근 6개 상호작용 모델과의 비교에서 회전 오류 11.95도로 가장 뛰어난 제어 정밀도를 보였으며, 카메라 이동의 일관성 면에서도 최고 성능을 기록했습니다.
- **장기 기억력:** 64초 길이의 롤아웃 테스트에서, 고정된 12개 덩어리의 캐시만 사용하고도 시작 지점의 장면을 정확히 재현했습니다. 이는 기존의 슬라이딩 윈도우 방식이 정보를 모두 잃어버리는 시점에서도 ReWorld는 기억을 유지함을 의미합니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
- **몰입형 환경 생성:** 게임이나 메타버스 서비스에서 사용자의 자유로운 이동에 따라 끊김 없이 변화하는 방대한 3D 환경을 실시간으로 스트리밍하는 데 활용될 수 있습니다.
- **지능형 가상 에이전트:** 사용자가 이전에 방문했던 장소를 기억하는 능력이 필요한 시뮬레이션 환경이나 가상 비서 시스템의 핵심 기술로 적용될 가능성이 큽니다.
- **연구적 시사점:** 데이터 소스가 달라도 메트릭 기반으로 데이터를 정렬하여 학습 효율을 높이는 방식은 향후 복합 데이터셋을 다루는 다양한 AI 연구의 표준이 될 수 있습니다.
