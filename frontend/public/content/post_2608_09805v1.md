# 가변 학습을 통한 RLVR을 위한 파라미터 탐색

> **원본 논문 정보**
> - **제목:** Parameter Exploration for RLVR via Variational Learning
> - **저자:** Vatsal Venkatkrishna, Nico Daheim, Iryna Gurevych
> - **발행일:** 2026-08-10
> - **PDF 링크:** [Parameter Exploration for RLVR via Variational Learning](https://arxiv.org/pdf/2608.09805v1)


## ✨ 3줄 핵심 요약
* 기존의 언어 모델 강화학습(RLVR)은 행동 공간(액션 스페이스) 탐색에 의존하여 토큰 순서 변경이 불가능하고 훈련 정체 현상이 잦음.
* 제안하는 '교란 파라미터 정책 최적화(3PO)'는 모델 가중치에 노이즈를 주어 모델의 정책 자체를 샘플링하는 파라미터 공간 탐색 방식을 도입함.
* OLMo 및 Qwen2.5-Math 모델 실험 결과, 표준 GRPO 대비 뛰어난 성능을 보이며 오류가 있는 결과물 생성 비율을 낮춤.

## 📖 쉽게 풀어쓴 1분 핵심
강화학습을 통해 언어 모델을 학습시킬 때, 모델이 '다양한 시도'를 하도록 만드는 것은 매우 중요합니다. 기존 방식은 출력되는 단어의 확률 분포만 조절하는 '행동 공간 탐색(온도 조절 등)'을 주로 사용했습니다. 하지만 이 방식은 이미 정해진 단어 순서 내에서만 변화를 줄 수 있어 학습이 정체되는 한계가 있었습니다. 

본 논문은 모델의 **'두뇌(파라미터)' 자체에 미세한 노이즈를 섞어, 모델이 아예 다른 정책으로 문제를 해결하도록 유도하는 파라미터 공간 탐색 기법(3PO)**을 제안합니다. 마치 똑같은 문제라도 다른 성격의 전문가에게 풀게 하는 것과 같으며, 이를 통해 더 창의적이고 정확한 답변을 찾아내고 훈련 과정에서의 실패(zero-advantage groups)를 획기적으로 줄였습니다.

## 🎯 배경 및 문제점
* **기존 RLVR의 한계:** 스스로 생성한 결과물(Rollout)에서 학습하는데, 보상이 낮은 결과만 반복될 경우 모델이 개선되지 않고 훈련이 멈추는 정체 현상이 발생함.
* **행동 공간 탐색의 제약:** 온도(Temperature)를 높이는 방식은 토큰의 분포만 바꿀 뿐, 문장 구조를 결정하는 상대적 토큰 순서를 바꾸지 못함. 
* **훈련 비효율:** GRPO와 같은 기존 알고리즘은 그룹 내 모든 결과의 보상이 같을 경우 학습 신호를 얻지 못해 자원 낭비가 심함.

## 💡 핵심 기술 및 아키텍처
* **3PO (Perturbed Parameter Policy Optimization):** 모델의 파라미터에 가우시안 노이즈 등을 추가하여 샘플링하는 기법군.
* **학습 방식:**
    * **M3PO:** 여러 파라미터 샘플을 생성하여 정책을 다양화함.
    * **C3PO (Chunked noising):** 파라미터별로 롤아웃 그룹을 나누어 관리하며 더 효율적인 탐색을 유도함.
* **유연성:** 별도의 추가 학습 없이 기존에 존재하는 모델 체크포인트에 즉시 적용 가능한 '드롭인(Drop-in)' 대체제로 설계됨.

## 📊 실험 결과 분석
* **성능 향상:** OLMo-3-1025-7B와 Qwen2.5-Math-7B 모델에서 모든 3PO 변형 모델이 표준 GRPO 및 기존 액션 공간 탐색 베이스라인(EntReg, Polaris, KLCov)보다 수학/코딩 작업에서 더 높은 평균 점수를 기록함.
* **오류 감소:** 3PO 방식은 훈련 중 보상값이 0인 그룹(학습 불가능 구간)을 더 적게 발생시키고, 잘못되거나 비정상적인 결과물 생성을 유의미하게 줄임.
* **비용 효율:** 거의 동일한 연산 비용(FLOPs)으로 더 나은 성능을 달성함. 단, 실제 벽걸이 시간(Wall-clock time)은 구현상의 이유로 GRPO 대비 약 1.5배 증가하는 경향이 있음.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **범용성:** 특정 모델 구조에 얽매이지 않고, 이미 학습된 모델의 성능을 사후 학습(Post-training) 단계에서 추가로 극대화할 수 있음.
* **효율적인 강화학습:** 복잡한 추론이나 코딩 능력이 중요한 LLM 개발 시, 훈련 정체 문제를 해결함으로써 연구/개발 시간을 단축하고 비용을 절감하는 솔루션으로 활용 가능.
* **미래 전망:** 모델 규모가 커질수록 파라미터 공간 탐색의 이점이 더 커질 것으로 예상하며, 향후 더 정교한 노이즈 샘플링 전략을 통해 성능 한계를 지속적으로 높일 수 있을 것으로 기대됨.
