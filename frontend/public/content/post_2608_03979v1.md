# Video-DeepResearch: 차세대 멀티모달 딥 리서치 에이전트를 향하여

> **원본 논문 정보**
> - **제목:** Video-DeepResearch: Towards the Next-Generation Multimodal Deepresearch Agent
> - **저자:** Zhen Fang, Yu Zeng, Wenxuan Huang, Yiming Zhao, Shiting Huang, Tianfei Ren, Qi Lu, Qingnan Ren, Qisheng Su, Lionel Z. Wang, Qingyu Yin, Shuang Chen, Zehui Chen, Lin Chen, Zhenfei Yin, Yao Hu, Shaohui Lin, Wanli Ouyang, Shaosheng Cao, Feng Zhao
> - **발행일:** 2026-08-04
> - **PDF 링크:** [Video-DeepResearch: Towards the Next-Generation Multimodal Deepresearch Agent](https://arxiv.org/pdf/2608.03979v1)


## ✨ 3줄 핵심 요약
* **영상 기반 탐색의 혁신:** 기존 이미지 중심 에이전트의 한계를 넘어, 연속적인 비디오 스트림에서 정보를 추출하고 외부 웹 검색을 수행하는 'Video-DR' 프레임워크를 제안합니다.
* **학습 방식 개선:** 시각적 도구 사용을 회피하거나 내장 지식에만 의존하는 기존 모델의 고질적인 문제를 해결하기 위해, 단계별 도구 활성화와 GRPO 학습 기법을 도입했습니다.
* **압도적인 성능:** Video-DeepResearch-35B-A3B 모델은 64.0%의 정확도로 Claude-4.5-Sonnet(59.0%), GPT-5(52.5%), Gemini 2.5 Pro(57.5%)를 뛰어넘는 새로운 업계 최고 수준(SOTA)을 달성했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
기존의 인공지능 연구 에이전트들은 주로 텍스트나 정적인 사진을 보고 정보를 찾는 데 익숙했습니다. 하지만 실제 세상은 끊임없이 변화하는 비디오로 구성되어 있습니다. 'Video-DeepResearch'는 AI가 복잡한 영상을 보고, 어느 부분에서 무엇을 찾아야 할지 스스로 판단한 뒤, 실시간으로 웹 검색까지 수행하여 질문에 답하게 만드는 기술입니다. 이 모델은 AI가 자기 지식만 믿고 대충 대답하는 '지식 누설' 현상을 방지하고, 철저히 외부 정보를 확인하도록 설계되었습니다.

## 🎯 배경 및 문제점
기존 에이전트들은 다음의 두 가지 결정적인 한계를 보였습니다.
1. **양식 편향(Modality Bias):** 시각적 도구를 활용해 정보를 얻기보다 기존에 학습된 텍스트 정보에만 의존하려는 경향.
2. **지식 누설(Parametric Knowledge Leakage):** 외부 검색 도구 없이 모델 내부의 메모리만으로 문제를 해결하려는 현상.
또한, 비디오 데이터는 정적인 이미지보다 훨씬 방대하고 시간 변화에 따른 정보 처리가 필요함에도, 이를 제대로 평가할 수 있는 표준화된 벤치마크가 부족했습니다.

## 💡 핵심 기술 및 아키텍처
* **인지-탐색 분리 파이프라인:** 웹 검색을 수행하기 전에 영상 내에서 철저한 시각적 근거를 확보하도록 강제하는 단계별 워크플로우를 구축했습니다.
* **2단계 학습 레시피:** 
    1. **SFT(지도 미세 조정):** decoupled(분리된) 인지-탐색 과정을 학습시켜 올바른 추론 문법을 내재화합니다.
    2. **GRPO(그룹 상대적 정책 최적화):** 스스로 여러 경로를 탐색하고 성공적인 결과에 보상을 주어, 모방 학습의 성능 한계를 돌파하도록 돕습니다.
* **VIDEODR-BENCH:** 인간과 AI가 협업하여 구축한 200개의 복잡한 다중 도약(multi-hop) VQA 벤치마크를 통해 모델의 실질적인 영상 기반 연구 능력을 검증합니다.

## 📊 실험 결과 분석
* **Video-DeepResearch-35B-A3B:** 평균 정확도 64.0%로 평가 대상 모델 중 가장 우수한 성능을 기록했습니다.
* **비교 수치:** Claude-4.5-Sonnet(59.0%), Gemini 2.5 Pro(57.5%), GPT-5(52.5%) 대비 높은 정확도를 보였습니다.
* **경량 모델:** 30B-A3B 모델 또한 59.3%의 정확도를 기록하여, compact한 모델 크기로도 Claude-4.5-Sonnet과 대등한 성능을 보여주며 효율성을 증명했습니다.
*(참고: 실험에 사용된 GPU 환경은 NVIDIA H800 80GB 4개 노드로 구성된 클러스터입니다.)*

## 🌍 세상에 미치는 영향 & 실무 적용 사례
이 기술은 단순한 질문 응답을 넘어, 방대한 영상 자료 속에서 핵심 근거를 찾아 실시간으로 검증하는 '전문 리서치 에이전트'의 길을 열었습니다. 뉴스 분석, 다큐멘터리 조사, 영상 기반 기술 지원 등 고도의 정확성이 요구되는 분야에서 실무적인 도구로 활용될 가능성이 큽니다. 다만, 현재는 데이터 합성 및 모델 학습 과정에서 상당한 GPU 자원이 소모되며, 벤치마크 구축에 인간의 수작업이 일부 필요하다는 한계가 있어 향후 이를 경량화하고 자동화하는 연구가 이어질 예정입니다.
