# 솔라나 기반 머신러닝을 이용한 밈코인 러그풀 조기 탐지

> **원본 논문 정보**
> - **제목:** Catching the Rug: Early Prediction of Fraudulent Memecoins on Solana via Machine Learning
> - **저자:** Jianghai Li, Pavel Kuznetsov, Yury Yanovich, Konstantin Nott-Whaley, Igor Vodolazov
> - **발행일:** 2026-08-20
> - **PDF 링크:** [Catching the Rug: Early Prediction of Fraudulent Memecoins on Solana via Machine Learning](https://arxiv.org/pdf/2608.20271v1)


## ✨ 3줄 핵심 요약
- 솔라나 생태계 내 640만 개의 토큰 데이터를 분석하여 밈코인 러그풀(사기)을 조기 탐지하는 체계적인 연구를 수행함.
- 스마트 컨트랙트 코드 분석 없이 거래 데이터만으로도 거래 시작 5분 이내에 러그풀 여부를 예측할 수 있음을 입증함.
- PumpFun과 Raydium 등 플랫폼 간 데이터 융합을 통해 모델의 일반화 성능을 높이고 러그풀 탐지의 신뢰성을 확보함.

## 📖 쉽게 풀어쓴 1분 핵심
최근 암호화폐 시장, 특히 솔라나 블록체인에서 큰 인기를 끄는 '밈코인'은 개발자가 투자금을 가로채고 사라지는 '러그풀(Rug Pull)' 사기 위험이 매우 큽니다. 본 연구는 과거 이더리움 방식(코드 결함 이용)과 달리, 솔라나 생태계의 주된 사기 방식인 '유동성 조작'과 '소셜 네트워크 심리'에 주목했습니다. 연구진은 7개월간 수집한 640만 개의 토큰 데이터를 머신러닝 모델(XGBoost)로 분석하여, 코딩 지식 없이도 거래 시작 후 단 5분 만에 사기 여부를 판별해내는 실용적인 탐지 프레임워크를 제시했습니다.

## 🎯 배경 및 문제점
- **솔라나 시장의 특수성:** 기존 연구들은 주로 이더리움의 스마트 컨트랙트 취약점 분석에 집중했으나, 솔라나의 밈코인 러그풀은 주로 유동성 조작을 통해 발생함.
- **사기의 급속도:** 대다수의 러그풀이 코인 출시 1시간 이내에 발생함에 따라, 매우 짧은 시간 내에 사기를 감지하는 기술적 해결책이 시급함.
- **데이터 산재:** 여러 탈중앙화 거래소(DEX)마다 고유한 거래 특성이 있어 사기 탐지 모델을 범용적으로 적용하는 데 어려움이 존재함.

## 💡 핵심 기술 및 아키텍처
- **모델 활용:** Gradient Boosting 계열의 XGBoost 모델을 사용하여 거래 데이터를 처리함.
- **데이터 분석:** 토큰별 거래 횟수, 구매/판매 비율, SOL(솔라나) 거래 금액, 가격 변동성, 유동성 풀(TVL) 정보 등 다각적 피처를 추출하여 활용함.
- **다중 소스 데이터 융합:** PumpFun과 Raydium의 서로 다른 거래 패턴(PumpFun은 빈도가 높고 소액 거래, Raydium은 빈도가 낮고 고액 거래)을 융합하여 모델이 특정 플랫폼에 편향되지 않도록 학습함.

## 📊 실험 결과 분석
- **데이터 규모:** 7개월간 수집된 640만 개의 토큰 데이터를 활용함.
- **예측 효율성:** 거래 개시 5분 후의 데이터만으로도 높은 수준의 러그풀 탐지 성능을 달성함.
- **교차 플랫폼 성능:** 서로 다른 DEX 플랫폼 간의 데이터 분포 차이(도메인 시프트)가 존재하나, 다중 플랫폼 데이터를 결합했을 때 모델의 견고함과 탐지 신뢰도가 유의미하게 향상됨을 확인함.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
- **투자자 보호:** 실시간 러그풀 예측 시스템을 통해 개인 투자자의 자산 피해를 사전에 방지할 수 있는 기반을 마련함.
- **생태계 신뢰도 증진:** 탈중앙화 금융(DeFi) 플랫폼 운영자와 협력하여 사기 토큰을 사전에 차단함으로써 건전한 시장 환경 조성에 기여 가능.
- **향후 연구 방향:** 거래의 시간적 흐름을 더 잘 파악할 수 있는 그래프 신경망(GNN) 도입과 더불어, 거래소 실제 운영 환경에 본 탐지 모델을 배포하여 실제 피해 예방 효과를 측정할 계획임.
