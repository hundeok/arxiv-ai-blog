# 옴니팩: 효율적인 옴니모달 대규모 언어 모델을 위한 통합 토큰 압축

> **원본 논문 정보**
> - **제목:** OmniPack: Unified Token Compression for Efficient Omni-modal Large Language Models
> - **저자:** Wanshun Su, Yang Shi, Feihu Liu, Ziwen Yu, Yan Min, Zhuoran Zhang, Qixun Wang, Haotian Wang, Shixuan Liu, Yuanxing Zhang, Peng Wu, Chengfu Huo, Liang Ding
> - **발행일:** 2026-08-04
> - **PDF 링크:** [OmniPack: Unified Token Compression for Efficient Omni-modal Large Language Models](https://arxiv.org/pdf/2608.03812v1)


## ✨ 3줄 핵심 요약
* **OmniPack**은 옴니모달 LLM(Omni-LLM)의 긴 시각·청각 입력을 효율적으로 처리하기 위한 훈련이 필요 없는(training-free) 통합 토큰 압축 프레임워크입니다.
* LLM 외부에서 구조적 중복성을 제거하고, LLM 내부에서 텍스트 안내와 다중 모달 협력을 통해 과제 관련 정보를 정교하게 다듬어 성능 저하를 최소화합니다.
* Qwen2.5-Omni-7B 모델에서 기존 방식보다 월등한 성능과 효율성을 보이며, 특히 FLOPs를 6.8%로 줄이고도 기존 성능의 92.9%를 유지합니다.

## 📖 쉽게 풀어쓴 1분 핵심
영상이나 음성 데이터는 텍스트에 비해 정보량이 압도적으로 많아 AI가 처리할 때 막대한 비용이 듭니다. 기존에는 정보를 무작정 버리는 방식으로 압축했으나, 이 과정에서 중요한 단서가 사라져 성능이 떨어지는 문제가 있었습니다. OmniPack은 '어떤 정보를 버릴지' 결정하는 단계를 LLM 외부와 내부로 나누어 설계했습니다. 먼저 LLM 밖에서 중요하지 않은 구조적 정보를 덜어내고, LLM 안으로 들어가서는 질문 내용에 맞춰 꼭 필요한 정보만 집중적으로 남깁니다. 이를 통해 AI가 더 적은 계산량으로도 똑똑하게 핵심을 파악하도록 돕습니다.

## 🎯 배경 및 문제점
* **연산 비용 문제:** 옴니모달 LLM은 비디오와 오디오 데이터를 처리할 때 매우 긴 토큰 시퀀스를 생성하므로 추론 시 계산 및 메모리 비용이 매우 큽니다.
* **기존 압축 방식의 한계:** 
    * LLM 이전의 압축은 구조적으로 중요한 장거리 정보나 미세한 다중 모달 신호를 잃어버릴 위험이 큽니다.
    * LLM 내부의 압축은 질문에 따른 모달 간 협력(audio-visual collaboration)을 충분히 활용하지 못합니다.
    * 단순히 점수가 낮은 토큰을 제거하면 정보 손실이 비가역적으로 발생합니다.

## 💡 핵심 기술 및 아키텍처
* **훈련 없는 프레임워크:** 모델의 가중치를 새로 학습시킬 필요 없이 바로 적용 가능합니다.
* **LLM 외부 압축:** 모달별 중요도, 전체적인 범위, 유사도 기반 병합을 사용하여 구조적 중복을 선제적으로 제거합니다.
* **LLM 내부 정교화:** 충분한 다중 모달 상호작용 후, 텍스트 안내(textual guidance)와 청각-시각 협력(audio-visual collaboration)을 사용하여 과제 수행에 핵심적인 정보만을 남깁니다.

## 📊 실험 결과 분석
* **성능 효율성:** Qwen2.5-Omni-7B 기반 테스트 결과, 원본 성능의 98.0%를 유지하면서도 FLOPs(계산량)를 16.7% 수준으로 크게 줄였습니다.
* **압축률에 따른 강점:** 매우 낮은 보존율(6.8% FLOPs 사용)에서도 기존 성능의 92.9%를 유지하여 효율과 성능 사이의 최적의 균형을 보여줍니다.
* **비교 분석:** 5개 벤치마크 테스트에서 기존 압축 방법론(FastV-om, VisionZip-om, OmniSIFT, SEATS 등)보다 일관되게 우수한 성능을 기록했습니다.
* **견고성:** 하이퍼파라미터 변화에 따른 성능 변동폭이 작아, 특정 설정에 종속되지 않는 안정적인 모델임을 입증했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **실시간 서비스 최적화:** 막대한 컴퓨팅 자원이 필요한 멀티모달 AI 서비스를 더 가벼운 장비(엣지 디바이스 등)에서도 원활히 구동할 수 있는 길을 열었습니다.
* **실무 활용:** 영상 분석, 자동 캡션 생성, 복합 미디어 이해가 필요한 실시간 옴니모달 AI 시스템에서 연산 비용을 획기적으로 줄여 서비스의 경제성과 처리 속도를 동시에 확보할 수 있습니다. 
* **확장성:** 특정 모델에 국한되지 않고 다양한 옴니모달 LLM 백본에 적용할 수 있어 범용적인 성능 향상 도구로 활용 가능합니다.
