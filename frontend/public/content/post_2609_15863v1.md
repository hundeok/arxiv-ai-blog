# 린리얼-옴니: 에이전트 기반 시각 작업을 위한 네이티브 멀티모달 비디오 생성

> **원본 논문 정보**
> - **제목:** LynnReal-Omni: Native multi-modal Video Generation for Agentic Visual Workflows
> - **저자:** Xiaofeng Mao, Peijia Lin, Shaohao Rui, Yibo Zhang, Haibin Wan, Weijie Ma
> - **발행일:** 2026-09-14
> - **PDF 링크:** [LynnReal-Omni: Native multi-modal Video Generation for Agentic Visual Workflows](https://arxiv.org/pdf/2609.15863v1)


## ✨ 3줄 핵심 요약
* **통합 모델 구축:** 텍스트, 이미지, 3D 렌더링, 게임 기록 등 다양한 시각적 입력을 처리하는 32B 규모의 멀티모달 확산 트랜스포머(DiT)를 개발했습니다.
* **효율적 실시간 생성:** 27B 파라미터의 'Flash' 모델과 경량화된 VAE 디코더를 통해 비디오 생성 및 디코딩 비용을 획기적으로 줄였습니다.
* **제어 가능한 생성:** 물리적 타이밍과 의미론적 그룹화를 분리한 데이터 파이프라인을 구축하여 안정적이고 편집 가능한 비디오 생성을 실현했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
기존 비디오 생성 모델은 결과물을 예측하기 어렵고 시간이 흐를수록 영상의 일관성이 깨지는 문제가 있었습니다. 'LynnReal-Omni'는 이를 해결하기 위해 에이전트가 직접 3D 장면이나 게임 상태 같은 '설계도'를 입력하면, 이를 바탕으로 고품질 영상을 만들어내는 모델입니다. 특히 속도 문제를 해결하기 위해 모델을 압축한 'Flash' 버전을 별도로 운영하며, 복잡한 비디오 생성 작업을 효율적이고 정밀하게 제어할 수 있도록 설계되었습니다.

## 🎯 배경 및 문제점
* **확산 모델의 불안정성:** 기존 비디오 확산 모델은 확률적 특성이 강해 원하는 내용을 얻기 위해 반복적인 샘플링이 필요하며, 긴 영상 생성 시 시각적 일관성과 시간적 흐름을 유지하기 어렵습니다.
* **정밀 제어의 부재:** 생성 모델 자체만으로는 객체나 캐릭터의 충실도(fidelity)를 완벽하게 보장하지 못합니다.
* **실시간 생성의 한계:** 고화질 비디오를 실시간으로 생성하기에는 연산 비용과 디코딩 속도가 큰 걸림돌이었습니다.

## 💡 핵심 기술 및 아키텍처
* **통합 멀티모달 백본:** 32B DiT를 기반으로 텍스트-비디오, 이미지 조건부 생성, 구조적 제어, 비디오 편집 및 복원 기능을 통합했습니다.
* **Flash 모델 및 경량 VAE:** 27B 파라미터의 효율적인 모델 구조와 경량 디코더를 도입하여 추론 속도를 가속화했습니다.
* **데이터 파이프라인:** 비디오 클리닝, 주제 연관성 분석, 멀티모달 주석 달기, 제어 정렬 등을 체계화하여 고품질의 학습 데이터를 확보했습니다.
* **MSAVP 평가 체계:** 지침 준수, 생성 타당성, 시각적 품질, 시간적 동작, 오디오 조화 등을 다각도로 평가하는 100개 프롬프트 및 20개 지표 기반 평가 디자인을 도입했습니다.

## 📊 실험 결과 분석
* **생성 속도 비교:** H100 GPU 1대 기준, 540p 해상도 22프레임 영상 생성 및 디코딩 시 LynnReal-Omni는 843ms, Flash 모델은 377ms가 소요되었습니다. (기타 성능 수치는 본문 발췌에 구체적인 비교 지표로 제시되지 않았으나, 해당 수치는 모델의 효율성을 입증하는 지표로 언급되었습니다.)
* **정성적 분석:** 게임 기록 기반의 모션 타임라인 제어, 3D 메쉬 카메라 투어와 연동된 영상 생성 등에서 시각적 일관성과 제어 가능성을 확인했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **에이전트 시각 작업:** 에이전트가 생성한 시각적 조건(게임 상태, 3D 렌더링)을 실제 영상으로 변환하는 도구로서, 게임 개발 및 가상 환경 생성 분야에 기여할 수 있습니다.
* **실시간 비디오 스트리밍:** 효율적인 디코딩 및 생성 속도 덕분에 실시간 인터랙티브 미디어 생성의 기반 기술로 활용 가능합니다.
* **고급 영상 편집:** 기존 영상의 스타일을 바꾸거나 날씨 및 배경을 생성하는 등, 복잡한 비디오 편집 및 복원 작업의 자동화 도구로 활용될 전망입니다.
