# 이전 문제의 계산 과정이 거대언어모델(LLM)의 새로운 문제 해결에 도움이 될 수 있는가?

> **원본 논문 정보**
> - **제목:** Can Computation from Earlier Problems Help LLMs Solve New Ones?
> - **저자:** Jipei He, Wenhui Tan, Xiaoyi Yu, Enver Sangineto, Fiorenzo Parascandolo, Rita Cucchiara, Ruihua Song
> - **발행일:** 2026-09-30
> - **PDF 링크:** [Can Computation from Earlier Problems Help LLMs Solve New Ones?](https://arxiv.org/pdf/2609.39394v1)


## ✨ 3줄 핵심 요약
* LLM이 이전 대화의 맥락(기록)을 유지할 때, 성능이 향상되기도 하고 오히려 저하되기도 하는 등 불안정한 모습을 보입니다.
* 이를 개선하기 위해 이전 응답의 키와 값을 고정된 저장소에 보관하고 적절히 활용하는 ‘STAIR’ 기술을 제안합니다.
* STAIR를 적용하면 기본 모델을 유지한 채 소수의 파라미터만 학습시켜 후속 문제 해결 정확도를 크게 높일 수 있습니다.

## 📖 쉽게 풀어쓴 1분 핵심
사람은 앞서 했던 경험을 바탕으로 새로운 문제를 더 잘 해결하기도 합니다. LLM도 대화 맥락 속에 이전 문제의 답이 남아있지만, 이것이 항상 도움이 되는 것은 아닙니다. 때로는 이전 대화가 오히려 모델의 추론을 방해합니다. 연구진은 모델이 이전 대화의 '어떤 부분'을 중요하게 여기고 '어떤 부분'을 무시해야 하는지 학습하는 STAIR라는 기술을 개발했습니다. 이 기술은 거대한 모델을 다시 훈련할 필요 없이, 아주 적은 양의 데이터만 학습시켜 LLM의 문맥 이해 및 문제 해결 능력을 최적화합니다.

## 🎯 배경 및 문제점
LLM은 한 세션 내에서 여러 문제를 연속적으로 해결합니다. 이때 이전 대화 내용은 모델에게 고스란히 노출되는데, 기존 모델들은 이 기록을 처리하는 과정에서 일관된 성능을 내지 못합니다. 실험 결과, 어떤 태스크에서는 과거 기록이 정확도를 높이지만, 다른 태스크에서는 오히려 정확도를 떨어뜨리는 현상이 발견되었습니다. 연구진은 이전 문제 해결 과정에서 생성된 '내부 연산 기록'이 과연 새로운 문제 해결에 긍정적인 영향을 미칠 수 있는지 확인하고자 했습니다.

## 💡 핵심 기술 및 아키텍처
제안된 **STAIR(Stale-Token Attention for Inter-query Reuse)**는 이전 응답에서 생성된 토큰의 키(Key)와 값(Value)을 고정된 저장소(Fixed Bank)에 따로 보관합니다. 
* **작동 원리:** 새로운 질문이 입력될 때, 모델은 이 저장소에 저장된 과거 기록을 참조합니다. 
* **학습 방식:** 기본 모델의 파라미터는 전혀 수정하지 않고 고정(Frozen)하며, 오직 12,288개의 파라미터만을 학습시켜 현재의 질문에 필요한 과거 정보만을 선별적으로 활용하도록 유도합니다.

## 📊 실험 결과 분석
* **성능 변화:** Qwen 모델 기반 4개 벤치마크 테스트에서 STAIR 적용 시 후속 문제 해결 정확도가 이전 모델 대비 평균 최대 11.67% 포인트 향상되었습니다. 
* **불안정성 해소:** 기존 모델(Native)에서는 문제 유형과 모델 설정에 따라 성능이 하락하기도 했으나, STAIR는 이를 효과적으로 제어하여 전반적인 정확도 향상을 이끌어냈습니다.
* (참고: 위 11.67% 수치 외의 구체적인 성능 향상 폭은 각 벤치마크 모델마다 상이하며, 논문 내 표 D.1~D.4에 세부 수치가 제시되어 있습니다.)

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **효율적인 추론:** 대화형 AI 서비스에서 사용자의 과거 질문을 무분별하게 참조하여 생기는 오류를 줄이고, 맥락 파악 능력을 비약적으로 높일 수 있습니다.
* **낮은 비용:** 거대한 모델 전체를 튜닝하지 않고도 12,288개라는 극히 적은 파라미터만 학습하면 되므로, 실무 현장에서 추가적인 컴퓨팅 자원 부담 없이 즉시 적용 가능한 실용적인 기술입니다.
* **확장성:** 복잡한 다단계 추론이나 연속적인 문제 해결이 필요한 업무 환경에서 LLM의 신뢰도를 높이는 데 크게 기여할 것입니다.
