# 지속적 학습의 전환: 매개변수 중심에서 시스템 수준의 적응으로

> **원본 논문 정보**
> - **제목:** Continual Learning in Transition
> - **저자:** Zhiyan Hou, Dan Zhang, Tao Feng, Liyuan Wang, Wei Li, Xiangzhao Hao, Hongyan An, Junfeng Fang, Haokai Ma, Zhaohui Xu, Haiyun Guo, Jinqiao Wang, Tat-Seng Chua
> - **발행일:** 2026-08-06
> - **PDF 링크:** [Continual Learning in Transition](https://arxiv.org/pdf/2608.06216v1)


## ✨ 3줄 핵심 요약
* 기존의 지속적 학습(CL)은 모델의 가중치 수정에 집중했으나, 최근 거대언어모델(LLM)과 에이전트 시스템의 발전으로 외부 메모리, 스킬 라이브러리 등을 활용한 시스템 단위의 적응으로 패러다임이 전환되고 있습니다.
* 본 논문은 지속적 학습의 변화를 '언제(When)', '어떻게(How)', '어디서(Where)'라는 세 가지 차원의 프레임워크로 체계화했습니다.
* 매개변수 수정뿐만 아니라 외부 구조를 활용한 학습 방식을 통해, 시스템이 스스로 역량을 확장하고 변화하는 환경에 지속적으로 적응하는 방향을 제시합니다.

## 📖 쉽게 풀어쓴 1분 핵심
전통적인 인공지능 학습은 이미 만들어진 모델의 내부 설정(가중치)을 조금씩 바꾸는 것에 집중해 왔습니다. 하지만 최근 LLM 기반의 에이전트들은 스스로 기억을 저장하고, 필요한 기술을 라이브러리에 쌓아두며, 상황에 맞춰 프로토콜을 조정합니다. 이 논문은 인공지능이 사람처럼 평생 학습하기 위해서는 단순히 모델 내부를 수정하는 것을 넘어, 외부 도구와 기억 시스템을 통합하여 '전체 시스템'이 진화해야 한다고 강조합니다. 이를 위해 학습이 언제 일어나는지(When), 어떤 방식으로 업데이트되는지(How), 그리고 매개변수 내부인지 외부 구조인지(Where)라는 세 가지 축을 기준으로 현재의 기술 지도를 그렸습니다.

## 🎯 배경 및 문제점
인공지능이 진정한 범용 인공지능(AGI)으로 나아가려면 변화하는 세상 속에서 새로운 지식을 쌓고, 상호작용을 통해 기술을 조합하며, 경험으로부터 행동 방식을 조정할 수 있어야 합니다. 기존의 CL 방식은 '파국적 망각(catastrophic forgetting)'과 '안정성-가소성 트레이드오프(stability-plasticity trade-off)' 해결에 치중하여 모델의 내부 매개변수 업데이트에만 매몰되어 있었습니다. 그러나 실제 환경은 정적이지 않으며, 모델 내부의 업데이트만으로는 복잡한 환경에서의 지속적인 역량 확장에 한계가 있습니다.

## 💡 핵심 기술 및 아키텍처
논문은 지속적 학습의 진화를 세 가지 축으로 분류합니다.
* **언제(When):** 사전 학습(pre-training), 사후 학습(post-training), 그리고 실제 사용 중인 추론 단계(inference-time)에서의 진화 과정을 다룹니다.
* **어떻게(How):** 기존의 기울기 기반(gradient-based) 오프라인 학습을 넘어, 온-폴리시(on-policy) 학습, 기울기를 사용하지 않는 최적화(zeroth-order, 모델 병합, 프롬프트 진화 등) 방식을 포괄합니다.
* **어디서(Where):** 내부 매개변수(parameters) 업데이트와 외부 구조적 제약(memory, skill libraries, protocols 등)을 통한 업데이트로 구분합니다. 특히 메모리(Memory)와 스킬(Skills)을 시스템의 '하네스(harness)'로 간주하여, 매개변수를 직접 건드리지 않고도 외부 저장소를 통해 지식을 확장하는 방법을 강조합니다.

## 📊 실험 결과 분석
본 논문은 학술적 조사(Survey)와 방법론적 체계화를 수행한 논문으로, 특정 모델이나 실험의 성능 수치를 제시하지는 않습니다. 대신, 기존의 다양한 CL 방법론들을 3차원 좌표계 위에 배치하여 현재 연구가 어느 방향으로 집중되어 있는지, 그리고 어떤 영역이 비어 있는지를 시각적으로 보여줍니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
이 연구는 기업이나 연구자가 LLM 기반의 에이전트를 구축할 때, 단순히 모델을 재학습시키는 것이 아니라 **'기억과 기술 도서관을 가진 시스템'**을 설계해야 함을 시사합니다.
* **실무 적용:** 모델의 배포 이후에도 외부 메모리(MemoryBank 등)나 실행 가능한 코드 스킬 라이브러리(Voyager 등)를 통해 실시간으로 시스템 역량을 보완하는 설계가 가능해집니다.
* **미래 전망:** 이 프레임워크는 AGI 구현을 위해 필요한 지속적 학습의 로드맵을 제공합니다. 저자들은 개별 도메인 지식 습득을 넘어, 시스템 자체가 경험을 통해 스스로 진화하는 '자동 역량 확장'이 AGI로 가는 핵심 경로가 될 것이라고 결론짓습니다.
