# rMuscle: 효율적인 비전-언어-행동 모델 추론을 위한 로봇 근육 기억

> **원본 논문 정보**
> - **제목:** rMuscle: Robotic Muscle Memory for Efficient Vision-Language-Action Model Inference
> - **저자:** Kaijun Zhou, Zhiyang Li, Le Chen, Jinyu Gu
> - **발행일:** 2026-09-16
> - **PDF 링크:** [rMuscle: Robotic Muscle Memory for Efficient Vision-Language-Action Model Inference](https://arxiv.org/pdf/2609.19104v1)


## ✨ 3줄 핵심 요약
* **로봇 근육 기억 도입**: 반복적인 로봇 작업에서 관찰되는 내부 모델 상태의 유사성을 활용하여 연산을 최적화하는 'rMuscle' 프레임워크를 개발했습니다.
* **이중 캐시 구조**: 시각적 토큰을 재사용하는 '컨텍스트 캐시'와 뉴런 활성화 패턴을 재사용하는 '액션 캐시'를 결합해 연산량과 가중치 접근 부하를 대폭 줄였습니다.
* **실질적 성능 향상**: RTX 4090 및 Jetson Thor 환경에서 기존 최첨단 기술 대비 1.29~1.42배의 추론 속도 향상을 달성하면서도, 로봇의 작업 성공률은 그대로 유지했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
로봇이 공장에서 같은 동작을 반복할 때, 매번 처음부터 모든 계산을 다시 하는 것은 비효율적입니다. 'rMuscle'은 사람이 특정 동작을 몸으로 기억하듯, 이전에 수행했던 작업의 내부 데이터(시각적 문맥, 뉴런 활성 정보)를 저장하고 필요할 때 꺼내 쓰는 '근육 기억' 방식을 적용했습니다. 이를 통해 로봇이 환경을 인지하고 행동을 결정하는 과정에서 불필요한 계산을 건너뛰어, 결과적으로 더 빠르고 부드러운 동작 수행이 가능해졌습니다.

## 🎯 배경 및 문제점
로봇의 실시간 성능은 '관찰-추론-실행' 주기의 지연 시간(Latency)에 크게 의존합니다. 기존 비전-언어-행동(VLA) 모델 추론 방식은 다음과 같은 한계가 있습니다.
* **업무 특성 미반영**: 공장 등 로봇 작업 환경은 매우 구조적이고 반복적임에도 불구하고, 기존 방식은 이러한 작업 간의 유사성을 활용하지 못합니다.
* **병목 현상 방치**: 기존 최적화 기법들은 주로 커널 퓨전이나 양자화에 집중하여, VLA 모델 내부의 비전 인코딩과 디퓨전 기반 액션 생성 단계에서 발생하는 고유한 병목 현상을 해결하지 못합니다.

## 💡 핵심 기술 및 아키텍처
* **컨텍스트 캐시 (Context Cache)**: 시각적 토큰 출력을 재사용하여 연산량을 절감합니다.
* **액션 캐시 (Action Cache)**: 디노이징 과정에서 중요 뉴런의 활성화 패턴을 재사용하여 가중치 접근 부하를 최소화합니다.
* **지능형 캐시 관리**:
    * **비동기 온라인 재구성**: 로봇이 물리적 동작을 수행하는 동안 다음 작업에 필요한 데이터를 미리 준비합니다.
    * **슬라이딩 윈도우 프리페칭**: 시간적 지역성을 활용해 필요한 데이터를 효율적으로 가져옵니다.
    * **그룹 공유 뉴런 마스크**: 연속적인 디노이징 단계에서 마스크를 공유하여 접근 오버헤드를 낮춥니다.

## 📊 실험 결과 분석
* **속도 향상**: LIBERO, RoboTwin 및 실제 물리적 조작 과업에서 RTX 4090 및 Jetson Thor를 사용했을 때, 기존 기술 대비 **1.29배에서 1.42배**의 속도 향상을 기록했습니다.
* **안정성**: 속도 향상에도 불구하고 기존 로봇의 작업 성공률을 그대로 유지하여 신뢰성을 확보했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **생산성 극대화**: 동일한 하드웨어 환경에서 로봇의 추론 지연 시간을 줄임으로써, 작업 주기를 단축하여 단위 시간당 처리할 수 있는 작업량을 늘릴 수 있습니다.
* **유연한 적용**: BMW 생산 라인(Figure AI), 테슬라 옵티머스, 에이지봇 등 고정된 작업 환경에서 반복적인 업무를 수행하는 휴머노이드 및 산업용 로봇의 응답성과 동작 연속성을 개선하는 데 즉각적으로 기여할 수 있습니다.
* **확장성**: 처음 접하는 작업은 일반적인 방식으로 수행하고, 이후 성공 사례가 쌓이면 자동으로 캐시를 활용해 속도가 최적화되는 동적 업데이트 구조를 통해 새로운 환경에도 유연하게 적응합니다.
