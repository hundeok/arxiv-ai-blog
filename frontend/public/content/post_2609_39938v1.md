# LEAP: 장시간 시청각 지각을 위한 학습된 블록 단위 증거 검색

> **원본 논문 정보**
> - **제목:** LEAP: Learned Block-wise Evidence Retrieval for Long Audio-Video Perception
> - **저자:** Juyi Lin, Zhiqiang Lao, Jiali Cui, Lin Zhao, Pu Zhao, Dichang Zhang, Arman Akbari, Yu Qi, Xinru Jiang, Yanzhi Wang, Heather Yu, Liang Peng
> - **발행일:** 2026-09-30
> - **PDF 링크:** [LEAP: Learned Block-wise Evidence Retrieval for Long Audio-Video Perception](https://arxiv.org/pdf/2609.39938v1)


## ✨ 3줄 핵심 요약
- **문맥 병목 해소:** 전체 영상을 한 번에 입력하지 않고, 영상을 짧은 블록으로 나누어 필요한 정보만 검색하여 처리합니다.
- **2단계 처리 방식:** 가벼운 로컬라이제이션(위치 탐색) 단계로 후보를 선별하고, 최종 답변 단계에서 선별된 정보만 정밀하게 재구성합니다.
- **성능 향상:** 기존 베이스라인 모델 대비 주요 벤치마크에서 3.1%에서 최대 16.8%까지 성능 향상을 달성했습니다.

## 📖 쉽게 풀어쓴 1분 핵심
긴 영상(수 시간 분량)을 다루는 AI는 전체를 한꺼번에 처리하려다 보니 기억력 한계에 부딪히거나 중요한 세부 정보를 놓치는 문제가 발생합니다. LEAP은 마치 사람이 긴 책을 읽을 때 전체를 외우지 않고 필요한 부분만 찾아보는 방식과 비슷하게 작동합니다. 먼저 전체 영상을 작은 조각(블록)으로 나누고, 질문과 관련된 중요한 부분만 빠르게 찾아냅니다. 이후 찾아낸 핵심 조각들만 모아서 모델이 깊이 있게 분석하도록 유도함으로써, 영상 길이에 상관없이 일관되고 정확한 답변을 생성합니다.

## 🎯 배경 및 문제점
- **문맥 딜레마:** 전체 영상을 인코딩하면 AI의 제한된 문맥 길이를 금방 초과하며, 반대로 전체를 압축하면 시각적·청각적 세부 정보가 손실됩니다.
- **기존 방식의 한계:** 
    - **선택적 방식:** 너무 넓은 범위에서 정보를 고르다 핵심 증거를 놓칩니다.
    - **압축 방식:** 압축 과정에서 중요한 상세 내용이 사라집니다.
    - **에이전트 방식:** 증거를 찾는 별도의 훈련이 되어 있지 않아 일반 모델에 의존합니다.

## 💡 핵심 기술 및 아키텍처
- **블록 단위 검색:** 영상을 고정된 시간 길이의 블록으로 분할합니다.
- **2단계 파이프라인:**
    1. **로컬라이제이션 패스(Localization pass):** 질문과 관련도가 높은 후보 구간을 짧은 윈도우 단위로 검색하고 순위를 매깁니다.
    2. **답변 패스(Answer pass):** 선별된 상위 윈도우들만을 정밀하게 재인코딩하여 최종 답변을 생성합니다.
- **특화된 어댑터:** 위치 탐색 성능을 높이는 'Localization LoRA'와 답변 정확도를 높이는 'Answer LoRA'를 각각 학습시켜 모델의 효율을 최적화했습니다.

## 📊 실험 결과 분석
- **성능 비교:** 
    - Qwen3-Omni-30B-A3B 베이스라인 대비 4.5~16.8% 향상된 성능을 보였습니다.
    - MiniCPM-o 4.5 모델 적용 시, 기존 발표 성능보다 3.1~13.0% 향상되었습니다.
- **일관성:** 증거가 영상의 어느 부분(시작, 중간, 끝)에 위치하든 성능 저하 없이 안정적인 결과를 유지했습니다.
- **효율성:** vLLM 서버 환경에서 블록 프리픽스 캐싱(prefix caching)을 통해 추론 속도를 약 1.6배 가속했습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
- **장시간 영상 분석:** 영화, 강의, 회의 기록 등 수 시간짜리 콘텐츠에서 특정 정보를 즉각적으로 찾아내야 하는 서비스(영상 검색, 지능형 요약)에 즉시 적용 가능합니다.
- **실시간 추론 지원:** 본 프레임워크는 스트리밍 방식의 질의도 별도의 추가 훈련 없이 지원하므로, 실시간 라이브 스트리밍 분석 환경에서도 활용도가 높습니다.
- **컴퓨팅 효율:** 전체 영상을 매번 다시 처리할 필요가 없어 메모리 자원을 절감하면서도 정밀한 지각 능력을 유지할 수 있습니다.
