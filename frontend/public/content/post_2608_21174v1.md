# 어텐션 마스크에서 관성 영벡터 토큰으로: 토큰 동역학을 위한 OAttention과 O-Closure

> **원본 논문 정보**
> - **제목:** From Attention Masks to Inert Zero-Vector Tokens: OAttention and O-Closure for Token Dynamics
> - **저자:** Heyang Gong
> - **발행일:** 2026-08-21
> - **PDF 링크:** [From Attention Masks to Inert Zero-Vector Tokens: OAttention and O-Closure for Token Dynamics](https://arxiv.org/pdf/2608.21174v1)


## ✨ 3줄 핵심 요약
* 기존 어텐션 모델은 입력값이 '0'일 때도 연산 결과가 0이 되지 않는 문제가 있어, 이를 해결하기 위해 토큰의 활성도를 나타내는 '존재 계수(presence coefficient)'를 도입했습니다.
* 토큰의 존재 계수를 활용해 쿼리 출력은 차단하고 소스(key/value) 기여도는 0으로 만드는 'OAttention'과 이를 확장한 'OTransformer' 아키텍처를 제안합니다.
* 이 방식은 별도의 미세 조정(fine-tuning) 없이도 모델 내에서 'NULL' 상태를 정확하게 유지하며, 기존 모델 구성 요소들과의 호환성을 보장합니다.

## 📖 쉽게 풀어쓴 1분 핵심
기존의 인공지능 모델(Transformer)은 특정 입력이 없다는 의미로 '0'을 넣어도, 모델 내부의 연산 방식 때문에 결과값이 완전히 0이 되지 않고 다른 토큰들의 연산에 영향을 미칩니다. 본 논문은 모든 토큰에 **'현재 얼마나 활성화되어 있는가'를 나타내는 값(존재 계수)**을 부여합니다. 이 값을 통해 입력이 '0'인 토큰은 스스로 정보를 방출하지도 않고(쿼리 차단), 다른 토큰의 연산 과정에도 전혀 기여하지 않도록(소스 차단) 제어합니다. 즉, 토큰이 마치 존재하지 않는 것처럼(NULL) 동작하게 만드는 수학적 장치를 마련한 것입니다.

## 🎯 배경 및 문제점
* **관계 vs 상태의 불일치:** 어텐션 마스크는 어떤 토큰끼리 상호작용할지 결정하지만, 토큰 자체가 활성화되지 않았음을 나타내는 근본적인 '상태(state-level)'는 표현하지 못합니다.
* **표준 어텐션의 한계:** 표준 스케일드 닷 프로덕트 어텐션에서는 입력 벡터가 0이어도 소프트맥스 연산 과정에서 가중치가 재조정되어 결과값이 0이 되지 않습니다.
* **비활성 상태의 필요성:** 패딩(Padding), 결측값, 사용하지 않는 라우팅 슬롯 등에서는 토큰이 계산에 전혀 관여하지 않는 '순수한 영(Zero)' 상태가 요구되나 기존 모델은 이를 지원하지 못합니다.

## 💡 핵심 기술 및 아키텍처
* **존재 계수($p_i$):** 토큰의 히든 상태($h_i$)를 활용하여 $p_i = \|h_i\|^2 / (\tau + \|h_i\|^2)$로 정의된 계수를 사용합니다. 이는 토큰이 정보를 내보낼지(로컬 업데이트)와 다른 토큰과 상호작용할지(컨텍스트 서포트)를 동시에 결정합니다.
* **OAttention:** 표준 어텐션의 연산 구조를 유지하면서, 각 토큰의 존재 계수를 곱하여 쿼리 출력과 소스 기여도를 완벽하게 제어합니다.
* **O-Closure(영-폐쇄):** 잔차 연결(Residual connection) 및 구성 요소들이 결합할 때, 'NULL' 토큰을 삽입해도 모델 전체의 출력값이 변하지 않도록 하는 수학적 법칙입니다.
* **O-Components:** 존재 계수를 적용한 OFFN, ONorm, OInject 등을 통해 모델 전반에 걸쳐 '0'이 흡수되는 환경을 조성합니다.

## 📊 실험 결과 분석
* **성능 변화:** 기존 TabPFN v3 모델에 제안 기법을 적용했을 때, 미세 조정 없이도 평균 RMSE 변화율은 OAttention 변형에서 +0.088%, Full-O 변형에서 +0.177%로 나타나 성능 저하가 매우 적음을 확인했습니다.
* **NULL 상태 유지:** 두 개의 블록을 사용한 실험에서 OAttention 단독으로는 일반적인 컴포넌트 환경에서 NULL 상태를 완전히 보존하지 못했으나, 제안된 OTransformer 경로를 통해서는 NULL 상태가 정확히 유지됨을 입증했습니다.
* **참고:** 위 실험 수치 외에 별도의 범용적인 손실 제로 상태나 학습된 인력(attraction)에 대한 수치는 원문에서 제공하지 않습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
* **결측값 및 패딩 처리 효율화:** 데이터가 누락되었거나 패딩된 부분을 명확하게 '무시'하도록 설계하여 모델의 예측 오류를 줄일 수 있습니다.
* **동적 구조의 안정성:** 토큰의 수가 가변적이거나 모델 구성 요소가 복잡하게 얽힌 환경에서도 '0' 상태를 명확히 정의함으로써, 모델의 연산 안정성을 높일 수 있습니다.
* **확장성:** 본 논문의 방식은 특정 모델에 국한되지 않고, 기존의 복잡한 트랜스포머 아키텍처 내에서 NULL 상태를 구현해야 하는 다양한 실무 응용 사례에 적용 가능합니다. 단, 절대 위치 인코딩이나 특정 토큰 병합 기법 등과는 호환되지 않을 수 있음을 주의해야 합니다.
