# 양자화 모델이 향하는 곳으로 훈련하기: 저비트 추론을 위한 온-폴리시 증류

> **원본 논문 정보**
> - **제목:** Train Where the Quantized Model Goes: On-Policy Distillation for Low-Bit Reasoning
> - **저자:** Yuanteng Chen, Zhilei Liu, Peisong Wang, Yuantian Shao, Chuangyi Li, Weining Wang, Shuang Qiu, Gang Li, Jing Liu, Jian Cheng
> - **발행일:** 2026-09-22
> - **PDF 링크:** [Train Where the Quantized Model Goes: On-Policy Distillation for Low-Bit Reasoning](https://arxiv.org/pdf/2609.26708v1)


## ✨ 3줄 핵심 요약
- 3비트 미만의 극단적 양자화 모델은 긴 문맥 추론 시 반복 루프에 빠지며 성능이 급격히 저하되는 문제가 있습니다.
- 기존의 양자화 증류(QAD)는 정적인 데이터 경로만 학습시켜 모델 자체의 오차 누적을 해결하지 못합니다.
- 본 논문이 제안한 '온-폴리시 증류(OPD)'는 모델이 실제 생성 경로에서 추론하도록 유도하여 수학 및 코드 추론 성능을 크게 향상합니다.

## 📖 쉽게 풀어쓴 1분 핵심
거대언어모델을 압축할 때 사용하는 '양자화'는 모델을 작고 빠르게 만들지만, 3비트 미만으로 넘어가면 모델이 말을 끝맺지 못하고 같은 말을 반복하는 치명적인 오류가 발생합니다. 기존 학습 방식은 정해진 정답 경로만 따라가도록 가르치지만, 실제 모델은 스스로 생성한 결과물을 바탕으로 그다음 글자를 예측하므로 여기서 발생하는 오차가 눈덩이처럼 불어납니다. 본 연구의 '온-폴리시 증류(OPD)'는 모델이 실제 서비스 환경에서 생성하는 경로를 따라가며 똑똑한(풀 프리시전) 교사 모델에게 실시간 피드백을 받는 방식입니다. 이를 통해 모델은 스스로 만든 긴 추론 경로에서도 길을 잃지 않고 정확한 결론에 도달할 수 있게 됩니다.

## 🎯 배경 및 문제점
- **성능 저하:** 3비트 미만 양자화 시 일반 질의응답 성능은 비교적 잘 유지되나, 수학(MATH-500) 등 추론 능력은 크게 훼손됩니다.
- **반복 루프:** 긴 생성을 수행할 때 모델이 특정 토큰을 반복하는 루프에 빠져 추론을 완료하지 못하고 연산 자원만 낭비합니다.
- **데이터 불일치(Mismatch):** 기존 양자화 증류(QAD)는 교사가 제시한 고정된 데이터만 학습하지만, 실제 배포된 모델은 자신이 생성한 오차 섞인 경로를 따라가므로 학습 경로와 실제 배포 경로 간 괴리가 발생합니다.

## 💡 핵심 기술 및 아키텍처
- **QAD 초기화:** 우선 양자화 증류(QAD)를 통해 모델의 기본적인 언어 능력과 정책의 유효성을 확보합니다.
- **온-폴리시 증류(OPD):** QAD 단계 이후, 모델이 배포 환경과 동일한 양자화 경로를 통해 스스로 문장을 생성하게 합니다.
- **피드백 결합:** 모델이 생성한 경로에 대해 고정된 풀 프리시전(BF16) 교사 모델이 토큰 단위의 지도를 제공하고, 정답 확인(Task-verifier) 보상을 통해 성공적인 추론을 강화합니다.

## 📊 실험 결과 분석
- **성능 유지 및 향상:** 2.79비트 및 1.88비트 모델에서 MATH-500 성능 유지율이 35%에서 70%로, HumanEval 성능 유지율이 66%에서 91%로 상승했습니다.
- **비교 분석:** 기존의 교사 강제 학습(Teacher-forced) 방식과 동일한 예산으로 실험했을 때, OPD가 모든 벤치마크에서 더 우수한 성능을 보였습니다. 
- **반복 감소:** 수학 문제 해결 시 모델이 반복 루프에 빠지는 비율이 현저히 줄어들었으며, 더 긴 추론 과정을 완벽하게 완료하는 능력이 입증되었습니다.

## 🌍 세상에 미치는 영향 & 실무 적용 사례
- **고효율 추론:** 극단적인 저비트 압축을 통해서도 고성능 모델 수준의 수학적 추론과 코드 작성 능력을 유지할 수 있어, 제한된 하드웨어 자원(엣지 디바이스 등)에서도 고성능 AI 활용이 가능해집니다.
- **비용 절감:** 추론 시 메모리 요구량을 획기적으로 낮추면서도 복잡한 논리적 추론이 필요한 작업에 투입할 수 있어 기업의 서빙 비용을 최적화할 수 있습니다.
